# 筛选功能重构 — 完整分阶段实施计划

> 目标:把当前分散的多套筛选/配置,**汇总成唯一一个卖家精灵风格筛选面板**;删除变体折叠逻辑,列表改为"一变体一卡 + 变体级筛选";选品页与品线页统一只认这一套面板。
>
> 本文档为多任务并行实施而写:每个任务标注 **依赖** 与 **可并行组**,无依赖关系的任务可同时分派给不同执行者。

---

## 0. 已冻结的产品决策(不要再动摇)

1. **唯一筛选面** = 卖家精灵风格面板 + 顶部(站点 / 周批次 / 类目)。
2. **两层时间维度,彼此独立**:
   - **周批次**(看 `created_at` 导入批次):默认锁最新周;下拉可取消(= 看全部);**支持多选周**。纯圈范围。
   - **上架时间**(看商品上架时长 `listing_days`):预设 `30/60/90/180/360 天内` + 自由区间。批内精筛。
   - ❌ 删除原"具体月份(2026-05)"选择器。
3. **删变体折叠**:列表扁平,一个变体 = 一张卡;面板筛选作用在变体级(命中留下);详情页始终显示该父商品**全部变体**(不受列表筛选影响)。
4. **`filter_mode` 列继续照写**(候选店铺 / 类目计数 / 品类基线仍用),仅"列表查询不再用它折叠"。
5. **保留的搜索/排序工具**:多合一搜索框(ASIN/标题/店铺/大类)、店铺搜索(卖家选择器)、多项精确搜索、多合一排序(销量/上架时间/BSR/价格/评分)。
6. **藏掉**:两个"数据筛选模式(MODE1/2)"下拉、FilterConfigPanel 精筛配置面板、具体月份选择器、weekTag/isCurrent 入口。
7. **grade(S/A/B/C/D)** → 收进面板做多选。
8. **预设**(每用户每国家保存)保留,需携带全部新字段。
9. ❌ 作废:此前讨论的"每国家 MODE1 兜底配置"方案。

### 待执行者在 Phase 0 与用户确认的开放项
- **QualifyRuleFilter(新品多规则 OR 编辑器)** 的去留:本计划默认"折叠进面板/隐藏",面板筛选统一走 **AND 语义**。若用户要保留多规则 OR 能力,需在 Phase A 调整。

## 1. 现状关键事实(已核实,执行者可直接信赖)

### 后端(java-backend / sjzm-product)
- 查询有两条路径,由 `CompetitorQueryRequest.groupByParent` 切换:
  - `CompetitorService.queryGroupedByParent()`(`groupByParent=true`)→ 调 `CompetitorProductMapper.selectGroupedByParent` / `countGroupedByParent`,**内含变体折叠**(`WHERE filter_mode IN ('MODE1','MODE2') AND rn<=3 OR ... rn=1`,Mapper 行 111-112 / 254-255)。

- 排序白名单(Mapper `selectGroupedByParent` ORDER BY / Service `applySort`)支持 bsr/units/price/listingDays/weightG/createdAt/score。
- `filter_mode` 写入唯一来源:`CompetitorFilterService.filter()`(MODE1/MODE2/FAIL)。**本次不动**。
- 业务统计仍用 filter_mode(本次不动,仅记录):`selectNewProductCandidates`(=MODE1)、`countByNodeId`(=MODE1)、`CategoryBaselineService`(≠FAIL)。

## 2. 统一数据契约(前后端共同遵守)

### 列表查询请求(扁平模式,`groupByParent=false`)
所有面板字段以 **AND 语义** 拼进扁平查询的 wrapper(变体级过滤):

| 维度 | 请求字段 | 后端落点 | 备注 |
|------|----------|----------|------|
| 站点 | `marketplace` | `eq` | |
| 周批次(多选) | `createdWeeks: string[]` | `IN`(新增) | 空=不限;默认=[最新周] |
| 类目 | `category` | `FIND_IN_SET` | |
| 价格 | `priceMin/priceMax` | `ge/le price` | |
| 销量 | `unitsMin/unitsMax` | `ge/le units`(新增 wrapper) | |
| 上架时间 | `listingDaysMin/listingDaysMax` | `ge/le listing_days`(新增 wrapper) | 预设 30/60/90/180/360 = 设 max |
| 变体上限 | `maxVariantCount` | `le variations` | |
| BSR | `bsrMax` | `le bsr`(且 bsr>0) | |
| 重量 | `weightMax` | `le weight_g` | |
| 配送方式 | `fulfillment: string[]` | `IN` | |
| 评级 | `grade: string` | `IN`(逗号分隔) | 多选 |
| 搜索 | `title/sellerName/asin/category` | 按搜索类型 | 多合一搜索框 |
| 多词 | `keywords` | 多 `like` AND | |
| 排序 | `sortBy/sortOrder` | 白名单 | 含 bsr/units/listingDays/price/score |

> **决策:面板区间统一改为直接 wrapper 条件(AND),不再翻译成 qualifyRules。** 理由:面板语义是"全部满足",AND 直观;qualifyRules 的 OR 多规则能力仅在用户明确要保留新品多规则时启用(开放项)。

### 上架时间预设映射
- "30天内" → `listingDaysMax=30, listingDaysMin=null`
- "60/90/180/360天内" 同理。
- "自由选择" → 用户直接填 `listingDaysMin/listingDaysMax`。
- 预设与自由二选一(选预设即写入对应 max,可清空)。

### 周批次接口
- `GET /api/v1/competitor/created-weeks`:**去掉 `filterMode` 默认 MODE1**(改为不传或可选,默认统计全部)。返回 `[{week, count}]`。
- 前端默认选中返回的第一项(最新周);用户可取消(清空)或多选。

## 5. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 扁平列表卡片刷屏(一父多变体=多卡) | 已是用户选择(每变体一卡);分页 size 默认 60,排序兜底 bsr |
| 去折叠后 total 计数 | 扁平路径用 `selectCount(wrapper)`,天然一致,无折叠镜像问题 |
| 多选周 SQL 注入 | `createdWeeks` 必须参数化占位符,禁止字符串拼接 |
| filter_mode 停用过滤但仍写 | 仅停"列表折叠/过滤";写入与统计不动,徽章保留;列不删=可回滚 |
| 品线页与选品页共用面板的差异 | 共用 RangeFilterPanel,页面差异只在数据源(bsrId/nodeId 场景) |
| qualifyRules 与面板 AND 双轨 | 默认面板走 AND 直连 wrapper;qualifyRules 仅在开放项保留时启用,二者不混用 |
