## 架构改造计划

### 改造点 1：CompetitorController 对象绑定

**文件**：`java-backend/sjzm-product/src/main/java/com/sjzm/product/controller/CompetitorController.java`

**改前**（15 个参数逐个声明 + 15 个手动 set）：
```java
@GetMapping("/products")
public Result<...> getProducts(
    @RequestParam(required = false) String marketplace,
    @RequestParam(required = false) String month,
    ...  // 13 more
) {
    CompetitorQueryRequest request = new CompetitorQueryRequest();
    request.setMarketplace(marketplace);
    request.setMonth(month);
    ...  // 13 more
}
```

**改后**（Spring 自动绑定，零手写）：
```java
@GetMapping("/products")
public Result<...> getProducts(@Valid CompetitorQueryRequest request) {
    return Result.success(competitorService.queryFromDb(request));
}
```

**注意**：
- `CompetitorQueryRequest` 中 `page` 和 `size` 有默认值 `1` 和 `20`，需要改为与原来 `@RequestParam(defaultValue)` 一致
- `asin` 字段是 `List<String>`，Spring 对象绑定默认支持 `asin=xxx&asin=yyy` 格式
- `groupByParent` 是 `Boolean`，Spring 自动转换字符串 `"true"`/`"false"`
- `isCurrent` 是 `Integer`，同样自动转换
- controller 中删除的手动 sortBy/sortOrder 调用移到 service 的 `queryFromDb` 入口处

### 改造点 2：前端统一参数映射

**文件**：`frontend/src/views/AllSelection/index.vue`

**改前**（两个手动映射对象，20+ 行重复代码）：
```typescript
const apiParams: any = {
  page: pagination.page,
  asin: queryParams?.asin || '',
  category: queryParams?.category || '',
  ...
}
const competitorParams: any = {
  page: apiParams.page,
  category: apiParams.category || undefined,
  ...
}
```

**改后**（从 SelectionQueryParams 自动映射到 API 参数）：
```typescript
// 映射表：formData 字段 → API 查询参数名
const FILTER_TO_API_KEY: Record<string, string> = {
  country: 'marketplace',
  dataFilterMode: 'filterMode',
  productTitle: 'title',
  storeName: 'sellerName',
  sortField: 'sortBy',
  // 同名无需映射：category, grade, weekTag, isCurrent, asin
}

function buildApiParams(queryParams: SelectionQueryParams): Record<string, any> {
  const params: Record<string, any> = {
    page: pagination.page,
    size: pagination.size,
    sortOrder: queryParams.sortOrder || 'desc',
    groupByParent: groupByParent.value || undefined,
    maxVariantCount: maxVariantCount.value ?? undefined,
  }
  // 自动映射所有筛选字段（空字符串跳过）
  const filterFields = ['asin', 'productTitle', 'storeName', 'sellerSelect', 'category',
    'country', 'dataFilterMode', 'grade', 'weekTag']
  for (const field of filterFields) {
    const val = queryParams[field as keyof SelectionQueryParams]
    if (val !== '' && val !== undefined && val !== null) {
      const apiKey = FILTER_TO_API_KEY[field] || field
      params[apiKey] = Array.isArray(val) ? val.join(',') : val
    }
  }
  return params
}
```

**使用**：
```typescript
const params = buildApiParams(queryParams)

// source 根据 activeTab 补充
const sourceMap = { 'new': '新品榜', 'reference': '竞品店铺', 'zheng': '郑总店铺' }
if (sourceMap[activeTab.value]) params.source = sourceMap[activeTab.value]
```
