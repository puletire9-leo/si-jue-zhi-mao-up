# 05 飞书只读与凭证总账

## 飞书多维表格 → RDS

系统里**有**操作记录，连的是 **`ai_platform`，不是业务库 `sijuelishi`**。

原文：`docs/飞书操作/飞书多维表格链接数据库操作/飞书多维表格连接RDS操作记录.md`

现状要点：

- 必须用外网地址/公网 IP，内网域名飞书解析失败（`no such host`）。
- 白名单是**数据库连接器**出口 IP，不是飞书「自动化」出口 IP。
- 账号 `feishu_ro`：`GRANT SELECT ON ai_platform.*`。验证过可读、写被拒。
- 密码环境变量：`FEISHU_RDS_READONLY_PASSWORD`。不要把 `RDS_PASSWORD` 填给飞书。
- 免费版同步表行数上限 1000，大业务表不能靠飞书当全量库。

**系统里没有**：给 `feishu_ro` 开 `sijuelishi` 的授权；没有飞书同步业务大表的正式方案。

## 凭证总账 `system_config`

- 库：`ai_platform.system_config`。
- 分类：rds / feishu / proxy / system（及文档所述）。
- Java：`SystemConfigController`，`/api/v1/system-config*`，**admin 且明文**。
- 这不是 RDS 管理中心。管理中心不读这张表、不展示密码。

## 账号（名称可写，密码不写）

| 账号 | 现状 |
|------|------|
| `ai_platform_app` | 实例级高权限，应用读写 `ai_platform` 和 `sijuelishi` |
| `feishu_ro` | 只读 `ai_platform` |
| Docker `sijue` | 只给本地 `prod-mysql` |
