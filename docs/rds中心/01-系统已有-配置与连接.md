## 应用如何读

| 路径 | 现状 |
|------|------|
| `java-backend/sjzm-user/src/main/resources/application.yml` | `USER_MYSQL_*`，缺省回退 `MYSQL_*` |
| `java-backend/sjzm-product/src/main/resources/application.yml` | **主库** `RDS_*` 优先再 `MYSQL_*`；**rds.datasource** 一直 `RDS_*` 回退 `MYSQL_*` |
| `backend/app/config.py` | `MYSQL_*` 默认业务库；`__init__` 里若 `RDS_HOST` 非空则改写 MYSQL 连接；另有 `USER_MYSQL_*` |
| `docker-compose.prod.yml` | mysql 服务吃 `MYSQL_*`；java-product / backend / celery 吃 `prod.env`（含 RDS_*）；java-user 额外 user-prod.env。java-product 仍 `depends_on: mysql`（容器还在，业务切走后这是启动顺序残留） |
