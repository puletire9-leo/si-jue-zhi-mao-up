### 技术细节

**SKU前缀真实规则**：
- 领星SKU全为7位数字(如2600038)，不是字母前缀
- TOP10前缀及占比：225(3601)、255(3424)、256(3105)、262(1384)、263(1251)、261(805)、260(777)、264(508)、266(341)、258(303)
- 当前配置：TOP10前缀 → "通用" 开发人(临时方案，后续按真实开发人映射)

**operator字段数据源**：
- `getBatchDetailList` API返回字段：wid/wh_name/batch_no/sku/good_num/good_transit_num/plan_sn/purchase_order_sns/purchase_in_time等
- **不包含**：creator_real_name/creator_uid
- plan_sn字段示例：`["PP260810006"]` (JSON数组，可多个采购计划)
- 解决方案：`lingxing_purchase_plan`表有creator_real_name，通过plan_sn关联

**前端分组逻辑**：
```typescript
// Map<sku, {sku, productName, imageUrl, batches: [...]}> 
// batches按purchase_in_time DESC排序
groupBySku(list) → Array<{sku, batches: [...]}>
```
