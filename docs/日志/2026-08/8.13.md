## 到货看板前端原型定稿

今天完成 `艾为系统/分析/采购发货管理/到货看板_主列表+抽屉.html` 的多轮业务口径梳理和前端交互验收。当前仅保存独立 HTML 原型，尚未迁移正式 Vue 系统、未连接真实 API。

### 页面结构

- 一个 SKU 一行，一个 SKU 可对应多个采购批次。
- 批次使用独立框展示约 3 行，超出后框内滚动；右侧抽屉查看完整批次。
- 页面按 SKU 分页，默认 50 条，可选 50 / 100 / 200；同一 SKU 的批次不跨页。
- 亚马逊已入库批次自动沉到每个 SKU 批次列表最下面。

### 字段口径修正

- “批次号”改为采购计划号 `plan_sn`。
- “时间”改为采购单真实下单时间 `order_time`，不再使用采购入库时间。
- 删除仓库列，当前业务统一按一个本地仓处理。
- 本地数量统一展示：本地已到、本地在途、未到本地、总数。
- SPS 作为亚马逊货件号附属于物流节点，不再和本地到货状态并列形成第二套状态。

### 唯一物流流程

`已下单 → 发往本地仓 → 已到本地仓 → 已建亚马逊货件 → 发往亚马逊仓 → 亚马逊接收中 → 亚马逊已入库`

- 采购计划采用整单状态，不存在“部分到本地仓”。
- 部分数量已到、部分仍在途时，整单仍属于“发往本地仓”。
- 本地未全部到齐时，禁止进入已到本地仓及亚马逊后续阶段。

### 警示与筛选

- 新增红色“本地滞留待发亚马逊”指标：整单已到本地仓，但尚未真正发往亚马逊。
- 覆盖“已到本地仓未建货件”和“已建货件未发出”两种情况。
- 点击顶部红色指标可快速筛选，具体批次显示红色“待发亚马逊”标签。
- 开发人、运营人、采购时间、物流进度、普通搜索、批量搜索支持组合筛选。
- 普通和批量搜索均支持 SKU、品名、采购计划号、SPS；批量输入支持换行、空格、逗号和分号，批量项之间为 OR，其他筛选之间为 AND。
- 重置会清空全部可见条件和隐藏批量条件。

## RDS 账号表同步（ai_platform.users）

将 Docker 源库账号同步到远程阿里云 RDS `ai_platform.users`，保证两套系统账号密码互不失效。

### 决策与方案

- **只动 users 单表**：先单表转储备份 + 复制到宿主机（Git ignored）并核对容器/宿主机 SHA-256 一致，再操作。
- **不覆盖 RDS 原账号**：原有 23 个 RDS 用户逐字段保持不变（password/role/id 原值）。
- **密码明文**：按郑总"越简单越好"的决定，新增账号密码统一明文 `123456`；不再引入 `sjzm_password` 双字段方案。Java 登录同时兼容明文和历史 BCrypt。
- **只插缺失账号**：同名账号不新增行，只补 RDS 中 username 为空但姓名相同的记录；缺失账号才新增。

### 连接隔离（关键）

- 仅 `prod-java-user` 容器加载 `config/public/user-prod.env` + `config/secrets/user-prod.env`，通过 `USER_MYSQL_*` 单独连 RDS。
- `java-product`、`gateway`、Python backend、Celery **都不加载** user-prod.env，仍连 Docker 本地 MySQL（`prod-mysql`）。两条数据线不交叉。
