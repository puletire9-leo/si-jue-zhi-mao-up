## 八爪鱼榜单导入四大优化（③中断恢复 + ②一键全导 + ④提速 + ①前端分类）

用户报四痛点：不能分类、不能一键导入、中断不能续、导入太慢。诊断后按 ③→②→④→① 顺序推进。

### ③ 中断恢复（数据正确性，最优先）
**根因**：导入任务中途遇重启/崩溃/线程死 → 永卡 `RUNNING` → `createStreamingTask` 把 RUNNING 当"已导入"跳过 → **该批次永久堵死**。且无任何僵尸恢复。

| 文件 | 改动 |
|------|------|
| `mapper/AsinImportTaskMapper.java` | 加 `selectStaleRunningTasks(importType, staleBefore)`：查 RUNNING/DRAINING 且 updated_at 早于阈值 |
| `service/AsinImportService.java` | 加 `recoverStaleImportTasks()`：心跳超 10 分钟的僵尸 → 新终态 `INTERRUPTED` + errorMessage + completedAt。`@PostConstruct` 启动扫 + `@Scheduled`(每5分钟)reconcile |
| `service/AsinImportService.java` | 改 `createStreamingTask`：RUNNING 心跳**新鲜**=真在跑跳过；**过期**=僵尸就地收口后放行重跑；INTERRUPTED/ERROR 允许重跑；仅 READY/DONE 算已导入 |
| `frontend/.../bazhuayu-auto/index.vue` | `INTERRUPTED` 加状态标签（"已中断"红色）+ 终态列表 |

- 心跳靠现成 `flushProgress`（每5页/5秒刷 updated_at）。10 分钟阈值远大于正常翻页节奏，不误伤慢任务。写入侧幂等（唯一键+skip_asins），重跑补齐缺失。
- **验证**：造僵尸 RUNNING（心跳30分钟前）→ 重启 → 日志 `[启动恢复] 收口 1 个僵尸...→ INTERRUPTED`，DB 确实翻 INTERRUPTED+completed_at+errorMessage ✅

### ② 一键全导
- 后端 `triggerAllBangdanTasks()`：遍历所有 bangdan 任务，各自锁定最新批次后逐个异步 `triggerTaskAsync`（复用批次校验+幂等+僵尸重跑）。任务间 **400ms 节流**避免八爪鱼 `TooManyRequests`（statuses/v2 限 1s5次）。单任务失败不阻塞其它。
- 端点 `POST /api/v1/modules/bazhuayu/trigger-all`，返回 total/submitted/alreadyImported/failed + 每任务明细。
- 前端顶栏「一键全导」按钮 + 确认框 + 复用 3s 轮询看转态。
- **验证**：9 任务 → 1 QUEUED（新批次提交）/ 5 ALREADY_IMPORTED（已导入跳过）/ 3 ERROR（云端仍 Extracting，正确拒绝）。节流后 0 个 TooManyRequests ✅

### ④ 提速
- 主瓶颈：`BazhuayuClient` 每翻一页固定 `sleep 2s`（30万行≈300页×2s≈10分钟纯 sleep）。
- 改 `bazhuayu.page-delay-ms` 可配（默认 **800ms**，原2000），`<=0` 不 sleep（自测用）。`sleep2s()` 方法名保留（单测 spy 兼容），语义改为可配翻页间隔。数据接口比采集接口宽松，800ms 通常安全，遇 429 再调回。
- `filterPageAndAppend` 页内 3 次 DB 查询已批量+索引，未并行化（收益小、风险高）。

### ① 前端按分类分组/筛选
- 历史任务卡加**分类下拉筛选** + **分类计数彩色标签**（点击切换筛选）。`categoryOptions`/`categoryCounts` 按 scope+站点计算，`filteredHistory` 叠加分类过滤。纯前端，后端 `task_category` 字段本就有。

### 部署
- 前端宿主机 `npm run build`；后端 `docker compose build java-product` + `up -d`（编译进镜像）。SchemaGuard 通过 tables=64，Started ProductApplication ✅。无表结构变更、无 nginx 变更（预检通过）。

### 上线后两个 bug 修复（Playwright 实测定位）
1. **点开详情报 "marketplace 不能为空"**：VO 只返回 country(UK/DE)，但卡片/点击日志(`getTrackParams`)/详情页多处读 `marketplace`，导致 `POST /click-logs` 传空 marketplace 被后端 400 拒。修复：`normalizeLingxingShopProduct` 加 `marketplace: raw.country` 别名。实测点击日志转 200、详情页正确显示 UK。
2. **图片糊**：领星 small_image_url 是 `._SL75_.`(75px) 缩略图。修复：normalizer 加 `upgradeAmazonImage` 把 Amazon CDN 尺寸修饰符统一换 `._SL500_.`(500px)。实测卡片图 naturalWidth 75→500，清晰。
均为前端改动，重新 build + frontend 容器重建。
