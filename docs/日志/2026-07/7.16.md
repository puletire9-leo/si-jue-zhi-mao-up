# 7.16 修改记录

## MySQL 缓冲池与健康检查保护

- 生产 MySQL InnoDB Buffer Pool 默认从 MySQL 8 的 `128MB` 调整为 `1G`，可通过 `MYSQL_INNODB_BUFFER_POOL_SIZE` 覆盖。
- MySQL 容器内存上限默认设为 `2g`，可通过 `MYSQL_MEMORY_LIMIT` 覆盖。
- 健康检查由 `mysqladmin ping` 改为真实执行 `SELECT 1`：连接超时 1 秒、检查总超时 2 秒、启动宽限期 30 秒。
- 保留 Docker 构建缓存，不执行缓存或数据卷清理。

## 数据库并发保护

- MySQL `max_connections` 设置为 60。
- Java product 连接池调整为 min 3/max 15，Java user 调整为 min 2/max 5，连接等待统一为 5 秒。
- Python API 连接池调整为 min 3、基础池 10、overflow 5；连接获取真实执行 5 秒超时。Celery 单任务池限制为 min 1/max 2。
- 新增 `DatabaseWorkloadGate`：大型聚合查询并发 2，全量 CSV 并发 1，批量写入并发 1。
- 八爪鱼云端采集等待保持并行，导入DB阶段进入公平单通道队列；卖家精灵请求中心保持原单线程。

## 下载中心大文件流式下载

- 修复 613MB ZIP 点击后长时间无反馈：前端不再用 XHR 将完整文件加载为 Blob。
- 新增 2 分钟有效、绑定任务 ID 的签名 HttpOnly 下载凭证，JWT 不进入下载 URL。
- 下载接口改用 `FileResponse`，保留 Range 能力并返回 `X-Accel-Buffering: no`。
- Nginx 对下载路径关闭响应缓冲和请求缓冲，避免大文件写入 Docker 临时目录。
- 下载按钮增加 loading/禁用状态，阻止短时间重复点击产生多个并发下载。
