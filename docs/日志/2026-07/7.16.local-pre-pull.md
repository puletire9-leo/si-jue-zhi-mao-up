## 五、这次形成的Skill设计思考

### 5.1 Skill不是商品分类表

商品方向知识卡回答“以前开发过什么”，但不应把每一个商品类目都做成一个独立Skill。

真正可以复用的Skill主要包括：

- 套装与多组件组合；
- 数量、尺寸和规格矩阵；
- 主题元素差异化；
- 人群和使用场景细分；
- 设备/车型适配；
- 维修替换需求开发；
- 季节和节日提前布局。

多个不同产品可以共同证明同一个Skill。例如圣诞挂饰、圣诞贺卡、圣诞服饰不是三个“圣诞Skill”，而是多个产品共同证明“圣诞节季节场景开发”和“季节主题提前布局”。

### 5.2 商品方向层必须1对1

每个有效产品方案只能有一个最主导的商品方向。

同一个产品可以同时拥有多个场景和开发方法，但不能因为同时出现“宠物、礼物、装饰”等词，就在商品方向层重复计数。

否则会出现：

- 一个产品重复支持多个方向；
- Skill证据虚高；
- 三位开发人的画像趋同；
- AI无法知道产品真正属于哪里。

### 5.3 标题事实优先，关键词只做辅助

逐条深审已经证明，关键词会出现典型陷阱：

- “猫咪贺卡”不能因为猫咪归宠物；
- “车载电子表附贴纸”不能把贴纸当产品本体；
- “儿童电动高铁模型”不能因为电动归电子配件；
- “K-pop笔记本”不能因为IP主题归玩具收藏；
- “蛋糕动物摆件”不能因为摆件归家居装饰。

判断顺序应固定为：

```text
完整标题中的真实产品本体
→ 主要功能/购买目的
→ 使用对象和场景
→ 主题、材质、数量等辅助信息
```

### 5.4 第一层不能冒充经营结论

当前Skill主要是第一层开发证据，只能证明：

- 团队开发过哪些产品；
- 哪些方向跨月重复；
- 使用过哪些套装、主题、规格和人群方法；
- 哪些能力更集中在某个开发人。

不能直接证明：

- 已经成功上架；
- 有销量；
- 能盈利；
- 已回本；
- 值得继续扩大。

第二层要接FBA首次可售和运营上架；第三层再接销量、利润、留存、淘汰和回本。

### 5.5 Skill的实战作用

当AI拿到几千个新品榜或商品候选时，正确流程是：

```text
数据库/规则先做基础过滤
→ Skill判断团队是否会做、过去怎么做
→ AI说明风险和证据
→ 缩成少量值得人工看图片、成本和竞争的商品
```

Skill不替代新品榜规则，也不制造新的复杂评分表。它负责回答：

```text
这是不是团队熟悉的开发方向？
过去用过什么方法？
为什么值得继续看？
最大风险是什么？
下一步应该查什么？
```

### 10.2 Amazon 字段补齐（enrich 阶段）

从 `lingxing_product_performance` 补 8 列：

- 亚马逊 `item_name`（3,857/5,703 ASIN 命中，67.6%）
- `parent_asin` / `tacos` / `最新月销量` / `最新月销售额` / `最新月仍在卖`
- `累计广告花费` / `首月销量`

工程坑：

- Windows CMDLINE 32KB 限制 → SQL IN 子句分批 400 ASIN
- MySQL ONLY_FULL_GROUP_BY 严格模式 → `MAX(item_name)` 聚合规避
- "最新月仍在卖" 定义修正：**2026-06 整月 volume > 0**（不是最近 7 天，不是最新周）

诊断结果：`data/enrich_diagnostics.md`
- 最新月(2026-06)仍在卖：**1,828 条**
- 补上亚马逊标题：**3,857 条**

### 10.3 关键纠错：三层数据 → 图 + 亚马逊标题

用蒋舒 4 月 SKU 2255624 做首条深审时踩了几个错，被用户直接纠正：

| 我的错 | 正确做法 |
|---|---|
| 只看开发标题"农场热气球款"就下结论 | 必须看 `lingxing_product_performance.item_name`，那才是消费者看到的搜索入口 |
| 判"边缘留存"因为累计销量只有 8 | 结合 tacos 5.52% + 单单毛利 → 是"低量长销稳赚"，不是"边缘留存" |
| 认为 method-08 "FBM 验证 FBA 补发" 存在 | **团队只做 FBA，不做 FBM**，这个手法整个是错的 |
| 只分析文字不看图 | **定制品的卖点是图案本身**，跳过图就没法解释"为什么这一件能赚" |

### 10.4 新方法论沉淀：非标定制看图深审（4 步法）

针对定制/非标品（占蒋舒 ~30%，团队总量约 1/5）建立独立方法论：

```text
产品数据/思考理实团队的开品方向/第二版/理实开品经验/
└── references/L1-开品层/audit-method-非标定制看图深审.md
```

**触发条件**：`产品名称` 含"【定制】" / L2 标签含"非标品" / 采购价 ≤ ¥5 且含"挂牌/贴牌"。

**4 步流程**：
