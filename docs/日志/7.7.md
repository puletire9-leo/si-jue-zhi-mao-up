### 8. 卖家精灵变体参数实测

验证郑总店铺数据是否可以通过接口直接避免变体污染。

本地污染样本：

```text
UK / xinchenliang
旧抓取：155 行
父 ASIN 去重后：99 个父组
重复父组：30 个
重复变体行：86 行
最大单父组变体数：5
```

实测请求 1：

```json
{
  "marketplace": "UK",
  "sellerName": "xinchenliang",
  "asins": [],
  "variationString": "Y",
  "page": 1,
  "size": 100,
  "orderDesc": true
}
```

结果：`total=158`、`pages=2`，第一页仍有 `22` 个重复父组，说明 `variationString` 在当前接口/场景下不可靠或被忽略。

实测请求 2：

```json
{
  "marketplace": "UK",
  "sellerName": "xinchenliang",
  "asins": [],
  "variation": "Y",
  "page": 1,
  "size": 100,
  "orderDesc": true
}
```

结果：

```text
total=98
pages=1
items=98
父 ASIN 重复组=0
```

结论：

- 正确字段是 `variation`，不是 `variationString`。
- `variation=N` = 含变体；`variation=Y` = 不含变体。
- 郑总店铺后续抓取应使用 `variation=Y`，可以显著减少变体污染和分页请求次数。
- 本地清洗后的代表 ASIN 集合不一定与 `variation=Y` 完全一致，因为 API 实时数据会变化，且本地代表行选择规则与卖家精灵不一定相同；但父 ASIN 层面的去重目标是一致的。
- 已将郑总店铺系统同步与快速抓取脚本改为 `variation=Y`。
