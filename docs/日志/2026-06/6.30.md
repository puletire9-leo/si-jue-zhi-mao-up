**API 实测（用 Python 客户端对英国任务跑端到端）**
- ✅ 全链路打通：登录 → 写 URL 进循环 → 启动 → 查状态/子任务 → 拉数据 → 停止 → 清空。
- ❗ 纠正①：写 URL 必须用**循环步骤**，`updateLoopItems` **必带 actionId**；任务无循环步骤报 `TaskSettingsNotFound`。英国任务原本只有 NavigateAction，**在客户端手动加了 LoopAction（actionId `8djrlk2mqdh`）后才能写入**。
- ❗ 纠正②：`/task/urls:file` 对本任务无效（接口成功但 0 子任务）。
- ⚠️ **阻塞**：10 条 URL 正确写入、生成 10 子任务后启动，7+ 分钟仅 1 个 Finished 且**0 数据**，其余 9 个 Waiting 不动 → **八爪鱼任务模板抓不到 stylesnap 页数据**，API/代码无法解决，需在客户端查任务提取步骤。**该任务暂保留。**

**待修缺陷（编码层）**
- `BazhuayuClient.updateLoopItems` 漏 `actionId` 参数（实测必填）→ 需补 + 先 `getActions` 取 LoopAction id。
