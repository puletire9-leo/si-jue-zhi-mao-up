## 九、调度中心V2 — 报告驱动调度 (14:30)

### 问题
- exit_code=0 ≠ 任务成功，agent可能输出diff但未写磁盘
- 主模型无法判断agent是否真的完成了工作
- 没有标准化的完成信号

### 方案
**agent必须生成结构化报告才算任务完成**。引擎自动：
1. 在每份prompt末尾追加报告模板指令
2. 监控报告文件 `.dispatch/reports/{task_id}.md`
3. 解析报告提取结构化数据

### 改动 (6文件, ~120行)

| 文件 | 改动 |
|------|------|
| `models.py` | TaskStatus: +REPORTED/+NO_REPORT; Task: +report_file/status/summary/files |
| `config.py` | +reports_dir 配置 |
| `engine.py` | +REPORT_TEMPLATE; submit追加模板; +_parse_report(); wrapper检测报告 |
| `registry.py` | V2列迁移; CRUD适配新字段 |
| `tasks.js` | 前端显示reported/no_report状态 + 报告摘要 |
| `docs/调度中心报告规范.md` | SOP文档 |

### 新任务状态流
```
QUEUED → RUNNING → (写报告) → REPORTED ✅
                  → (没写报告) → NO_REPORT ⚠️
                  → (异常退出) → FAILED ❌
```
