# ASIN 月度经营模型：正式口径

> 生效版本：2026-07-13；数据观察范围：2025-04 至 2026-06。

## 适用范围

本口径用于团队开发产品的 ASIN 月度经营复盘：按批次查看销量、结算利润、标签留存、淘汰与后续财务回正。

它不替代 SKU 周表现、采购 Q1/Q2 或店铺级库存运营模型。

## 时间口径

`模型分析起算月` 按以下优先级确定：

1. 月度产品表现中首次观察到 `FBA-可售 > 0` 的月份；
2. 若覆盖期内未观察到 FBA 可售，取商品信息 `创建时间` 所在月作为兜底。

`FBA库存`仅作为核查字段，不参与当前批次起算。

上述时间都是领星观察或本地商品记录时间，均不得称为“亚马逊真实上架日”。

## 实体与币种

- ASIN 是经营复盘的主实体。
- 后续正式落库需要同时维护 `ASIN 总基准` 与 `ASIN + 币种/站点起算基准`：同一 ASIN 在英国、德国的可售首现时间可能不同。
- GBP、EUR 不换汇、不合并。

## 状态与财务

- 仅最新 Listing 标签为“欧洲精铺2025淘汰”时计为淘汰；待淘汰暂计入留存。
- 标签留存率不等于持续有销量率。
- 总结算销售额、总结算利润来自 `lingxing_profit_asin` 日事实；利润率为总结算利润除以总结算销售额。
- 累计结算利润回正不等于资金回本；后者仍需采购、头程和入库现金投入映射。
