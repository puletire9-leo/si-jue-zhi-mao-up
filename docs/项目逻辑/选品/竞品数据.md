# 竞品数据逻辑

> 最后更新：2026-05-18
> 涵盖：选品阶段的竞品数据获取、筛选、展示全流程

***

系统当前的API调用限额设置如下：每分钟最多可执行40次请求，每月最多可执行20000次请求。在单次API请求中，最多支持同时查询40个ASIN编号；而针对卖家信息的查询，每次请求仅能查询一个卖家账号，且该操作计为一次请求次数。

<br />

## 一、系统架构

```
前端 Vue3                      Python FastAPI                MySQL
────────────────────────────────────────────────────────────────────
AllSelection/index.vue  ──→  /api/v1/selection/reference/list  ──→  selection_products
  (竞品店铺标签页)               selection.py:511                   (source LIKE '%竞品%')

SelectionQueryForm       ──→  查询参数                            ←── 返回 30+ 字段
  国家/模式/等级/时效           SelectionProductQueryParams          UniversalCard 卡片展示
```

当前数据来源

：Excel 手动导入 → `selection_products` 表 → 静态快照\\

新架构

：卖家精灵 API → `competitor_products` 表 → 实时数据（Java sjzm-product 微服务）

## 三、国家（country）逻辑

### 3.1 可选值

| 值    | 含义           |
| ---- | ------------ |
| `英国` | Amazon UK 站点 |
| `德国` | Amazon DE 站点 |
| 空字符串 | 不筛选（全部）      |

### 3.2 筛选方式

- 数据库  ：`country` 列，精确匹配 `country = %s`
- 前端  ：下拉选择器，选项 `['英国', '德国']`
- Excel 导入  ：列名 `国家 / country / Country`

### 3.3 业务含义

- 同一 ASIN 在不同国家是不同产品
- 新品榜和竞品数据按国家独立管理
- 评分系统不区分国家（同表混评）

## 五、新品榜 vs 竞品（product\_type + source）

区分是是是双重是是的：

### 5.1 product\_type（ENUM）

| 值           | 含义   |
| ----------- | ---- |
| `new`       | 新品榜  |
| `reference` | 竞品店铺 |
| `zheng`     | 郑总店铺 |

### 5.2 source（VARCHAR，模糊匹配）

| 值        | 含义       |
| -------- | -------- |
| 包含 `新品榜` | 来自新品榜爬取  |
| 包含 `竞品`  | 来自竞品店铺爬取 |

### 5.3 API 强制

`GET /selection/reference/list`：

```python
params = SelectionProductQueryParams(
    product_type="reference",   # 固定
    source="竞品",              # 固定，LIKE 模糊匹配
    ...
)
result = await service.get_products_by_source(page, size, params)
```

在 `get_products_by_source()` 中：

```python
if params.source:
    where_conditions.append("source LIKE %s")
    query_params.append(f"%{params.source}%")
```

## 六、筛选参数全表

### 6.1 前端 → 后端参数映射

| 前端字段               | API 参数名            | 类型     | SQL 条件                   | 说明         |
| ------------------ | ------------------ | ------ | ------------------------ | ---------- |
| `asin`             | `asin`             | string | `asin LIKE %x%`          | ASIN 模糊搜索  |
| `productTitle`     | `productTitle`     | string | `product_title LIKE %x%` | 标题模糊搜索     |
| `storeName`        | `storeName`        | string | `store_name LIKE %x%`    | 店铺模糊搜索     |
| `category`         | `category`         | string | `main_category_name = x` | 大类榜单精确匹配   |
| `country`          | `country`          | string | `country = x`            | 英国/德国      |
| `dataFilterMode`   | -                  | string | 已停用                   | 旧 MODE1/MODE2/FAIL 不再参与查询 |
| `listingDateStart` | `listingDateStart` | string | `listing_date >= x`      | 上架起始日期     |
| `listingDateEnd`   | `listingDateEnd`   | string | `listing_date <= x`      | 上架结束日期     |
| `grade`            | -                  | string | 已停用                   | 旧 S/A/B/C/D 品级不再参与查询 |
| `weekTag`          | `weekTag`          | string | `week_tag = x`           | 周标记        |
| `isCurrent`        | `isCurrent`        | int    | `is_current = x`         | 1=本周, 0=往期 |
| `sortField`        | `sortBy`           | string | ORDER BY                 | 默认 `createdAt` |
| `sortOrder`        | `sortOrder`        | string | ASC/DESC                 | 默认 `desc`  |
| `page`             | `page`             | int    | LIMIT/OFFSET             | 默认 1       |
| `size`             | `size`             | int    | LIMIT                    | 默认 60      |

### 6.2 默认排序规则

当按 `score` 排序时，使用复合排序：

```sql
ORDER BY is_current DESC, score DESC, created_at DESC
```

（本周数据优先，再按评分降序，再按创建时间降序）

## 七、核心数据字段

### 7.1 selection\_products 表（当前系统）

基础字段：`id, asin, product_title, price, sales_volume, listing_date, delivery_method`\
店铺字段：`store_name, store_url, shop_id`\
类目字段：`main_category_name, main_category_rank, main_category_bsr_growth, main_category_bsr_growth_rate`\
链接字段：`product_link, similar_products, image_url`\
分类字段：`source, product_type, country, data_filter_mode`\
评分字段：`score, grade, week_tag, is_current`\
其他：`tags, notes, local_path, thumb_path, created_at, updated_at`

### 7.2 前端卡片展示字段

`UniversalCard` 组件展示：

- 标题  ：`productTitle`
- 价格  ：`price`
- 图片  ：优先 `thumbPath` → `localPath` → `imageUrl`
- 店铺  ：`storeName`
- 类目  ：`category`（映射自 `main_category_name`）
- 标签  ：`tags`（最多 3 个）
- 类型徽章  ：`productType === 'reference'` → "竞品"
- 销量徽章  ：`salesVolume`
- 旧等级、模式与未通过原因不再在卡片展示（`grade` / `sales_tier` / `filter_mode` / `filter_reasons`）。
- 时效标签  ：`isCurrent === 1` → "本周上架"，否则计算天数

### 7.3 详情页展示字段

`SelectionDetail` 额外展示：

- 上架天数、配送方式、BSR 增长数/率
- 商品链接、店铺链接、相似商品链接
- 备注、创建/更新时间

## 八、评分系统

### 8.1 评分维度

| 维度    | 权重  | 数据来源                 | 评分方式    |
| ----- | --- | -------------------- | ------- |
| 上架时间  | 30% | `listing_date`       | 天数越短分越高 |
| 销量    | 33% | `sales_volume`       | 区间匹配    |
| 大类BSR | 25% | `main_category_rank` | 排名越小分越高 |
| 价格竞争力 | 12% | `price`              | 区间匹配    |

### 8.2 等级阈值

| 等级 | 分数     | 颜色         |
| -- | ------ | ---------- |
| S  | 90-100 | 绿色 #67C23A |
| A  | 80-89  | 蓝色 #409EFF |
| B  | 65-79  | 橙色 #E6A23C |
| C  | 50-64  | 灰色 #909399 |
| D  | 0-49   | 红色 #F56C6C |

### 8.3 特殊规则

- FBM 配送  ：`delivery_method == 'FBM'` → 自动 S 级 100 分
- 周标记  ：ISO 周号如 `2026-W19`，新周自动将旧数据降级 `is_current=0`

## 九、数据来源与现状

### 9.1 当前：Excel 手动导入

```
Excel 文件 → POST /selection/import → 解析 → INSERT INTO selection_products
```

- 18 个 Excel 列名映射
- 支持 skip/update/overwrite 三种导入模式
- 导入后自动触发评分 + 周标记
- 数据是静态快照，导进来就过时

### 9.2 问题

| 问题    | 说明                                         |
| ----- | ------------------------------------------ |
| 数据陈旧  | 导入后不再更新，销量/排名/BSR 都是历史值                    |
| 字段缺失  | 无销售额(revenue)、评分(ratings)、变体数、卖家信息、BSR 详情等 |
| 手动操作  | 每次要重新导出 Excel → 上传，效率低                     |
| 无历史追踪 | 同一 ASIN 不同时间的数据无法对比趋势                      |

## 十、新架构：卖家精灵 API 接入

### 10.1 新表设计

```
competitor_products         -- 55 字段全量（按 marketplace + asin + month 唯一）
competitor_subcategories    -- 子类目排名（一对多）
competitor_lookup_log       -- API 调用日志
```

### 10.2 Java 微服务

```
sjzm-product :8002
  POST /api/v1/competitor/lookup    → 调 API → 入库 → 返回
  POST /api/v1/competitor/products  → 查本地 DB
  GET  /api/v1/competitor/{asin}/history → 历史趋势
```

### 10.3 新旧对比

| <br />   | 旧系统 (selection\_products) | 新系统 (competitor\_products)                  |
| -------- | ------------------------- | ------------------------------------------- |
| 数据来源     | Excel 手动导入                | 卖家精灵 API 实时拉取                               |
| 字段数      | \~30                      | 55+                                         |
| 历史追踪     | 无（覆盖）                     | 按月份多行，天然支持趋势                                |
| 销售额      | 无                         | revenue, amzSales                           |
| 评分       | 内部评分系统                    | ratings, rating, ratingsCv                  |
| BSR      | main\_category\_rank 单一值  | bsr, bsrCr, bsrCv + 子类目排名                   |
| 卖家信息     | store\_name               | sellerName, sellerId, sellerNation, sellers |
| 品牌       | 无                         | brand, brandUrl                             |
| 变体       | 无                         | parentAsin, variations                      |
| 配送       | delivery\_method          | fulfillment, fba, deliveryPrice             |
| 利润率      | 无                         | profit, fba                                 |
| 更新方式     | 重新导入覆盖                    | 按月份 upsert，可增量                              |
| 缓存       | 无                         | Caffeine + Redis 双层缓存                       |
| 熔断       | 无                         | Resilience4j CircuitBreaker                 |
| API 用量追踪 | 无                         | competitor\_lookup\_log                     |
| 后端技术     | Python FastAPI            | Java Spring Boot 3.2                        |
| 微服务      | 无                         | Nacos 注册 + Gateway 路由 + OpenFeign           |
