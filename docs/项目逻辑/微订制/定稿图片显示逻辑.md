# 定稿图片显示逻辑

## 数据流全景

```
MySQL: final_drafts.images (JSON数组，存COS完整URL)
        ↓
后端: GET /api/v1/final-drafts
        ↓  _convert_image_paths_to_urls() — 基本无操作（已是URL）
        ↓
前端: DraftCard.vue → displayImage 计算属性
        ↓  ImageUrlUtil.getThumbnailUrlSync(cosUrl)
        ↓  → getProxiedUrlSync() → extractObjectKey()
        ↓  → 返回 /api/v1/image-proxy/proxy?object_key=...
        ↓
后端: GET /api/v1/image-proxy/proxy
        ↓  cos_service.get_full_url(object_key)
        ↓  → 构建公网COS URL: https://bucket.cos.region.myqcloud.com/{object_key}
        ↓  → aiohttp 下载 → 返回图片字节
        ↓  失败 → COS SDK get_object() 兜底
        ↓  都失败 → SVG占位图 "图片暂不可用"
```

## 关键文件

| 层 | 文件 | 作用 |
|---|------|------|
| 数据库 | `final_drafts` 表 | `images` 列存 COS URL JSON 数组；`reference_images` 列存参考图 URL |
| 后端 API | `backend/app/api/v1/final_drafts.py` | `GET /api/v1/final-drafts` 返回草稿列表，含图片 URL |
| 图片代理 | `backend/app/api/v1/image_proxy.py` | `GET /image-proxy/proxy?object_key=` 从 COS 拉图片并返回 |
| COS 服务 | `backend/app/services/cos_service.py` | `get_full_url()` 构建公网 URL；`get_object()` SDK 下载 |
| 前端卡片 | `frontend/src/views/FinalDraft/components/DraftCard.vue` | `displayImage` 属性决定展示哪张图 |
| URL 工具 | `frontend/src/utils/imageUrlUtil.ts` | `getProxiedUrlSync()` 把 COS URL 转成代理 URL |
| 配置 | `backend/app/config.py` | `COS_BUCKET`, `COS_REGION`, `IMAGE_READ_MODE` |

## 数据库结构

```sql
-- final_drafts 表关键列
images TEXT DEFAULT '[]'          -- JSON数组: ["https://bucket.cos.../final_drafts/xxx.webp", ...]
reference_images TEXT DEFAULT '[]' -- 参考图，同样格式
local_thumbnail_path VARCHAR(512)  -- 本地缩略图路径（可选）
local_thumbnail_status ENUM        -- pending/downloading/completed/failed
```

**实际数据示例:**
```json
[
  "https://sijuelishi-1328246743.cos.ap-guangzhou.myqcloud.com/images/20260123_134340_638b6e00.webp?q-sign-algorithm=sha1&q-ak=...&q-sign-time=..."
]
```

注意：数据库存的是**带签名的完整 COS URL**，签名有过期时间。

文件：`backend/app/api/v1/image_proxy.py` 行 136-185

```python
# 入参: object_key 或 url

# 步骤1: 通过 cos_service.get_full_url(object_key) 构建公网 URL
#    → https://{bucket}.cos.{region}.myqcloud.com/{object_key}

# 步骤2: aiohttp 直接 GET 此 URL
#   成功 → 返回图片字节 (image/webp)

# 步骤3: 失败时用 COS SDK 的 get_object() 兜底

```

**占位图出现条件：**
1. COS 上不存在该文件（404）
2. COS 访问凭证无效（403）
3. 网络超时

## 后端：COS 服务

文件：`backend/app/services/cos_service.py`

```python
# get_full_url(object_key) — 构建无签名公网 URL
def get_full_url(self, object_key):
    return f"https://{bucket}.cos.{region}.myqcloud.com/{object_key}"

# 对象键生成规则
def generate_object_key(filename, is_thumbnail, image_type):
    if image_type == "final":
        return f"final_drafts/{timestamp}_{md5}.webp"
    return f"images/{timestamp}_{md5}.webp"
```

配置默认值：
- `COS_BUCKET`: `sijuelishi-dev-1328246743`（开发环境）
- `COS_REGION`: `ap-guangzhou`
- `COS_FINAL_DRAFT_PREFIX`: `final_drafts/`
- `LOCAL_THUMBNAIL_DIR`: `/app/images/thumbnails`
- `IMAGE_READ_MODE`: `cloud`（**声明但代码中未实际使用**）

## 图片显示为空白/占位图的原因

### 当前问题根因

**COS 存储桶中没有这些文件。** 数据库迁移自生产备份，`images` 列存的是生产环境的 COS URL。开发环境 COS 配置指向 `sijuelishi-dev-1328246743`，但文件从生产 COS 同步到开发 COS，或文件已被清理。

### 所有可能原因

| 原因 | 表现 | 排查方法 |
|------|------|----------|
| COS 上文件不存在 | 代理返回 SVG 占位图 | `curl /api/v1/image-proxy/proxy?object_key=...` → 407 bytes SVG |
| COS 凭证无效 | 403 Forbidden | 查看后端日志 COS 初始化 |
| `images` 列为空 JSON `[]` | 前端显示 No Image | `SELECT id, images FROM final_drafts WHERE images='[]'` |
| URL 不含 COS 域名 | 被 validImages 过滤掉 | 检查数据库中的 URL 格式 |
| 网络超时 | 加载中 → 占位图 | 后端日志有 TimeoutError |
| 对象键提取错误 | COS 404 | URL 格式异常导致 extractObjectKey() 解析错误 |

### 当前排查结果

```
GET /api/v1/image-proxy/proxy?object_key=20260514_113508_74a7e3ae.webp
→ Status: 200
→ Content-Type: image/svg+xml
→ Content-Length: 407 bytes
→ 返回了占位图，说明 COS 上没有这个文件
```

## 需要修复的点

1. **`IMAGE_READ_MODE` 未生效**：代码中没有任何地方读取此配置，`cloud` 模式是唯一行为。如果需要本地文件模式，需在 `image_proxy.py` 中实现分流逻辑。

2. **开发环境需要本地图片**：Docker 开发环境没有 COS 文件。解决方案：
   - 方案 A：把生产 COS 的图片同步到开发 COS 桶
   - 方案 B：在 `image_proxy.py` 中实现 `IMAGE_READ_MODE=local`，从 `LOCAL_THUMBNAIL_DIR` 读取
   - 方案 C：把生产环境的缩略图文件复制到 Docker 的 `dev-thumbnails` 卷中
