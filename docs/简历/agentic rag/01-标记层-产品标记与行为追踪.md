# 阶段一：标记层 — 产品标记与行为追踪

> 已有实现。开发者在前端浏览新品榜，通过点击"选中此产品"按钮标记有潜力的商品。

---

## 1. 数据库设计

### 1.1 product_click_log 表

```sql
CREATE TABLE IF NOT EXISTS product_click_log (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT NOT NULL COMMENT '用户ID',
    user_name VARCHAR(50) DEFAULT NULL COMMENT '用户名(冗余，方便显示)',
    asin VARCHAR(20) NOT NULL COMMENT '产品ASIN',
    marketplace VARCHAR(10) NOT NULL COMMENT '站点 UK/DE',
    source VARCHAR(50) DEFAULT '新品榜' COMMENT '来源页面',
    action VARCHAR(20) NOT NULL COMMENT '行为: click=浏览, select=选中, unselect=取消',
    product_title VARCHAR(500) DEFAULT NULL COMMENT '产品标题(冗余)',
    clicked_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '时间',

    INDEX idx_user (user_id),
    INDEX idx_asin (asin),
    INDEX idx_source_action (source, action, clicked_at),
    INDEX idx_user_time (user_id, clicked_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### 1.2 状态判定逻辑

不做"当前状态表"，而是通过**最近一条 action 记录**判定：

```
同一个 (user_id, asin) 的最新一条 select/unselect 记录即为当前状态
  - 最新 action = 'select'  → 已选中
  - 最新 action = 'unselect' → 未选中
  - 没有记录 → 未选中
```

**优点**：不需要维护状态表、不担心并发更新、天然带操作历史、可分析"选中→取消→再选中"的行为模式。

```java
// java-backend/sjzm-product/src/main/java/com/sjzm/product/service/ProductClickLogService.java

@Service
@Slf4j
@RequiredArgsConstructor
public class ProductClickLogService {

    private final ProductClickLogMapper mapper;

    // ===================== 写入 =====================

    /** 记录一次行为。fire-and-forget 模式，失败不抛异常。 */
    public void log(Long userId, String asin, String marketplace,
                    String source, String action, String productTitle,
                    String userName) {
        try {
            ProductClickLog log = new ProductClickLog();
            log.setUserId(userId);
            log.setUserName(userName);
            log.setAsin(asin);
            log.setMarketplace(marketplace);
            log.setSource(source);
            log.setAction(action);
            log.setProductTitle(productTitle);
            log.setClickedAt(LocalDateTime.now());
            mapper.insert(log);
        } catch (Exception e) {
            log.warn("点击记录写入失败: userId={} asin={} action={}", userId, asin, action, e);
        }
    }

    // ===================== 查询 =====================

    /**
     * 获取用户当前选中的 ASIN 集合。
     * 逻辑：每个 (user, asin) 取最新一条 select/unselect 记录，
     *       若最新动作为 select，则该 ASIN 视为选中。
     */
    public Set<String> getUserSelections(Long userId, String marketplace) {
        LambdaQueryWrapper<ProductClickLog> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(ProductClickLog::getUserId, userId)
               .eq(ProductClickLog::getMarketplace, marketplace)
               .in(ProductClickLog::getAction, "select", "unselect")
               .orderByDesc(ProductClickLog::getClickedAt);
        List<ProductClickLog> logs = mapper.selectList(wrapper);

        Set<String> selected = new HashSet<>();
        Set<String> seen = new HashSet<>();
        for (ProductClickLog log : logs) {
            String key = log.getAsin();
            if (seen.add(key) && "select".equals(log.getAction())) {
                selected.add(key);
            }
        }
        return selected;
    }

    /**
     * 获取多个 ASIN 各自的选中用户列表。
     * 返回: Map<asin, List<{userId, userName}>>
     */
    public Map<String, List<Map<String, Object>>> getSelectionUsers(List<String> asins) {
        // 1. 查所有相关记录的 select/unselect，按时间倒序
        LambdaQueryWrapper<ProductClickLog> wrapper = new LambdaQueryWrapper<>();
        wrapper.in(ProductClickLog::getAsin, asins)
               .in(ProductClickLog::getAction, "select", "unselect")
               .orderByDesc(ProductClickLog::getClickedAt);
        List<ProductClickLog> logs = mapper.selectList(wrapper);

        // 2. 找每个 (asin, userId) 的最新 action
        Map<String, String> latestAction = new HashMap<>();
        for (ProductClickLog log : logs) {
            String key = log.getAsin() + "_" + log.getUserId();
            latestAction.putIfAbsent(key, log.getAction());
        }

        // 3. 构建结果：只保留最新 action 为 select 的用户
        Map<String, List<Map<String, Object>>> result = new LinkedHashMap<>();
        Set<String> seen = new HashSet<>();
        for (ProductClickLog log : logs) {
            String key = log.getAsin() + "_" + log.getUserId();
            if (!seen.add(key)) continue;
            if (!"select".equals(latestAction.get(key))) continue;

            result.computeIfAbsent(log.getAsin(), k -> new ArrayList<>())
                  .add(Map.of("userId", log.getUserId(),
                              "userName", log.getUserName() != null ? log.getUserName() : ""));
        }
        return result;
    }
}
```

### 2.4 Controller

```java
// java-backend/sjzm-product/src/main/java/com/sjzm/product/controller/ProductClickLogController.java

@RestController
@RequestMapping("/api/v1/click-logs")
@RequiredArgsConstructor
@Tag(name = "用户点击行为", description = "记录用户浏览/选择产品行为")
public class ProductClickLogController {

    private final ProductClickLogService clickLogService;

    @PostMapping
    @Operation(summary = "记录一次产品行为（click/select/unselect）")
    public Result<Map<String, String>> logClick(
            @RequestHeader(value = "X-User-Id", defaultValue = "1") Long userId,
            @Valid @RequestBody ClickLogRequest request) {
        clickLogService.log(userId, request.getAsin(), request.getMarketplace(),
                request.getSource(), request.getAction(),
                request.getProductTitle(), request.getUserName());
        return Result.success(Map.of("status", "ok"));
    }

    @GetMapping("/my-selections")
    @Operation(summary = "获取当前用户已选中的 ASIN 列表")
    public Result<Set<String>> mySelections(
            @RequestHeader(value = "X-User-Id", defaultValue = "1") Long userId,
            @RequestParam(defaultValue = "UK") String marketplace) {
        return Result.success(clickLogService.getUserSelections(userId, marketplace));
    }

    @GetMapping("/selection-users")
    @Operation(summary = "获取指定 ASIN 的选中用户列表")
    public Result<Map<String, List<Map<String, Object>>>> selectionUsers(
            @RequestParam List<String> asins) {
        return Result.success(clickLogService.getSelectionUsers(asins));
    }
}
```

### 2.6 数据库演进 — product_selection_log（分析层扩展用）

阶段二需要知道"哪些产品被标记了"来触发分析。当前 `product_click_log` 表通过 `latest action` 判定状态已经够用，但为了更高效地支持批量分析任务的调度，建议新增一张**轻量快照表**：

```sql
-- 可选：加速分析任务调度，避免每次扫全量 click_log 表
CREATE TABLE product_selection_snapshot (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    asin VARCHAR(20) NOT NULL,
    marketplace VARCHAR(10) NOT NULL,
    selected_by_count INT DEFAULT 0 COMMENT '当前选中人数',
    last_selected_at DATETIME COMMENT '最近一次被选中的时间',
    analysis_version INT DEFAULT 0 COMMENT '已生成的分析报告版本号',
    UNIQUE KEY uk_asin_market (asin, marketplace)
);
```

每次 `action='select'` 时 upsert 该表，Celery 定时任务按 `analysis_version = 0`（待分析）取数。

## 3. 前端集成

### 3.1 API 层

```typescript
// frontend/src/api/clickLog.ts

import { useUserStore } from '@/stores/user'

export interface ClickLogParams {
  asin: string
  marketplace: string
  source: string
  action: 'click' | 'select' | 'unselect'
  productTitle: string
}

function getUserName(): string {
  const userStore = useUserStore()
  return userStore.userInfo?.username || userStore.userInfo?.realName || ''
}

/** fire-and-forget: 不 await，静默失败，不阻塞 UI */
export function trackClick(params: ClickLogParams) {
  const userStore = useUserStore()
  const token = userStore.token
  fetch('/api/v1/click-logs', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': token ? `Bearer ${token}` : '',
    },
    body: JSON.stringify({ ...params, userName: getUserName() }),
  }).catch(() => {})  // 静默失败
}

export async function fetchMySelections(marketplace: string): Promise<Set<string>> {
  const userStore = useUserStore()
  const token = userStore.token
  const res = await fetch(
    `/api/v1/click-logs/my-selections?marketplace=${marketplace}`,
    { headers: { 'Authorization': token ? `Bearer ${token}` : '' } }
  )
  const data = await res.json()
  return data.code === 200 && Array.isArray(data.data) ? new Set(data.data) : new Set()
}

export async function fetchSelectionUsers(
  asins: string[]
): Promise<Record<string, { userId: number; userName: string }[]>> {
  if (asins.length === 0) return {}
  const userStore = useUserStore()
  const token = userStore.token
  const params = asins.map(a => `asins=${encodeURIComponent(a)}`).join('&')
  const res = await fetch(
    `/api/v1/click-logs/selection-users?${params}`,
    { headers: { 'Authorization': token ? `Bearer ${token}` : '' } }
  )
  const data = await res.json()
  return data.code === 200 && data.data ? data.data : {}
}
```

### 3.2 页面集成 — AllSelection/index.vue

```typescript
// 关键状态
const mySelections = ref<Set<string>>(new Set())
const selectionUsersMap = ref<Record<string, { userId: number; userName: string }[]>>({})

// 加载选中数据（产品列表加载后调用）
const loadSelections = async () => {
  const marketplace = queryParams.value.country || 'UK'
  mySelections.value = await fetchMySelections(marketplace)
  // 从当前展示的 asin 列表拉取所有选中用户
  const asins = productList.value.map(p => p.asin).filter(Boolean)
  selectionUsersMap.value = await fetchSelectionUsers(asins)
}

// 乐观更新：点击即生效，后台校准
const handleToggleSelect = async (asin: string, selected: boolean) => {
  // 1. 乐观更新 UI
  if (selected) {
    mySelections.value.add(asin)
  } else {
    mySelections.value.delete(asin)
  }

  // 2. POST 到后端
  trackClick({
    asin,
    marketplace: queryParams.value.country || 'UK',
    source: '新品榜',
    action: selected ? 'select' : 'unselect',
    productTitle: productList.value.find(p => p.asin === asin)?.productTitle || '',
  })

  // 3. 拉取最新选中用户列表，校准展示
  const users = await fetchSelectionUsers([asin])
  selectionUsersMap.value = { ...selectionUsersMap.value, ...users }
}
```

## 5. 标记层作为 AI 知识飞轮的入口

当前标记数据已经完整记录了"谁、什么时候、标记了什么产品"。阶段二将利用这些数据触发自动分析：

```
标记触发 → 阶段二分析
   │
   ├─ 每次标记时 WebSocket 通知 → 即时分析（适用于需立即反馈的产品）
   ├─ 每日凌晨 Celery 批量任务 → 批量分析前一天所有新标记
   └─ 用户对话指令 → "分析这周标记的产品"
```
