# 思觉智贸 — 跨境电商 AI 化运营平台

## 一句话概述

面向亚马逊卖家的全链路产品运营平台，覆盖选品→竞品分析→ASIN批量导入→智能评分→定稿→素材管理的完整业务闭环，支持百万级商品数据处理，双后端并行架构（Java 微服务 + Python AI）。

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| Java 后端 | Spring Boot 4.0.4 + Spring Cloud Gateway + MyBatis-Plus 3.5.15 | 微服务架构，Nacos 注册中心 |
| Python 后端 | FastAPI + Celery + Qdrant | AI 功能（向量检索/图像识别/LLM） |
| 前端 | Vue 3 + TypeScript + Element Plus + Vite + Pinia | 27 个功能页面 |
| 数据库 | MySQL 8.0 + Redis 7 | HikariCP 连接池 + Redisson 分布式锁 |
| 消息队列 | RocketMQ | 异步任务解耦（图片处理/通知/订单） |
| 向量数据库 | Qdrant | 以图搜图，ViT 模型向量编码 |
| 部署 | Docker Compose（dev/prod 环境隔离） + GitHub Actions CI | 一键启动 8 个容器服务 |

## 架构亮点

- **双后端并行**：Java 扛高并发业务（竞品分析/评分/导入），Python 扛 AI 计算（向量检索/图像识别/LLM 视觉），Nginx 统一入口
- **微服务拆分**：Gateway（JWT + RBAC 鉴权）→ User（认证）→ Product（核心业务），Nacos 服务发现，Feign 远程调用
- **三级缓存体系**：Caffeine 本地缓存（1min/5min/30min）→ Redis 分布式缓存 → MySQL，缓存注解一行接入
- **三级限流 + 熔断**：全局 100/s → API 10/s → IP 5/s，Resilience4j 滑动窗口熔断（失败率 50% 触发）
- **多级评分引擎**：多维加权评分（上架天数/销量/BSR排名/价格）→ S/A/B/C/D 等级，支持自定义阈值，周级自动重算
- **卖家精灵 API 对接**：竞品数据批量拉取，40 条/批，速率限制 + 熔断保护

## AI 能力

- **以图搜图**：ViT（Vision Transformer）图片向量编码 + Qdrant 向量检索，支持相似商品搜索
- **图像识别**：腾讯云 + 百度双引擎图像识别，自动提取商品属性标签
- **LLM 视觉分析**：混元大模型，商品图片智能描述与分类
- **SQL 智能查询**：自然语言转 SQL，降低运营人员数据查询门槛

## 项目规模

- Java 模块：4（common/gateway/user/product），13 张业务表，8 个 Service
- Python 模块：25 个 API 路由，24 个 Service，39 个数据库迁移
- 前端：27 个页面视图，20 个 API 模块，8 个通用组件
- 基础设施：Docker Compose 一键启动 8 容器（MySQL/Redis/Nacos/RocketMQ/Qdrant/Python/Java/Frontend）
- CI/CD：GitHub Actions 自动构建 + Docker 镜像打包
