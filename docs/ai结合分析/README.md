## 各模块对应的系统组件

| 模块 | 关联的系统组件 |
|------|---------------|
| 01-品类分析 | `competitor_products.node_label_path`, `ScoringService`, `category_ratings`(新表) |
| 02-系统结合 | AsinImport 页面, AllSelection 页面, FinalDraft 页面, FilterConfigPanel, `competitor_products`(扩展 4 字段), `ai_recommend_log`(新表), `skip_asins` |
| 03-Agent架构 | 独立服务，可对接 Java/Python 后端 API。Phase 1 走 REST，Phase 2+ 评估 MCP |
| 04-能力评估 | 不涉及系统组件 |

> **v2 关键调整（2026-06）**：
> - 品类分析**只读** `competitor_products`，不读 `selection_products`（后者缺品类字段）
> - AI 推荐写入**新表** `ai_recommend_log`，不污染 `selection_products`
> - `final_drafts` 缺 `asin`，ASIN 反查方案**需先加 `source_asin` 字段**
> - LLM 仅图像可用，文本能力**需先扩展** `tencent_llm_vision_service.py`
> - Agent 框架分阶段，**Phase 1 立即可做**（Pipeline REST），**Phase 2 MCP 评估后决定**
