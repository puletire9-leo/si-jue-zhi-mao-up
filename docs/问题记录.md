### 问题 1：N 个卖家 N 次单条 INSERT

**现状**：`sellerPreview()` 每行一个 INSERT，50 个卖家 = 50 次 DB 往返
```java
for (String sellerName : sellerNames) {
    AsinImportResult r = new AsinImportResult();
    r.setTaskId(task.getId());
    ... 
    resultMapper.insert(r); // 每行一次 DB
}
```

**修复**：
```java
// Mapper 新增
@Insert("<script>INSERT INTO asin_import_results (task_id, seller_name, status) VALUES " +
    "<foreach collection='list' item='r' separator=','>" +
    "(#{r.taskId}, #{r.sellerName}, #{r.status})" +
    "</foreach></script>")
void insertBatch(@Param("list") List<AsinImportResult> results);

// sellerPreview 改用
resultMapper.insertBatch(results); // 1 次 DB 往返
```

### 问题 2：卖家名不去重、不验空

**现状**：空字符串或重复卖家名直接入库
```java
for (String sellerName : sellerNames) { ... }
```

**修复**：在 `sellerPreview()` 开头预处理
```java
List<String> cleaned = sellerNames.stream()
    .map(String::trim)
    .filter(name -> !name.isEmpty())
    .distinct()
    .collect(Collectors.toList());
if (cleaned.isEmpty()) throw new RuntimeException("没有有效的卖家名");
```

**前端同步修**：`parsedSellerNames` 计算属性加去重和空过滤，重复卖家名给用户提示。

**现状**：
```java
int estimatedApiCalls = sellerNames.size() * 3; // 为什么是 3？
```

**修复**：每个卖家按默认页数估算，注释说明

```java
int estimatedPagesPerSeller = 3; // 按每个店铺平均 3 页产品估算
int estimatedApiCalls = cleaned.size() * estimatedPagesPerSeller;
```

### 问题 4：`delayMs: 500` 返回值与实际不一致

**现状**：`sellerPreview` 返回 `delayMs: 500`，但 `sellerExecute` 用 `Thread.sleep(500)` 硬编码，不读这个值。

**修复**：
```java
// 统一使用常量
private static final long SELLER_API_DELAY_MS = 500;

// sellerPreview 返回

// sellerExecute 用
Thread.sleep(SELLER_API_DELAY_MS);
```

### 问题 5：循环内每次查 DB 检查暂停状态

**现状**：每个卖家处理前都查一次 DB
```java
for (AsinImportResult r : results) {
    task = taskMapper.selectById(taskId); // ← 浪费
    if ("PAUSED".equals(task.getTaskStatus()) || ...
```

**修复**：每隔 N 个卖家（如 5 个）才查一次 DB
```java
private static final int STATUS_CHECK_INTERVAL = 5;

for (int i = 0; i < results.size(); i++) {
    if (i % STATUS_CHECK_INTERVAL == 0) {
        task = taskMapper.selectById(taskId);
        if ("PAUSED".equals(task.getTaskStatus()) || "CANCELLED".equals(task.getTaskStatus())) {
            log.info("卖家导入任务 {} 已被暂停或取消", taskId);
            return;
        }
    }
    ...
}
```

### 问题 6：循环内每轮两次 updateById

**现状**：每轮 update 两次——第一次写进度日志，第二次写产品数

```java
task.setProgressLog(logBuf.toString());

```

### 问题 7：@Async 没有自定义线程池

**现状**：只有 `@EnableAsync`，Spring 默认 `SimpleAsyncTaskExecutor` 无限创建线程。

**修复**：在 `ProductApplication` 中新增 Bean
```java
@Bean("sellerImportExecutor")
public ThreadPoolTaskExecutor sellerImportExecutor() {
    ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
    executor.setCorePoolSize(1);        // 只允许一个导入任务
    executor.setMaxPoolSize(1);
    executor.setQueueCapacity(10);
    executor.setThreadNamePrefix("seller-import-");
    executor.setRejectedExecutionHandler(new CallerRunsPolicy());
    return executor;
}
```

`sellerExecute` 指定线程池：
```java
@Async("sellerImportExecutor")
public void sellerExecute(Long taskId, String month) { ... }
```

### 问题 8：无事务——半路挂了不回滚

**现状**：`sellerExecute()` 没有事务，中途异常后已入库的 `DengZongShop` 产品不回滚。

**修复**：`syncProductsBySeller()` 加 `@Transactional`（单店铺内回滚）
```java
@Transactional(rollbackFor = Exception.class)
private int syncProductsBySeller(String sellerName, String marketplace, String month) { ... }
```

说明：整个 `sellerExecute` 不能加事务（跨多个 API 调用、可能运行数分钟），但**每个店铺的产品写入应原子化**。

### 问题 9：`apiSuccess` 命名误导

**现状**：`apiSuccess` 存的是**产品总数**，不是 API 成功次数。

```java
/**
 * 已导入的产品总数（注意：不是 API 调用成功次数）

 * - ASIN 导入：成功处理的 ASIN 数  
 * - 卖家导入：累计导入的产品数
 */
private Integer apiSuccess;
```

### 问题 10：RUNNING 检查一刀切

**现状**：只要有任何一个 RUNNING 任务，所有市场都不能启动新导入
```java
Long activeCount = taskMapper.selectCount(
    new LambdaQueryWrapper<AsinImportTask>()
        .in(AsinImportTask::getTaskStatus, List.of("RUNNING", "PAUSED")));
if (activeCount != null && activeCount > 0) {
    task.setTaskStatus("REJECTED");
```

**修复**：新增 `importType` 字段区分导入类型，同类型 + 同市场才能拦截
```java
// 只检查同市场 + 同类型（SELLER）的活动中任务
Long activeCount = taskMapper.selectCount(
    new LambdaQueryWrapper<AsinImportTask>()
        .eq(AsinImportTask::getImportType, "SELLER")
        .eq(AsinImportTask::getMarketplace, task.getMarketplace())
        .in(AsinImportTask::getTaskStatus, List.of("RUNNING", "PAUSED")));
```

### Controller 修复：sellerExecute 返回 batchTotal

```java
@PostMapping("/seller/execute")
public Result<Map<String, Object>> sellerExecute(
        @RequestParam Long taskId,
        @RequestParam(defaultValue = "") String month) {
    AsinImportTask task = taskMapper.selectById(taskId);
    int batchTotal = task != null && task.getBatchTotal() != null ? task.getBatchTotal() : 0;
    asinImportService.sellerExecute(taskId, month);
    return Result.success(Map.of("taskId", taskId, "status", "RUNNING", "batchTotal", batchTotal));
}
```
