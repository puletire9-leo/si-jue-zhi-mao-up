## 二、筛选体验升级

### 2.1 多条件筛选组合逻辑

**设计目标**: 用户可以灵活组合多个筛选条件，支持 AND / OR / NOT 逻辑。

#### UI 交互

```
筛选条件栏:
┌─────────────────────────────────────────────────────────────────────┐
│ [+ 添加条件]  [组合逻辑: AND ▾]  [保存为预设]  [加载预设]          │
├─────────────────────────────────────────────────────────────────────┤
│ ✕ [元素] [Highland Cow]                    [▾ AND] [+ 添加子条件] │
│ ✕ [载体] [Metal Signs]     [▾ AND]                                   │
│ ✕ [价格] [£5.99] - [£8.99] [▾ AND]                              │
│ ✕ [BSR]  [≤ 80,000]        [▾ NOT]  [排除此条件]                    │
└─────────────────────────────────────────────────────────────────────┘
```

#### 组合逻辑说明

| 模式 | 行为 | 适用场景 |
|------|------|---------|
| AND（默认） | 所有条件必须同时满足 | 常规筛选，精确匹配 |
| OR | 满足任一条件即可 | 探索多个元素/载体 |
| NOT | 排除匹配的结果 | 排除已知噪音品 |

**实现方案**: 每个条件行右侧有逻辑连接符下拉（AND/OR），最外层有一个全局组合逻辑开关。NOT 通过"排除此条件"按钮切换，不参与 AND/OR 组合，独立作为排除层。

#### 查询参数扩展

现有竞品查询 API（`/api/v1/competitor-products/search`）需要扩展：

```
GET /api/v1/competitor-products/search
  ?marketplace=UK
  &bsrId=kitchen
  &filterGroups=[                          ← 新增：筛选组
    {
      "logic": "AND",
      "conditions": [
        {"type": "element", "op": "contains", "value": "Highland Cow"},
        {"type": "carrier", "op": "contains", "value": "Metal Signs"}
      ]
    }
  ]
  &excludeGroups=[                         ← 新增：排除组
    {
      "conditions": [
        {"type": "seller", "op": "equals", "value": "Generic Brand"}
      ]
    }
  ]
  &priceMin=5.99&priceMax=8.99             ← 保留兼容
  &bsrMax=80000&ratingMin=4.4&weightMax=250
```

### 4.2 载体利润率计算器

**设计目标**: 帮助用户快速评估不同载体的利润空间。

#### 计算逻辑

```
净利润 = 售价 - 采购成本 - FBA费用 - 亚马逊佣金 - 其他费用
利润率 = 净利润 / 售价 × 100%

其中:
- 售价 = 用户输入（或取模型 priceBand.avg）
- 采购成本 = 用户输入（或取默认估算值）
- FBA费用 = 模型中的 fbaMedian
- 亚马逊佣金 = 售价 × 15%（英国站标准）
- 其他费用 = 运费 + 包装等（用户可自定义）
```

interface ShareState {

  month: string
  batchId: string
  nodeId: number
  bsrId: string
  filters: FilterCondition[]
  view?: string           // 当前视图（表格/对比）

function encodeShareState(state: ShareState): string {
  // 使用 LZ-String 压缩 + Base64 编码
  // 或简单的 JSON + URLSearchParams
  const json = JSON.stringify(state)
  return btoa(encodeURIComponent(json))

function decodeShareState(encoded: string): ShareState {
  return JSON.parse(decodeURIComponent(atob(encoded)))
}

// 复用 selection.ts 的 exportAsins 模式
import * as XLSX from 'xlsx'
import { saveAs } from 'file-saver'

function exportToExcel(data: CompetitorProduct[], columns: Column[], filename: string) {
  const ws = XLSX.utils.json_to_sheet(data, { header: columns.map(c => c.key) })
  const wb = XLSX.utils.book_new()
  XLSX.utils.book_append_sheet(wb, ws, '选品清单')
  const buf = XLSX.write(wb, { bookType: 'xlsx', type: 'array' })
  saveAs(new Blob([buf], { type: 'application/octet-stream' }), filename)
}
