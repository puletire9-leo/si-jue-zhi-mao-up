# 开发流程

## 架构

```
代码在宿主机 → Docker 挂载 → 容器内运行 → 改代码自动生效
```

## 服务热更新

| 服务 | 代码位置 | 热更新机制 | 生效时间 |
|------|----------|-----------|---------|
| 前端 | `frontend/` | Vite HMR | 即时 |
| Python 后端 | `backend/app/` | uvicorn --reload | 即时 |
| Java 后端 | `java-backend/` | DevTools 重启 | ~15-30s |

## 启动命令

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

## 端口映射

| 服务 | 端口 |
|------|------|
| 前端 | localhost:8179 |
| Python 后端 | localhost:8090 |
| Java 后端（产品） | localhost:8002 |
| Java 后端（用户） | localhost:8001 |
| MySQL | localhost:3307 |
| Redis | localhost:6379 |

## 开发时

1. 改前端代码 → 浏览器自动刷新
2. 改 Python 代码 → 自动重载
3. 改 Java 代码 → 自动编译重启（控制台会打印重启日志）
4. 不需要手动重启容器

## 新增功能模块（即插即用）

新功能页面用模块化方式，**不改 router/sidebar**，放文件夹自动生效：

```
1. 前端：src/modules/xxx/manifest.ts + index.vue
2. 后端：com.sjzm.product.modules.xxx/（Controller/Service/Entity）
3. 后端 Mapper 放 com.sjzm.product.mapper/（被 @MapperScan 覆盖）
```

详见 [frontend/CLAUDE.md](../frontend/CLAUDE.md) 和 [java-backend/CLAUDE.md](../java-backend/CLAUDE.md) 的模块化规则。

## 注意事项

- Docker 仅作运行环境，代码通过 volume 挂载
- Java 后端依赖 Maven 缓存卷 `java-m2`，首次启动需下载依赖
- 容器间通信用 Docker 容器名（如 `dev-backend`、`java-product`）
- Vite 代理配置在 `frontend/vite.config.js`，区分 Java 和 Python 后端路由
