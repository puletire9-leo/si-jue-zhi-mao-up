## 背景：四层架构 (定稿)

最终架构确认：

```
competitor_products (329K 原始行, 含变体)
    ↓ 清洗 (A-scheme 去变体)
```

- 清洗层 = `competitor_products_clean` 物化表 + 每周增量刷新

## 阶段 1：发现变体污染 (最重要)

**问题**：卖家精灵 API 将父 ASIN 的销量/IPR/BSR 复制给所有变体子 ASIN。
**后果**：DE 数据中 64% 的行是重复值（如 200 个子 ASIN 都显示 "月销 200"）。
**发现路径**：

1. 随手 `SELECT units, bsr FROM competitor_products WHERE asin IN (...)` 发现同父 ASIN 下 units/bsr 全部相同
2. `SELECT COUNT(*) / COUNT(DISTINCT ...)` 确认 64% DE 数据污染
3. 推及 fashion 类目更严重（60-90% 重复）

**排查过的品类**：
| 品类 | 重复率 |
|------|--------|
| DE 全量 | 64% |
| DE Tops & Blouses | 60% |
| DE jackets | ～20% |
| DE fashion 综合 | 60-90% |
| UK/US 推测类似但未精确统计 |

## 阶段 2：数据清洗层 — competitor_products_clean

### 2a 方案演进

| 版本 | 方案 | 结果 |
|------|------|------|
| v1 | CREATE VIEW + ROW_NUMBER | 28 分钟 + OOM (MySQL killed) |
| v2 终版 | 物化表 + 批次 INSERT | **17 秒** 完成 329K 行 |

### 2b 去重逻辑 (A-scheme)

```sql
ROW_NUMBER() OVER (
  PARTITION BY marketplace, effective_week_tag,
    COALESCE(parent_asin, asin)    -- 同一变体系
  ORDER BY listing_days DESC, units DESC  -- 上架最久 + 销量最高代表
) = 1
```

- 取变体族中 **上架时间最久** 的那个 → 新品榜/基线最公道的代表
- 同 listing_days 则取 units 最高的
- 非变体 (parent_asin IS NULL) 不受影响

### 2c 增量刷新

**每周 2 次导入流程**：
```
导入CSV → AsinImportService.DONE hook
    → ScoringService.updateWeekTags()  [返回 weekTag]
    → CleanLayerService.cleanWeekBatch(marketplace, weekTag) [增量刷干净表]
```

- `cleanWeekBatch()`：按 marketplace × week_tag 只处理本周新数据
- `refreshByEffectiveWeekTag()`：处理 legacy 数据 (month-W00 格式)

### 2d 分批次策略

防 OOM：全表 329K 行拆成 11 个批次（按 marketplace × effective_week_tag 分组），最小批次优先跑，**17 秒完成**。

**Java 文件** (8 个)：

**核心 SQL** (百分位 + 置信度)：
```sql
SELECT
  PERCENT_RANK() OVER (PARTITION BY marketplace, bsr_id, age_bucket
    ORDER BY units) AS units_p,
  PERCENT_RANK() OVER (PARTITION BY marketplace, bsr_id, age_bucket
    ORDER BY bsr) AS bsr_p,
  -- 置信度逻辑:
  CASE WHEN COUNT(*) >= 100
       AND MAX(units_p50) <> MAX(units_p75)  -- 未 collapse
    THEN 'high'
  ...
  END AS confidence
```

**置信度规则**：
| 条件 | 置信度 |
|------|--------|
| ≥100 samples + 无 collapse | high |
| ≥50 samples | mid |
| <50 或 P50=P75=P90 | low (collapse 检测) |

**M04 结果** (geji_analysis 全量验证)：
- **DE**: 24 buckets
- **UK**: 10 buckets
- **US**: 17 buckets
- 合计 51 buckets，16,537 ASINs 已打标签
