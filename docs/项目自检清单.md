## 六、操作规范速查

### 开发环境常用命令

```powershell
# 启动/停止
docker compose -f docker-compose.dev.yml up -d
docker compose -f docker-compose.dev.yml down

# 查看状态
docker compose -f docker-compose.dev.yml ps

# 查看日志
docker compose -f docker-compose.dev.yml logs --tail 50 java-product

# 重启单个服务
docker compose -f docker-compose.dev.yml restart frontend
docker restart java-product

# Java 代码更新（⚠️ 禁止 mvn clean！）
docker exec java-product mvn install -pl sjzm-product -am -DskipTests -q
docker restart java-product

# Python 代码更新
docker compose -f docker-compose.dev.yml restart backend

# 前端代码更新
# Vite HMR 自动热重载，无需手动操作
```

### 紧急恢复

```powershell
# app.jar 丢失恢复
Copy-Item java-backend/sjzm-product/target/sjzm-product-1.0.0-SNAPSHOT.jar java-backend/sjzm-product/target/app.jar
Copy-Item java-backend/sjzm-gateway/target/sjzm-gateway-1.0.0-SNAPSHOT.jar java-backend/sjzm-gateway/target/app.jar
Copy-Item java-backend/sjzm-user/target/sjzm-user-1.0.0-SNAPSHOT.jar java-backend/sjzm-user/target/app.jar

# 容器不断重启排查
docker compose -f docker-compose.dev.yml logs --tail 20 java-product
docker compose -f docker-compose.dev.yml stop java-product
```

### MySQL 直连

```powershell
# 开发环境
docker exec dev-mysql mysql -usijue -psijue123456 sijuelishi_dev -e "SQL"

# 生产环境
docker exec prod-mysql mysql -usijue -psijue123456 sijuelishi -e "SQL"
```
