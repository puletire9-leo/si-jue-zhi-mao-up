# 通过 Browse Node ID 获取 Amazon 子类目搜索结果页流程

Amazon 每个子类目都有对应的 **Browse Node ID（简称 Node ID / BSR ID）**。
通过修改固定链接中的子类目 ID，可以直接进入该子类目的商品搜索结果页，用于后续选品分析、数据采集和竞品分析。

## 操作步骤

### 第一步：获取目标子类目的 Node ID

1. 进入 Amazon 目标站点。
2. 找到需要分析的子类目。
3. 进入该子类目的 **BSR（Best Sellers Rank）榜单页面**。
4. 查看浏览器地址栏，找到该子类目对应的 **Node ID** 并复制。

例如：

子类目：

**Bath Rugs（浴室地垫）**

对应 Node ID：

```
1063242
```

> 注意：
>
> * 一级大类目前通常无法查看 TOP100 以后的商品数据。
> * 建议选择具体的二级、三级或更细分子类目进行分析。
> * 不同国家站点的 Node ID 完全独立，不能混用。

---

### 第二步：替换搜索链接中的 Node ID

Amazon 子类目搜索结果页链接格式：

美国站：

```
https://www.amazon.com/s?rh=n:NodeID&fs=true
```

只需要将 `NodeID` 替换为目标子类目的 Node ID 即可。

例如：

Bath Rugs 子类目：

Node ID：

```
1063242
```

替换后：

```
https://www.amazon.com/s?rh=n:1063242&fs=true
```

进入后，即可查看该子类目的商品列表。

---

## 第三步：切换不同国家站点

不同 Amazon 国家站点，需要使用对应的网址后缀：

| 国家 | 站点        | 链接格式         |
| -- | --------- | ------------ |
| 美国 | Amazon US | amazon.com   |
| 英国 | Amazon UK | amazon.co.uk |
| 德国 | Amazon DE | amazon.de    |

例如同一个操作逻辑：

### 美国站

```
https://www.amazon.com/s?rh=n:1063242&fs=true
```

### 英国站

```
https://www.amazon.co.uk/s?rh=n:1769594031&fs=true
```

### 德国站

```
https://www.amazon.de/s?rh=n:4339564031&fs=true
```

---

## 重要注意事项

### 1. Node ID 不同国家不能混用

Amazon 每个国家站点拥有独立的分类体系：

例如：

| 类目        | 美国站 Node ID | 英国站 Node ID | 德国站 Node ID |
| --------- | ----------- | ----------- | ----------- |
| Bath Rugs | 1063242     | 1769594031  | 4339564031  |

即：

```
美国 Node ID ≠ 英国 Node ID ≠ 德国 Node ID
```

必须使用对应国家站点自己的 Node ID。

---

### 第四步：翻页查看更多商品

进入子类目搜索页后，可以通过修改 `page` 参数查看后续页面。

第一页：

```
https://www.amazon.com/s?rh=n:1063242&fs=true&page=1
```

第二页：

```
https://www.amazon.com/s?rh=n:1063242&fs=true&page=2
```

第三页：

```
https://www.amazon.com/s?rh=n:1063242&fs=true&page=3
```

以此类推。

通常抓取：

```
page=1~10
```

即可获得该子类目前约 400 个商品数据，用于：

* 爆款分析
* 价格区间分析
* 评论数量分析
* 图片元素分析
* 竞品筛选
* AI 选品模型训练

---

## 最终流程总结

```
确定目标子类目
        ↓
进入BSR榜单页面
        ↓
获取该国家站点 Node ID
        ↓
替换搜索链接中的 Node ID
        ↓
进入子类目搜索结果页
        ↓
修改 page 参数翻页
        ↓
采集TOP商品数据
        ↓
进行选品分析
```

核心规则：

**Node ID 决定类目，国家站点决定链接，两者必须匹配。**
