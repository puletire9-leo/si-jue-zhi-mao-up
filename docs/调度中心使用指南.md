# 调度中心使用指南

> 最后更新: 2026-06-11

## 启动

```bash
cd /mnt/f/项目/调度中心
.venv/bin/python -m uvicorn dispatch_center.web.server:app --host 0.0.0.0 --port 8101
```

Web: `http://localhost:8101`

## 工作流

```
1. 写提示词    → 相对路径，边界清晰
2. 启动任务    → Web Dashboard 或 API（仅 opencode）
3. 监控进度    → ▶ 实时按钮看终端输出
4. 审查报告    → 📋 报告按钮看完成报告
5. 确认/重试   → 通过则保留沙盒，失败则看错误重试
```

## 关键规则

### 路径必须用相对路径
```
✅ 读文件 frontend/src/xxx.vue
❌ 读文件 /mnt/f/项目/si-jue-zhi-mao-up/frontend/src/xxx.vue
```

### Agent 禁止的操作
- 删文件、docker、git、系统配置、安装软件

### 报告 = 完成标志
- agent 不写报告 → `NO_REPORT` → 任务不算完成
- 主模型只读报告，不读原始输出

## 状态含义

| Status | 含义 |
|--------|------|
| `reported` | ✅ 完成并生成报告 |
| `done` | ⚠️ 完成但无报告 |
| `no_report` | ⚠️ 退出0但未写报告 |
| `failed` | ❌ 异常退出 |
| `running` | 执行中 |

详见: `docs/调度中心报告规范.md`, `/mnt/f/项目/调度中心/CLAUDE.md`
