# 理实开品工作流

---

## 一、流程总览

```
每日新品发现 → 快速筛选 → 竞品分析 → 利润核算 → 选品决策 → 开品执行
     ↑
     └── 每日循环，以日为单位
```

**核心原则：比别人早发现、早判断、早行动。目标从发现到上架10天内。**

---

## 二、每日新品发现

### 2.1 数据采集（每日08:00自动执行）

| 数据源 | 采集内容 | 判断"新"的依据 |
|--------|---------|---------------|
| 郑总店铺 | 每日新增ASIN | 对比昨日数据，新出现=新品 |
| 竞品店铺（3-5个） | 每日新增ASIN | 同上 |
| BSR榜单 | TOP100变化 | 对比昨日，新进入=新品 |
| New Releases榜单 | 亚马逊新品榜 | 直接抓取 |
| 关键词趋势 | 搜索量变化 | 7日涨幅>50%=异常信号 |

### 2.2 新品判断条件

| 条件 | 说明 |
|------|------|
| 上架时间 ≤ 30天 | 最核心指标 |
| 评论数 ≤ 50 | 越少越新 |
| BSR排名快速上升 | 需求验证 |
| 多个竞品同时上 | 赛道热 |
| 搜索量突增 | 需求端验证 |

### 2.3 新品信号分级

| 级别 | 信号 | 响应 |
|------|------|------|
| 🔴 紧急 | 郑总+3个竞品同时上同一类产品 | 当天决策，立即行动 |
| 🟡 重要 | BSR新品榜出现多个同类产品 | 当天分析，次日决策 |
| 🟢 一般 | 单个竞品上了新品 | 记录观察，不急 |

### 2.4 每日数据表结构

| 字段 | 说明 |
|------|------|
| 发现日期 | 今天发现的 |
| ASIN | 产品唯一标识 |
| 来源 | 郑总店铺/竞品店铺/BSR/New Releases/关键词突增 |
| 产品标题 | 产品名称 |
| 子类目 | 所属类目 |
| 首次出现时间 | 上架日期 |
| 当前售价 | €X.XX |
| 当前月销 | 估算月销 |
| 当前评论数 | 评论数 |
| BSR排名 | 当前排名 |
| 排名变化 | 对比昨日 |
| 7日销量趋势 | 上升/平稳/下降 |

## 三、快速筛选

### 3.1 排除禁止类目（19个）

**数字/虚拟类：** Apps & Games、Digital Music、Kindle Store、Prime Video、Software、Gift Cards

**电子类：** Electronics & Photo、Computers & Accessories、Amazon Devices & Accessories

**大型/重型：** Large Appliances、Lighting

**媒体类：** Books、CDs & Vinyl、DVD & Blu-ray

**特殊资质：** Grocery、Musical Instruments & DJ、Amazon Renewed、New Finds、PC & Video Games

### 3.2 排除不达标产品

| 条件 | 标准 | 不达标 |
|------|------|--------|
| 重量 | ≤ 300g | 排除 |
| 最大尺寸 | ≤ 33 × 23 cm | 排除 |
| 高度 | ≤ 6cm | 排除 |
| 售价 | €5.99 – €16.99 | 排除 |
| 月销量(父体) | ≥ 100 | 排除 |

### 3.3 数据清洗

| 处理 | 说明 |
|------|------|
| 去重 | 同一父体只保留一条 |
| 合并变体 | 子体销量汇总到父体 |
| 补充字段 | 从卖家精灵补充缺失数据 |
| 标记来源 | 标记数据来源 |

**输出：** 候选清单（留存率约20-30%）

## 四、竞品分析

### 4.1 竞争强度评估

| 指标 | 怎么算 | 判断标准 |
|------|--------|---------|
| 头部集中度 | TOP10销量占比 | >60%说明头部垄断 |
| 评论门槛 | TOP10平均评论数 | <500易进入，>2000难进入 |
| 新品机会 | 上架<1年产品占比 | >30%说明市场未固化 |
| 品牌分布 | TOP10中大品牌数 | >5个大品牌说明难进入 |

### 4.2 差异化分析

| 维度 | 看什么 | 找什么 |
|------|--------|--------|
| 主图风格 | TOP10主图类型 | 视觉差异化空间 |
| 价格分布 | TOP10价格区间 | 价格带空白 |
| 评分分布 | 差评集中点 | 产品改进机会 |
| 变体策略 | 竞品变体类型 | 裂变方向 |
| 卖点描述 | 五点描述重点 | 差异化卖点 |

### 4.3 市场趋势判断

| 趋势 | 判断方法 | 含义 |
|------|---------|------|
| 上升期 | 新品多+月销增长 | 好机会 |
| 稳定期 | 新品少+排名稳定 | 需差异化 |
| 下降期 | 月销下降 | 谨慎进入 |

**输出：** 机会清单（含竞品分析报告）

## 五、利润核算

### 5.1 成本结构

```
售价（€12.99 举例）
│
├─ 平台费用
│   ├─ 佣金 15% = €1.95
│   └─ FBA配送费（查表）
│
├─ 物流费用
│   ├─ 头程运费（空运¥30-40/kg，海运¥8-12/kg）
│   ├─ 关税（0-12%）
│   └─ 清关/杂费
│
├─ 产品成本
│   ├─ 采购价（1688报价）
│   └─ 包装/标签/贴标
│
├─ 运营费用
│   ├─ 广告费（预留售价10-15%）
│   └─ 退货损耗（预留售价2-3%）
│
└─ 净利润
```

### 5.2 利润率公式

```
净利润率 = (售价 - 平台费用 - 物流费用 - 产品成本 - 运营费用) ÷ 售价 × 100%
```

### 5.3 利润率判断

| 净利润率 | 决策 |
|---------|------|
| ≥ 25% | ✅ 优质 |
| 20-25% | ✅ 可接受 |
| 15-20% | ⚠️ 需优化成本 |
| < 15% | ❌ 不做 |

### 5.4 敏感性分析

每个产品计算：
- 采购成本涨10%，利润率变多少？
- 售价降10%，利润率变多少？
- FBA配送费涨一档，利润率变多少？

**输出：** 利润核算表（含敏感性分析）

## 八、选品池管理

### 8.1 池子分类

| 池子 | 说明 | 处理方式 |
|------|------|---------|
| 待分析 | 今日新发现，还没看 | 当天处理完 |
| 观察中 | 有潜力但不确定 | 每日跟踪数据，3天内决策 |
| 已决策_开品 | 确定要做 | 进入执行流程 |
| 已决策_放弃 | 确定不做 | 记录原因，避免重复 |

### 8.2 每日流程

```
08:00  数据自动采集
        │
        ▼
09:00  生成「每日新品报告」
        ├─ 新品列表
        ├─ 异常信号
        └─ 竞品动态
        │
        ▼
09:30  快速筛选（5分钟/个）
        │
        ▼
10:00  竞品分析+利润核算（15分钟/个）
        │
        ▼
11:00  决策
        ├─ 值得跟 → 选品池
        ├─ 观察 → 标记，明日再看
        └─ 放弃 → 记录原因
        │
        ▼
11:30  选品池管理
        ├─ 新增：今日新发现
        ├─ 晋升：观察期满确认可行
        └─ 淘汰：观察期数据不理想
```

```
Total Score = 0.15*SizeScore + 0.15*VolumeCostScore + 0.20*ProfitScore
            + 0.15*EmotionScore + 0.10*DecorScore + 0.10*FissionScore
            + 0.05*CultureScore + 0.10*MarketScore
```
