# 本地数据库家底清单与「删 / 留 / 整合」判定

> 生成：2026-08-13。对象：Docker 生产库 `sijuelishi`（124 张表，约 8.5 GB）。
> 目的：摸清家底，逐表定去留，作为后续「数据库统一到 RDS ai_platform」工程的家底基线。
> 依据：运行库真实台账（行数/大小）× Java 78 张表引用 × Python 引用 × 代码冗余分析（见 `艾为系统/分析/数据库设计对比与优化分析.md`）× 领星存疑表实地对账。

## 一、判定标准

- **留**：代码（Java/Python）在用，或空表但属活跃功能骨架。
- **删**：备份表 / 影子表 / 代码零引用的废弃表。
- **整合**：同类可合并或有冗余副本，需人工决策合并方式。
