## 一、核心思想

> **09告诉你"做什么品"，10告诉你"谁在做"，11告诉你"怎么做进去"。**

竞品差异化分析回答的是：选定品类后，哪个价格带有空白？现有竞品弱在哪？我们用什么角度切入？

## 二、价格带分析（含FBA配送费）

### 2.1 四档价格带

**已确认决策**：固定区间，£4.99-16.99范围。

| 价格带 | 区间 | 特征 | 策略建议 |
|--------|------|------|---------|
| **低利润带** | £4.99-5.99 | 利润薄，FBA费占比高 | 慎入，除非有成本优势 |
| **适中带** | £5.99-7.99 | 利润还行 | 可以做，需要控制成本 |
| **重点带** | £7.99-9.99 | **轻小件黄金价位** | ⭐优先切入，利润空间最大 |
| **高配送费带** | £9.99-16.99 | 售价高但FBA费也高 | 可以做，但必须算清利润 |

### 2.2 FBA配送费计算

**已确认决策**：竞品分析必须考虑配送费。

配送费参考表见 [配送费.md](../郑总公司分析/配送费.md)。

**计算逻辑**：

```
每个商品的真实利润 = price - fba(表中已有) - 估算采购成本
                   ≈ price - fba - (price × 0.25~0.35)   // 采购成本按售价25-35%估算
```

**关键**：系统 competitor_products 表中已有 `fba` 和 `profit` 字段，直接使用。如果 `profit` 为空，按上述公式估算。

### 2.3 价格带 × FBA费交叉分析

每个品类输出以下交叉矩阵：

| 价格带 | 商品数 | 占比 | 均利润£ | FBA占比 | 竞争密度 | 机会判断 |
|--------|-------|------|--------|--------|---------|---------|
| £4.99-5.99 | 45 | 18% | £32 | 32% | 高 | 利润薄，竞争多 |
| £5.99-7.99 | 82 | 33% | £55 | 25% | 中 | 可以做 |
| **£7.99-9.99** | **38** | **15%** | **£78** | **20%** | **低** | **⭐空白机会** |
| £9.99-16.99 | 85 | 34% | £85 | 18% | 高 | 利润好但竞争大 |

**核心输出**：找到"利润高 + 竞争少"的价格带空白。

### 2.4 假数据过滤

**已确认问题**：商品重量和体积数据可能不真实。

假数据特征（规则过滤）：

| 假数据模式 | 示例 | 判定规则 |
|-----------|------|---------|
| 整数异常 | weight=100g, dimension=10×10×1cm | 重量为整百且尺寸全为整数 |
| 尺寸不合理 | 20×15×2.5cm 但 weight=1000g | 密度超出合理范围 |
| 缺失值 | weight/dimension 为NULL | 无法计算FBA费 |
| 统一值 | 店铺所有商品同一weight | 批量填充的假数据 |

**处理策略**：
- 假数据商品：FBA费用按品类中位数估算，不参与精确利润计算
- 真实数据商品：正常计算，权重更高
- 标记字段 `weight_reliability`：high / low / unknown

## 三、5维差异化分析

### 3.1 维度总览

| # | 维度 | 数据来源 | 分析目标 |
|---|------|---------|---------|
| D1 | **价格带空白** | price, profit, fba | 哪个价位竞争最少 |
| D2 | **Listing质量差距** | rating, ratings_rate, video, ebc | 现有竞品运营有多烂 |
| D3 | **评论弱点** | ratings, ratingsCv | 评论壁垒多高、质量多差 |
| D4 | **变体策略** | variations, parent_asin | 变体多还是少好 |
| D5 | **品牌定位** | brand, seller_name | 有没有品牌空白 |

### 3.2 D1 价格带空白分析

**输入**：品类内所有商品，按2.1的四档价格带分组。

**计算**：

| 指标 | 计算方式 | 含义 |
|------|---------|------|
| 价格带商品数 | 该价格带内商品总数 | 竞争密度 |
| 价格带均利润 | AVG(profit) | 能赚多少 |
| 价格带新品占比 | listing_days≤90的比例 | 新品进入难度 |
| 价格带成功率 | 新品BSR<10万的比例 | 新品能不能活 |

**空白判断**：

```
空白价格带 = 商品数 < 品类中位数×0.5  // 竞争少于平均的一半
           AND 均利润 > 品类中位数      // 但利润不差
           AND 新品成功率 > 30%         // 新品能活
```

### 3.3 D2 Listing质量差距分析

**已确认决策**：先用已有数据，不引入额外数据源。

| 指标 | 数据来源字段 | 计算方式 | 含义 |
|------|-------------|---------|------|
| 低评分比例 | rating | rating < 4.0 的商品占比 | 产品质量差的比例 |
| 低评论率比例 | ratings / units | ratings_rate < 2% 的占比 | 用户满意度低的比例 |
| 无视频比例 | video | video IS NULL 的占比 | 没做视频的竞品 |
| 无A+比例 | ebc | ebc IS NULL 的占比 | 没做A+页面的竞品 |
| **综合运营差距** | 以上综合 | 满足≥2项条件的占比 | 运营水平低=我们有超越空间 |

**输出**：运营差距 > 50% = "该品类大量竞品运营水平低，做好运营即可超越"

### 3.4 D3 评论弱点分析

| 指标 | 数据来源字段 | 计算方式 | 含义 |
|------|-------------|---------|------|
| 评论壁垒 | ratings | TOP10均评论数 | >2000=高壁垒 |
| 评论壁垒(价格带级) | ratings | 目标价格带TOP5均评论数 | 我们切入的价格带的壁垒 |
| 评论一致性 | ratingsCv | 品类平均ratingsCv | 高=质量不稳定，有机会 |
| 低评论热销品 | ratings + units | ratings<50 AND units>中位数 | 不需要评论也能卖=我们可以 |

**关键洞察**：找到"低评论但高销量"的产品，证明该品类不依赖评论积累。

### 3.5 D4 变体策略分析

| 指标 | 数据来源字段 | 计算方式 | 含义 |
|------|-------------|---------|------|
| 均变体数 | variations | 品类均变体数 | 竞品普遍做几个变体 |
| 少变体成功品 | variations + units | variations≤3 AND units>中位数 | 少变体也能卖好 |
| 多变体垄断者 | variations + parent_asin | 单父体变体>10且BSR<5万 | 多变体大卖家 |

**策略建议**：
- 均变体≤3 → 建议1-3个变体切入（成本低）
- 均变体>5 → 需要多变体策略（颜色/尺寸/套装）

### 3.6 D5 品牌定位分析

| 指标 | 数据来源字段 | 计算方式 | 含义 |
|------|-------------|---------|------|
| 目标价格带品牌数 | brand | 目标价格带unique_brands | 品牌竞争密度 |
| 无品牌占比 | brand | brand IS NULL 的比例 | 白牌机会 |
| 中国卖家占比 | seller_nation | seller_nation='CN' 的比例 | 供应链端是否已打通 |
| 头部品牌份额 | brand + units | TOP3品牌占总销量的比例 | >60%=品牌垄断 |

## 四、差异化切入角度推荐

### 4.1 5种切入角度

根据5维分析结果，推荐最适合的切入角度：

| 切入角度 | 触发条件 | 说明 |
|---------|---------|------|
| **价格空白切入** | D1发现空白价格带 | 直接瞄准竞争少的价位 |
| **运营超越切入** | D2运营差距>50% | 做好视频/A+/主图即可超越 |
| **低评论快启动** | D3存在低评论热销品 | 不需要评论积累，新品即可卖 |
| **变体差异化** | D4少变体成功品多 | 用差异化变体（独特颜色/组合）切入 |
| **白牌替代** | D5无品牌占比>30% | 不需要品牌建设，直接白牌竞争 |

### 4.2 切入角度优先级

```
优先级排序逻辑：
1. 有价格空白 → 首选（最直接的竞争优势）
2. 运营差距大 → 次选（投入小回报快）
3. 低评论快启动 → 第三（降低起步门槛）
4. 变体差异化 → 第四（需要供应链配合）
5. 白牌替代 → 第五（长期竞争力弱）
```

### 4.3 与08品类原型的联动

不同品类原型偏好不同的切入角度：

| 品类原型 | 优先切入角度 | 原因 |
|---------|-------------|------|
| DA 装饰艺术 | 运营超越 > 变体差异化 | 装饰品靠视觉，做好图就能赢 |
| FH 功能家居 | 价格空白 > 运营超越 | 功能品看性价比 |
| FP 时尚个人 | 变体差异化 > 白牌替代 | 时尚品靠款式多样 |
| TN 趋势潮流 | 低评论快启动 | 趋势品不靠评论积累 |
| PE 派对活动 | 价格空白 > 变体差异化 | 派对品看价位和款式丰富度 |
| PS 纸品文具 | 价格空白 > 运营超越 | 文具利润薄，价格是关键 |

## 五、输出格式

### 5.1 结构化字段

每个品类×价格带组合输出：

| 字段 | 类型 | 说明 |
|------|------|------|
| category | VARCHAR | 品类 |
| price_band | VARCHAR | 价格带（low/ok/key/high） |
| product_count | INT | 该价格带商品数 |
| avg_profit | DECIMAL | 均利润 |
| fba_ratio | DECIMAL | FBA费占比 |
| blank_opportunity | BOOLEAN | 是否为空白机会 |
| listing_gap_score | INT(0-100) | Listing质量差距分 |
| review_barrier_score | INT(0-100) | 评论壁垒分（低=壁垒低） |
| variant_strategy | VARCHAR | simple/diverse/monopoly |
| brand_density | DECIMAL | 品牌密度 |
| entry_angle | VARCHAR | 推荐切入角度 |
| confidence | DECIMAL | 置信度 |

### 5.2 LLM解读

```
你是跨境电商选品专家。以下是品类"{category}"在UK站的竞品差异化分析数据：

## 价格带分析
{price_band_table}

## 5维差异化数据
{diff_analysis_table}

## 品类原型：{archetype}（{archetype_desc}）

请输出差异化切入建议：
1. 推荐切入的价格带及理由
2. 推荐切入角度（价格空白/运营超越/低评论快启动/变体差异化/白牌替代）
3. 该角度的具体执行建议（做几个变体？主图什么风格？定价策略？）
4. 预估利润空间
5. 风险提示

输出JSON：
{
  "target_price_band": "key",
  "price_range": "£7.99-9.99",
  "entry_angle": "运营超越",
  "execution": "建议3个变体，主图走简约北欧风，定价£8.99",
  "estimated_profit": "£72-85",
  "risks": ["风险1", "风险2"],
  "confidence": 0.8
}
```

## 六、触发机制

**已确认决策**：C. 两者都要

### 6.1 自动触发（跟随09测品推荐）

```
09蓝海雷达输出测品推荐
    │
    ▼
对每个推荐ASIN所属品类，自动触发差异化分析
    │
    ▼
生成该品类的"切入角度建议"
    │
    ▼
附加到09品类机会卡中
```

### 6.2 手动触发（用户主动分析）

用户在商品树页面或选品列表中，点击任意品类/ASIN的"差异化分析"按钮：
- 输入：品类名或ASIN
- 输出：完整的5维差异化报告 + 切入建议

### 6.3 与10卖家画像的联动

```
10卖家画像发现：
  "wuzhengxiong 在 Storage > Cosmetic Bags 表现突出（S级卖家）"
    │
    ▼
自动触发该品类的差异化分析：
  "£7.99-9.99 价格带空白，运营差距62%，建议3变体切入"
```

## 八、完整算法链路总结

```
01 硬筛选 → 02 AI评分 → 07 动态基线 → 08 品类权重
    │
    ▼
09 蓝海发现（品类机会雷达 + 测品推荐）
    │
    ├─→ 10 卖家画像（聪明卖家在做什么）
    │       │
    │       ▼
    │   品类热度 + 跟品信号
    │       │
    ▼       ▼
11 竞品差异化（怎么切入）
    │
    ├─→ 价格带空白（含FBA费）
    ├─→ Listing质量差距
    ├─→ 评论弱点
    ├─→ 变体策略
    └─→ 品牌定位
    │
    ▼
最终输出：品类 + 价格带 + 切入角度 + 测品ASIN + 预估利润
```
