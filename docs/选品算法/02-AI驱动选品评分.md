# AI驱动选品评分 — 软维度实现方案

> 本文档聚焦8维评分模型中"软维度"（情绪价值/装饰价值/裂变能力/欧洲文化匹配度）的AI实现方案，强耦合现有系统的CLIP、Qdrant和混元大模型能力。

---

## 一、问题定义

8维评分模型中，4个硬维度（轻小件/体积成本/利润/市场容量）可通过SQL直接计算，覆盖55%权重。

4个软维度（情绪价值/装饰价值/裂变能力/欧洲文化匹配度）覆盖45%权重，**无法从结构化数据直接提取**——需要AI来"理解"商品。

### 核心矛盾

- 候选池可能有 **数千条** 商品
- 逐条调LLM分析 = 慢+贵
- 必须找到一种方式：**用少量AI标注覆盖大量商品**

---

## 二、解决方案：种子标注 + 向量传播

### 核心思路

```
LLM标注200条种子商品 → 提取图片向量 → Qdrant相似搜索 → 标签传播到全量
```

这不是"用AI分析每一条商品"，而是"用AI标注少量样本，然后让向量相似度去传播"。

### 为什么可行

1. **图片是选品软维度的最强信号**——情绪、装饰、裂变、文化匹配，看一张图就知道
2. **CLIP模型已经部署**——512维向量，能捕获语义级图片相似度
3. **Qdrant已经部署**——毫秒级向量检索
4. **相似商品大概率有相似的选品属性**——两个长得差不多的墙面装饰，情绪/装饰/裂变评分应该接近

### 置信度衰减

标签传播不是"复制粘贴"，置信度随相似度衰减：

```
传播置信度 = 种子置信度 × 图片相似度
```

| 相似度 | 种子置信度 | 传播置信度 | 可信度 |
|-------|-----------|-----------|-------|
| 0.92 | 0.8 | 0.74 | 高 |
| 0.85 | 0.8 | 0.68 | 中高 |
| 0.75 | 0.8 | 0.60 | 中 |
| <0.65 | 0.8 | <0.52 | 不可信，需单独分析 |

## 三、第1步：种子商品标注

### 选种策略

从候选池（MODE1/MODE2）中选取200条种子商品：

| 策略 | 数量 | 目的 |
|------|------|------|
| 按品类分层随机抽样 | 150条 | 覆盖所有主要品类（Wall Art/Card/Mug...） |
| 高BSR样本 | 30条 | 学习"卖得好"的特征 |
| 低BSR样本 | 20条 | 学习"卖不好"的反面特征 |

每个品类至少3条种子，确保品类内多样性。

### LLM标注Prompt

对每条种子商品，输入以下信息给混元大模型：

```
你是一个跨境电商选品专家。请分析以下商品，给出4个维度的评分（0-10分）。

商品标题：{title}
类目：{node_label_path}
价格：{price}
月销：{units}
BSR：{bsr}

请严格按以下标准评分：

## 情绪价值（0-10分）
商品是否能激发积极情感反应？
- 9-10分：强情绪触发（励志语录、幽默文案、温馨家庭主题）
- 7-8分：中等情绪触发（风景画、抽象艺术、节日装饰）
- 5-6分：弱情绪触发（普通收纳盒、简单挂钩）
- 0-4分：无情绪触发

## 装饰价值（0-10分）
商品是否主要用于装饰空间？
- 9-10分：纯装饰品（墙面画、墙贴、摆件）
- 7-8分：兼具装饰和实用功能（装饰性收纳、创意灯具）
- 5-6分：实用为主但有设计感（造型独特的挂钩、彩色文件夹）
- 0-4分：纯实用，无装饰属性

## 裂变能力（0-10分）
这类商品是否容易通过更换图案/颜色生成大量SKU？
- 9-10分：极强裂变（同一产品20+图案变体：墙画、T恤、马克杯）
- 7-8分：中等裂变（5-20变体：贴纸、收纳盒）
- 5-6分：弱裂变（3-5变体）
- 0-4分：不可裂变（单品无法变体）

## 欧洲文化匹配度（0-10分）
商品是否适合欧洲市场？
- 9-10分：强烈匹配（欧洲元素、英式幽默、德语文化）
- 7-8分：普适性好（自然风景、通用主题、简约设计）
- 5-6分：偏美式但有潜力
- 0-4分：文化不匹配

输出JSON格式：
{
  "emotion": {"score": 0-10, "reason": "一句话理由"},
  "decoration": {"score": 0-10, "reason": "一句话理由"},
  "fission": {"score": 0-10, "reason": "一句话理由"},
  "culture": {"score": 0-10, "reason": "一句话理由"},
  "overall_impression": "一句话总评",
  "confidence": 0.0-1.0
}
```

### 批量处理

- 每次传入5条商品结构化信息，让LLM一次性评估
- 200条种子 = 40次LLM调用
- 总耗时约10-15分钟（可异步，Celery任务）

### 种子存储

新建 `product_ai_labels` 表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| asin | VARCHAR | 关联competitor_products |
| marketplace | VARCHAR | 站点 |
| month | VARCHAR | 月份 |
| label_type | VARCHAR | seed（种子）/ propagated（传播） |
| emotion_score | TINYINT | 情绪价值(0-10) |
| decoration_score | TINYINT | 装饰价值(0-10) |
| fission_score | TINYINT | 裂变能力(0-10) |
| culture_score | TINYINT | 欧洲文化匹配(0-10) |
| confidence | DECIMAL | 置信度(0-1) |
| source_model | VARCHAR | 标注来源（混元大模型/gpt-4） |
| created_at | DATETIME | 标注时间 |

## 四、第2步：图片向量检索

### 现有能力

| 组件 | 状态 | 当前用途 |
|------|------|---------|
| CLIP模型 | 已部署 | 图片编码为512维向量 |
| Qdrant | 已部署 | 向量存储与相似度检索 |
| 混元大模型视觉 | 已部署 | 素材库图片分析 |

### 流程

```
候选池商品
    │
    ▼ 获取商品图片URL（主图）
    │
    ▼ CLIP编码 → 512维向量
    │
    ▼ 写入Qdrant（如已有则跳过）
    │
    ▼ 对每条种子：在Qdrant中搜索top-K相似图片
    │
    ▼ 返回相似商品ASIN列表 + 相似度分数
    │
    ▼ 传播标签（confidence = seed_confidence × similarity）
```

### 覆盖策略

- 每个种子搜索top-20相似图片
- 200个种子 × 20 = 最多4000条传播覆盖
- 去重后预计覆盖1000-2000条商品
- 同一商品被多个种子传播时，取加权平均（按置信度加权）

### 未覆盖商品的兜底

对向量传播未覆盖的商品，使用规则兜底：

```python
# 基于类目路径的启发式规则
def fallback_scoring(node_label_path: str) -> dict:
    path_lower = node_label_path.lower()

    if "wall art" in path_lower or "wall decor" in path_lower:
        return {"emotion": 7, "decoration": 9, "fission": 8, "culture": 7}
    elif "storage" in path_lower or "organizer" in path_lower:
        return {"emotion": 4, "decoration": 4, "fission": 5, "culture": 6}
    elif "card" in path_lower or "greeting" in path_lower:
        return {"emotion": 8, "decoration": 3, "fission": 7, "culture": 6}
    elif "fidget" in path_lower or "toy" in path_lower:
        return {"emotion": 6, "decoration": 2, "fission": 6, "culture": 7}
    elif "mug" in path_lower or "cup" in path_lower:
        return {"emotion": 5, "decoration": 5, "fission": 8, "culture": 6}
    else:
        return {"emotion": 5, "decoration": 5, "fission": 5, "culture": 5}
```

规则评分的置信度固定为0.3（低于种子传播），确保AI标注优先级更高。

## 五、第3步：混元大模型视觉增强（可选）

### 适用场景

对S1级（≥85分）商品，用混元大模型视觉做**二次确认**：

1. 获取商品主图
2. 调用 `tencent_llm_vision_service` 分析图片
3. 将视觉分析结果与种子标注交叉验证
4. 如果偏差>3分，以视觉分析为准更新评分

### 现有视觉服务能力

`backend/app/services/tencent_llm_vision_service.py` 已实现：
- `product_type`：产品类型识别
- `theme`：主题识别
- `elements`：元素提取
- `text_content`：文字内容识别
- `description`：描述生成

### 选品增强的Prompt扩展

```
你是跨境电商选品专家。请分析这张商品图片，评估以下维度：

1. 情绪价值：这个产品能否激发积极情感？（看图案、文案、色彩）
2. 装饰价值：这个产品是否适合装饰空间？（看设计感、材质感、风格）
3. 裂变潜力：这类产品是否容易通过换图案/颜色产生大量变体？（看设计复杂度、图案类型）
4. 欧洲市场适配：这个设计是否适合欧洲消费者审美？（看风格、文化元素）

每个维度0-10分，给出简短理由。
```

### 成本评估

| 方式 | 单价 | 数量 | 总成本 |
|------|------|------|--------|
| 种子标注（文本LLM） | ~0.01元/条 | 200条 | ~2元 |
| 视觉增强（混元Vision） | ~0.05元/张 | S1商品~50条 | ~2.5元 |
| **总计** | | | **~5元** |

极低成本，可每日执行一次。

## 六、品类级AI分析（补充）

### 设计原则（来自品类分析规范）

> AI选品以**品类**为分析单位，而非逐商品分析。

### 品类画像生成

```sql
-- 按node_label_path前两级聚合品类画像
SELECT
  SUBSTRING_INDEX(SUBSTRING_INDEX(node_label_path, ':', 3), ':', -1) AS category_name,
  COUNT(DISTINCT asin) AS total_products,
  AVG(units) AS avg_units,
  AVG(profit) AS avg_profit,
  AVG(bsr) AS avg_bsr,
  AVG(weight_g) AS avg_weight,
  AVG(price) AS avg_price,
  AVG(CASE WHEN listing_days <= 90 THEN 1 ELSE 0 END) AS new_product_ratio,
  COUNT(DISTINCT seller_name) AS unique_sellers,
  COUNT(DISTINCT brand) AS unique_brands,
  AVG(CASE WHEN seller_name LIKE '%cn%' OR seller_name LIKE '%shenzhen%' THEN 1 ELSE 0 END) AS cn_seller_ratio
FROM competitor_products
WHERE marketplace = 'UK' AND month = '2026-05' AND filter_mode != 'FAIL'
GROUP BY category_name
HAVING total_products >= 5
ORDER BY avg_units DESC
```

### LLM批量品类评估

将上述SQL结果（20-50个品类描述）一次性喂给LLM：

```
你是跨境电商选品专家。以下是UK站点主要品类的画像数据。
请对每个品类给出评级（推荐/中性/不推荐），并说明理由。

重点关注：
1. 蓝海信号（新品占比高 + BSR好 + 卖家分散）
2. 利润空间（均利润 + 价格带）
3. 竞争格局（品牌集中度 + 中国卖家占比）
4. 是否符合轻小件+情绪价值+裂变的选品DNA

[品类数据表格]

输出格式：
| 品类 | 评级 | 一句话理由 | 关键风险 |
```

### 品类评级反写

LLM输出的品类评级反写回 `competitor_products` 表，作为选品排序的加权因子。

## 七、与现有AI能力的对接

### 对接矩阵

| 选品需求 | 现有模块 | 对接方式 | 改动量 |
|---------|---------|---------|-------|
| 图片向量化 | `vector_service.py` + CLIP | 复用编码接口，新增"选品"集合 | 小 |
| 向量相似搜索 | `qdrant_repo.py` | 复用search接口，新增传播逻辑 | 中 |
| 种子标注 | 混元大模型（文本） | 新增选品标注Prompt + 批量任务 | 中 |
| 视觉增强 | `tencent_llm_vision_service.py` | 复用视觉分析，新增选品维度 | 小 |
| 批量任务 | Celery + Redis | 新增选品评分定时任务 | 小 |
| 品类聚合 | `CompetitorProductMapper` | 新增品类画像SQL | 小 |

### 关键约束（LLM职责边界）

| 可做 | 不做 |
|------|------|
| 种子标注（200条，批量） | 逐商品分析（6991条） |
| 品类级评估（20-50个品类描述） | 逐品类深度分析 |
| 视觉增强确认（S1级，~50条） | 全量图片分析 |
| 结果解读与报告生成 | 原始数据处理 |
| 蓝海信号解读 | 蓝海信号计算（SQL做） |

**LLM只做"解读"和"标注"，不做"计算"和"遍历"。**
