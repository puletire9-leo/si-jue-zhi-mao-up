# 选品算法 — 动态基线与相对评分

> 解决当前设计的根本性问题：绝对阈值不适用于跨站点、跨品类的选品评分。算法必须“因地制宜”——按(站点×品类)动态计算评分基线。

> **[已确认决策]** 本文档的所有核心方案已全部确认：
> - 评分采用百分位替代绝对阈值
> - 品类基线使用第2级品类（约40个子类目）
> - 硬筛选按站点差异化（UK≥10 / US≥50 / DE≥8）
> - 品类健康度系数(0.6-1.2)作为乘法因子
> - 基线每月随数据导入自动更新

---

## 一、问题：绝对阈值的致命缺陷

### 1.1 当前设计的问题

01文档中的评分标准是**绝对值**：

```
市场容量指数：月销≥3000得10分，2000-3000得8分，1000-2000得6分...
利润指数：利润率≥30%得20分，25-30%得17分...
硬筛选：月销≥100才进入候选池
```

这些阈值来自邓总的UK/DE经验，但存在两个维度的不适用：

### 1.2 站点维度：体量差异巨大

| 站点 | 新品月销基线 | "好"的定义 | 原因 |
|------|------------|-----------|------|
| **US** | 1天20，10天100，30天200 | 月销200+ | 市场体量是UK的5-8倍 |
| **UK** | 月均30-50 | 月销30+ | 邓总店铺数据验证 |
| **DE** | 月均25-40 | 月销25+ | 略小于UK |

同一个"月销100"：
- 在US站 = 普通水平，不算好
- 在UK站 = 优秀，是均值的3倍
- 在DE站 = 非常好

**绝对阈值"月销≥100"在US站放进来太多平庸品，在UK站过滤掉太多好品。**

### 1.3 品类维度：品线之间天差地别

邓总店铺数据（UK站）揭示了品类间的巨大差异：

| 品类 | 均月销 | 均BSR | 均售价 | 均利润 | 特征 |
|------|------:|------:|------:|------:|------|
| **Sunglasses 太阳镜** | 138 | 11.6万 | £6.59 | £71.95 | 高销量，低BSR |
| **Party Supply 派对** | 94 | 16.3万 | £7.21 | £73.36 | 高销量，高利润 |
| **Dog 狗狗用品** | 83 | 11.7万 | £7.35 | £65.58 | 高销量，好BSR |
| **Balloon 气球** | 62 | 16.3万 | £8.37 | £71.49 | 中高销量 |
| **Car Freshener** | 58 | 4.4万 | £5.61 | £68.46 | 蓝海，BSR极好 |
| **Bathroom 浴室** | 50 | 18.1万 | £7.35 | £66.82 | 中等 |
| **Wall Sticker 墙贴** | 48 | 23.3万 | £5.70 | £65.04 | 低客单价 |
| **Card 贺卡** | 43 | 15.6万 | £5.95 | £67.84 | 中等 |
| **Fidget Toy 解压** | 37 | 13.7万 | £8.58 | £67.49 | 新品占比高 |
| **Backpack 双肩包** | 35 | 20.8万 | £10.42 | £70.65 | 高客单价 |
| **Wall Art 墙画** | 30 | 32.2万 | £7.65 | £70.05 | 体量大，BSR差 |
| **Notebook 笔记本** | 12 | 10.2万 | £7.20 | £72.77 | 小众高利润 |

**关键发现**：
- Sunglasses均月销138，Wall Art均月销30 → **4.6倍差距**
- Car Freshener均BSR 4.4万，Wall Art均BSR 32.2万 → **7倍差距**
- Blanket均售价£12.88，Card均售价£5.95 → **2倍差距**

用"月销≥3000得满分"评分：
- Sunglasses品类里几乎没有满分（均月销才138）
- Wall Art品类里更不可能（均月销才30）
- **满分标准对这个品类完全不适用**

用"月销≥100进候选池"：
- Sunglasses品类：大量普通品被放进来
- Wall Art品类：大量好品被过滤掉（均值才30）

### 1.4 结论

**绝对阈值 = 用UK Wall Art的标准衡量一切 = 系统性偏差**

## 二、解决方案：百分位相对评分

### 2.1 核心思路

不跟绝对值比，**跟同类商品比**。

```
一个商品好不好 = 它在(同站点 × 同品类)中排第几
```

### 2.2 百分位评分模型

对每个硬维度，计算商品在**同(站点, 品类)群体**中的百分位排名：

| 百分位 | 含义 | 得分比例 |
|--------|------|---------|
| TOP 10% | 同类中最好的10% | 满分 |
| TOP 25% | 同类中前1/4 | 85% |
| TOP 50% | 同类中上半区 | 65% |
| TOP 75% | 同类中中上 | 40% |
| 后25% | 同类中最差的 | 15% |

### 2.3 各维度应用

#### 市场容量（月销量）

```
传统方式：月销≥3000得10分 → 在UK几乎不可能满分
百分位方式：在UK Wall Art品类中月销排TOP10%得10分 → 月销≥60即可
```

邓总UK数据的推算阈值（以Wall Art 997条为例）：

| 百分位 | 月销估算 | 得分（满分10） |
|--------|---------|--------------|
| TOP 10% | ≥80 | 10 |
| TOP 25% | ≥45 | 8.5 |
| TOP 50% | ≥20 | 6.5 |
| TOP 75% | ≥10 | 4 |
| 后25% | <10 | 1.5 |

而Sunglasses品类的阈值完全不同：

| 百分位 | 月销估算 | 得分（满分10） |
|--------|---------|--------------|
| TOP 10% | ≥300 | 10 |
| TOP 25% | ≥180 | 8.5 |
| TOP 50% | ≥100 | 6.5 |
| TOP 75% | ≥50 | 4 |
| 后25% | <50 | 1.5 |

**同一个"月销100"**：
- 在Wall Art品类 = TOP 10%，得10分（极好）
- 在Sunglasses品类 = TOP 50%，得6.5分（一般）

#### BSR排名

BSR越低越好（排名越靠前），同样是"BSR 15万"：
- 在Wall Art品类（均值32.2万）= TOP 25%，非常好
- 在Car Freshener品类（均值4.4万）= 后25%，很差

#### 利润

利润率是相对通用的指标（不同品类利润率差异不大，邓总数据显示各品类均在£65-78区间），但仍应按品类计算百分位更准确。

#### 价格

不同品类的价格带完全不同：
- Card均售价£5.95
- Blanket均售价£12.88
- 用同一价格区间筛选会错过低价品类的机会

## 三、基线计算引擎

### 3.1 数据模型：category_baselines 表

```
category_baselines
├─ marketplace: UK / DE / US
├─ category_path: 品类路径（node_label_path前2-3级）
├─ month: 数据月份
├─ stats_json: 各维度的统计摘要
│   ├─ units: {p10, p25, p50, p75, p90, mean, std}
│   ├─ bsr: {p10, p25, p50, p75, p90, mean, std}
│   ├─ profit: {p10, p25, p50, p75, p90, mean, std}
│   ├─ price: {p10, p25, p50, p75, p90, mean, std}
│   ├─ ratings: {p10, p25, p50, p75, p90, mean, std}
│   └─ weight_g: {p10, p25, p50, p75, p90, mean, std}
├─ total_products: 该品类商品总数
├─ new_product_count: 90天内新品数
├─ new_product_ratio: 新品占比
├─ updated_at: 计算时间
```

### 3.2 计算时机

```
每日数据导入后
    │
    ▼ 自动触发
基线计算任务（Python/Celery）
    │
    ├─ 按(marketplace, category_path, month)分组
    ├─ 对每组计算各维度的百分位分布
    ├─ 写入 category_baselines 表
    │
    ▼
评分任务
    │
    ├─ 读取 category_baselines
    ├─ 对每个商品：查所属(站点,品类)的基线
    ├─ 计算百分位得分
    └─ 写回 selection_score
```

### 3.3 计算SQL示意

```sql
-- 计算 UK站 Wall Art 品类的月销量百分位
SELECT
  PERCENTILE_CONT(0.10) WITHIN GROUP (ORDER BY units) AS p10,
  PERCENTILE_CONT(0.25) WITHIN GROUP (ORDER BY units) AS p25,
  PERCENTILE_CONT(0.50) WITHIN GROUP (ORDER BY units) AS p50,
  PERCENTILE_CONT(0.75) WITHIN GROUP (ORDER BY units) AS p75,
  PERCENTILE_CONT(0.90) WITHIN GROUP (ORDER BY units) AS p90,
  AVG(units) AS mean,
  STDDEV(units) AS std
FROM competitor_products
WHERE marketplace = 'UK'
  AND month = '2026-05'
  AND node_label_path LIKE '%Wall Art%'
  AND filter_mode != 'FAIL'
```

### 3.4 品类层级选择

品类路径有多层，应该用哪一层做基线计算？

| 层级 | 示例 | 适用场景 |
|------|------|---------|
| 第1级 | Home & Kitchen | 太粗，不同品线混在一起 |
| 第2级 | Home Decor / Kitchen & Dining | **推荐**，品线区分度好 |
| 第3级 | Wall Art / Signs & Plaques | 太细，部分品类数据不够 |

**策略**：优先用第2级，当第2级商品数<20时回退到第1级。

## 四、站点差异化

### 4.1 站点体量系数

不同站点的绝对体量不同，但**百分位已经自动适配了**。

不过，某些决策维度需要站点级的绝对判断：

| 维度 | 是否需要绝对阈值 | 原因 |
|------|---------------|------|
| 月销量评分 | **不需要** | 百分位已适配 |
| BSR评分 | **不需要** | 百分位已适配 |
| 利润评分 | **不需要** | 百分位已适配 |
| 硬筛选（进入候选池） | **需要** | 需要绝对底线 |
| 蓝海指数 | 部分需要 | 品类规模因子需站点调整 |

### 4.2 站点级硬筛选底线

即使使用百分位评分，硬筛选仍需要绝对底线（不能月销1件也进来）：

| 站点 | 月销底线 | 价格区间 | 重量上限 | 依据 |
|------|---------|---------|---------|------|
| **UK** | ≥10 | £4.99-£30 | 300g | 邓总数据：均月销30，底线取1/3 |
| **DE** | ≥8 | €4.99-€30 | 300g | 略低于UK |
| **US** | ≥50 | $4.99-$40 | 300g | 体量5-8倍，底线相应提高 |

**硬筛选用绝对底线（防止垃圾品进入），评分用百分位（区分好品中的好坏）。**

### 4.3 US站特殊处理

US站体量远大于UK/DE，需要独立的硬筛选参数和独立的百分位基线：

```
US站新品表现参考（用户提供的经验值）：
├─ 第1天：20单
├─ 第10天：100单（日均10）
├─ 第30天：200单（月累计）
├─ 月销稳态：200+ / 月
│
└─ US站硬筛选底线：
   ├─ 月销 ≥ 50（UK的5倍）
   ├─ 价格 $4.99-$40（上限更高，US客单价更高）
   └─ 重量 300g（物流约束不变）
```

### 4.4 站点间交叉发现

当一个商品同时出现在多个站点时：

```
同一ASIN在UK和DE都有数据
├─ UK: 月销45, BSR 15万 → UK Wall Art百分位 TOP 15%（极好）
├─ DE: 月销12, BSR 80万 → DE Wall Art百分位 TOP 45%（一般）
│
└─ 交叉分析结论：
   "该品在UK表现远优于DE，建议优先UK站点开品"
```

## 五、品类健康度指数

### 5.1 品类之间也有好坏

百分位评分解决的是"品类内比较"。但我们还需要知道**品类本身好不好**。

一个商品在Wall Art品类排TOP 10% ≠ 一个商品在Car Freshener品类排TOP 10%。

因为Car Freshener品类本身更健康（BSR 4.4万，新品占比62%）。

### 5.2 品类健康度指标

| 指标 | 计算方式 | 含义 |
|------|---------|------|
| 新品活力 | 90天新品数 / 品类总数 | 越高说明赛道越活跃 |
| BSR质量 | 品类均BSR的倒数 | BSR越低（排名越好）品类质量越高 |
| 利润空间 | 品类均利润率 | 赚钱能力 |
| 卖家分散度 | 独立卖家数 / 商品总数 | 越高说明未垄断 |
| 增长趋势 | 本月商品数 / 上月商品数 - 1 | 正增长=赛道在扩张 |

### 5.3 品类健康度 → 评分加权

品类健康度作为一个**乘法因子**影响最终评分：

```
最终选品得分 = 8维评分 × 品类健康度系数

品类健康度系数：
├─ 健康品类（蓝海）：1.1-1.2（加分）
├─ 一般品类：1.0（不加不减）
├─ 衰退品类：0.8-0.9（减分）
└─ 红海品类：0.6-0.7（大幅减分）
```

**举例**：

| 商品 | 8维评分 | 品类 | 品类系数 | 最终得分 |
|------|--------|------|---------|---------|
| A | 80 | Car Freshener（蓝海） | 1.2 | 96 → S1 |
| B | 80 | Wall Art（红海） | 0.8 | 64 → S3 |

**同样80分的商品，因为品类健康度不同，最终决策完全不同。**

### 5.4 与蓝海信号的关系

品类健康度是蓝海信号（03文档 §四）的**细化版本**：
- 蓝海指数：每周自动扫描，发现蓝海品类
- 品类健康度：持续计算，作为评分加权因子
- 蓝海指数高 → 品类健康度系数高 → 品类内商品加分

## 六、新评分公式总览

### 6.1 完整公式

```
selection_score = 8维百分位评分加权总分 × 品类健康度系数

其中：
  8维百分位评分 = Σ(维度权重 × 维度百分位得分)
  
  维度百分位得分 = percentile_rank(商品在该维度上的值, 同站点同品类基线)
  
  品类健康度系数 = f(新品活力, BSR质量, 利润空间, 卖家分散度, 增长趋势)
```

### 6.2 评分流程

```
Step 1: 数据导入
    │
Step 2: 硬筛选（绝对底线，按站点差异化）
    │
Step 3: 计算品类基线（category_baselines）
    │  按(marketplace, category_l2, month)分组
    │  计算各维度的p10/p25/p50/p75/p90
    │
Step 4: 百分位评分（每个商品 vs 同品类基线）
    │  硬维度：units/bsr/profit/price → 查基线表 → 百分位得分
    │  软维度：向量传播（不受影响，仍用CLIP+LLM）
    │
Step 5: 品类健康度系数
    │  计算每个品类的健康度 → 映射为系数(0.6-1.2)
    │
Step 6: 最终得分
    │  selection_score = 8维加权 × 品类系数
    │
Step 7: 等级判定
    └─ S1/S2/S3/X
```

### 6.3 对01文档评分标准的修正

| 维度 | 01文档（绝对值） | 本文档（百分位） |
|------|---------------|----------------|
| 轻小件指数 | ≤100g得15分 | **保留绝对值**（重量是物理约束，不随品类变化） |
| 体积成本指数 | FBA占比≤15%得15分 | **保留绝对值**（FBA占比是成本结构，通用标准） |
| 利润指数 | 利润率≥30%得20分 | **改为百分位**（各品类利润率基线不同） |
| 情绪价值 | CLIP+LLM | 不变 |
| 装饰价值 | CLIP+LLM | 不变 |
| 裂变能力 | CLIP+LLM | 不变 |
| 文化匹配 | CLIP+LLM | 不变 |
| 市场容量 | 月销≥3000得10分 | **改为百分位**（各品类月销基线差4-5倍） |

**结论**：8个维度中，3个改百分位（利润/市场容量 + 可选BSR），2个保留绝对值（轻小件/体积成本），3个不变（AI软维度）。

## 九、核心结论

1. **绝对阈值是错的** [已确认]：不同站点、不同品类的体量差异太大，固定标准必然产生系统性偏差
2. **百分位是解法**：商品跟同(站点×品类)的其他商品比，而不是跟一个绝对数字比
3. **硬筛选仍用绝对底线**：防止垃圾品进入，但底线按站点差异化（UK≥10，US≥50）
4. **品类健康度是乘数**：品类本身的好坏会影响品类内每个商品的最终评分
5. **基线需要动态更新**：每月数据导入后重新计算，随市场变化自动调整

**一句话总结：好品不是"月销多少"，而是"比同类好多少"。**
