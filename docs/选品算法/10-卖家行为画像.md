## 一、核心思想

> **从"这个品好不好"升级到"聪明人在做什么"。**

郑总29家店铺 + competitor_products中的外部卖家 = 天然的选品情报网。

算法要做的不是"告诉你品类数据"，而是"告诉你谁在赚钱、谁在跟进、谁在试错"。

## 二、店铺名单管理

### 2.1 郑总店铺表（deng_zong_shops）

**已确认决策**：维护一份店铺名列表，模型可推荐数据表现好的新店铺，但最终需用户确认。

```
管理流程：
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 现有29家店铺  │ ──→ │ 模型推荐候选  │ ──→ │ 用户确认入库  │
│ (人工维护)    │     │ (数据驱动)    │     │ (人工决策)    │
└──────────────┘     └──────────────┘     └──────────────┘
```

**推荐候选的逻辑**：

系统从 competitor_products 中发现以下特征的外部卖家，推荐为"疑似郑总关联"或"值得关注的聪明卖家"：

| 推荐信号 | 判定条件 | 理由 |
|---------|---------|------|
| 品类高度重叠 | 与郑总店铺品类分布余弦相似度 > 0.8 | 可能在做同样的生意 |
| 新品同步率高 | 近90天新品中>30%与郑总新品品类相同 | 在跟同样的赛道 |
| 数据表现优秀 | 聪明卖家评分 TOP10（见§三） | 选品眼光好，值得学习 |
| 多店铺模式 | 同sellerNation + 相似品类 + 多店铺 | 可能是郑总的新马甲 |

**用户确认后**：写入 deng_zong_shops 表，标记 confirmed = true。

### 2.2 外部卖家分析

**已确认决策**：同时分析 competitor_products 中的外部卖家。

| 分析对象 | 目的 | 输出 |
|---------|------|------|
| 郑总29家店铺 | 内部情报：谁做得好、谁在跟进 | 聪明卖家排名、跟品节奏 |
| 外部卖家 | 竞争情报：谁在抢市场、谁运营好 | 竞品威胁预警、学习对象 |

## 三、聪明卖家综合评分

### 3.1 关键问题：BSR不能直接比较

> **排名看的是大类榜单排名，而每个国家的每个榜单市场不一样，所以排名需要结合销量进行综合判断。**

BSR 10万在英国站 Home & Kitchen 和在德国站 Spielzeug 是完全不同的含义。

**解决方案：市场内标准化**

```
商品实力分 = BSR百分位(同marketplace同类目) × 0.4 + 月销量百分位(同marketplace同类目) × 0.6
```

- BSR百分位：该商品BSR在同marketplace+nodeLabelPath第2级中的百分位排名（越低越好→反转）
- 月销量百分位：该商品units在同marketplace+nodeLabelPath第2级中的百分位排名（越高越好）
- 权重0.4:0.6 — 销量比BSR排名更直接反映真实市场表现

### 3.2 聪明卖家评分（3维度加权）

| 维度 | 计算方式 | 权重 | 含义 |
|------|---------|------|------|
| **A. 选品眼光** | 店铺商品中"实力分"TOP25%的比例 | 35% | 选的品卖得好 = 眼光好 |
| **B. 新品成功率** | 新品(listing_days≤90)中BSR<10万的比例 | 35% | 新品进入后能活 = 选品精准 |
| **C. 盈利能力** | 店铺均利润率的百分位排名 | 30% | 能赚钱 = 模式可行 |

```
聪明卖家得分 = A × 0.35 + B × 0.35 + C × 0.30
```

**评分范围：0-100分，按百分位归一化。**

### 3.3 卖家分级

| 等级 | 得分 | 标记 | 含义 |
|------|------|------|------|
| S | ≥80 | ⭐ | 顶级选品眼光，值得深度学习 |
| A | 60-79 | 🏆 | 优秀卖家，新品值得跟进 |
| B | 40-59 | 📊 | 中等水平，部分品类有优势 |
| C | <40 | 📋 | 参考价值有限 |

### 3.4 与08品类原型的联动

同一卖家在不同品类原型下可能有不同评级：

```
示例：wuzhengxiong
- 整体评级：A（75分）
- Home & Kitchen 品类：S级（均月销76，BSR 10.2万）
- Fashion 品类：B级（品类分散，没有明显优势）
- Stationery 品类：A级（利润率高）
```

**输出**：每个卖家不仅有总体评级，还有按品类原型的分项评级。

## 四、品类级跟品节奏分析

### 4.1 分析目标

> "这个品类郑总几家店在做？外部聪明卖家几家在做？"

### 4.2 品类热度矩阵

按品类聚合卖家数据，生成品类热度矩阵：

| 品类 | 郑总店铺数 | 外部S/A级卖家数 | 总卖家数 | 郑总占比 | 聪明卖家密度 | 热度判断 |
|------|-----------|---------------|---------|---------|------------|---------|
| Wall Art | 18/29 | 12 | 45 | 62% | 高 | 🔥 郑总重仓+竞争激烈 |
| Car Freshener | 3/29 | 1 | 8 | 38% | 低 | 🌊 郑总试水+竞争少 |
| Tool | 8/29 | 5 | 22 | 36% | 中 | ⚡ 外部聪明卖家多 |

### 4.3 信号解读规则

| 信号组合 | 判断 | 建议 |
|---------|------|------|
| 郑总多店+聪明卖家多 | 赛道已验证，但竞争加剧 | 需要差异化切入 |
| 郑总多店+聪明卖家少 | 郑总独占优势赛道 | 优先投入 |
| 郑总少店+聪明卖家多 | 外部发现了郑总没重视的机会 | 重点关注，可能是盲区 |
| 郑总少店+聪明卖家少 | 冷门赛道或新品类 | 小批量测试 |

### 4.4 与09蓝海雷达的融合

品类热度矩阵作为09蓝海雷达的补充信号：

```
09蓝海雷达（品类客观数据）
    +
品类热度矩阵（卖家行为数据）
    =
增强的品类机会判断
```

具体融合点：
- 09的 D5卖家分散度 → 结合品类热度矩阵的"聪明卖家密度"
- 09的 D1新品活跃度 → 结合"郑总几家店在做"
- 09品类分型 → "郑总重仓+蓝海" = 最优机会，"郑总无+红海有缝" = 可能的盲区

## 五、产品级跟品节奏分析

### 5.1 分析目标

> "A店先上了这个ASIN，B店30天后跟了" — 追踪产品在不同店铺间的传播路径

### 5.2 跨店铺ASIN追踪

通过 `parent_asin` 和 `title` 匹配（同一产品不同卖家），追踪：

| 追踪维度 | 计算方式 | 选品价值 |
|---------|---------|---------|
| **首发店铺** | 该品类中listing_days最大的卖家 | 谁最先发现这个机会 |
| **跟进延迟** | 第2个卖家的listing_days - 首发的listing_days | 多快有人跟进 = 信号强度 |
| **跟进卖家数** | 同品类中listing_days < 180的卖家数 | 短期内多少人跟进 = 赛道热度 |
| **跟进者质量** | 跟进卖家的聪明卖家评级 | S/A级卖家跟进 = 信号更可靠 |

### 5.3 跟品信号分级

| 信号 | 条件 | 标记 | 含义 |
|------|------|------|------|
| **强跟品信号** | ≥3个S/A级卖家在60天内跟进同一品类 | 🔴 | 聪明人集体看好，立即关注 |
| **中度跟品** | 2个S/A级卖家跟进 | 🟡 | 值得观察 |
| **弱跟品** | 仅1个卖家或C级卖家跟进 | 🟢 | 可能是个人行为 |
| **郑总内部同步** | 郑总≥3家店在90天内上了同品类 | 🔴 | 邓总验证过的赛道 |

### 5.4 产品级输出示例

```
品类：Storage > Cosmetic Bags（UK站）

跟品时间线：
Day 0   → wuzhengxiong 上架 ASIN-A（首个发现者）
Day 15  → BENHUANZPZ 跟进 ASIN-B（相似产品）⭐A级卖家
Day 22  → CLX-UK 跟进 ASIN-C ⭐S级卖家
Day 35  → zhangxiaodonG 跟进 ASIN-D
Day 42  → 外部卖家X跟进 ASIN-E ⭐外部S级卖家

跟品分析：
- 信号强度：🔴 强跟品（3个S/A级卖家42天内跟进）
- 首发者：wuzhengxiong（聪明卖家A级，选品眼光可靠）
- 建议：该品类已被验证，建议尽快测品
```

## 七、融入09蓝海雷达

### 7.1 作为品类信号增强

卖家画像的输出作为09蓝海雷达的增强信号维度：

| 09原有维度 | 卖家画像增强 |
|-----------|-------------|
| D5 卖家分散度 | + 聪明卖家密度（S/A级卖家数/总卖家数） |
| D1 新品活跃度 | + 郑总店铺新品占比（郑总新品数/品类总新品数） |
| D2 新品成功率 | + 聪明卖家新品成功率（比普通新品成功率更有参考价值） |
| 品类分型 | + 卖家行为信号（"蓝海+聪明卖家多" = 最优机会） |

### 7.2 蓝海雷达品类机会卡增强

```

  品类：Wall Art  🌊 蓝海机会
  雷达：D1=72 D2=65 D3=78 ...

增强后：
  品类：Wall Art  🌊 蓝海机会
  雷达：D1=72 D2=65 D3=78 ...
  卖家信号：郑总18店在做 | 外部S级卖家8家 | 跟品延迟22天
  🔴 强跟品信号：本月3个S级卖家同时上新
```

## 九、执行流程

### 9.1 定时执行（每月数据导入后）

```
数据导入完成
    │
    ├─→ Step 1：卖家画像计算
    │   ├─ 按seller_name分组聚合
    │   ├─ 计算聪明卖家综合评分（A+B+C）
    │   ├─ 分级 S/A/B/C
    │   └─ 写入 seller_profiles 表
    │
    ├─→ Step 2：品类热度矩阵
    │   ├─ 按category×seller交叉聚合
    │   ├─ 郑总店铺数 vs 外部聪明卖家数
    │   └─ 融入09蓝海雷达品类信号
    │
    ├─→ Step 3：跟品信号扫描
    │   ├─ 按category分组，追踪listing_days差异
    │   ├─ 识别强/中/弱跟品信号
    │   └─ 写入 follow_signals 表
    │
    ├─→ Step 4：智能推荐生成
    │   ├─ 交叉分析：聪明人共识 + 郑总验证 + 盲区发现
    │   └─ 输出推荐列表
    │
    └─→ Step 5：LLM解读
        ├─ 卖家洞察面板数据生成
        └─ 09品类机会卡增强
```

### 9.2 新店推荐流程

```
每月执行一次：
    │
    ├─ 从 competitor_products 中发现"疑似郑总关联"或"数据优秀"的外部卖家
    │
    ├─ 生成推荐列表（附推荐理由）
    │
    └─ 推送给用户确认
        ├─ 确认 → 写入 deng_zong_shops 表
        └─ 拒绝 → 标记为 not_dengzong，下月不再推荐
```

## 十、与开品模型信号体系的对应

本文档的卖家画像+跟品分析，实现了开品模型（邓总原始设计）中定义的三级信号体系：

| 开品模型信号 | 本文档实现 | 数据源 |
|-------------|-----------|--------|
| 🔴 紧急：郑总+3个竞品同时上 | 强跟品信号 + 品类热度矩阵 | follow_signals |
| 🟡 重要：BSR新品榜多个同类 | 09蓝海雷达D1新品活跃度 | blue_ocean_snapshots |
| 🟢 一般：单个竞品上新 | 弱跟品信号 | follow_signals |

**升级点**：从"数量计数"升级为"质量加权" — 不仅看"几个卖家跟进"，还看"什么级别的卖家跟进"。
