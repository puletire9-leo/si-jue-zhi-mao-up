# 选品算法 — 品类专属评分模型

> 不同品类的成功标准本质不同。一套权重无法同时服务Wall Art（图案驱动裂变）和Sunglasses（纯市场需求驱动）。
> 本文档定义"品类原型"分类体系和每个原型的专属评分权重，替代统一权重。

---

### 1.2 统一权重的系统性偏差

邓总的8维权重模型本质上是**装饰礼品类**的选品模型：

```
情绪价值(15%) + 装饰价值(10%) + 裂变能力(10%) = 35% 软维度
```

**对Wall Art完美匹配**——这类产品就是靠图案、装饰、裂变来赚钱的。

**对以下品线产生系统性偏差**：

| 品线 | 偏差类型 | 具体表现 |
|------|---------|---------|
| **Storage/Bathroom/Backpack** | 35%的软维度是噪音 | 情绪/装饰/裂变对功能型产品无区分力，LLM打分趋同 |
| **Sunglasses** | 30%的软维度不适用 | 情绪+装饰+文化对太阳镜毫无意义 |
| **Party Supply** | 市场容量权重(10%)过低 | 月销94是核心优势，但被10%权重严重稀释 |
| **Card/贺卡** | 裂变维度定义不匹配 | 贺卡靠"图案变体"裂变，不是"场景裂变" |
| **Towel/毛巾** | 轻小件维度不适用 | 毛巾天然200-500g，用统一标准所有毛巾都是0分 |

### 1.3 更深层的问题：LLM评分资源的浪费

软维度（情绪/装饰/裂变/文化）需要LLM评分，成本不低。

对于Sunglasses品类：
- 情绪价值：所有太阳镜都≈5分（无情绪属性）→ **无区分力，白算**
- 装饰价值：所有太阳镜都≈3分（非装饰）→ **无区分力，白算**
- 文化匹配：所有太阳镜都≈2分（通用时尚）→ **无区分力，白算**

**结论：对于非装饰类品线，40%的LLM评分预算被浪费在产出噪音上。**

## 二、解决方案：品类原型（Category Archetype）

### 2.1 核心思路

不为每个品类单独设计模型（40+品类太多），而是将品类归入**6个原型**：

```
品线（~40个具体品类）
    │
    │  归类
    ▼
品类原型（6个）
    │
    │  决定
    ▼
专属评分权重（每个原型一套8维权重）
```

### 2.2 六个品类原型

| 原型 | 代号 | 核心逻辑 | 代表品类 | 关键特征 |
|------|------|---------|---------|---------|
| **装饰艺术型** | DA | 视觉驱动，图案裂变 | Wall Art, Light, Garden, Cushion | 装饰价值高，裂变靠图案 |
| **功能家居型** | FH | 实用驱动，性价比 | Storage, Bathroom, Tool, Cookware, Towel | 功能>美观，轻小件和体积成本重要 |
| **时尚个人型** | FP | 风格驱动，身份认同 | Jewellery, Tote Bag, Backpack, Sock, Key Chain | 情绪价值来自身份认同，非装饰 |
| **趋势潮流型** | TN | 热度驱动，快速迭代 | Fidget Toy, Puzzle | 市场容量最重要，情绪=解压 |
| **派对活动型** | PE | 文化驱动，高销量 | Party Supply, Card, Balloon, Mug | 文化匹配最重要，月销量高 |
| **纸品文具型** | PS | 极轻，图案裂变 | Pen, Bookmark, Paper, Notebook, Sticker | 轻小件满分，裂变靠设计变体 |

## 三、各原型专属权重

### 3.1 权重矩阵

| 维度 | DA装饰艺术 | FH功能家居 | FP时尚个人 | TN趋势潮流 | PE派对活动 | PS纸品文具 | 基础(邓总) |
|------|-----------|-----------|-----------|-----------|-----------|-----------|-----------|
| 轻小件 | 15% | **20%** | 10% | 10% | **15%** | **25%** | 15% |
| 体积成本 | 10% | **20%** | 10% | 10% | 10% | 15% | 15% |
| 利润 | 15% | **25%** | 20% | **20%** | **20%** | 20% | 20% |
| 情绪价值 | 10% | 3% | **20%** | **20%** | **20%** | 5% | 15% |
| 装饰价值 | **20%** | 0% | 5% | 0% | 10% | 0% | 10% |
| 裂变能力 | **20%** | 5% | 10% | 5% | 10% | **25%** | 10% |
| 文化匹配 | 5% | 2% | 10% | 5% | **15%** | 5% | 5% |
| 市场容量 | 5% | **25%** | 15% | **30%** | 10% | 5% | 10% |
| **有效维度** | **8维** | **5维** | **7维** | **5维** | **7维** | **5维** | 8维 |

> **有效维度** = 权重≥5%的维度数。权重<5%的维度对该原型没有区分力，可跳过。

### 3.2 各原型的设计逻辑

#### DA — 装饰艺术型（Wall Art、Wall Sticker、Banner、Cushion等）

**成功标准**：好看的图案 × 能裂变 × 有装饰场景

```
轻小件  15% — 墙面装饰品通常轻（画/贴纸/旗帜）
体积成本 10% — 装饰品类利润率够高，配送费占比自然低
利润    15% — 重要但不是核心差异
情绪价值 10% — 礼品场景加分，但不是核心
装饰价值 20% — 核心！装饰价值决定产品天花板
裂变能力 20% — 核心！图案裂变是装饰品的商业模式
文化匹配  5% — 图案需文化适配，但多数设计是通用的
市场容量  5% — 装饰品月销普遍30左右，容量不是核心竞争点
```

**与邓总模型的差异**：邓总模型就是这个原型的"原生版本"。几乎一致。

#### FH — 功能家居型（Storage、Bathroom、Cookware、Towel等）

**成功标准**：好用 × 轻小 × 便宜 × 利润高

```
轻小件  20% — 核心！功能品越轻便越好（收纳/浴室/厨房）
体积成本 20% — 核心！配送费占比直接影响定价竞争力
利润    25% — 最重要！功能品利润是硬指标
情绪价值  3% — 噪音！收纳用品没有情绪属性 → 跳过LLM
装饰价值  0% — 噪音！功能品不是装饰品 → 跳过LLM
裂变能力  5% — 低！功能品裂变空间有限
文化匹配  2% — 噪音！功能品不分文化 → 跳过LLM
市场容量 25% — 核心！功能品走量是硬道理
```

**关键变化**：情绪(3%)+装饰(0%)+文化(2%) = **5%全部跳过LLM**。
这意味着FH型产品**只需做3个软维度中的0个LLM评分**，节省大量成本。

#### FP — 时尚个人型（Jewellery、Backpack、Hat、Dress Up等）

**成功标准**：好看 × 身份表达 × 利润合理 × 有市场

```
轻小件  10% — 首饰极轻，但背包/帽子较重，取平衡
体积成本 10% — 背包体积大，首饰体积极小，取平衡
利润    20% — 重要，时尚品利润是核心
情绪价值 20% — 核心！身份认同（我是猫奴/我是妈妈/我是朋克）
装饰价值  5% — 低！时尚品≠装饰品
裂变能力 10% — 中等，风格变体
文化匹配 10% — 重要！时尚有文化差异（UK vs DE）
市场容量 15% — 重要，时尚品需要足够大的受众
```

**关键变化**：情绪价值的含义从"礼品场景"变为"身份认同"。LLM评分Prompt需要调整。

#### TN — 趋势潮流型（Fidget Toy、Sunglasses、Sticker等）

**成功标准**：市场大 × 时机好 × 利润够 × 能解压

```
轻小件  10% — 太阳镜轻，但Fidget Toy不一定
体积成本 10% — 同上，取平衡
利润    20% — 重要，趋势品利润必须够
情绪价值 20% — 核心！但含义不同：解压/疗愈/上瘾感（非礼品）
装饰价值  0% — 噪音！趋势品不是装饰品 → 跳过LLM
裂变能力  5% — 低！趋势品通常不可裂变（一个颜色/款式）
文化匹配  5% — 低，趋势是全球化的
市场容量 30% — 最重要！趋势品=大流量=高月销
```

**关键变化**：情绪价值的含义从"礼品场景"变为"解压/成瘾/上瘾感"。市场容量权重高达30%。

#### PE — 派对活动型（Party Supply、Card、Balloon、Mug等）

**成功标准**：文化契合 × 能送礼 × 量大 × 有情绪

```
轻小件  15% — 贺卡/气球极轻，马克杯中等
体积成本 10% — 派对用品利润高，配送费占比低
利润    20% — 重要，但派对品利润通常够（73%+）
情绪价值 20% — 核心！礼品/祝福/庆祝=强情绪
装饰价值 10% — 中等，派对装饰属性
裂变能力 10% — 中等，场景裂变（生日/婚礼/毕业）
文化匹配 15% — 核心！派对高度依赖文化（圣诞/万圣节/复活节）
市场容量 10% — 重要，月销高是特征（94/月）
```

**关键变化**：文化匹配从5%提升到15%——派对用品是最文化敏感的品类。

#### PS — 纸品文具型（Pen、Bookmark、Paper、Notebook等）

**成功标准**：极轻 × 能裂变 × 利润够

```
轻小件  25% — 最重要！纸品文具天然极轻（<100g）
体积成本 15% — 重要，配送费占比影响利润
利润    20% — 重要
情绪价值  5% — 低！文具不是情绪品 → 可跳过LLM
装饰价值  0% — 噪音！文具不是装饰品 → 跳过LLM
裂变能力 25% — 核心！图案变体是文具的商业模式
文化匹配  5% — 低，设计通用
市场容量  5% — 低，文具月销普遍30左右
```

**关键变化**：轻小件25%+裂变25% = 50%权重集中在"极轻+能裂变"。这是纸品文具的核心公式。

## 四、数据模型设计

### 4.1 品类权重配置表

```
category_weight_profiles
├─ id: BIGINT PK
├─ archetype: VARCHAR(10)          -- DA/FH/FP/TN/PE/PS
├─ archetype_name: VARCHAR(50)     -- "装饰艺术型"
├─ weights_json: JSON              -- {"light_weight":0.15,"volume_cost":0.10,...}
├─ skip_soft_dims: JSON            -- ["emotion","decoration","culture"] 跳过的维度
├─ emotion_prompt_variant: VARCHAR -- "gift" / "identity" / "stress_relief"
├─ created_at: DATETIME
└─ updated_at: DATETIME
```

### 4.2 品类→原型映射表

```
category_archetype_map
├─ id: BIGINT PK
├─ category_path: VARCHAR(200)     -- "Home & Kitchen > Home Accessories > Wall Art"
├─ product_type: VARCHAR(50)       -- "Wall Art"（来自品线分析报告的分类）
├─ archetype: VARCHAR(10)          -- DA
├─ marketplace: VARCHAR(5)         -- UK/DE/US（允许站点级差异）
├─ confidence: FLOAT               -- 映射置信度（1.0=明确映射，<0.7=待验证）
├─ created_at: DATETIME
└─ updated_at: DATETIME
```

### 4.3 评分公式（升级版）

```
# 1. 查找品类原型
archetype = lookup_archetype(product_type, marketplace)

# 2. 使用原型专属权重
weights = archetype.weights  # 如DA: [15,10,15,10,20,20,5,5]

# 3. 跳过无效软维度
active_dims = [d for d in 8维 if weights[d] >= 5%]
skip_dims = [d for d in 8维 if weights[d] < 5%]

# 4. 对有效维度做评分
#    - 硬维度（轻小件/体积成本/利润/市场容量）：SQL百分位计算
#    - 有效软维度：LLM评分（使用原型对应的prompt变体）
for dim in active_dims:
    if dim.is_hard:
        score[dim] = percentile_score(product, category_baseline)
    else:
        score[dim] = llm_score(product, prompt_variant=archetype.emotion_prompt)

# 5. 跳过维度赋默认分（中位数，不影响排名）
for dim in skip_dims:
    score[dim] = 50  # 百分位中位数

# 6. 加权求和
weighted_score = Σ(weights[d] × score[d] for d in 8维)

# 7. 乘以品类健康度系数
selection_score = weighted_score × category_health_coefficient
```

### 4.4 情绪价值的Prompt变体

不同原型对"情绪价值"的理解不同，LLM评分Prompt需要调整：

| 原型 | Prompt方向 | 示例 |
|------|-----------|------|
| DA | 礼品场景明确度 | "这个墙面装饰适合作为什么场合的礼物？" |
| FP | 身份认同强度 | "这个首饰/帽子是否表达了一种明确的生活态度或身份？" |
| TN | 解压/成瘾性 | "这个解压玩具/太阳镜是否有让人上瘾或反复使用的特质？" |
| PE | 庆祝/祝福场景 | "这个派对用品/贺卡是否契合特定的庆祝场景？" |

> FH（功能家居）和PS（纸品文具）的情绪价值权重<5%，不需要LLM评分。

## 五、LLM成本优化

### 5.1 跳过策略的效果

| 原型 | 需要LLM评分的软维度 | 跳过的维度 | LLM调用节省 |
|------|-------------------|-----------|------------|
| DA | 情绪(10%)+装饰(20%)+裂变(20%)+文化(5%) = 4个 | 0个 | 0% |
| FH | 0个（全部<5%） | 情绪+装饰+裂变+文化 = 4个 | **100%** |
| FP | 情绪(20%)+文化(10%) = 2个 | 装饰(5%)+裂变(10%) | 50% |

## 六、百分位基线的配合

### 6.1 与07文档的关系

07文档定义了按(站点×品类)的百分位基线。品类专属权重在此基础上叠加：

```
最终评分 = 百分位加权分（用原型专属权重）× 品类健康度系数
```

**两层差异化的叠加**：

| 层 | 差异化方式 | 解决的差异 |
|----|----------|----------|
| **百分位基线**（07文档） | 同品类内比较 | "月销30在Wall Art中算好，在Party Supply中算差" |
| **品类专属权重**（本文档） | 不同品类用不同维度 | "Wall Art看装饰+裂变，Storage看轻小+利润+量" |

两者缺一不可：
- 只有百分位没有专属权重 → 用装饰品的维度去评功能品，结果失真
- 只有专属权重没有百分位 → 用绝对阈值去比较不同体量的品类，结果偏差

### 6.2 基线计算的维度分组

百分位基线（category_baselines表）需要为**每个可量化维度**存储分布：

| 维度 | 基线来源 | 是否按原型差异化 |
|------|---------|---------------|
| 轻小件 | weight_g 百分位 | 否（重量是物理值） |
| 体积成本 | fba/price 百分位 | 否（比例是通用值） |
| 利润 | profit/price 百分位 | 否（利润率是通用值） |
| 市场容量 | units 百分位 | 否（销量是通用值） |
| 情绪价值 | LLM评分分布 | **是**（不同原型用不同Prompt，分布不同） |
| 装饰价值 | LLM评分分布 | 是（仅DA/PE/FP需要） |
| 裂变能力 | LLM评分分布 | 是（不同原型的裂变定义不同） |
| 文化匹配 | LLM评分分布 | 是（仅PE/FP需要高精度） |

## 十、品类利润结构深度分析

> 当前文档中的利润率（profit/price）各品类都在64-73%区间，**没有区分力**。
> 真正区分品类利润能力的是绝对利润额、月度总利润、广告后净利润。

### 10.1 利润率为什么不是区分因素

从08文档§一的数据提取：

| 品类 | 均售价 | 利润率 | 每单利润£ | 均月销 | 月度总利润£ |
|------|-------|-------|---------|-------|----------|
| Card 贺卡 | £5.95 | 68% | **£4.05** | 43 | **£174** |
| Wall Art | £7.65 | 70% | **£5.36** | 30 | **£161** |
| Storage | £7.94 | 70% | **£5.56** | 31 | **£172** |
| Party Supply | £7.21 | 73% | **£5.26** | **94** | **£495** |
| Backpack | £10.42 | 71% | **£7.40** | 35 | **£259** |
| Sunglasses | £6.59 | 72% | **£4.74** | **138** | **£655** |

**发现**：利润率都在68-73%，但月度总利润从£161（Wall Art）到£655（Sunglasses）差4倍。利润率不是决策依据，**月度总利润才是**。

### 10.2 竞品利润计算算法（精确版）

> **参考实现**：`利润计算器_最终版.py` + `理实产品对接表06.02.xlsx`
> 利润计算的核心只需 **4个输入**：重量、长宽高、价格、FBA配送费
>
> **两层利润概念**（已确认）：
> - **卖家精灵 `profit` 字段**：平台费用后毛利（扣了佣金+VAT+FBA，**未扣产品成本+头程运费**），利润率约68-73%。**用于第2层8维评分的利润指数**。评分公式：`利润指数 = profit / price`，百分位排名。
> - **本节精确公式**：扣除全部成本后的真实利润 = `profit - 产品成本 - 头程运费`。真实利润率约15-25%。**用于第3层Agent深度分析**，需要额外输入产品采购成本。

#### 数据来源

竞品数据（competitor_products 表）中**4个输入全部可用**：

| 输入 | 字段 | 示例值 | 解析方式 |
|------|------|--------|----------|
| 价格 | `price` | `10.99` | 直接使用 |
| FBA配送费 | `fba` | `2.69` | 直接使用 |
| 重量 | `weight` | `"180 Gramm"` | 提取数字 → 0.180 kg |
| 尺寸 | `dimension` | `"20 x 15 x 3 cm"` | 提取 → L=20, W=15, H=3 cm |

> `pkgDimensions` 和 `pkgWeight` 可作为备用来源，当 `dimension`/`weight` 缺失时使用。

#### 完整计算公式

```
// 简化路径（第3层Agent深度分析推荐）：
// 卖家精灵已算好平台费用，只需再扣产品成本+头程
真实利润 = seller精灵_profit - 产品成本 - 头程运费
真实利润率 = 真实利润 / price

// ──── 以下为完整路径（验证用 / 无profit字段时） ────

// 第一步：计算体积重量和计费重量
体积重量 = (长 × 宽 × 高) / 6000    // cm³ → kg
计费重量 = max(体积重量, 实际重量)

// 第二步：计算各项成本
佣金 = price × 15%                  // 亚马逊佣金，UK/DE统一
VAT = price / (1 + 20%) × 20%      // 增值税（含税价反算）
头程运费 = 计费重量 × 运费单价      // 空运UK: ¥45/kg, DE: ¥55/kg; 海运: ¥15/kg
产品成本 = 采购价(¥) / 汇率         // UK: 汇率8.54, DE: 汇率7.5

// 第三步：计算利润
空运利润 = price - 佣金 - VAT - FBA配送费 - 产品成本 - 空运头程
海运利润 = price - 佣金 - VAT - FBA配送费 - 产品成本 - 海运头程

// 第四步：利润率
空运利润率 = 空运利润 / price
海运利润率 = 海运利润 / price
```

#### 站点配置参数

| 参数 | UK (£) | DE (€) |
|------|--------|--------|
| 佣金比例 | 15% | 15% |
| VAT税率 | 20% | 20% |
| 汇率(当地→CNY) | 8.54 | 7.5 |
| 空运头程(¥/kg) | 45 | 55 |
| 海运头程(¥/kg) | 15 | 15 |

#### FBA配送费查找

优先使用竞品数据中的 `fba` 字段。当缺失时，按尺寸+重量从 [配送费.md](../郑总公司分析/配送费.md) 查找对应费率。

配送费分档规则：
- **低价商品**：售价 < £10 / €10 → 按信封/包裹尺寸+重量查表
- **高价商品**：售价 ≥ £10 / €10 → 费率略高

#### 示例计算

以DE站某产品为例（`price=10.99€, 180g, 20×15×3cm, fba=2.69€`）：

```
体积重量 = (20 × 15 × 3) / 6000 = 0.15 kg
计费重量 = max(0.15, 0.18) = 0.18 kg

佣金 = 10.99 × 15% = €1.65
VAT  = 10.99 / 1.2 × 0.2 = €1.83
头程(空运) = 0.18 × 55 / 7.5 = €1.32
产品成本(估) = 假设采购¥13 → 13/7.5 = €1.73

空运利润 = 10.99 - 1.65 - 1.83 - 2.69 - 1.73 - 1.32 = €1.77
空运利润率 = 1.77 / 10.99 = 16.1%
```

#### 产品成本估算策略

精确公式需要产品采购成本，但竞品数据中无此字段。默认策略：

| 方法 | 适用场景 | 精度 | 说明 |
|------|---------|------|------|
| **品类均值法（默认）** | 批量分析 | ⭐⭐ | 按品类原型中位数成本估算（见§10.5原型利润特征） |
| **1688参考** | 单品深度分析 | ⭐⭐⭐ | 从1688搜索同类品取中位价，人工确认后输入 |
| **反推法（验证用）** | 已有产品对标 | ⭐⭐⭐ | 已知自己产品的采购价，反推验证公式准确性 |

> **推荐**：
> - 第2层批量评分 → 直接用卖家精灵 `profit/price`，无需成本估算
> - 第3层批量深度分析 → 用**品类均值法**
> - 第3层单品精确分析 → 用**1688参考**或人工输入成本

#### 重量/尺寸数据质量注意

11文档§假数据过滤规则同样适用于利润计算：
- 整百重量 + 整数尺寸 → **可疑**，需交叉验证
- `weight` 缺失或为0 → 使用同品类中位数替代
- `dimension` 缺失 → 使用 `pkgDimensions` 替代

#### 利润分析三层拆解

用§10.2的精确算法算出每单利润后，进行三层拆解：

```
第一层：每单利润 = 精确计算结果（§10.2公式）
第二层：广告后净利润 = 每单利润 - 估算广告成本（§10.3）
第三层：月度总利润 = 广告后净利润 × 月销量（units字段）
```

> 月度总利润才是真正的区分因素——各品类利润率都在64-73%，但月度总利润差4倍。

### 10.3 广告成本估算模型

当前数据中无广告成本字段，需要按品类估算。

**估算依据**：按品类竞争程度推算PPC成本。

| 竞争程度 | 品类特征 | 估算广告费/单 | 典型品类 |
|---------|---------|-------------|--------|
| 低竞争 | 品类小、品牌分散、新品多 | £0.3-0.8 | Stamp, Notebook, Car Freshener |
| 中竞争 | 品类中等、有一定品牌 | £0.8-1.5 | Wall Art, Storage, Card |
| 高竞争 | 品类大、品牌集中、评论壁垒高 | £1.5-3.0 | Sunglasses, Backpack, Bathroom |

**估算公式**：

```
estimated_ppc_cost = base_ppc × competition_multiplier

base_ppc = price × 0.08        // 基础广告费为售价的 8%
competition_multiplier：
  - 品类D3评论壁垒分≥70 → ×0.6（壁垒低，广告成本低）
  - 品类D3评论壁垒分40-70 → ×1.0（中等）
  - 品类D3评论壁垒分<40 → ×1.5（壁垒高，广告成本高）
  - 品类D4品牌分散度≥70 → ×0.8（品牌分散，广告竞争小）
  - 品类D4品牌分散度<40 → ×1.3（品牌集中，广告竞争大）
```

> **与09蓝海雷达的联动**：D3评论壁垒和D4品牌分散度直接影响广告成本估算。

| 每单利润 | profit（已有） | 单个商品能赚多少 |
| 每单净利润 | profit - estimated_ppc_cost | 扣广告后实际赚多少 |

### 10.7 利润维度对评分的影响

当前01文档中利润指数只用了 `profit/price` 比率。建议升级为复合利润评分：

```
利润综合分 = 0.4 × 利润率百分位    // 每单赚得多
          + 0.4 × 月度总利润百分位    // 总体赚得多
          + 0.2 × 净利润率百分位      // 扣广告后还能赚
```

**与01文档的对接**：01文档§3.2“利润指数（20分）”可升级为上述复合分，替代单一的`profit/price`比率。

## 十一、核心结论

1. **统一权重是装饰礼品类的偏见** — 邓总的模型天然适合Wall Art，但对功能型/趋势型/时尚型品类产生系统性偏差
2. **6个原型覆盖51个品类** — 经6991条实际数据验证，不是每个品类一套模型（太多），而是6种成功逻辑覆盖所有品类
3. **有效维度>全维度** — 功能型品类只需5个维度评分，LLM调用节省45%
4. **情绪价值的含义因品类而异** — 礼品场景(DA/PE) ≠ 身份认同(FP) ≠ 解压成瘾(TN)，LLM Prompt需要变体
5. **两层差异化缺一不可** — 百分位解决“同类内比较”，专属权重解决“不同类用不同标准”
6. **数据量验证通过** — 5个原型数据充足(>15%)，TN原型调整后保留核心品线，德语产品通过nodeLabelPath100%覆盖
7. **利润率不是区分因素，月度总利润才是** — 各品类利润率都在64-73%，但月度总利润从£161到£655差4倍
8. **利润分析三层拆解** — 每单利润 → 广告后净利润 → 月度总利润，广告成本通过09蓝海雷达的D3/D4维度估算
9. **竞品利润可精确计算** — 只需重量、长宽高、价格、FBA配送费4个输入，竞品数据中全部可用，参考`利润计算器_最终版.py`完整算法
