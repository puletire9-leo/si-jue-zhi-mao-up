# 端口（以 Compose 为准）

Docker 地图：[docker使用经验/README.md](../docker使用经验/README.md)  
生产发布：[docker使用经验/部署流程.md](../docker使用经验/部署流程.md)

Windows 排除段大约是 `7998-8197`，开发宿主不要绑 8001/8002/8090/5175。

## 开发 `docker-compose.dev.yml`

入口：`http://localhost:6175`

| 服务 | 宿主 | 容器内 |
|---|---|---|
| 前端 Vite | 6175 | 5175 |
| Python | 18090 | 8090 |
| Java user | 18001 | 8001 |
| Java product | 18002 | 8002 |
| MySQL | 13338 | 3306 |
| Redis | 6379 | 6379 |
