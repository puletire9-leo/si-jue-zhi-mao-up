# 筛选机制架构与后续新增功能指导

## 数据流（改后）

```
SelectionQueryParams (TS 类型，单一定义)
    ↓ 自动映射
buildApiParams() → API query string
    ↓
CompetitorController: @Valid CompetitorQueryRequest（Spring 自动绑定）
    ↓ 直接传入
CompetitorService.queryFromDb(request)
    ↓ 字段透传
CompetitorProductMapper（MyBatis XML）
    ↓ <if test='...'>
SQL WHERE 条件
```

**核心原则：新增字段只需加定义，不用改 Controller。**

## 新增筛选字段操作清单

### Step 1：Java DTO — 加字段

文件：`java-backend/.../dto/CompetitorQueryRequest.java`

```java
@Data
public class CompetitorQueryRequest {
    ...
    private String category;        // 已有
    private String newFilterField;  // ← 新增：前端传什么名，这里就用什么名
}
```

### Step 2：Java Mapper — 加 SQL 条件

文件：`java-backend/.../mapper/CompetitorProductMapper.java`

在 `selectGroupedByParent` 和 `countGroupedByParent` 中各加一行：

```xml
<if test='newFilterField != null'> AND cp.你的列 = #{newFilterField}</if>
```

同时在方法参数列表加 `@Param("newFilterField") String newFilterField`。

### Step 3：Java Service — 透传

文件：`java-backend/.../service/CompetitorService.java`

`queryGroupedByParent()` 中加一行参数传递：

```java
request.getNewFilterField(),
```

> **Spring 对象绑定已经自动把请求参数注入 DTO，Controller 不用改，Service 只加一行传参。**

### Step 4：前端类型 — 加字段

文件：`frontend/src/components/SelectionQueryForm/types.ts`

```typescript
export interface SelectionQueryParams {
  ...
  category: string
  newFilterField: string  // ← 新增
}

export const defaultQueryParams = {
  ...
  category: '',
  newFilterField: '',  // ← 新增默认值
}
```

### Step 5：前端映射 — 加一行

文件：`frontend/src/views/AllSelection/index.vue`

在 `loadProducts()` 的 `filterFields` 数组中加一行：

```typescript
const filterFields = ['asin', 'productTitle', ..., 'category', 'newFilterField']
```

> 字段名跟前后端一致时无需改映射表，直接加进数组即自动透传。

### Step 6：前端 UI — 加表单控件

文件：`frontend/src/components/SelectionQueryForm/index.vue`

1. 在 `<template>` 中加新的表单输入控件（`<el-select>` / `<el-input>` / 等）
2. 绑定 `v-model="formData.newFilterField"`
3. 加 `@change="handleSearch"`

## 踩坑速查

| 坑 | 症状 | 原因 | 解法 |
|----|------|------|------|
| Controller 漏参数 | 前端传了但筛选不生效 | 旧架构要手动加 @RequestParam（已修） | 新架构只需改 DTO |
| 前端映射漏字段 | 前端选了但 API 没传过去 | filterFields 数组没加新字段 | Step 5 |
| 下拉框没有 @change | 选了不触发搜索 | 忘加事件 | Step 6-3 |
| 数组变字符串丢失 | 多选传到后端是 JSON 数组 | emit 没调 getQueryParams()（已修） | handleSearch 已统一 |
| SQL 条件写错列 | 筛选不生效或报错 | 列名拼错或字段类型不匹配 | 对照 SHOW COLUMNS |
| 前后端字段名不一致 | 参数传了收不到 | Java 驼峰 vs TypeScript 驼峰 | 统一用小驼峰 |

## 郑总店铺（deng_zong_shop）筛选

走独立 Controller + Mapper，**不走 CompetitorController**。

新增筛选字段需要改：
1. `DengZongShopController` — `@RequestParam` 加参数（此 Controller 暂未重构为对象绑定）
2. `DengZongShopMapper` — SQL 加条件
3. 前端 `loadProducts` 中 `dengParams` 对象 — 加映射

> 郑总店铺后续也应迁移为 DTO 对象绑定，消除 @RequestParam 逐个手写的风险。
