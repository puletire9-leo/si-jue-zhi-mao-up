  五、跨模块共性问题

  1. 前后端 API 对接风险 — Python 27 个"待废弃"路由仍在线，Java 已实现同名接口，存在双后端竞争响应的隐患
  2. 重复造轮子 — 图片处理/COS 操作/分页逻辑在前端、Python、Java 三端各自实现，无统一抽象
  3. 命名规范缺位 — API 路径、文件名、变量名在各层各自为政

  ---
  建议优先级

  1. 立即 — 清理密钥硬编码；删除 Java 顶层 src/ 拷贝；删除前端死代码
  2. 短期 — 下线已迁移的 Python 路由；合并前端图片缓存模块；Python 路由逻辑下沉到 service 层
  3. 中期 — 统一 API 命名规范；Java Service 抽接口；Docker Compose 环境变量去重
