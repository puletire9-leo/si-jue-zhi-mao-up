# 商品基础销量分级

这是商品基础特征处理层的辅助字段，不是方法卡片本身，也不直接决定商品是否合格。

## 分级规则

| 月销量 units | 基础销量分级 |
|-------------|--------------|
| >= 100 | A |
| 50-99 | B |
| 15-49 | C |
| 0-14 | D |
| 空值 | UNKNOWN |

## 定位

商品销量分级用于后续分析和决策，属于“数据处理层”的通用基础特征。

方法卡片属于“消费层”，可以引用这个基础特征，但每张方法卡必须保持独立筛选逻辑。例如未来可以有一张新方法卡专门消费 `sales_tier IN ('A', 'B')`，但 `sales_tier` 本身不等于方法卡命中。

## 店铺模型里的用法

建立店铺模型时，可以观察一家店的商品分布：

- A/B 级多：这家店可能持续产出高销量新品或强势商品。
- C 级多：这家店可能有稳定但未爆发的候选池。
- D/UNKNOWN 多：这家店需要谨慎，可能是低质、数据不足或未起量商品多。

这类分布是店铺分析的辅助证据；真正的店铺命中数仍由选择的独立方法卡片计算。
