# 商品基础销量分级

这是商品基础特征处理层的辅助字段，不是方法卡片本身，也不直接决定商品是否合格。

## 分级规则

| 月销量 units | 基础销量分级 |
|-------------|--------------|
| >= 100 | A |
| 50-99 | B |
| 15-49 | C |
| 0-14 | D |
| 空值 | UNKNOWN |

## 定位

商品销量分级用于后续分析和决策，属于“数据处理层”的通用基础特征。

方法卡片属于“消费层”，可以引用这个基础特征，但每张方法卡必须保持独立筛选逻辑。例如未来可以有一张新方法卡专门消费 `sales_tier IN ('A', 'B')`，但 `sales_tier` 本身不等于方法卡命中。

## 店铺模型里的用法

建立店铺模型时，不能把 A/B/C/D 简单理解成“好/坏”。销量等级更像商品生命周期里的阶段信号：

- A 级：已经被市场验证过的利润锚点，代表店铺“最终靠什么赚钱”。
- B 级：强候选利润品，通常已经具备稳定销量，但还未达到 A 级强度。
- C 级：稳定小单或潜力池，是判断店铺主打法和可复制方向的重要样本。
- D 级：未起量商品，可能是新品/测品，也可能是长期失败品，必须叠加时间判断。
- UNKNOWN：数据缺失，不能直接用于正负判断。

因此：

| 观察口径 | 适合回答的问题 | 不适合回答的问题 |
|---------|---------------|----------------|
| A | 这家店最终跑出来的利润方向是什么 | 这家店完整打法是什么 |
| A+B | 这家店的确定性盈利/强候选池在哪里 | 这家店的测品能力如何 |
| A+B+C | 这家店较稳定的经营画像和主打法 | 哪些新品刚开始测试 |
| D | 这家店的测品池规模、铺货方向、未起量库存 | 不能不看时间就判定垃圾 |

这类分布是店铺分析的辅助证据；真正的店铺命中数仍由选择的独立方法卡片计算。

## 店铺商品数量口径

店铺维度默认采用“不含变体”的父体商品口径。

原因：

- 亚马逊店铺页面显示的总商品数，本质上是不含变体的父体商品数量。
- 店铺画像要回答的是“这家店铺有多少独立商品方向、这些方向分布在哪些销量层级”，而不是颜色、尺寸、套装等子变体数量。
- 卖家精灵含变体数据会把同一父体下多个子 ASIN 重复计入，容易放大商品数、销量分布和店铺规模。

因此后续店铺筛选、店铺画像、销量分级、店铺品级统计默认使用：

```text
SellerSprite competitor-lookup
variation=Y
```

即不含变体口径。只有在专门研究变体策略、子 ASIN 表现、颜色/尺寸/套装结构时，才使用 `variation=N` 抓取含变体数据。

## 精铺店铺模型里的解释

对精铺型卖家，销量分级分布不应按“精品店”逻辑解读。

精品店倾向于：

```text
SKU 少，A/B 占比高，单品吃透
```

精铺店更接近：

```text
大量 D 测品
部分 D 升 C
少量 C/B 升 A
A+B 的利润覆盖 D 的试错亏损
下一批继续复制
```

所以判断一家精铺店是否值得学习，重点不是只看 A 多不多，而是看：

- D 是否足够多：说明是否有持续测品动作。
- C 是否足够厚：说明测品是否能沉淀出稳定小单池。
- A+B 是否健康：说明利润端是否能覆盖试错成本。
- D 的类目方向是否和 ABC/A 有重叠：说明测品是否围绕可验证方向，而不是乱铺。
- 老 D 是否过多：如果 D 商品上架时间很久仍未起量，应视为低效库存或失败品。

## 三维店铺画像：替代单维分类解释

后续店铺分析不再用单一 A/B/C/D 来描述一家店。A/B/C/D 只保留为“销量层”，它不单独决定店铺好坏。

正式店铺画像采用三维结构：

```text
销量层：A / B / C / D / UNKNOWN
时间层：新品 / 成长期 / 成熟品 / 老品 / 未知
注意与倾向层：好品倾向 / 普通 / 需复核 / 强注意 / 未知
```

这三维分别回答：

| 维度 | 回答的问题 | 说明 |
|---|---|---|
| 销量层 | 卖得动吗？ | 判断利润锚点、稳定候选池、测品池 |
| 时间层 | 是最近卖动的吗？ | 判断新品能力、持续选品能力、老品沉淀 |
| 注意与倾向层 | 我们能不能学、能不能做？ | 只做分析和筛选提示，不做系统拒绝 |

### 1. 销量层

销量层沿用现有 A/B/C/D：

| 月销量 units | 基础销量分级 | 解释 |
|-------------|--------------|---|
| >= 100 | A | 强销量品 / 利润锚点 |
| 50-99 | B | 明确起量品 / 强候选 |
| 15-49 | C | 有验证的候选品 / 稳定小单 |
| 0-14 | D | 测品或未起量品 |
| 空值 | UNKNOWN | 数据缺失 |

### 2. 时间层

时间层建议按 `listing_days` 分：

| 上架天数 | 时间层 | 解释 |
|---:|---|---|
| 0-90 | 新品 | 重点看新品机会和 M01 产出能力 |
| 91-180 | 成长期 | 已过新品期，看是否能沉淀 |
| 181-365 | 成熟品 | 稳定销售品，适合看长期方向 |
| >365 | 老品 | 老利润品或低效沉淀品 |
| 空值 | 未知 | 时间数据缺失，不能做生命周期判断 |

### 3. 注意与倾向层

注意与倾向层来自类目、标题、形态等标签。它不是“拒绝/禁做”结论，只是分析提示。

| 标签层 | 解释 |
|---|---|
| 好品倾向 | 轻小、主题化、可组合、可定制，接近验证好品线 |
| 普通 | 暂无明显好品倾向或注意信号 |
| 需复核 | 带电、带液体、儿童、汽车、宠物、美妆等边界，需要结合具体商品看 |
| 强注意 | 电源/插头、化学功效、安全责任、大件重货、强功效修复等，需要人工重点判断 |
| 未知 | 类目或标题信息不足 |

### 4. 组合解释

三维组合后，店铺商品不再被简单理解成“好/坏”，而是有明确业务含义：

| 组合 | 解释 |
|------|------|
| A + 新品 + 好品倾向 | 极强信号，说明店铺最近打出了符合我们模型的爆品 |
| A + 老品 + 好品倾向 | 稳定利润锚点，可学习类目和款式，但不是最新机会 |
| B/C + 新品 + 好品倾向 | 最值得挖的起量方向，可能比老 A 更有价值 |
| D + 新品 + 好品倾向 | 正常测品池，适合观察后续转化 |
| A/B + 新品 + 强注意 | 有销量但要小心，可能是高责任、高合规或大件方向 |
| B/C + 成熟品 + 普通 | 稳定候选池，可看类目是否长期有效 |
| D + 老品 + 普通/强注意 | 低价值沉淀，通常不是优先学习对象 |
| UNKNOWN + 任意时间 + 任意标签 | 数据不足，不能下强判断 |

### 5. 店铺描述方式

店铺级别不再只描述“A 多不多”，而要描述三维结构：

| 店铺类型 | 判断重点 | 解释 |
|---|---|---|
| 新品发动机型 | 新品 A/B/C 多，M01 命中多，好品倾向高 | 最近选品能力强，最值得盯 |
| 健康精铺飞轮型 | 老 A/B 有利润，新 D 有测品，新 B/C 有成长 | 最符合我们“测品-沉淀-覆盖亏损”的精铺模型 |
| 成熟利润型 | A/B 多，但大多是成熟/老品 | 说明过去做对了，可看类目样貌，但不一定代表当前新品能力 |
| 成长测品型 | 新 D 多，少量新 C/B 出现 | 正在测品，适合观察 D/C 后续转化 |
| 稳定候选池型 | B/C 成熟品厚，A 不多 | 不一定爆，但方向稳定，可挖相似品 |
| 高注意高销量型 | 新 A/B/C 不少，但强注意/需复核占比高 | 有市场信号，但不应直接学习，需要人工判断能否做 |
| 老品沉淀型 | 老 D 多，新品少 | 低效沉淀，不是优先学习对象 |
| 小样本待观察型 | 商品数太少 | 暂时不能下判断 |

最终店铺画像要回答三个问题：

```text
卖得动吗？
是最近卖动的吗？
我们能不能学习复制？
```
