# 店铺全集画像标签说明

## 核心口径

店铺全集画像里的类目标签不是拒绝标签，也不是系统自动淘汰结论。

它们只是“注意标签”和“好品倾向标签”，用于帮助我们快速理解一个店铺的商品结构，并作为前端筛选条件。最终是否要跟进，需要结合商品标题、图片、价格、体积、上架时间、销量和人工经验判断。

这些标签是店铺三维画像的第三维：

```text
销量层：卖得动吗？
时间层：是最近卖动的吗？
注意与倾向层：我们能不能学习复制？
```

所以前端展示时应把它叫做“注意/倾向标签”，不要叫“违禁判断”“禁做判断”或“系统拒绝”。

## 时间层口径

店铺三维画像里的时间层必须使用互斥 `ageBucket`：

| ageBucket | 条件 | 前端文案 |
| --- | --- | --- |
| `NEW` | `listing_days <= 90` | 新品 |
| `GROWING` | `91 <= listing_days <= 180` | 成长期 |
| `MATURE` | `181 <= listing_days <= 365` | 成熟品 |
| `OLD` | `listing_days > 365` | 老品 |
| `UNKNOWN` | `listing_days 为空` | 上架时间未知 |

现有 `new30Count / new90Count / new180Count / old180Count` 只是累计观察窗口：

- `new30Count`：30 天内超新商品。
- `new90Count`：90 天内新品窗口，和 `ageBucket.NEW` 口径接近。
- `new180Count`：180 天内累计窗口，包含新品和成长期。
- `old180Count`：180 天以上沉淀窗口，包含成熟品和老品，不能等同于 `ageBucket.OLD`。

前端做矩阵、店铺类型和商品筛选时，必须使用 `ageBucket`；展示“近期上新强度”时，可以额外展示这些累计窗口。

## 后端字段

单店画像接口：

`GET /api/v1/modules/shop-collection/{marketplace}/{sellerName}/insight`

前端优先读取：

- `categoryLabelStats`：按标签聚合后的类目结构。
- `categoryStats[].attentionLevel`：该类目的注意等级。
- `categoryStats[].attentionReason`：命中的标签代码。
- `categoryStats[].labelMeaning`：给前端展示用的解释文本。
- `categoryStats[].attentionTags`：注意标签列表。
- `categoryStats[].tendencyTags`：好品倾向标签列表。

兼容字段：

- `riskStats`
- `riskLevel`
- `riskReason`

这些字段只是第一版接口兼容别名，新页面不要作为主要展示字段。

## 标签等级

| attentionLevel | 前端建议文案 | 含义 |
| --- | --- | --- |
| `ATTENTION_STRONG` | 强注意 | 有明显责任、合规、体积或功效承诺信号，需要人工重点看，不代表拒绝 |
| `ATTENTION_REVIEW` | 需复核 | 涉及履约、儿童、汽车、宠物、美妆等边界，不能一刀切淘汰 |
| `GOOD_TENDENCY` | 好品倾向 | 类目形态接近轻小、主题化、可组合、可定制的验证好品线 |
| `NEUTRAL` | 未命中标签 | 未命中当前规则，需要继续看商品本身 |
| `UNKNOWN` | 类目缺失 | 类目数据不足，只能先看商品标题、销量、新品时间 |

## 重要防误杀

- 带电、带磁、带液体是履约/物流注意，不是选品淘汰理由。
- 小电池消费品、LED 小玩具、电子计数器这类可以复核，不要直接杀。
- 真正需要强注意的是充电器、适配器、插头、电源、接市电、给其他设备供电的商品。
- 玩具、宠物、汽车、儿童、季节、卡通都不能单独定生死，要看它是轻小装饰/主题小件，还是安全责任件、药剂、大件、强功效品。
- IP 也不能一刀切。真人明星、强粉丝、正版角色照片属于强注意；可改写的 meme、泛动物、通用主题进入复核。

## 前端展示建议

单店画像页面不要写“禁做类目”“拒绝类目”。

建议展示为：

- “注意标签”：显示 `ATTENTION_STRONG` 和 `ATTENTION_REVIEW`。
- “好品倾向”：显示 `GOOD_TENDENCY`。
- 每个标签旁边展示 `labelMeaning`，让用户知道这是分析提示，不是最终判断。
- 筛选条件可以支持：只看强注意、只看需复核、只看好品倾向。
