## 三站落点规律总结

1. **钥匙扣**：US/DE 明显偏 Automotive，UK 偏 Fashion。三站都要带上 Toys Fidget 交叉。
2. **手链**：UK 在 Fashion 珠宝、US 在球迷周边、**DE 在手工串珠**（Schmuckperlen 282 最大）。差异最大的一条线。
3. **太阳捕手**：三站都跨 Garden + Home/Toys 装饰 + Crafts + 拼图噪音，是最典型的"必须多小类并采"品线。
4. **蛋糕装饰**：三站都散在 派对插牌 + 生日蜡烛 + 烘焙模 + 气球，US 尤其偏蜡烛/烘焙。
5. **帆布袋 / 马克杯**：三站主力小类语义一致（购物袋 / 咖啡杯），node_id 各不同。

**完整采集→初筛链路**：
1. 按各站"品线 node 清单"配采集任务（主力必采 + 分散补采）。
2. 采集后用标题关键词全站兜底捞取（防漏散落在未知小类的同类品）。
3. 落到单个 ASIN 走 `垃圾asin分析.md`：标题形态 + 价格带 + IP + 大件/带电/化学过滤。
4. 白名单可迭代：新爆款落到新小类就加进主力，持续不出单的移除。
