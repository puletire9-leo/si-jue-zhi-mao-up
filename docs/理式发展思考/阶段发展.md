# 精铺阶段发展模型

> 整合材料：
>
> - `智能纪要：竞品店铺运营数据对比分析会 2026年7月7日.md`
> - 会议图片中的店铺阶段对比表、商品分级说明、利润沟通截图
> - 当前系统里的店铺画像、商品销量分级、郑总 clean no variants 数据口径

## 一、核心结论

我们当前处在：

```text
撑盘子阶段 -> C/D 池扩张与验证阶段
```

当前目标不是立刻进入精品模式，也不是只追求 A 级爆品数量，而是先把店铺的商品盘子撑起来，让 D 层测品足够多、C 层稳定小单池足够厚，再从 C/B/A 中回融出精品化方向。

一句话：

```text
当前不是缺单个爆品，而是需要把 D -> C -> B -> A 的精铺飞轮跑厚。
```

## 二、图片内容分析

### 1. 店铺阶段对比图

图片里的表格把自有店铺和郑总店铺按店龄拆成两类：

| 店铺类型 | A 类产品数量 | B 类产品数量 | C 类产品数量 |
|---|---:|---:|---:|
| 自有老店铺（300-400天） | 4-6 个 | 20 个左右 | 20 个左右 |
| 郑总公司老店铺（300-400天） | 6 个 | 14 个 | 61 个 |
| 自有新店铺（<200天） | 0.6-1 个 | 4 个 | 29-30 个 |
| 郑总公司新店铺（<200天） | 未完整展示 | 未完整展示 | 41 个 |

这张图最关键的不是 A，而是 C。

老店铺对比里：

- 自有 A：4-6 个
- 郑总 A：6 个

这说明 A 层差距不大。

B 层甚至自有店铺不弱：

- 自有 B：20 个左右
- 郑总 B：14 个

真正拉开的是 C 层：

- 自有老店铺 C：20 个左右
- 郑总老店铺 C：61 个

也就是郑总老店铺的 C 层大约是自有老店铺的 3 倍。

新店铺也类似：

- 自有新店铺 C：29-30 个
- 郑总新店铺 C：41 个

郑总新店铺 C 层约为自有新店铺的 1.4 倍。

所以这张图指向一个重要判断：

```text
我们不是没有 A，也不是 B 完全不行，真正短板是 C 层沉淀能力。
```

C 层代表月销量 15-49 的稳定小单池。它不是大爆品，但它是精铺模型里最关键的中间层：

- D 能不能沉淀成 C，代表测品质量。
- C 能不能变厚，代表店铺盘子是否撑起来。
- C 能不能继续推到 B/A，代表运营飞轮是否成立。
- C 层类目和 A/B 是否重叠，代表开发方向是否围绕已验证方向。

### 2. 商品分级说明图

截图里明确了郑总 UK/DE 商品销量分级模型的口径：

```text
数据源：zheng_clean_no_variants_20260707
请求口径：SellerSprite competitor-lookup 店铺名查询
variation=Y，不含变体
```

分级解释为：

| 等级 | 月销量 | 含义 |
|---|---:|---|
| A | >=100 | 已经跑出来的利润锚点，看店铺最终靠什么赚钱 |
| B | 50-99 | 稳定强候选盈利品，通常已经有稳定销量但还没达到 A |
| C | 15-49 | 稳定小单/潜力池，是判断店铺主打法和可复制方向的重要中间层 |
| D | 0-14 | 测品池或未起量池，在精铺模型里不是垃圾，而是后续转化观察对象 |
| UNKNOWN | 空 | 数据缺失，不参与正负判断 |

截图还强调了三个观察口径：

| 口径 | 看什么 |
|---|---|
| A | 看利润答案：这家店最后跑出来的赚钱方向 |
| A+B | 看确定性盈利和强候选池 |
| A+B+C | 看店铺稳定经营画像和主打法，比只看 A 更完整 |

这和我们当前系统里的两层结构一致：

```text
数据处理层：销量等级、上架时间、类目、父体口径
消费层：方法卡、店铺画像、新品雷达、爆款复制卡
```

商品分级本身不是方法卡，它是所有方法卡和店铺画像可以共同消费的基础证据。

### 3. 利润沟通截图

聊天截图里有几个关键信息：

- 4 月份数据里，在线销售约 10707 个产品。
- 大于 100 单的是 120 个 SKU。
- 大于 30 单的约 1000 个产品，大约 10%。
- 大量产品低于 30 单/月。
- 5% 净毛利不好，大部分应大于 15%。
- 关键还是利润率，有利润率才有复制性。
- 老公司利润率大约 18%-22%。
- 低于 30 单/月的商品也可能有利润，但如果是低销量、低利润率，就没有价值。

这张图补上了销量分级缺失的一层：利润。

也就是说：

```text
销量等级只判断市场验证强度，不能单独判断经营价值。
经营价值 = 销量层级 × 利润率 × 上架时间 × 广告/运营成本
```

对当前阶段尤其重要的是：

- D/C 层可以接受销量不高，但必须有转化为利润池的可能。
- C 层如果利润率健康，就是很重要的稳定盘。
- 低销量且低利润率的老 D/老 C，才是真正要淘汰的低效库存。
- A/B 层如果利润率不足，也不能直接当成优质精品。

## 三、阶段模型

### 阶段 1：撑盘子阶段

关键词：

```text
大量上新、大量 D、形成 C 池、先做样本量
```

这个阶段的核心不是追求所有新品立刻赚钱，而是让店铺具备足够的测试样本。

重点指标：

| 指标 | 解释 |
|---|---|
| D 数量 | 是否有足够测品动作 |
| 新 D 占比 | D 是否是新测品，而不是老失败品 |
| C 数量 | 测品是否开始沉淀 |
| D 与 ABC 类目重叠度 | 是否围绕已验证方向测品 |
| 上新节奏 | 是否持续补充样本 |

判断方式：

```text
如果 D 多但 C 很薄，说明只是铺货，没有沉淀。
如果 D 多且 C 开始变厚，说明撑盘子有效。
```

### 阶段 2：C 层沉淀阶段

关键词：

```text
C 层变厚、稳定小单、主打法清晰
```

这是当前最应该盯的阶段。

根据图片对比，自有店铺和郑总店铺的核心差距集中在 C 层：

```text
老店铺：郑总 C 约为自有 3 倍
新店铺：郑总 C 约为自有 1.4 倍
```

所以当前阶段的核心目标应该是：

```text
提高 D -> C 的转化能力，而不是只盯 A 的数量。
```

重点指标：

| 指标 | 解释 |
|---|---|
| C 商品数 | 稳定小单池厚度 |
| C 占比 | 店铺是否有稳定盘 |
| 新 C 数量 | 新品是否开始起量 |
| 老 C 数量 | 是否形成长尾利润 |
| C 类目集中度 | 主打法是否清晰 |
| C 到 B 的推升比例 | 运营是否能继续放大 |

### 阶段 3：B/A 利润沉淀阶段

关键词：

```text
强候选品、利润锚点、稳定盈利
```

这个阶段开始关注 A/B，但不能只看销量，还要叠加利润率。

重点指标：

| 指标 | 解释 |
|---|---|
| A 数量 | 已验证核心利润品 |
| B 数量 | 强候选利润品 |
| A+B 占比 | 利润池厚度 |
| A/B 利润率 | 是否真的值得复制 |
| 广告占比 | 是否被广告成本吃掉 |
| A/B 类目集中度 | 精品化方向是否明确 |

注意：

```text
A 是结果，不是过程。
```

如果只看 A，会产生幸存者偏差。真正要学的是：

```text
这些 A 是从哪些 D/C/B 路径跑出来的？
```

### 阶段 4：精品回融阶段

关键词：

```text
从精铺里选精品，把已验证方向做深
```

这个阶段不是否定精铺，而是在精铺飞轮跑出结果后，把已经验证过的方向精品化。

可回融对象：

- A 级高利润商品
- B 级高潜力商品
- C 层里高利润、低广告、稳定出单的长尾品
- 多店铺、多国家重复验证的题材/载体/元素

精品化动作：

- 强化图片和视觉表达
- 做变体策略
- 做系列化开发
- 做供应链成本优化
- 做广告和自然排名沉淀
- 做跨国家迁移验证

## 四、我们当前到底是什么时候

结合材料，当前最准确的判断是：

```text
我们处在“撑盘子后段 + C 层沉淀初期”。
```

原因：

1. 自有老店铺已经有 A/B，不是完全没有利润品。
2. A 层和郑总老店铺差距并不大，自有 4-6 个，郑总约 6 个。
3. B 层自有店铺也不弱，自有约 20 个，郑总约 14 个。
4. 真正不足的是 C 层，自有老店铺约 20 个，郑总约 61 个。
5. 新店铺阶段也一样，自有 C 约 29-30 个，郑总约 41 个，差距仍然存在。
6. 利润截图说明，低销量商品不是不能做，但必须有利润率；因此 C/D 池要看利润和时间，而不是只看销量。

所以当前最重要的经营动作不是：

```text
立刻要求每个店多几个 A
```

而是：

```text
把 D 测品池做大、做准，把 C 稳定小单池做厚，再从 C/B/A 里回融精品。
```

## 五、对系统模型的影响

### 1. 店铺画像要增加“阶段判断”

当前店铺画像不应只输出“像不像郑总”，还应输出店铺所处阶段：

| 阶段类型 | 典型结构 |
|---|---|
| 撑盘子测品型 | D 多，新 D 多，C 开始出现 |
| C 池沉淀型 | C 厚，A/B 不一定多 |
| 飞轮验证型 | D 与 ABC 类目重叠高，C/B 持续增长 |
| 利润沉淀型 | A/B 稳定，利润方向明确 |
| 精品回融型 | A/B 高利润品可系列化开发 |
| 低效库存型 | 老 D 多、低利润、类目发散 |

### 2. 商品分级要叠加时间和利润

现有 `sales_tier` 仍然保留，但系统解释要升级为：

```text
sales_tier + age_bucket + profit_signal
```

优先级：

| 组合 | 判断 |
|---|---|
| 新 D | 正常测品 |
| 老 D + 无利润 | 低效库存 |
| 新 C | 重点观察 |
| 老 C + 有利润 | 长尾稳定盘 |
| B + 有利润 | 强候选精品 |
| A + 有利润 | 核心利润锚点 |
| A/B + 低利润 | 有销量但未必优质 |

### 3. 前端展示要从“看 A”转成“看阶段”

店铺页面需要突出：

- 当前店铺阶段
- A/B/C/D 分布
- C 层厚度
- D -> C 是否有效
- C/B/A 的类目重叠
- 老 D 是否过多
- 高利润 A/B/C 候选
- 可精品回融商品池

## 六、下一步落地建议

### 短期

1. 在店铺画像模型里增加 `developmentStage` 字段。
2. 增加 C 层核心指标：`cCount`、`cRatio`、`cCategoryConcentration`。
3. 增加 D/C 时间拆分：新 D、老 D、新 C、老 C。
4. 前端店铺画像列表增加“阶段”列，不只展示 A/B/C/D 数量。

### 中期

1. 引入利润信号，至少先支持手动导入或运营标注。
2. 做 `D -> C -> B -> A` 批次追踪。
3. 做“精品回融候选池”：从高利润 A/B 和稳定 C 中筛。
4. 做多店铺、多国家重复验证：同题材/同载体在多个店铺出现时，提高权重。

### 长期

1. 形成“精铺飞轮模型”：

```text
大量测品 -> C 层沉淀 -> B/A 利润品 -> 精品回融 -> 新一轮测品方向
```

2. 系统不再只回答“这个商品好不好”，而是回答：

```text
这个商品处在哪个阶段？
它属于哪个店铺打法？
它有没有从测品变成精品的可能？
```

## 七、最终判断

当前阶段不是精品阶段，也不是纯铺货阶段，而是：

```text
精铺撑盘子后的 C 层沉淀阶段。
```

郑总模式值得学习的重点，不是简单复制 A 级商品，而是复制其 C 层厚度和 D -> C -> B -> A 的转化能力。

我们下一阶段的关键目标：

```text
让 C 层变厚，让 D 层更准，让 A/B 从 C 池自然长出来。
```
