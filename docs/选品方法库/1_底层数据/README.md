# L1 · 底层数据

> 数据本身的清洗、字典、归档。**所有 L2/L3 上层只能消费 L1 的产物，不直接动原始表。**

---

## 这一层负责什么

把"脏数据 / 原始数据 / 字典数据"理成"上层能直接用的干净版本"：

1. **物化清洗** — 把含变体污染的原始表清洗成可信底座
2. **字典对齐** — 多语言锚点词、小类别名、标题匹配规则
3. **归档校验** — 原始数据快照、库表现状校验

## L1 → L2 的契约

L2 任何统计、判断都必须满足：

1. **FROM `competitor_products_clean`** — 不要 FROM 原始 `competitor_products`(变体污染)
2. **标题解析走 [[标题匹配规则]] 三步算法** — 不要自己拼正则
3. **多语言走 [[载体元素三语映射表]]** — 不要硬编码中文/英文/德文
4. **真值对照走 `product_performance_actual`** — 不要直接读原始 markdown

违反任何一条，结果不可信。
