## 三、三国搜索策略

### 载体锚点匹配(两条路径共用)
```
对每条标题:
  根据 marketplace 选锚点词库:
    UK → 英文锚点
    US → 英文锚点
    DE → 德文锚点 + 英文锚点(德国站常混英文)
  锚点词按长度降序 → 最长匹配优先
```

### 元素搜索(路径1)
```
已验证元素的英文锚点 → LIKE '%keyword%' 搜三国标题
DE附加德文变体 → LIKE '%德文词%'
```

### 元素匹配(路径2)
```
提取到的英文词 → element_library.element_en 模糊匹配
  → 匹配=已知元素(取中文名)
  → 未匹配=新元素(留英文,等人工)
DE提取的德文词 → element_library.element_de 也搜一遍
```

## 四、维护规则

1. **载体**:final_drafts 出现新载体→人工加三语→入库 is_active=1
2. **元素**:路径2发现→你人工确认"好卖"→补中文名+三语→入库 is_curated=1
3. **`??`标记**:德文不确定,暂 is_active=0,确认后启用
4. **同义/变体**:用 `/` 分隔,引擎按 LIKE 搜索
