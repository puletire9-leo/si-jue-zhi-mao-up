## 三层架构 (先理解全局)

```
┌─────────────────────────────────────────────────────────────┐
│  L3 前端组合层  把多个 L2 证据组合成方法卡片、视图、接口       │
│                "前端怎么筛、怎么看、怎么复盘"                │
├─────────────────────────────────────────────────────────────┤
│  L2 选品证据层  在干净数据上产出可组合的决策证据              │
│                "销量基线 / 错位机会 / 自有战绩 / 元素机会"    │
├─────────────────────────────────────────────────────────────┤
│  L1 数据底座层  原始数据、清洗数据、字典、归档                │
│                "所有上面层都依赖这层数据是干净的"             │
└─────────────────────────────────────────────────────────────┘
```

**关键依赖原则**：L2 从 L1 取干净数据算证据；L3 组合多个 L2 证据给前端用，不直接动原始数据。

## 闭环 (方法怎么活、怎么进化)

```
00_业务认知 ──给世界观──┐
                        ↓
认知卡 ──划数据红线──→ 方法卡 ──编译──→ filterRules ──→ 前端筛货
                        ↑
③线真实战绩(大脑·定方向)──圈定该猎的小类型──→ ①线(小类内看销量) + ②线(看错位)
                        ↑                                    │
                        └──── 回测green/eliminated校准模型 ←──┘
```

⚠️ 修正：猎场是**小类爆款**(大类中后段)，不是大类头部。榜单模型按小类建，不按大类。
