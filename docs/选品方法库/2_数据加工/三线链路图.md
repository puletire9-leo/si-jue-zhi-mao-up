# 三线链路图 · 选品推荐的三条独立方向

> 这不是流水线,是三个独立的分析维度。每个维度用自己的数据+自己的加工引擎,从不同角度回答"这个品能不能做"。
> 最终三线投票合成推荐。**链路由心,数据为基**——先看清每条线的完整链路,再动手修。
>
> 最后更新:2026-06-23 · 维护人:Claude + 你

```
                            competitor_products (32.9万行, ⭐唯一有燃料的公共底座)
                           /              |              \
          ① 跟着销量走           ② 跟着聪明卖家走          ③ 跟着自己经验走
```

```
                    ┌──────────────────────┼──────────────────────┐
                    ↓                      ↓                      ↓
              ①线查基线               ②线查热度             ③线查战绩
         "这品BSR段在大盘        "这品所在品类聪明        "这品像我们赢过的吗?"
          卖得动吗?"              卖家在进场吗?"
                    │                      │                      │
          ┌─────────┴─────────┐  ┌────────┴────────┐  ┌─────────┴──────────┐

                    │                      │                      │

                              ┌───────────────────────┐
```

## 三条线成熟度一览

| | ① 跟着销量走 | ② 跟着聪明卖家走 | ③ 跟着自己经验走 |
|---|---|---|---|
| 原料数据 | ✅ 32.9万行满油 | ✅ 6991家+32.9万行满油 | ⚠️ md文件228行(未入库) |

| 触发方式 | ⚠️ 只差手动POST | ❌ 无人接线 | ❌ |
| 计算结果表 | category_baselines(0行) | heat_matrix(0行) | agg_*(0行) |
| 消费方 | ❌ 无 | ❌ 无 | ❌ 无 |
| **卡壳点** | 拧钥匙(1次HTTP) | 缺计算大脑 | 缺入库管道 |
