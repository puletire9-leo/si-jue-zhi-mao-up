## 一句话本质(用户定调 2026-06-23)

③线 = **看那些大类里的小类怎么挣钱,分析这个品线为什么能挣钱**。而"为什么赢"只有有限几种模式,之前都说过:

| 原型 | 看什么 | 真实榜单/例子 |
|------|--------|--------------|
| **标品**(功能类) | 性价比 + 搭配 + **更快上架站住市场**(时间差) | 功能性工具/配件 |
| **非标品**(微定制) | **元素 + 载体** | 帆布袋、化妆包、挂牌(Suncatcher)、玩具人偶、帽子、钥匙扣 |

**判定规则(一刀切,用户原话):只要不是功能类的,都算非标品。**

## 战绩表设计(明天建表用)

现有 `agg_*` 表 schema 装不下(缺退款率/自然订单/小类排名),**新建 ASIN 粒度表**:

```sql
CREATE TABLE product_performance_actual (
  id BIGINT NOT NULL AUTO_INCREMENT,
  asin VARCHAR(20) NOT NULL,
  parent_asin VARCHAR(20) DEFAULT NULL,
  sku VARCHAR(100) DEFAULT NULL,
  marketplace VARCHAR(10) NOT NULL COMMENT '国家:UK/DE/IT',
  price DECIMAL(10,2) DEFAULT NULL COMMENT '售价(总价)',
  sales_volume INT DEFAULT NULL COMMENT '销量(周期待确认)',
  category_rank_main VARCHAR(200) DEFAULT NULL COMMENT '大类:排名 原文',
  category_main VARCHAR(100) DEFAULT NULL COMMENT '大类名(拆出)',
  category_rank_sub VARCHAR(200) DEFAULT NULL COMMENT '小类:排名 原文',
  category_sub VARCHAR(150) DEFAULT NULL COMMENT '小类名(拆出,方向参考)',
  acoas DECIMAL(8,4) DEFAULT NULL COMMENT 'ACoAS广告销售成本占比,空=纯自然',
  natural_clicks INT DEFAULT NULL COMMENT '自然点击量',
  ctr DECIMAL(6,4) DEFAULT NULL,
  ad_cvr DECIMAL(6,4) DEFAULT NULL COMMENT '广告转化率',
  natural_orders INT DEFAULT NULL COMMENT '自然订单量',
  fba_available INT DEFAULT NULL COMMENT 'FBA可售',
  refund_rate DECIMAL(6,4) DEFAULT NULL COMMENT '退款率',
  -- 原型与复盘(半自动打标)
  archetype VARCHAR(8) DEFAULT NULL COMMENT '标品STD/非标品CUSTOM',
  element VARCHAR(100) DEFAULT NULL COMMENT '元素(非标:Football/F1/猫头鹰)',
  carrier VARCHAR(100) DEFAULT NULL COMMENT '载体(非标:Tote Bag/Suncatcher/Cap)',
  listing_tags VARCHAR(200) DEFAULT NULL COMMENT '原始标签:欧洲精铺/淘汰/绿标',
  is_eliminated TINYINT DEFAULT 0 COMMENT '是否淘汰(负样本)',
  is_green TINYINT DEFAULT 0 COMMENT '是否绿标(正样本)',
  product_name VARCHAR(500) DEFAULT NULL COMMENT '中文品名',
  title VARCHAR(1000) DEFAULT NULL COMMENT '英文标题',
  bsr_id VARCHAR(100) DEFAULT NULL COMMENT '映射到competitor的大类slug(JOIN①线用)',
  source_batch VARCHAR(50) DEFAULT NULL COMMENT '导入批次',
  imported_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_asin (asin, marketplace),
  KEY idx_archetype (archetype),
  KEY idx_category_sub (category_sub(64)),
  KEY idx_eliminated (is_eliminated)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='自有真实战绩(tier1真值)';
```

## 原型半自动打标规则(导入时跑)

明天导入器按规则初筛 archetype,人工核:

```
1. archetype 判定:
   - 标题命中非标载体词(Bag/Tote/Suncatcher/Sun Catcher/Figure/Cap/
     Bracelet/Keychain/Keyring/Coin Purse/Cosmetic Bag) → 非标品CUSTOM
   - listing标签含"非标品" → 非标品CUSTOM
   - 否则 → 标品STD(功能类)

2. 非标品的 element+carrier 拆解:
   - 从英文title开头提取:首个名词短语前的修饰=element,核心名词=carrier
   - 例:"Football Canvas Tote Bag..." → element=Football, carrier=Tote Bag
   - 复杂的人工核(规则只做初筛)

3. 复盘标记:
   - listing标签含"淘汰" → is_eliminated=1
   - listing标签含"绿标" → is_green=1
```

## 导入方案

- **源**:`产品表现ASIN_转换版2.md`(markdown表格,591行)
- **方式**:写个一次性 Python/SQL 导入器,解析md表格→字段映射→打原型标→入库
- **国家映射**:英国→UK,德国→DE,意大利→IT
- **大类/小类拆分**:`Home & Kitchen：282571` 用 `：`(全角冒号)拆成 category_main + rank
- **bsr_id 映射**:大类名→competitor的slug(Toys&Games→toys, Garden→garden/outdoors, Home&Kitchen→kitchen...),用于和①线JOIN。这张映射表要建(大类英文名↔bsr_id slug)。
- **持续性**:md是一次性人工导出,**先做一次性导入拿80%价值**;领星持续同步以后再评估(Python端目前只有"系统→领星"导出,无回流)。

## ③线的三大用途(为什么它是tier1)

1. **回测标尺**:用 is_green(正)/is_eliminated(负)样本,跑①②③三线投票,看能否命中真实成败 → 这才是"80%成功率"的真实来源,不是拍脑袋加权。
2. **校准卖精**:我们真实 sales_volume vs 同品①线基线预测 → 算 marketplace×bsr_id 的卖精预测偏差。⚠️ 591样本按国家×大类分组后每组偏少,**只能定性参考,做不了严格定量校准**(修正之前夸大)。
3. **指挥深耕方向**:真实赢家集中的小类(Suncatcher/Tote Bag/Figure)= 该重点猎的方向,反向喂给方法卡和②线。
