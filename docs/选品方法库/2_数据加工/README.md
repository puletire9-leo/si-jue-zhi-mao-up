# L2 · 数据加工

> 在 L1 干净数据上算业务统计、判断、机会。**三线模型住在这层。**

---

## 这一层负责什么

把 L1 的干净数据加工成"能直接用来做决策"的中间产物：

1. **基线统计** — 大类/小类/账龄的销量、价格、BSR 分布
2. **机会判断** — 错位机会、可行动机会、新品分级
3. **真值对照** — 自有战绩库 vs 候选池的交集
4. **元素发现** — 标题里的元素+载体冒头候选

## L2 → L3 的契约

L3 任何视图、卡片、接口都必须：

1. **只读 L2 产物表** — 不直接 FROM `competitor_products_clean`
2. **不做新统计** — 想新统计就建到 L2
3. **方法卡只是镜头** — 不要把方法卡变成"入库时自动打的死标签"
