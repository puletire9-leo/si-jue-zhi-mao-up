# C02 · 聪明卖家分层与扎堆读法

> ②线"跟着聪明卖家走"的判断框架。回答一件事:郑总系卖家扎堆一个品类,到底是机会还是红海?
> 结论:**不是非黑即白,要分层看 + 按小类落地 + 三种读法并存。**
> 状态:框架已定(2026-06-23,用户拍板)；读法 C 的错位公式已由 `category_dislocation` + `/api/v1/category-dislocation/**` 落地（2026-06-26 对码更新）。

---

## 这张卡为什么存在(核心认知)

`deng_zong_shop` 不是"全球优质卖家名单",经数据验证(2026-06-23)是:**29家中国跨境卖家**(郑总的同行/对标盘子),seller_nation 全是 CN,名字全是拼音公司名。

所以"smart_density(聪明卖家密度)"的真实语义 = **"中国精铺同行already杀进了哪些品类"**。

这一点决定了:**密度高 ≠ 一定是机会**。对你这种同类型卖家,同行扎堆可能意味着时间差已关闭(红海)。方向不能想当然。

---

## 三种读法(都对,看小类才能定)

| 读法 | 含义 | 何时成立 |
|------|------|----------|
| **A 扎堆=红海,躲开** | 9家同行都在做某细分 → 卷死了 → 放弃 | 小类已高度饱和,价格战、低利润 |
| **B 扎堆=验证,跟进** | 同行在做且活着 → 需求被验证 → 值得进 | 大类有量,但小类里还有没被占的空位 |
| **C 错位=真信号(最优)** | **外部优质卖家(非CN)在做、郑总系还没进** | 别人验证了需求 + 你还有时间差 → 最该开拓 |

**用户拍板(2026-06-23):三种读法都要做,因为市场是变化的,我们也要灵活变化。**
- a(跟进)要看**具体小类**——有些实在太卷,放弃是应该的。
- c(开拓错位市场)**也要做**——市场在变,主动找别人没占的空位。

---

## 这要求卖家必须分三层,而不是算一个密度

旧设计里的 `category_heat_matrix` 曾试图把卖家热度揉成一个 `smart_density`，但这会抹掉最关键的"错位"信号。当前已改为 `category_dislocation`：直接按小类统计郑总系 / 其他 CN / 非 CN 三层卖家，并计算 `dislocation_score` 与 `heat_signal`。

```
某品类/小类里的卖家 →  ┌ 郑总系(29家CN同行)        ← 我们已知的对标
                      ├ 其他CN卖家                  ← 同质竞争
                      └ 非CN优质卖家(US/DE/GB等)   ← 验证需求、且我们有时间差
```

**真正的机会信号(读法C)= 非CN优质卖家在做 + 郑总系=0或极少。**
**红海信号(读法A)= 郑总系扎堆 + 价格战特征(待定义)。**

---

## 已验证的事实(2026-06-23,真实数据)

- 匹配率:29家郑总卖家,**25家**(86%)能在 competitor_products 用 `seller_id` 匹配上。seller_name 也基本可用,但 **seller_id 更稳**(亚马逊卖家主键)。
- ⚠️ **collation 坑**:`competitor_products.seller_id` 是 `utf8mb4_0900_ai_ci`,`deng_zong_shop.seller_id` 是 `utf8mb4_unicode_ci`,直接 JOIN 报 "Illegal mix of collations"。**任何跨表JOIN必须加 `COLLATE utf8mb4_unicode_ci`**。这是真实代码坑,记牢。
- 郑总扎堆图(202606):UK outdoors(9家)、DE garden(4)、DE kitchen(8)、DE toys(5)、UK sports(7)。
- **共线警告**:郑总扎堆的大类,和①线销量最厚的大类高度重叠 → ①(销量)②(聪明卖家)**不独立**,三线投票不能简单相加。

---

## 与①线、③线的关系

- **vs ①线**:高度共线(聪明卖家往销量大的池子扎)。所以②线的价值**不在"密度高"**,而在**"错位"**(读法C)——这是①线给不了的独立信号。
- **vs ③线**:③线(我们自己赢过的品)可以反过来标注"郑总系里哪些是真值得对标的"——我们也赢过的品类,郑总同行的动作更可信。
