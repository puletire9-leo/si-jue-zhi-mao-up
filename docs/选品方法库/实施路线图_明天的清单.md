## 里程碑验证(每步可独立见效)

```
M1(③线入库)  → 能查"我赢过哪些小类型"          ← Day1
M2(①线基线)  → 能查"某BSR段/小类大盘卖多少"     ← Day1-2
M3(②线错位)  → 能查"哪些小类本土在做CN没进"      ← Day2
M4(合成回测)  → 能跑"给候选品打分+区分成败"      ← Day3
M5(前端)      → 你能在界面上看到推荐            ← Day3+
```

每个M独立可用,不必等全部完成。M1完成你就已经有"赢家类型库"可用了。

## 不做什么(避免范围蔓延)

- ❌ 不碰老 agg_* 表(空壳,职责不同,别复活)
- ❌ 不做领星持续同步(md一次性导入够,以后评估)
- ❌ 不做category_baselines老8维(emotion/culture那套,先放着)
- ❌ 不入库自动打标(filterMode改mo1/mo2是手动,见[[系统落地映射]])
- ❌ 不追求精确"80%"(回测先能区分成败,数字随数据逼近)
