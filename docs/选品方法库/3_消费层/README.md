# L3 · 前端组合层

> 目录名仍是 `3_消费层`，但更直观的职责名是 **前端组合层**。
> 它把多个 L2 选品证据组合成前端方法卡片、产品卡片、filterRules 和接口。**这层不新增底层统计。**

---

## 这一层负责什么

把 L2 的证据产物组合成"能直接给用户看 / 给前端调 / 给业务复盘"的东西。**方法卡片归这一层**，因为它直接对接前端筛货、展示和复盘。

1. **门面卡** — "当前系统能拿出什么"全景
2. **方法卡片 → 规则编译** — 把销量基线、错位机会、元素机会等多个 L2 证据组合成 filterRules / 前端显示镜头
3. **产品卡片** — 把 ①②③④/M04 组合成新品分级卡、可行动机会卡、赢家方向卡等
4. **接口产物** — 已开放的接口验证报告

## 当前建议直接做成"产品卡片"的

### 主卡

1. **③×② 可行动机会卡** — 既有市场错位，又有历史赢家证据，最接近"能行动的方向"
2. **M04 新品分级卡** — 已能批量给 S/A/B/C/D
3. **③ 赢家方向卡** — 告诉你"我们真实赢过什么 archetype / carrier / element"

### 辅助卡

1. **① 销量基线解释卡** — 当尺子用，挂在详情边
2. **④ 非标候选卡** — 当前更适合做"人工审阅卡"，不要包装成全自动

### 当前不建议包装过头

- ④ 不要现在就讲成"正式元素库 + 全自动机会推荐"
- M05 没真实内容，不要做前端产品卡

---

## L3 的红线

1. **只组合 L2 证据产物** — 不直接 FROM `competitor_products_clean`
2. **不做新的底层统计** — 想加新统计回到 L2
3. **方法卡片只是镜头** — 不要把方法卡片变成"入库时自动打的死标签"
