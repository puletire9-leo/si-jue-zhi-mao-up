# 手动非标候选导出接口（2026-06-24）

## 1. 目标

给手动 AI 审核链路提供一份稳定的后端候选输出。

当前链路定位为：

`competitor_products -> 文档载体命中 -> 标准品粗过滤 -> ①线大类 BSR 基线参考 -> JSON 候选结果`

它解决的是“系统筛过的数据从哪里来”这一段，不负责：

- 最终 AI 判断
- 最终元素定稿
- 直接写入 `selection-agent/系统来源/*.csv`

后续宿主机脚本只需要调用这个接口，再把 `items` 写成 CSV 即可。

---

## 2. 接口

### 路径

`GET /api/v1/element-discovery/manual-candidates`

### 参数

- `marketplace`：站点，默认 `UK`
- `month`：月份，可空；为空时取 `competitor_products` 最新月
- `scanLimit`：扫描前置样本数，默认 `1000`
- `limit`：返回候选条数上限，默认 `200`
- `carrier`：可选；传入 canonical 载体名时，只输出该载体候选

---

## 3. 口径

### 3.1 载体来源

当前仍使用代码中 bootstrap 的文档载体清单：

- `ProductTitleParsingServiceImpl.CARRIER_PATTERNS`

这只是过渡态。
后续应切到你手动维护的“选品载体表”。

### 3.2 载体提取

- 载体只从标题提取
- 不从大类/小类反推载体
- `matched_carrier_anchor` 表示标题里命中的载体锚点
- `carrier_candidates` 当前先给 1 个 canonical 载体，供手动 AI 标准化使用

### 3.3 粗过滤

当前复用 `ElementDiscoveryServiceImpl` 里的粗过滤规则：

- 配件/适配件/硬件类
- 官方周边/收藏品类
- 明显赛程图表/活动布景类
- 功能型标准品类

注意：

- 这一步只是“粗过滤”
- 不是最终非标判定
- 真正的 `element + carrier` 定稿仍由后续人工 AI 审核完成

### 3.4 ①线作用

当前接口里，①线只做**参考信息**，不做硬门槛卡死：

- 查询 `category_bsr_baseline`
- 返回 `baseline_bucket / baseline_p25 / baseline_p50 / baseline_p75 / baseline_confidence`
- 写进 `notes`

也就是说：

- 现在先让系统把候选吐出来
- 再由你看这批载体命中的精度
- 等口径稳定，再决定是否把 ①线改成硬筛选条件

---

## 4. 返回结构

顶层字段重点看：

- `scannedProducts`
- `matchedProducts`
- `keptNonStandardProducts`
- `filteredStandardProducts`
- `filteredByReason`
- `baselineResolvedCandidates`
- `items`

`items` 里的字段已对齐手动链路需要的核心列：

- `row_id`
- `asin`
- `marketplace`
- `title`
- `matched_carrier_anchor`
- `carrier_candidates`
- `category_hint`
- `bsr_id`
- `notes`

并补充了后端参考字段：

- `canonical_carrier`
- `element_hint`
- `brand`
- `raw_subcategory`
- `units`
- `bsr`
- `price`
- `baseline_has_data`
- `baseline_month`
- `baseline_bucket`
- `baseline_sample_size`
- `baseline_confidence`
- `baseline_p25`
- `baseline_p50`
- `baseline_p75`
- `baseline_price_avg`

---

## 5. 与任务开关的关系

当前 `selection-agent/0.1版本手动/非标选品/任务开关.json` 还是**下游开关**。

它控制的是：

`系统来源 CSV -> 按 50 个 ASIN 分批`

而本接口负责的是更上游这一段：

`真实库筛后候选 -> JSON 输出`

下一步应该补一层宿主机导出脚本，把本接口的 `items` 写成：

`selection-agent/0.1版本手动/非标选品/系统来源/<日期>/system_filtered_candidates.csv`

这样现有开关就能直接接上。
