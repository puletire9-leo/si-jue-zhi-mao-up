## 7. 抽查结论

### UK

前几条候选整体合理，像：

- `Garden Flag`
- `Backdrop`

说明 UK 当前链路可直接进入人工 AI 审核。

### DE

链路已经能稳定凑到 `100` 条，但前排样本出现了明显噪音：

- `PLAYMOBIL ... Figur`
- `PLAYMOBIL ... Armband`
- `PLAYMOBIL ... Handtasche`

问题不是载体识别失败，而是：

- 玩具标题里的“配件词”被当成了载体
- 当前粗过滤还没有把“玩具套装自带小配件”排掉

### US

链路能稳定凑到 `100` 条，但前排有明显误判：

- `Chemical Guys ... Microfiber Towel`
- `Cleaner ... Towel Bundle`

问题是：

- 汽车清洁/功能型套装里的 `towel` 被当成了非标载体
- 当前粗过滤对 `automotive cleaning kit / bundle / degreaser / solvent` 这类标准功能品过滤不够

## 8. 本次测试后的直接结论

### 已经确认可用的部分

1. 真正的全量分析库是 `geji_analysis`
2. `manual-candidates` 接口可以在全量库上跑通三国
3. `系统来源 CSV -> 50 ASIN 批次文件` 的下游链路已经跑通
4. 现在已经能稳定给 `UK / DE / US` 各落一套 `100 ASIN` 人工审核输入

### 当前最主要的问题

不是“链路不通”，而是“粗过滤精度不够”：

1. `DE`：玩具套装类噪音偏多
2. `US`：汽车清洁套装 / 功能品噪音偏多
3. `baseline_*` 在 `geji_analysis` 上当前为空，因为缺 `category_bsr_baseline`

---

## 9. 下一步建议

优先顺序建议：

1. 先人工抽样审核三国这 `300` 条，判断真实非标命中率
2. 根据误判样本补 `FILTER_RULES`
3. 给 `US` 增加汽车清洁/功能 bundle 过滤词
4. 给 `DE` 增加“玩具套装内配件词”过滤
5. 之后再决定是否要把 `category_bsr_baseline` 同步到 `geji_analysis`

如果只看“系统有没有通”，答案是：**已经通了。**
如果看“现在拿去大规模自动喂 AI 是否足够干净”，答案是：**还需要继续压噪音。**

## 12. 6.24 第三轮回归（r7：补 DE Sticker 助威套装过滤）

### 12.1 本轮新增的后端修正

在 `r6` 样本复核时，发现 `DE` 里还残留两类明显不想要的 `Sticker` 候选：

- `Fanartikel Set ... Handfahne ... Tattoo Sticker`
- `Fahrradfahne ... Tattoo Sticker ... Fanartikel`

它们的问题不是“贴纸元素不对”，而是：

- 标题里虽然带了 `Sticker`
- 但实际商品更像“足球助威套装 / 旗子配件包”
- 不适合作为当前手动非标链路里的干净贴纸样本

因此本轮在后端新增了一个很窄的过滤规则：

- 仅当 `canonical_carrier = Sticker`
- 且同时命中 `handfahne / handfahnen / fahrradfahne / fahrrad fahne / blumenkette`
- 再叠加 `fanartikel / tattoo sticker / public viewing`

才过滤为：

- `sticker_fan_set_bundle`

这样不会误伤普通贴纸，只拦足球助威套装型噪音。
