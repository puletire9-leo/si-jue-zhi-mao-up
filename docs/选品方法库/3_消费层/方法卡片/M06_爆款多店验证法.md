# M06 · 爆款多店验证法

> 方法卡片归属 L3 前端组合层。它消费商品基础特征、店铺画像证据、标题相似/商品族证据，用来发现“已经被市场和多家店铺验证过，但当前新链接还没来得及起量”的候选商品。

---

## 身份

`id: M06` · `状态: draft` · `消费页面: 选品 / 店铺画像 / 单店详情`

一句话：当某个商品形态已经在多个店铺被验证为能卖，后续出现同款或高度相似新品时，即使这个新品刚上架 2 天、暂时没有销量，也可以作为候选，因为我们判断的不是“当前 ASIN 已经卖起来”，而是“这个商品族已经被验证过”。

## 何时用

- 已发现一个爆款或稳定款，例如 30 天销量 50+。
- 同一个 ASIN 或高度相似商品在多家店铺出现。
- 多家店铺里存在“新店 / 好店 / 郑总相似店 / 自有优质相似店”共同验证。
- 新出现的相似商品刚上架，销量还没来得及体现，但标题、类目、图片或商品结构高度相似。
- 想提前抓“已验证爆款的新品跟进款”，而不是等它销量起来后再追。

不适合：

- 只因为标题像，但类目、用途、价格带、图片结构完全不同。
- 可能涉及侵权、品牌词、明显仿牌的商品。
- 只有单店单品出现，缺少多店验证。
- 店铺质量很差，且缺少其他独立证据支撑。

## 输入

这张卡不只看单个商品销量，而是组合多个证据：

| 证据 | 来源 |
|---|---|
| 爆款种子 ASIN | 新品榜、竞品池、郑总店铺、自有战绩 |
| 商品基础特征 | `sales_tier`、`listing_days`、价格、重量、BSR、类目 |
| 店铺画像证据 | 店铺 A/B/C/D 分布、ABC 稳定盘、A 层类目、D 测品池、方法卡命中 |
| 多店出现证据 | 同 ASIN / 同父体 / 标题高度相似 / 商品族相似 |
| 标题与品名相似证据 | 标题关键词、载体、元素、用途词、规格词 |
| 风险证据 | 品牌词、侵权词、异常低价、类目错配 |

## SOP

1. 先确定爆款种子：例如某商品 30 天销量 50+，或进入 B/A 销量层。
2. 抽取商品族特征：标题核心词、载体、元素、用途、规格、类目路径、价格带。
3. 查找同 ASIN、同父体或高度相似商品，统计出现在哪些店铺。
4. 读取这些店铺的画像：是否有 ABC 稳定盘、是否是郑总相似店、自有优质相似店、方法卡高命中店。
5. 对新出现的相似商品，不强依赖当前销量；重点看“商品族是否已验证”。
6. 输出候选清单，并标注为什么可以提前看。

## 判定标准

第一版可以用解释型规则，不急着做黑盒分数。

### 必须满足

| 条件 | 说明 |
|---|---|
| 商品族已有验证 | 至少存在一个销量达到 B/A 或稳定 C 的同款/相似款 |
| 多店出现 | 同款/相似款出现在多家店铺，避免单点偶然 |
| 类目一致 | 类目路径或榜单类目应基本一致 |
| 标题核心一致 | 标题中的载体、用途、元素或规格高度相似 |
| 风险不过线 | 无明显品牌侵权、仿牌、类目错配、异常低价 |

### 加分证据

| 证据 | 解释 |
|---|---|
| 出现在郑总相似店 | 说明它符合已验证精铺打法 |
| 出现在自有优质相似店 | 说明它靠近我们已有成功经验 |
| 出现在方法卡高命中店 | 说明店铺本身有持续产出能力 |
| 新品刚上架 | 说明当前销量低可能只是时间不够 |
| D 层测品与 ABC 类目重合 | 说明店铺不是乱铺，而是在已验证方向继续测 |

## 核心判断

这张卡和 M01 最大不同是：

```text
M01：看这个新品当前是否已经达到销量/BSR/账龄标准。
M06：看这个新品所属商品族是否已经被多店、多证据验证。
```

所以一个 2 天无销量的新 ASIN，在 M01 里可能不会命中；但如果它属于一个已经被多家优质店验证的爆款商品族，M06 可以把它提前圈出来。

## 产出

- 候选 ASIN 列表。
- 商品族名称或相似组 ID。
- 种子爆款 ASIN。
- 同款/相似款出现店铺数。
- 出现店铺画像摘要。
- 是否命中郑总相似店 / 自有优质店 / 方法卡高命中店。
- 当前 ASIN 销量、上架天数、类目、价格。
- 中文命中原因。

示例命中原因：

```text
该商品当前上架 2 天、销量暂未体现，但其商品族已有 3 个相似 ASIN 在 5 家店铺出现，其中 2 家接近郑总精铺基线；种子 ASIN 30 天销量 50+，类目和价格带一致，因此可作为爆款跟进候选。
```

## 数据层边界

M06 本身不直接计算底层统计。它应该消费以下 L2 / 店铺画像证据：

| 层 | 产物 |
|---|---|
| 商品基础特征层 | 销量分级、上架天数、价格、重量、类目 |
| 商品族/标题相似证据层 | 同款、相似款、标题核心词、元素载体 |
| 店铺画像证据层 | 店铺 A/B/C/D 分布、ABC 稳定盘、D 测品池、基线相似 |
| 方法卡命中层 | M01/M03/未来方法卡命中摘要 |

这意味着店铺画像不只是“选店铺”用，也会反过来帮助“选商品”：一个商品如果被多家优质画像店铺共同验证，它的未来确定性会提高。

## 边界与风险

- 标题相似不能单独作为命中依据，必须叠加类目、图片/结构、价格带或人工复核。
- 同款多店出现不等于一定能做，仍要看侵权风险、供应链可得性、价格空间。
- 新品无销量不是问题，但“商品族没有被验证”才是问题。
- 不能把 M06 做成简单的“销量高就跟”卡，否则会退化成普通爆款追踪。
