# 郑总店铺数据按日期分批次存储

## 问题

当前 `deng_zong_shop` 表唯一键是 `(marketplace, asin, month)`，每次导入同一 ASIN 的数据会覆盖旧记录（ON DUPLICATE KEY UPDATE），无法保留历史批次。

## 目标

- 每次导入生成新批次，用 `batch_date`（如 `20260616`）区分
- 旧数据永久保留，不覆盖
- 前端默认读取最新批次
- 本次只改 `deng_zong_shop`（郑总店铺），`competitor_products` 后续再做

## 方案

给 `deng_zong_shop` 加 `batch_date` 列，唯一键改为 `(marketplace, asin, month, batch_date)`，每次导入写不同行。

## 改动清单

### 1. 数据库迁移 SQL

**文件**: `mysql/init/06-batch-date-migration.sql`（新建）

```sql
ALTER TABLE deng_zong_shop ADD COLUMN batch_date VARCHAR(8) DEFAULT NULL COMMENT '批次日期 YYYYMMDD';
ALTER TABLE deng_zong_shop DROP INDEX uk_marketplace_asin_month;
ALTER TABLE deng_zong_shop ADD UNIQUE KEY uk_marketplace_asin_month_batch (marketplace, asin, month, batch_date);
ALTER TABLE deng_zong_shop ADD INDEX idx_batch_date (batch_date);
```

已有 6991 行 `batch_date = NULL`，MySQL InnoDB 中 NULL 不互相冲突，旧数据完整保留。

### 2. 实体类

**文件**: `DengZongShop.java`

加一个字段：
```java
private String batchDate;
```

### 3. Mapper

**文件**: `DengZongShopMapper.java`

- `upsert()` — INSERT 中加 `batch_date` 列和值，ON DUPLICATE KEY UPDATE 加 `batch_date=VALUES(batch_date)`
- 新增 `selectMaxBatchDate(marketplace)` — `SELECT MAX(batch_date) FROM deng_zong_shop WHERE marketplace = ?`
- 所有查询方法加 `@Param("batchDate")` 参数，SQL 中加 `<if test='batchDate != null'> AND batch_date = #{batchDate}</if>`
  - `selectGroupedByParent` / `countGroupedByParent`
  - `selectSellerSummary`
  - `selectFetchedSellerNames`
  - `selectRatingData`
  - `selectZhengNodeCounts` / `selectZhengBsrIdsOrdered`

### 4. Service

**文件**: `DengZongShopService.java`

- `mapToEntity()` 加: `e.setBatchDate(LocalDate.now().format(DateTimeFormatter.ofPattern("yyyyMMdd")))`
- 新增 `getMaxBatchDate()` 方法
- `countGroupedByParent` / `selectGroupedByParent` / `selectSellerSummary` 签名加 `String batchDate` 并透传到 mapper

### 5. Controller

**文件**: `DengZongShopController.java`

- 新增 `GET /api/v1/deng-zong-shop/max-batch-date` — 返回最新批次日期
- `/products`、`/seller-summary`、`/variants`、`/stats` 端点加可选参数 `batchDate`，未传时自动取最新批次
- `toResponse()` 加 `batchDate` 字段

### 6. 其他 Java 服务

- **`ProductLineGuidanceService`**: `aggregateData()` 加 `batchDate` 参数
- **`ProductLineController`**: `/aggregated-data`、`/all-categories` 用 `selectMaxBatchDate` 替代 `selectMaxMonth`
- **`ShopRatingServiceImpl`**: mapper 调用处传入最新 `batchDate`

### 7. 前端 API

**文件**: `competitor.ts`

- `CompetitorProductRaw` 接口加 `batchDate?: string`
- 新增 `getDengZongMaxBatchDate()` 方法

### 8. 前端 Store

**文件**: `product-line-selection/store.ts`

- 新增 `zhengBatchDate` ref
- `fetchTree()` 先调 `/max-batch-date` 获取最新批次
- `loadProducts()` 郑总模式下传 `batchDate` 参数

### 9. 前端页面

**文件**: `zheng-shop-analysis/index.vue`

- `UnifiedStore` 接口加 `latestBatchDate` 字段映射

## 验证方式

1. 执行迁移 SQL，确认已有数据 `batch_date = NULL` 且查询正常
2. 导入一个郑总卖家 → `batch_date` = 当天日期
3. 刷新品线选品页 → 显示最新批次数据
4. 二次导入同一卖家 → 旧批次保留，前端显示最新
5. `GET /api/v1/deng-zong-shop/max-batch-date` 返回正确日期
