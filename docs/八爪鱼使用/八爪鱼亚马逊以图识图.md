| | 本功能：八爪鱼亚马逊以图识图 | 腾讯云图像搜索（已存在） |
|---|---|---|

## 整体逻辑（原始构想）

设想：数据库有每个 ASIN 的图片，一个图片链接转变为 3 个国家的格式：

- **德国**：`https://www.amazon.de/shopthelook?q=https%3A%2F%2Fm.media-amazon.com%2Fimages%2FI%2F51VP9KSOYUL.png`
- **英国**：`https://www.amazon.co.uk/stylesnap?q=https%3A%2F%2Fm.media-amazon.com%2Fimages%2FI%2F51VP9KSOYUL.png`
- **美国**：`https://www.amazon.com/shopthelook?q=https%3A%2F%2Fm.media-amazon.com%2Fimages%2FI%2F51VP9KSOYUL.png`

> 即把 ASIN 的图片 URL（如 `https://m.media-amazon.com/images/I/51VP9KSOYUL.png`）做 URL 编码后拼到各站点视觉搜索页的 `?q=` 后面。注意 **UK 用 `stylesnap`，US/DE 用 `shopthelook`**。

然后在后端新增八爪鱼的接口，用于以图识图。这样实现：

1. **批次集成**：每批次商品在初筛选后，再调用八爪鱼的接口做以图识图。
2. **结果存储**：新建一个「以图识图表」，用于存储以图识图的结果。
3. **对外接口**：再对外暴露一个接口，输入 ASIN，返回以图识图的结果。前端就可以使用了。
4. **前端入口**：在商品的右上角新增一个按钮，点击后调用以图识图的接口，返回以图识图的结果。单独设计一个以图识图页面卡片用于看结果（前端具体实现后续，当前是整体逻辑）。
5. **实时模式**：也可以实时调用以图识图的接口——输入图片链接，直接返回以图识图的结果。

## 2026-06-30 实测纪要（API 实验，以官方文档 docs/八爪鱼使用/文档.md 为准）

用 Python 客户端 `产品数据/八爪鱼api/bazhuayu_api.py` 对英国任务（taskId `5c2ae37f-3128-4c82-84d6-70ad6d3d3655`）跑了端到端实验，结论如下：

**✅ API 全链路打通**（每环实测成功）：登录 → `updateLoopItems` 写 URL 进循环 → `startExtraction` → `getTaskStatusesV2` / `getSubtaskStatuses` 查状态 → `getAllDataByOffset` 拉数据 → `stopExtraction` 停止 → 清空循环列表。

**关键纠正 ①：写 URL 必须用「循环步骤」，且 `updateLoopItems` 必带 `actionId`。**
- 任务**没有循环步骤**时，`updateLoopItems` 报 `TaskSettingsNotFound`（任务更新失败，无法找到对应的步骤）。
- 英国以图识图任务原始结构只有一个 `NavigateAction`（actionId `s6tnzlut7sp`，url 写死一个 stylesnap 示例图），**没有 LoopAction**。
- 在八爪鱼**客户端手动给任务加了循环步骤**后（LoopAction actionId `8djrlk2mqdh`，loopType `URLList`），`updateLoopItems(taskId, actionId, "UrlList", urls)` 才成功，10 条 URL 正确写入并生成 10 个子任务。
- `updateLoopItems` 正确请求体（文档 962-984 行）：`{taskId, actionId, loopType:"UrlList", loopItems:[...], isAppend:false}`。loopType 传 `UrlList`，回显 `URLList`，八爪鱼内部归一。

**关键纠正 ②：`/task/urls:file` 对本任务无效。**
- 上传 URL 文件接口返回成功（`data:null`），但启动后**0 子任务、3 秒结束、0 行**。该任务不吃这条路，只认循环步骤。

**关键纠正 ③：`updateActionProperties` 改 NavigateAction url（单条）可行但格式严格。**
- 正确格式：`actions:[{actionId, actionType:"NavigateAction", properties:[{name:"Url", value:"<url>"}]}]`。直接放 `url` 字段会报 `ServerError`。

**⚠️ 阻塞问题：采集产出 0 行（待查八爪鱼任务模板）。**
- 10 条 URL 正确写入、生成 10 个子任务后启动，运行 7+ 分钟：仅 1 个子任务 Finished 且**无数据**，其余 9 个一直 `Waiting` 不动，`currentTotalExtractCount` 始终 0。
- 这是**八爪鱼任务模板设计**层面的问题（打开 stylesnap 页 ≠ 能抓到数据），**API 与后端代码均无法解决**。需在客户端确认：循环里「打开网页」后是否有「提取数据」步骤、内置浏览器能否加载出 stylesnap 相似商品、提取规则是否配好。
- **该任务暂保留，待模板调通后再继续。**
