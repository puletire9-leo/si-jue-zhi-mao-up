通过开放接口，您可以获取或更新任务信息、控制云采集、读取采集到的数据等。在此之前，您应该拥有一个八爪鱼的账号。

## URI 规范

我们提供的开放接口都应该基于如下 URL 访问：

```
BaseURL: https://openapi.bazhuayu.com
```

例如：【搜索任务】的完整访问地址应该是：

```
GET https://openapi.bazhuayu.com/task/search?taskGroupId={taskGroupId}
```

> **注意**：对于本文档出现的 `{xxxx}`，它表示占位符，你需要用实际真实的值来替换它。如上文中的 `taskGroupId={taskGroupId}`，你需要用真实的 `taskGroupId` 替换 `{taskGroupId}`。

## 接口说明

为了更稳定地使用我们的服务，建议接口访问频率不超过 **20 次/秒**。如果超出该频率将会返回 `429` 的状态码，此时请降低访问频率到 20 次/秒以下或者更低。频率限制是通过 IP 限制，可以用多个不同的 IP 访问来提高访问效率。

以下接口正常情况下返回的状态码为 `200`，若返回非 200 状态码请移步页尾查看[错误码](#错误码)来尝试解决问题。

> **遇到问题**：文档中的任意接口将会返回 `requestId`，如您调用接口发现任何错误或者结果不符合预期，请提供该值以供我们工作人员能够更加快速为您排查。

|------|------|

| 字段 | 类型 | 描述 |
|------|------|------|

| `grant_type` | String | 固定值填写 `password` |

### 查询任务采集与执行分析

按日/周/月粒度查询任务采集量、执行次数、成功率及资源消耗等指标。时间范围为 UTC 自然日，仅支持查询最近 3 个月内数据。未传 `memberNames` 或传空数组时，仅查询当前登录用户；传入成员名称时须为当前用户团队成员。

| 项目 | 内容 |
|------|------|

- 第二次：`offset = 1024`，`size = 100`，返回：`offset = 1124`
