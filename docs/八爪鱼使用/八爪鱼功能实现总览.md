# 八爪鱼功能实现总览

> 本目录记录基于「八爪鱼开放平台」的两个独立功能。最后更新 2026-06-29。

## 账号

八爪鱼团队版，账号 `sijuetec`，有效期至 2027-03-19。
凭证存 `config/secrets/{dev,prod}.env`（`BAZHUAYU_USERNAME` / `BAZHUAYU_PASSWORD`，gitignored），可被 DB `api_config` 运行时覆盖。
API 文档：[产品数据/八爪鱼api/文档.md](../../产品数据/八爪鱼api/文档.md)。

## 两个功能（边界清晰）

| 功能 | 状态 | 做什么 | 文档 |
|------|------|--------|------|
| **榜单链接采榜单数据** | ✅ 已实现 | 每周定时云端爬取亚马逊榜单新品 → 周表 → 复用初筛 → 前端确认 → 卖家精灵 | [榜单链接采榜单数据.md](榜单链接采榜单数据.md) |
| **亚马逊以图识图** | 🚧 设计中（未实现） | 把 ASIN 图片转三国视觉搜索 URL，用八爪鱼爬亚马逊原生以图搜图结果 | [八爪鱼亚马逊以图识图.md](八爪鱼亚马逊以图识图.md) |

两个功能**各自独立**：不同的八爪鱼任务、不同的数据表、不同的用途。**不要把任务 ID 混进对方的配置**。

## 共用基础设施（榜单采集已落地，以图识图可复用）

- `modules/bazhuayu/service/BazhuayuClient.java` — 八爪鱼 API 客户端（token 管理 + 启动/轮询/分页拉取）。
- `modules/bazhuayu/service/BazhuayuConfigService.java` — 凭证 + 任务映射（DB 覆盖 env）。
- `modules/bazhuayu/config/BazhuayuConfig.java` — `@ConfigurationProperties(prefix="bazhuayu")`。

## 不要混淆：八爪鱼以图识图 ≠ 腾讯云图像搜索

系统里另有一套**腾讯云图像搜索**（`backend/app/services/tencent_image_search_service.py`），用腾讯云 API 在自建图片库里以图搜相似图，服务于素材库。它和八爪鱼**毫无关系**。本目录文档只讲八爪鱼。
