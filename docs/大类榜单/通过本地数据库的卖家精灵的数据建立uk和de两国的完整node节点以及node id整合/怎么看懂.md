# UK / DE 完整 Node 类目树

两个 JSON 直接来自本机 MySQL 的卖家精灵结果表：`competitor_products` 与 `brs_ranking_raw`。

## 三个文件

- `UK_complete_node_tree.json`：英国完整类目树。
- `DE_complete_node_tree.json`：德国完整类目树。
- `怎么看懂.md`：本说明文件。

## 怎么看链路

从 JSON 最外层 `children` 开始，逐层继续看节点的 `children`，直到没有 `children`，就是叶子类目。沿途的 `label` 连起来是类目链路，沿途的 `node_id` 连起来是 node_id 链路。

## 字段

- `label`：当前层类目名；`node_id`：当前层 Node ID；`level`：层级。
- `product_count`：当前节点及下级去重 ASIN 数；`direct_count`：直接落在当前节点的 ASIN 数。
- `children`：下一级节点；没有该字段表示叶子节点。
- `bsr_ids`：该大类关联的 BSR 标识（如有）。

## 统计

```json
{
  "UK": {
    "nodes": 7841,
    "top_categories": 57,
    "products": 115703
  },
  "DE": {
    "nodes": 8466,
    "top_categories": 45,
    "products": 156000
  }
}
```

同一个 node_id 如果出现在多个实际链路中，树会按实际链路分别保留；判断类目时请结合完整链路和 node_id。
