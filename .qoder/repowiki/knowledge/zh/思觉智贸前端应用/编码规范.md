- API 模块采用集中式定义模式，在 `src/api` 下按业务域（如 `user.ts`, `product.ts`）导出包含具体请求方法的对象。
- 视图组件统一放置在 `src/views` 的子目录中，入口文件固定命名为 `index.vue`，复杂页面内部再拆分 `components` 子目录。
- 通用业务组件存放在 `src/components` 下，每个组件独占一个以大驼峰命名的文件夹，并通过 `index.vue` 暴露主逻辑。
- Pinia Store 采用 Setup Stores 写法（组合式 API），在 `src/stores` 中通过 `defineStore` 定义并导出 `useXxxStore` 钩子。
