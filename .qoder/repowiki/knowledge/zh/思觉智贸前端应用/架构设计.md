- **技术栈与构建**：采用 Vue 3 (Composition API) + TypeScript + Vite 7，UI 框架为 Element Plus，状态管理使用 Pinia，路由为 Vue Router。
- **目录分层**：`src/api` 封装 Axios 请求；`src/views` 承载业务页面；`src/components` 存放通用 UI 组件（如 `UniversalList`, `FilterConfigPanel`）；`src/stores` 管理全局状态（用户、应用设置等）；`src/layouts` 定义系统级布局（侧边栏、标签页）。
- **模块化路由设计**：通过 `src/modules` 目录下的 `manifest.ts` 实现动态模块注册，支持从一级子目录自动收集路由配置并注入主路由表，实现了业务功能的解耦与热插拔。
- **网络层架构**：`src/utils/request.ts` 基于 Axios 封装，实现了请求/响应拦截器、Token 自动刷新（JWT）、重复请求取消、端点级超时配置及指数退避重试机制。
- **代理与微服务适配**：`vite.config.js` 配置了多目标代理，根据环境变量将 `/api/v1` 请求分发至 Java 微服务（网关或直连）或 Python 后端，支持开发环境下的混合后端架构。
