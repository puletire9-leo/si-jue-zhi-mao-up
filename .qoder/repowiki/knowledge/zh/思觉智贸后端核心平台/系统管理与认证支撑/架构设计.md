- **分层架构**：采用 `api/v1` (路由层) -> `services` (业务逻辑层) -> `repositories` (数据访问层) 的经典三层结构。
- **网关协同**：认证中间件 `auth_middleware.py` 优先从 `X-User-*` 头部获取网关透传的身份信息，仅在直连场景下兜底使用 `jwt_utils` 进行本地解析（不验签）。
- **功能模块化**：通过 `system_config.py` 集中管理开发人、载体等业务字典；`backup_service.py` 封装了 `mysqldump` 调用与腾讯云 COS 上传逻辑；`monitoring_service.py` 提供基于内存冷却期的告警机制。
- **迁移状态**：核心认证接口（登录/注册）已标记为废弃并迁移至 Java 后端，当前 Python 模块主要承担业务数据的 CRUD 与辅助性系统维护任务。
