- **分层结构**：遵循 API (`scoring.py`) -> Service (`scoring_engine.py`) -> Model/Schema (`scoring.py`, `product_data.py`) 的经典三层架构。
- **核心逻辑**：`ScoringEngine` 封装了评分算法，支持从数据库动态加载维度权重与阈值配置，并内置缓存机制以提升性能。
- **数据交互**：通过 `aiomysql` 直接执行 SQL 进行配置读写与商品数据更新，采用事务保证配置更新与批量评分的数据一致性。
- **状态管理**：实现了基于 ISO 周的商品数据标记逻辑（`is_current`），支持按“本周”或“全量”范围进行评分统计与重算。
