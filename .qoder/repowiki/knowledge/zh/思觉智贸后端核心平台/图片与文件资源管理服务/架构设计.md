- **分层架构**：采用 API (`backend/app/api/v1`) -> Service (`backend/app/services`) -> Repository/Model (`backend/app/models`, `repositories`) 的经典三层结构。
- **核心模块**：`ImageService` 统筹图片生命周期，依赖 `COSService` 处理腾讯云对象存储，`ImageAnalysisService` 集成 Chinese CLIP 进行标签提取，`TencentLLMVisionService` 利用混元大模型进行深度视觉理解。
- **代理与缓存**：`image_proxy.py` 提供统一的图片代理服务，支持从 COS 或本地缓存获取图片，解决跨域问题并优化加载速度。
- **数据模型**：通过 `FileLink` 和 `FinalDraft` 等 Pydantic 模型定义业务数据结构，支持飞书链接、标准 URL 等多种文件引用类型。
- **迁移状态**：部分 API（如 `images.py`, `file_links.py`）标记为“待废弃”，表明业务逻辑正逐步迁移至 Java 后端，当前 Python 服务主要承担存量兼容与特定 AI 处理能力。
