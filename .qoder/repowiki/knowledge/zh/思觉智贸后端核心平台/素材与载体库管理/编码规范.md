- 统一响应格式：所有 API 接口均返回包含 `code`, `message`, `data` 字段的 JSON 结构，成功码为 200。
- 双路由兼容：关键接口同时注册带斜杠与不带斜杠的路由（如 `/recycle-bin` 和 `/recycle-bin/`），以增强客户端调用的兼容性。
- 事务性批量操作：批量创建或删除使用 `START TRANSACTION` / `COMMIT` / `ROLLBACK` 确保数据一致性，失败时自动回滚。
- 图片路径标准化：内置 `_convert_image_paths_to_urls` 工具函数，统一处理本地路径、相对路径及 HTTP/HTTPS 协议转换，确保前端获取有效的图片 URL。
