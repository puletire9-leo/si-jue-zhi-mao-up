- **分层架构**：采用 `API Router` (`selection.py`, `selection_recycle.py`) -> `Service` (`selection_service.py`, `selection_recycle_service.py`) -> `Repository` (MySQL) 的经典三层结构。
- **数据模型**：使用 `Pydantic` (`models/selection.py`) 定义请求/响应契约，支持字段别名映射（如 `productTitle` -> `product_title`）。
- **软删除机制**：删除操作通过事务将数据从 `selection_products` 迁移至 `selection_recycle_bin`，支持恢复与永久删除。
- **状态标记**：引入 `week_tag` 和 `is_current` 字段区分本周与往期数据，并在导入后触发自动评分引擎。
- **待废弃声明**：模块头部明确标注已迁移至 Java 后端，当前 Python 实现处于维护/待删除状态。
