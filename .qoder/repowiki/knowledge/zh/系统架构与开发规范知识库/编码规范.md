- Java 后端强制使用 `jakarta.*` 命名空间，Controller 层统一采用 `@RestController` 配合 `Result<T>` 响应格式。
- Python 后端路由统一挂载至 `/api/v1/{resource}`，所有 IO 操作必须使用 `async/await` 并强制类型注解。
- Git 提交信息遵循 `<type>(<scope>): <subject>` 格式，scope 限定为 java-backend/python-backend/frontend 等模块标识。
- 前端组件采用 PascalCase 命名，API 请求统一通过 `src/api/{module}.ts` 封装，状态管理使用 Pinia。
