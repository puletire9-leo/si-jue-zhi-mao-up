- **基础设施抽象层**：利用 `docker-compose.yml` 定义 MySQL/Redis 基础模板，通过 `dev/prod` overlay 文件实现端口映射、环境变量及存储卷的差异化配置。
- **双后端协同路由**：在开发环境中，Nginx 或 Vite 代理将 `/api/` 请求分发至 Python 后端（8090），同时通过环境变量 `VITE_JAVA_HOST` 引导前端直连 Java 微服务集群（Gateway/Nacos）。
- **服务发现与治理**：Java 微服务（User/Product/Gateway）依赖 Nacos 进行服务注册与配置管理，Python 后端则作为独立业务单元通过共享数据库与 Redis 与 Java 体系交互。
- **跨语言数据同步**：通过挂载共享卷（如 `产品数据`、`领星`）实现 Python 数据处理脚本与后端服务的文件系统级数据互通。
