### API 端点

| 端点 | 用途 | 触发时机 |
|------|------|----------|
| `GET /api/v1/product-line/aggregated-data` | 品线树数据 | 页面加载 |
| `GET /api/v1/product-line/batches` | 版本列表 | 页面加载 |
| `GET /api/v1/product-line/model/{nodeId}` | 模型 JSON | 点击小类节点 |
| `GET /api/v1/competitor/products?...` | 竞品筛选 | 点击"应用筛选" |

### 关键交互

1. **点击品线树节点** → 加载模型 JSON → 右侧渲染
2. **点击元素/载体** → 加入筛选标签 → 高亮已选
3. **点击"一键应用"** → 同时加入元素+载体+价格筛选
4. **点击"应用全部筛选"** → 调用竞品 API → 底部展示结果
5. **关闭筛选标签** → 移除该条件 → 可重新查询
6. **切换版本** → 重新加载模型数据
7. **勾选竞品行** → 可批量加入选品表

### 组件树

```
index.vue
├── 左侧: ChatPanel
│   ├── MessageList (对话气泡列表)
│   │   ├── UserMessage (用户消息, 右对齐)
│   │   └── AgentMessage (Agent消息, 左对齐, 支持 Markdown)
│   └── InputBar (输入框 + 发送按钮)
├── 右侧: ContextPanel (可折叠)
│   ├── CurrentContext (当前选品上下文)

```

### 关键交互

1. **自由对话** — 用户输入自然语言，Agent 流式回复 (SSE)
2. **上下文感知** — 自动获取当前选中的品线/小类/模型作为上下文
3. **数据引用** — Agent 回复中引用具体数据时可点击跳转到对应页面
4. **快捷操作** — 预设按钮一键触发常见分析
5. **会话历史** — 侧边栏可查看历史对话

## 六、设计风格指引

### 配色

- **主色**: Element Plus 默认蓝 `#409EFF`
- **健康度**: 绿(healthy) / 蓝(stable) / 黄(declining) / 红(risky)
- **热度**: 🔥已验证(红) / ⭐新兴(橙) / 👀待观察(灰)
- **等级**: S(金) / A(绿) / B(蓝) / C(黄) / D(橙) / E(红)

### 卡片风格

- 品线树: 紧凑列表，选中高亮
- 模型卡片: 白色 el-card，分区明确，间距 16px
- 竞品表格: 标准 el-table，stripe，hover 行

### 响应式

- 品线树宽度 320px，可拖拽调整
- 竞品结果高度初始折叠，有结果后展开至 40vh
- Agent 对话上下文面板可折叠
- 移动端: 三栏变单栏，品线树 → 模型 → 结果 依次堆叠
