# 品线分析页 — 功能增强设计

> 来源: OpenSpec `product-line-analysis-enhancement` 变更提案  
> 设计师: AI 产品设计师 #1 (AI 数据分析工具 UX 专家)  
> 日期: 2026-06-11  
> 当前实现: `frontend/src/views/ProductLineAnalysis/index.vue`

---

## 一、现状问题

当前品线分析页面只支持：
- 输入批次ID + 站点
- 点"开始分析"
- 看 SSE 进度条
- 分析结束看结果卡片

**缺失的核心能力**:
- ❌ 无法暂停/继续/停止分析
- ❌ 中断后无法恢复，只能重来
- ❌ 不能选择性分析（只能全量跑）
- ❌ 没有历史批次管理
- ❌ 没有结果导出

---

## 二、增强总览

| 能力域 | 核心价值 | 优先级 |
|--------|---------|--------|
| 分析生命周期管理 | 暂停/继续/停止 + 断点续传 + 重试 | P0 |
| 选择性分析 | 选品类分析、跳过已完成、增量分析 | P1 |
| 进度与通知 | 预计剩余时间、吞吐量图表、浏览器通知 | P1 |
| 结果管理 | 历史批次、对比分析、多格式导出 | P2 |
| 用户体验 | 空状态引导、暗色模式、响应式 | P2 |

## 三、分析生命周期管理 (P0)

### 状态机设计

```
                    ┌──────────┐
           ┌───────│  IDLE    │
           │       └────┬─────┘
           │            │ [开始分析]
           │       ┌────▼─────┐
           │       │ RUNNING  │◄──────────────┐
           │       └────┬─────┘               │
           │            │ [暂停]      [继续]   │
           │       ┌────▼─────┐               │
           │       │ PAUSED   ├───────────────┘
           │       └────┬─────┘
           │            │ [停止]
           │       ┌────▼─────┐
           │       │ STOPPED  │
           │       └────┬─────┘
           │            │ [重新开始]
           │            └────────┘
           │       ┌──────────┐
           └───────│  ERROR   │──[重试]──→ RUNNING
                   └──────────┘
```

### 交互设计

**控制按钮组**:
```
[▶ 开始分析]  [⏸ 暂停]  [▶ 继续]  [⏹ 停止]
```

- 不同状态显示不同按钮组合
- IDLE: 只有 [开始分析]
- RUNNING: [暂停] [停止]
- PAUSED: [继续] [停止]
- STOPPED/ERROR: [重新开始]

**断点续传流程**:
1. 分析中断（用户暂停/网络断开/页面刷新）
2. 后端保存当前进度到 Redis
3. 用户重新打开页面 → 自动检测未完成任务
4. 弹窗询问: "检测到未完成的分析，是否继续？"
5. 继续 → 从断点恢复，跳过已完成的节点

**失败重试**:
```
┌─ 品类: Signs & Plaques ──────────────────┐
│ ✅ data_fetch    完成 (2.3s)              │
│ ✅ burst_signal   完成 (1.1s)              │
│ ❌ competition   失败 — API 超时           │
│    [重试此节点]  [跳过]                    │
│ ⏸ 后续节点已暂停                          │
└──────────────────────────────────────────┘
```

### 通知机制

- **浏览器通知**: 分析完成后弹出 `Notification API` "品线分析已完成 — 12个小类分析成功"
- **异常告警**: 页面顶部黄色告警条 "⚠ 3个小类分析失败，点击查看详情"
- **声音提示**: 分析完成/异常时播放提示音（可配置关闭）

## 六、结果管理 (P2)

### 历史批次列表

```
┌─ 分析历史 ──────────────────────────────────┐
│ 批次ID              │ 时间     │ 状态 │ 操作 │
│ UK_202605_v1_20260610│ 06-10 09:57│ ✅  │[查看][对比][导出]│
│ UK_202604_v1_20260515│ 05-15 14:30│ ✅  │[查看][对比][导出]│
│ UK_202605_v2_20260611│ 06-11 10:30│ ⏸  │[继续][放弃]    │
└──────────────────────────────────────────────┘
```

### 批次对比

选择两个批次 → 并排对比 → 差异高亮：
- 评分变化: `85 → 72 ▼13`
- 推荐等级变化: `强烈推荐 → 推荐 ▼`
- 新增品类、消失品类

### 导出

- **PDF 报告**: 含品线健康度、元素分析、推荐组合（适合汇报）
- **Excel 数据**: 品类×维度评分矩阵（适合二次分析）

---

## 七、UX 细节 (P2)

- **空状态**: 首次使用显示"欢迎使用品线分析 — 输入批次ID开始分析"，附带操作指引
- **暗色模式**: 进度条/卡片/表格适配 dark theme
- **移动端**: 平板可查看进度和结果，手机端简化展示
- **键盘**: Escape 取消弹窗，Space 暂停/继续

## 八、后端新增需求

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/v1/analysis/{taskId}/pause` | POST | 暂停分析 |
| `/api/v1/analysis/{taskId}/resume` | POST | 继续分析 |
| `/api/v1/analysis/{taskId}/stop` | POST | 停止分析 |
| `/api/v1/analysis/{taskId}/retry/{nodeId}` | POST | 重试单个节点 |
| `/api/v1/analysis/batches` | GET | 历史批次列表 |
| `/api/v1/analysis/batches/compare` | GET | 批次对比 |
