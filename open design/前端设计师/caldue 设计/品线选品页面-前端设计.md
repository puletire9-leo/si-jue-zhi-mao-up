# 品线选品页面 — 前端设计文档

> 版本: v1
> 日期: 2026-06-10
> 基于: 郑总店铺模型 v3 + 模块化架构

---

## 一、页面目标

用户通过品线模型（郑总已验证的元素/载体/关键词）来筛选 competitor_products（161K 竞品），实现"模型驱动选品"。

**核心交互**：左侧选品线 → 右侧看模型 → 点击模型元素/载体 → 底部出竞品结果。

## 五、组件设计

### 5.1 index.vue — 主页面

```
职责: 三栏布局 + 全局状态管理 + API 协调
状态:
  - selectedBsiId: string | null       ← 选中的 L1 品线
  - selectedNodeId: number | null      ← 选中的 L2 小类
  - selectedMarketplace: string        ← UK/DE
  - selectedMonth: string              ← 202605
  - selectedBatchId: string            ← 当前批次
  - modelData: ProductLineModel | null ← 当前模型数据
  - activeFilters: FilterCondition[]   ← 用户点击的筛选条件
  - competitorResults: []              ← 竞品查询结果
  - loading: { tree, model, results }
子组件:
  - ProductLineTree    ← props: marketplace, month; emit: select(nodeId, bsrId)
  - ProductLineModel   ← props: modelData; emit: filter(conditions)
  - CompetitorResultTable ← props: results, loading
```

### 5.2 ProductLineTree.vue — 品线树

```
职责: 展示 L1→L2 树形结构，支持搜索过滤
UI: el-tree，按 productCount 降序排列
特性:
  - L1 节点: 显示品线名 + 商品总数 badge
  - L2 节点: 显示小类名 + 商品数
  - 搜索框: 输入过滤节点名
  - 懒加载: 首次展开 L1 才加载 L2（可选，数据量小时直接全量）
  - 高亮当前选中节点
  - 已分析完成的小类显示绿色圆点
```

### 5.3 ProductLineModel.vue — 品线模型

```
职责: 展示选中品线的完整模型，提供"点击筛选"交互
UI: 竖向滚动的卡片式布局

区域:
1. 健康度横幅
   - 颜色: healthy=绿, stable=蓝, declining=黄, risky=红
   - 内容: 健康度标签 + 一句总结

2. 质量基准速览（6个指标，水平排列）
   - 每个指标: 图标 + 数值 + 标签

3. 已验证元素列表 ← 点击添加到筛选
   - 每个元素: 名称 + 频次badge + 载体列表(小标签) + insight
   - hover 显示"点击筛选此类产品"
   - 点击后元素高亮，加入 activeFilters

4. 载体画像 ← 点击添加到筛选
   - el-table: 载体名 | 数量 | 均价 | 重量 | 变体策略 | 轻小件
   - 行可点击，点击后加入 activeFilters

5. 推荐组合
   - 卡片式: 热度图标 + 元素×载体 + 场景 + 搜索词
   - 每个组合有一个"一键应用"按钮 = 同时添加元素和载体筛选

6. 搜索关键词
   - EN: 标签式，点击复制到搜索框
   - CN: 标签式

7. 好品清单（可折叠）
   - el-table，最多显示 20 条
   - 列: ASIN | 元素 | 载体 | 场景 | 英文搜索词

8. 底部操作栏
   - [应用筛选条件] 按钮 — 汇总所有 activeFilters → 查询竞品
   - [清除筛选] 按钮
   - 显示当前筛选条件摘要
```

### 5.4 CompetitorResultTable.vue — 竞品结果

```
职责: 展示筛选后的竞品列表
UI: el-table + el-pagination

列:
  - ASIN (可点击跳转亚马逊)
  - 商品图片 (缩略图, 50px)
  - 标题 (可点击展开详情)
  - 价格 (£)
  - BSR
  - 评分 + 评论数
  - 卖家
  - 上架天数
  - 匹配度 (命中元素数/总筛选元素数)

特性:
  - 排序: 按匹配度降序, 按BSR升序, 按销量降序
  - 行点击: 展开详情弹窗 (ProductDetailDialog 已有)
  - 批量操作: 勾选 → 加入选品表
  - 导出: 导出当前页/全部结果为 Excel
  - 空状态: "请在品线模型中点击元素或载体来筛选竞品"
```

## 六、数据流

```
1. 页面初始化
   index.vue mounted → fetchBatches() → 默认选最新批次
                    → fetchTree(marketplace, month) → ProductLineTree 渲染

2. 用户点击小类
   ProductLineTree @select → index.selectNode(nodeId, bsrId)
     → fetchModel(nodeId, batchId) → ProductLineModel 渲染
     → 清空 activeFilters 和 competitorResults

3. 用户点击模型元素/载体
   ProductLineModel @filter → index.addFilter(condition)
     → activeFilters 更新
     → ProductLineModel 高亮已选元素/载体

4. 用户点击"应用筛选"
   index.applyFilters()
     → 合并所有条件: elements + carriers + qualityBenchmark + priceBand
     → searchCompetitors(params) → CompetitorResultTable 渲染

5. 用户切换版本
   顶部 version dropdown → index.selectBatch(batchId)
     → 重新 fetchModel (如当前有小类选中)
```

## 八、筛选逻辑映射

用户点击模型中的元素/载体 → 自动生成竞品查询参数：

| 模型操作 | 筛选条件 | competitor_products WHERE |
|----------|----------|--------------------------|
| 点击元素 "Highland Cow" | `type=element, value=Highland Cow` | `title LIKE '%highland cow%'` |
| 点击载体 "Metal Signs" | `type=carrier, value=Metal Signs` | `title LIKE '%metal sign%'` |
| 应用组合 | 元素 + 载体 + 价格 | 多个 LIKE + BETWEEN |
| 价格甜点区自动 | `priceBand.sweetSpot` | `price BETWEEN 5.99 AND 8.99` |
| 质量基准自动 | `qualityBenchmark` | `bsr <= bsrP90 AND rating >= ratingMin AND weight <= weightMax` |

**查询优先级**: 精确元素匹配 > 载体匹配 > 价格区间 > BSR 排序
