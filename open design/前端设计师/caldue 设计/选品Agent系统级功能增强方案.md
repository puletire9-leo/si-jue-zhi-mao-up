# 选品 Agent 系统级功能增强方案

> 版本: v1  
> 日期: 2026-06-11  
> 用途: 系统级交互架构设计  
> 范围: 跨页面工作流 + Agent对话 + 智能推荐 + 个性化 + 系统体验

---

## 〇、设计目标

**核心问题**: 4 个选品 Agent 页面（店铺总览、品线分析、品线选品、Agent对话）各自独立，缺少统一的工作流和跨页面协作。用户需要频繁切换页面，上下文容易丢失。

**设计目标**: 将 4 个页面编织成一个**有机的选品工作台**，让用户在任意页面都能感知全局状态、快速跳转、无缝协作。

```
现状:                          目标:
┌──────┐ ┌──────┐              ┌──────────────────────────────────────┐
│店铺总览│ │品线分析│              │         统一工作台                    │
└──────┘ └──────┘     →        │  ┌─────────────────────────────┐   │
┌──────┐ ┌──────┐              │  │ 任务面板 + 通知 + 快捷操作    │   │
│品线选品│ │Agent │              │  └─────────────────────────────┘   │
└──────┘ └──────┘              │  店铺│品线分析│品线选品│Agent对话    │
各自独立                       └──────────────────────────────────────┘
                               跨页面状态共享 + 后台任务 + 智能推荐
```

## 一、跨页面工作流架构

### 1.1 全局状态层: AgentWorkbench Store

新增 Pinia Store 作为选品工作台的全局状态中心，所有页面共享。

```
stores/agentWorkbench.ts
├── activeTasks: Task[]           // 正在运行的后台任务
├── completedTasks: Task[]        // 已完成的任务（最近20条）
├── notifications: Notification[] // Agent 推送通知
├── selectedContext: Context       // 当前选中的数据上下文
├── favorites: Favorite[]          // 用户收藏的品线/元素
└── preferences: Preferences       // 用户偏好设置
```

#### 数据结构定义

```typescript
// 后台任务
interface Task {
  id: string
  type: 'analysis' | 'selection' | 'import' | 'export' | 'chat'
  title: string                    // 如 "品线分析 - kitchen"
  status: 'pending' | 'running' | 'completed' | 'failed'
  progress: number                 // 0-100
  startedAt: number
  completedAt?: number
  result?: any
  meta: {
    batchId?: string
    marketplace?: string
    productLine?: string
    nodeCount?: number
    currentNode?: string
  }
}

// 通知消息
interface Notification {
  id: string
  type: 'task_complete' | 'insight' | 'alert' | 'recommendation'
  title: string
  message: string
  read: boolean
  actionUrl?: string               // 点击跳转的路由
  actionLabel?: string             // 按钮文字
  timestamp: number
  source: 'agent' | 'system' | 'analysis'
}

// 数据上下文
interface Context {
  marketplace: string              // UK / US / ...
  productLine?: string             // kitchen / fashion / ...
  subCategory?: string             // Signs & Plaques
  batchId?: string                 // 分析批次
  modelVersion?: string            // 模型版本 v1
  selectedAsins?: string[]         // 已选中的 ASIN 列表
}

// 收藏项
interface Favorite {
  id: string
  type: 'product_line' | 'element' | 'carrier' | 'asin'
  name: string
  value: string
  addedAt: number
}

// 用户偏好
interface Preferences {
  dashboardLayout: DashboardWidget[]
  notifications: {
    taskComplete: boolean
    newInsight: boolean
    alertOnNewProducts: boolean
    blueOceanAlert: boolean
  }
  favoriteLines: string[]          // 关注的品线
  favoriteElements: string[]       // 关注的元素
}
```

### 1.3 页面间跳转与上下文传递

#### 跳转路径设计

```
店铺总览 ──点击"运行分析"──→ 品线分析 (自动填入批次+站点)
    │
    └──点击"问Agent"──→ Agent对话 (带店铺上下文)
                            │
                            └──Agent建议──→ 品线选品 (带推荐筛选条件)

品线分析 ──分析完成──→ 品线选品 (查看模型结果)
    │                    │
    │                    └──点击"问Agent"──→ Agent对话 (带模型上下文)
    │
    └──"问Agent"──→ Agent对话 (带分析上下文)

品线选品 ──"问Agent"──→ Agent对话 (带竞品上下文)
    │
    └──"加入选品表"──→ 总选品管理 (批量添加)
```

#### 上下文传递机制

使用 `agentWorkbench` Store 的 `selectedContext` 作为跨页面数据桥梁：

```typescript
// 从品线选品跳转到 Agent 对话
function openAgentWithContext(source: string, context: Partial<Context>) {
  agentWorkbench.setSelectedContext(context)
  router.push({
    path: '/agent-chat',
    query: { from: source }   // 标记来源页面，Agent 可据此调整推荐
  })
}

// 从 Agent 对话跳转到品线选品，带上推荐筛选条件
function goToSelectionWithFilters(filters: SelectionFilter[]) {
  agentWorkbench.setSelectedFilters(filters)
  router.push({
    path: '/product-line-selection',
    query: { autoApply: 'true' }
  })
}
```

#### URL 参数传递

关键跳转使用 URL query 参数，支持浏览器前进后退：

| 跳转 | URL 格式 | 说明 |
|------|---------|------|
| 分析完成 → 品线选品 | `/product-line-selection?batchId=xxx&marketplace=UK` | 自动加载指定批次 |
| Agent → 品线选品 | `/product-line-selection?element=Highland+Cow&carrier=Metal+Sign` | 自动应用筛选 |
| 店铺 → 分析 | `/product-line-analysis?batchId=xxx&marketplace=UK` | 自动开始分析 |
| Agent → 店铺总览 | `/zheng-shop-overview?highlight=xxx` | 高亮指定店铺 |
