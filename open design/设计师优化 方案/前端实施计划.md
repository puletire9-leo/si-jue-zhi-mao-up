### 3.4 URL 状态统一序列化 (2h)

```typescript
// utils/url-state.ts
// 简单参数 (≤3): 直接用 query
// 复杂参数 (>3): LZ-String 压缩

export function encodeState(state: Record<string, unknown>): string {
  const keys = Object.keys(state)
  if (keys.length <= 3) {
    return new URLSearchParams(state as Record<string, string>).toString()
  }
  return `state=${compressToEncodedURIComponent(JSON.stringify(state))}`
}
```

## 技术决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 主色 | `#b45309` 琥珀 | Editorial 暖纸衬线风格 |
| 字体 | Playfair Display (标题) + Noto Sans SC (正文) + JetBrains Mono (数字) | 衬线标题 + 等宽数字 = 专业感 |
| 圆角 | 4/6/10/14px | Editorial 风格收紧，去除 AI 感 |
