## Pinia Store 数据模型

```typescript
interface ProductLineSelectionState {
  marketplace: 'US' | 'UK' | 'DE'
  month: string
  version: string
  selectedNodeId: string | null
  modelData: ModelData | null
  activeFilters: FilterCondition[]
  results: CompetitorProduct[]
  resultsTotal: number
  resultsPage: number
}

interface FilterCondition {
  type: 'element' | 'carrier' | 'combo' | 'price'
  label: string
  value: string
  source: string  // 节点ID 或 'manual'
}
```

## 关键交互流程

```mermaid
sequenceDiagram
    用户->>品线树: 点击已分析子类
    品线树->>Store: selectNode(nodeId)
    Store->>API: GET /model/{nodeId}
    API-->>Store: ModelData JSON
    Store-->>模型面板: 渲染健康度 + 元素 + 载体 + 组合
    
    用户->>元素标签: 点击"不锈钢"
    模型面板->>Store: addFilter({type:'element',value:'不锈钢'})
    Store-->>操作栏: 标签显示"不锈钢"
    
    用户->>组合卡: 点击"一键应用"
    模型面板->>Store: addFilters([元素,载体,价格])
    Store-->>操作栏: 标签显示所有条件
    
    用户->>操作栏: 点击"应用全部筛选"
    Store->>API: GET /competitor-products/search
    API-->>Store: CompetitorProduct[]
    Store-->>结果面板: 展开 45vh, 渲染表格
```

## 额外优化想法

### 1. 散点图替代纯表格
结果面板上半部分放 ECharts 价格-BSR 散点图（实现类 PriceSalesScatter），下半部分表格。散点图让用户一眼看到甜点区（低价格+低BSR）。

### 2. 健康度环形图动画
用 `requestAnimationFrame` 让环形图从 0 增长到目标值，800ms ease-out 动画（已在原型中静态展示）。

### 3. 元素标签热度标注
🔥已验证（销量好）用红色角标，⭐新兴（销量上升快）用橙色角标。原型中已通过 `.hot` 和 `.rising` 类实现。

### 4. 推荐组合一键对比
在推荐组合卡片右侧加"对比"按钮，点击后结果面板切到"对比模式"，只显示两个组合的差异行。

### 5. 键盘快捷操作
- `Ctrl+K` — 打开品线搜索
- `Ctrl+Enter` — 应用全部筛选
- `Escape` — 关闭结果面板
- `← →` — 焦点在品线树时切换节点

### 6. 版本快速切换
顶部版本下拉切换时，左侧品线树保持当前选中品类的 L2 节点位置不滚动。
