## 二、自动计算列

### 1. 体积重（AC / Col29）

```
体积重(kg) = (长cm × 宽cm × 高cm) / 6000
```

Excel 公式：`=(Z3*AA3*AB3)/6000`

### 2. 计费重量

```
计费重量(kg) = MAX(体积重, 毛重)
```

> 用于头程运费计算。注：此处与 FBA 配送费的计费重量逻辑不同。
> FBA 配送费：低价（售价<10）只看实重；正常价取 MAX(体积重, 实重)。

### 3. 空运物流费用¥（AI / Col35）

```
空运物流费用¥ = 空运头程报价(¥/kg) × MAX(体积重, 毛重)
```

Excel 公式：`=AE3*MAX(AC3:AD3)`

### 4. 海运物流费用¥（AK / Col37）

```
海运物流费用¥ = 海运头程报价(¥/kg) × MAX(体积重, 毛重)
```

Excel 公式：`=AF3*MAX(AC3:AD3)`

### 5. 采购费用$（AH / Col34）

```
采购费用$ = 采购费用¥ / 汇率
```

Excel 公式：`=AG3/W3`

### 6. 空运物流费用$（AJ / Col36）

```
空运物流费用$ = 空运物流费用¥ / 汇率
```

Excel 公式：`=AI3/W3`

### 7. 海运物流费用$（AL / Col38）

```
海运物流费用$ = 海运物流费用¥ / 汇率
```

Excel 公式：`=AK3/W3`

### 8. 平台费用（销售佣金$）（AM / Col39）

```
平台费用$ = 售价 × 佣金比例(0.15)
```

Excel 公式：`=O3*Y3`

### 9. VAT税费$

**英国：**
```
VAT税费$ = 售价 × VAT税率(0.2)
```
Excel 公式：`=O3*X3`

**德国：**
```
VAT税费$ = 售价 / 1.2 × 0.2
```
Excel 公式：`=O4/1.2*0.2`

> 差异说明：英国站售价视为不含 VAT；德国站售价视为含 VAT，需先除 1.2 再乘 0.2。

### 10. FBA配送费$（AN / Col40）

> 当前无公式，需根据尺寸/重量/售价从配送费表格自动匹配。
> 算法详见第三部分。

### 11. 空运利润$（P / Col16）

```
空运利润$ = 售价 - SUM(采购费$ + 空运物流费$ + 平台佣金$ + FBA配送费$ + VAT税费$ + 推广费$ + 退款费$)
```

Excel 公式：`=O3-SUM(AH3+AJ3+AM3+AN3+AO3+AP3+AS3)`

### 12. 海运利润$（S / Col19）

```
海运利润$ = 售价 - SUM(采购费$ + 海运物流费$ + 平台佣金$ + FBA配送费$ + VAT税费$ + 广告费$ + 促销费$ + 站外费$ + 退款费$)
```

Excel 公式：`=O3-SUM(AH3+AL3+AM3+AN3+AO3+AP3+AQ3+AR3+AS3)`

> 差异说明：海运利润多扣了促销费(AQ)和站外费(AR)，空运利润未扣这两项。

### 13. 空运利润¥（Q / Col17）

```
空运利润¥ = 空运利润$ × 汇率
```

Excel 公式：`=P3*W3`

### 14. 海运利润¥（T / Col20）

```
海运利润¥ = 海运利润$ × 汇率
```

Excel 公式：`=S3*W3`

### 15. 空运利润率（R / Col18）

```
空运利润率 = 空运利润$ / 售价
```

Excel 公式：`=P3/O3`

### 16. 海运利润率（U / Col21）

```
海运利润率 = 海运利润$ / 售价
```

Excel 公式：`=S3/O3`

## 三、FBA 配送费自动匹配算法

### 核心逻辑

```
输入: 长cm, 宽cm, 高cm, 毛重kg, 售价, 站点(UK/DE)
输出: FBA配送费（本地货币 £/€）

Step 1: 判断是否低价商品
  isLowPrice = (售价 < 10)   // 英国 £10, 德国 €10

Step 2: 计算计费重量
  体积重(kg) = (长 × 宽 × 高) / 6000
  体积重(g) = 体积重(kg) × 1000
  实重(g) = 毛重(kg) × 1000

  if isLowPrice:
      计费重量(g) = 实重(g)    // 低价只看实重
  else:
      计费重量(kg) = MAX(体积重(kg), 毛重(kg))
      计费重量(g) = 计费重量(kg) × 1000

Step 3: 尺寸排序（降序）
  sides = SORT_DESC([长, 宽, 高])  // 最长边, 中间边, 最短边

Step 4: 匹配尺寸段 + 重量段
  按以下顺序从最小到最大匹配，命中即停止：

  if 最长边≤33 AND 中间边≤23 AND 最短边≤2.5:
      → 信封类 (33×23×2.5)
      用 计费重量 在信封重量段中匹配
  elif 最长边≤33 AND 中间边≤23 AND 最短边≤4:
      → 大号信封 (33×23×4)
      用 计费重量 在大号信封重量段中匹配
  elif 最长边≤33 AND 中间边≤23 AND 最短边≤6:
      → 超大号信封 (33×23×6)
      用 计费重量 在超大号信封重量段中匹配
  elif 最长边≤35 AND 中间边≤25 AND 最短边≤12:
      → 小包裹 (35×25×12)
      用 计费重量 在小包裹重量段中匹配
  elif 最长边≤45 AND 中间边≤34 AND 最短边≤26:
      → 标准包裹 (45×34×26)
      用 计费重量 在标准包裹重量段中匹配
  else:
      → 超尺寸（费率表无法覆盖，需人工处理）

Step 5: 返回费率
  根据站点(UK→Col7, DE→Col8)和isLowPrice(低价→Col2/Col3, 正常→Col7/Col8)
  返回对应价格
```

### 注意事项

1. **重量超限处理**：如果计费重量超过当前尺寸段的最大重量，需升级到下一个尺寸段。例如小包裹最大 3.9kg，如果产品 4.5kg 但尺寸满足标准包裹，则升级到标准包裹。
2. **尺寸匹配顺序**：必须从最小尺寸段开始依次检查，确保匹配到最精确的费率。
3. **低价表与正常表**：低价配送费表只有信封和小包裹部分费率（≤960g），超过范围的低价商品也按正常表计算。

## 五、UK vs DE 算法差异点

| 差异项 | 英国 (UK) | 德国 (DE) |
|--------|-----------|-----------|
| 站点标识 | UK | DE |
| 汇率 | 8.54 (示例) | 7.5 (示例) |
| 空运头程报价 | 45 ¥/kg | 55 ¥/kg |
| 海运头程报价 | 15 ¥/kg | 15 ¥/kg |
| VAT 计算 | `售价 × 0.2` | `售价/1.2×0.2` |
| FBA 配送费货币 | £ (英镑) | € (欧元) |
| 列数 | 60 列 | 52 列 |

> 注：VAT 计算差异反映了两国售价的含税方式不同——英国售价视为未税价，德国售价视为含税价。

## 六、完整计算流程图

```
输入: 长, 宽, 高, 毛重, 售价, 采购费¥, 汇率, 空运报价, 海运报价, 站点

  ┌─────────────────────────────────────┐
  │ 1. 体积重 = (长×宽×高)/6000         │
  │ 2. 计费重量 = MAX(体积重, 毛重)     │
  └──────────────┬──────────────────────┘
                 │
    ┌────────────┼────────────┐
    ▼            ▼            ▼
┌─────────┐ ┌─────────┐ ┌───────────┐
│空运头程=│ │海运头程=│ │FBA配送费  │
│报价×    │ │报价×    │ │(按费率表  │
│计费重量│ │计费重量│ │自动匹配)  │
└────┬────┘ └────┬────┘ └─────┬─────┘
     │           │            │
     ▼           ▼            ▼
┌─────────┐ ┌─────────┐ ┌───────────┐
│÷汇率=$  │ │÷汇率=$  │ │  = $      │
└────┬────┘ └────┬────┘ └─────┬─────┘
     │           │            │
     │    ┌──────┴────────────┤
     │    │     采购费÷汇率=$ │
     │    │     售价×0.15=$   │ ← 平台佣金
     │    │     VAT=$         │
     │    │     广告/退款=$    │
     ▼    ▼      ▼            ▼
  ┌────────────────────────────────┐
  │ 空运利润$ = 售价 - SUM(以上$)  │
  │ 海运利润$ = 售价 - SUM(以上$)  │ ← 海运多扣促销费+站外费
  │ 利润¥ = 利润$ × 汇率           │
  │ 利润率 = 利润$ / 售价          │
  └────────────────────────────────┘
```
