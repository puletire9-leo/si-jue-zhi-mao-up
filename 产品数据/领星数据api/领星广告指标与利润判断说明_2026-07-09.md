# 领星广告指标与利润判断说明（2026-07-09）

## 核心结论

`ACOS`、`TACOS`、`ACOAS` 都和广告花费有关，但分母不同，能回答的问题不同。

| 指标 | 公式 | 主要用途 |
|------|------|----------|
| `ACOS` | 广告花费 / 广告销售额 | 判断广告订单本身投放效率 |
| `TACOS` | 广告花费 / 总销售额 | 判断广告费吃掉整个 SKU 生意多少 |
| `ACOAS` | 广告花费 / 净销售额 | 用净销售额判断广告费压力，更保守 |

一句话：

```text
看广告投得好不好，用 ACOS。
看这个 SKU 整体还有没有利润空间，用 ACOAS / TACOS。
```

## 例子

假设某 SKU 某月：

```text
广告花费 spend = 100
总销售额 amount = 1000
净销售额 net_amount = 900
广告销售额 ad_sales_amount = 400
```

则：

```text
ACOS  = 100 / 400  = 25.00%
TACOS = 100 / 1000 = 10.00%
ACOAS = 100 / 900  = 11.11%
```

解释：

- `ACOS=25%`：广告单本身看起来花费偏高。
- `TACOS=10%`：广告费只占整体销售额 10%，整体生意可能仍然健康。
- `ACOAS=11.11%`：用净销售额看更保守，广告压力仍低于 20%。

## 和 20% 利润率的关系

如果我们的基础利润率约为 20%，那么广告占比可以作为利润判断的重要红线。

建议口径：

```text
优先看 ACOAS。
如果 ACOAS > 20%，说明广告费已经吃掉净销售额中超过 20%，利润空间高度危险。

如果没有 net_amount，使用 TACOS 替代。
如果 TACOS > 20%，说明广告费已经吃掉总销售额中超过 20%，整体利润高度危险。

ACOS 不用于直接判断 SKU 整体有没有利润。
ACOS 只用于判断广告订单本身是否划算。
```

为什么不直接用 `ACOS` 判断利润：

- `ACOS` 的分母只是广告销售额。
- 它不包含自然销售。
- 一个 SKU 的广告 ACOS 很高，但如果自然销售很强，整体 `TACOS/ACOAS` 可能仍然低，SKU 仍可能赚钱。
- 反过来，ACOS 看起来不错，但整体销售太少、广告费占总销售过高，SKU 仍可能亏。

## 推荐利润判断顺序

### 1. 判断整体利润压力

优先：

```text
ACOAS = spend / net_amount
```

备用：

```text
TACOS = spend / amount
```

粗略判断：

| 条件 | 判断 |
|------|------|
| `ACOAS <= 10%` | 广告压力较低 |
| `10% < ACOAS <= 20%` | 广告压力可控，但要结合毛利 |
| `ACOAS > 20%` | 高风险，可能吃掉利润 |
| `TACOS > 20%` 且无 `ACOAS` | 高风险替代判断 |

### 2. 判断广告投放效率

看：

```text
ACOS = spend / ad_sales_amount
```

粗略判断：

| 条件 | 判断 |
|------|------|
| `ACOS <= 20%` | 广告订单效率较好 |
| `20% < ACOS <= 40%` | 广告效率一般，要看自然销售带动 |
| `ACOS > 40%` | 广告订单成本较高，需要排查关键词/Listing/价格 |

注意：这些阈值只是起始经验值，后续要结合品类、生命周期、库存、清货目标调整。

## 月表推荐计算方式

月度分析不要简单平均周 ACOS/TACOS/ACOAS，应使用汇总后的分子分母重算：

```sql
SELECT
  year_month,
  sku,
  SUM(spend) AS spend,
  SUM(amount) AS amount,
  SUM(net_amount) AS net_amount,
  SUM(ad_sales_amount) AS ad_sales_amount,
  SUM(spend) / NULLIF(SUM(amount), 0) AS tacos,
  SUM(spend) / NULLIF(SUM(net_amount), 0) AS acoas,
  SUM(spend) / NULLIF(SUM(ad_sales_amount), 0) AS acos
FROM lingxing_sku_monthly_performance
WHERE is_target_sku = 1
GROUP BY year_month, sku;
```

如果直接查月表单行，当前月表 `tacos` 和 `acos` 已经是聚合后重算值：

```text
tacos = SUM(spend) / SUM(amount)
acos  = SUM(spend) / SUM(ad_sales_amount)
```

## 后续利润模型建议

第一阶段可以用简单红线：

```text
广告风险 = ACOAS > 20%
备用广告风险 = net_amount 为空时 TACOS > 20%
```

第二阶段加入毛利：

```text
广告后利润率 = gross_margin - ACOAS
```

或：

```text
广告后利润 = predict_gross_profit - spend
广告后利润率 = 广告后利润 / net_amount
```

第三阶段加入退货和库存：

```text
最终利润压力 = 广告后利润 - 退货损失 - 滞销库存压力
```

## 当前判断规则

用于后续分析时先按这个顺序：

1. 先看 `net_amount` 是否有值。
2. 有 `net_amount`：用 `ACOAS = spend / net_amount` 判断整体广告占比。
3. 没有 `net_amount`：用 `TACOS = spend / amount` 替代。
4. 用 `ACOS = spend / ad_sales_amount` 判断广告订单效率。
5. 不要用 ACOS 直接判断 SKU 整体是否赚钱。
6. 如果 `ACOAS/TACOS > 20%`，默认进入利润风险池。
7. 如果 `ACOS` 高但 `ACOAS/TACOS` 低，说明广告订单贵，但整体自然销售可能还能兜住，需要单独分析。
