# 查询产品表现

---

## 接口信息

| 项目 | 内容 |
|------|------|
| **API Path** | `/bd/productPerformance/openApi/asinList` |
| **请求协议** | HTTPS |
| **请求方式** | POST |
| **令牌桶容量** | 1 |

---

## 请求参数

| 参数名 | 说明 | 必填 | 类型 | 示例 |
|--------|------|:----:|:----:|------|
| `offset` | 分页偏移量 | **是** | int | 0 |
| `length` | 分页长度，最大 10000 | **是** | int | 20 |
| `sort_field` | 排序字段，默认按 `volume` 排序，支持：`volume`、`order_items`、`amount`、`volume_chain_ratio`、`order_chain_ratio`、`amount_chain_ratio`、`b2b_volume`、`b2b_order_items`、`promotion_volume`、`promotion_amount`、`promotion_order_items`、`promotion_discount`、`avg_volume` | **是** | string | volume |
| `sort_type` | 排序方式：`desc`（降序）、`asc`（升序），默认 desc | **是** | string | desc |
| `search_field` | 搜索字段：`asin`、`parent_asin`、`msku`、`local_sku`（sku）、`item_name`（标题） | 否 | string | asin |
| `search_value` | 搜索值，最多批量搜索 50 个 | 否 | array | ["B085M7NH7K"] |
| `mid` | 站点 ID | 否 | int | 1 |
| `sid` | 店铺 ID，上限 200（单店铺传 string，多店铺传 array） | **是** | object | [1,109] |
| `start_date` | 开始日期，筛选范围不超过 92 天，双闭区间，格式：YYYY-MM-DD | **是** | string | 2024-08-01 |
| `end_date` | 结束日期，筛选范围不超过 92 天，双闭区间，格式：YYYY-MM-DD | **是** | string | 2024-08-07 |
| `extend_search` | 表头筛选 | 否 | array | |
| `extend_search>>field` | 筛选字段 | 否 | string | volume |
| `extend_search>>from_value` | 数值（左区间值） | 否 | int | 0 |
| `extend_search>>to_value` | 数值（右区间值，仅 exp 为 range 时） | 否 | int | 1000 |
| `extend_search>>exp` | 比较方式：`range`、`gt`、`lt`、`ge`、`le`、`eq` | 否 | string | range |
| `summary_field` | 汇总行维度：`asin`、`parent_asin`、`msku`、`sku` | **是** | string | asin |
| `currency_code` | 货币类型，不传代表原币种，仅支持 USD、CNY | 否 | string | CNY |
| `is_recently_enum` | 是否仅查询活跃商品：`true` 仅活跃（默认）、`false` 全部商品 | 否 | boolean | true |
| `purchase_status` | 退货退款统计方式：0-按发生时间统计，1-按下单时间统计 | 否 | int | 0 |

### 请求示例

```json
{
    "offset": 0,
    "length": 20,
    "sort_field": "volume",
    "sort_type": "desc",
    "search_field": "asin",

    "mid": 1,
    "sid": [1, 109],
    "start_date": "2024-08-01",
    "end_date": "2024-08-07",
    "extend_search": [
        {
            "field": "volume",
            "from_value": "0",
            "to_value": "1000",
            "exp": "range"
        }
    ],
    "summary_field": "asin",
    "currency_code": "CNY",
    "is_recently_enum": true,
    "purchase_status": 0
}
```

## 附加说明

### 限流规则

1. 令牌桶容量是 **1**，需串行调用（上一次请求返回后，下一次请求才不会被限流）
2. 上次请求传入一个店铺：需间隔 **1 秒**；上次传入多个店铺：需间隔 **10 秒**
3. `summary_field` 为 `asin` 时，`search_field` 不可为 `parent_asin`
4. 限流维度为 **账户 + Path**，同一账户下多个 appId 共享令牌桶容量，建议错开调用时间

### 字段说明

- `PV-Total`、`PV-Mobile`、`PV-Browser` 字段需在 ASIN 维度或父 ASIN 维度才有值

### 唯一键说明

| 维度 | 唯一键 |
|------|--------|
| ASIN 维度 | `asin + sid` |
| 父 ASIN 维度 | `parent_asin + sid` |
| MSKU 维度 | `seller_sku + sid` |
| SKU 维度 | `sku + sid` |
