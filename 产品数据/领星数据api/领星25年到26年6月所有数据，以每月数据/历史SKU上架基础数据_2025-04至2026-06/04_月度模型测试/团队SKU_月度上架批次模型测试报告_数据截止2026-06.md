# 团队 SKU 月度上架批次模型测试

## 输入和范围

- 月度数据：2025-04 至 2026-06 的 15 份领星产品表现导出。
- 对象粒度：站点 + 店铺 + SKU；同 SKU 跨店铺不合并。
- 团队范围：本地团队 SKU 中，月度数据已观察到 FBA 可售的对象。
- 首月 2025-04 的对象存在数据起点左截断，排除在阶段转化率之外。

## 阶段口径

- 首月阶段：首次 FBA 可售后的首个完整自然月，销量大于 0。
- 次月阶段：首月已出单，且第二个完整自然月仍有销量。
- 这不是采购批次的正式 R1/R2，也不是 Q1/Q2 盈亏模型：月度库存快照不能代替首批采购量。

## 汇总结果

| 指标 | 数量 | 比率 |
|---|---:|---:|
| 可归入非左截断上架批次的店铺-SKU | 5,162 | - |
| 具备首个完整月观察条件 | 4,282 | - |
| 首个完整月有出单 | 3,580 | 83.61% |
| 具备两个完整月观察条件 | 3,609 | - |
| 具备第二完整月观察条件且首月出单 | 3,003 | - |
| 第二完整月持续出单 | 2,331 | 77.62% |
| 两个月持续出单占已成熟上架批次 | 2,331 | 64.59% |

## 成熟度

- 2026-04 及更早首次 FBA 可售的上架批次，已具备两个月窗口。
- 2026-05 上架批次只具备首个完整月观察；2026-06 上架批次尚未有首个完整月。
- 组合主 SKU 已保留为一个对象；组合子件关系尚未取得，不能自动剔除。

## 限制

- `结算毛利润` 仅作为观察毛利，费用口径未核实，不能称为真实净利润。
- 采购事实表虽有 `quantity_real`，但月度导出缺少可直接对应的店铺 `sid`；在完成店铺映射前，不能把采购行严格归到某个店铺-SKU 的 Q1/Q2。
- 精确首个 FBA 可售日、断货日和补货到货日仍需日/周级事实。
