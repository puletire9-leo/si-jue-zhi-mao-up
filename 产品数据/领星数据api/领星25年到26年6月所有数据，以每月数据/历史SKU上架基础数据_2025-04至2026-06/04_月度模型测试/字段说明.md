# 月度上架批次模型字段说明

| 字段 | 含义 |
|---|---|
| 上架批次月份 | 店铺-SKU 首次观察到 FBA 可售的月份。 |
| 上架批次店铺SKU数 | 该月份首次 FBA 可售的店铺-SKU 数量。 |
| 首个完整月可观察对象数 | 首次 FBA 可售后的下一个完整自然月已落在数据窗口内的对象数。 |
| 首个完整月有出单对象数 / 首个完整月出单率 | 首个完整自然月销量大于 0 的对象数及占比。 |
| 两个月可观察对象数 | 第二个完整自然月也已落在数据窗口内的对象数。 |
| 第二完整月持续出单对象数 / 第二完整月持续出单率 | 首月已出单的对象中，第二个完整月仍有销量的数量及占比。 |
| 两个月持续出单率 | 第二完整月仍出单的对象，占两个月已成熟对象的比例。 |
| 首次FBA可售月销量 | 首次出现 FBA 可售当月的销量，可能是部分月，仅作参考。 |
| 首个完整月 / 第二完整月销量 | 两个完整观察月内的销量。 |
| 结算毛利润 / 广告花费 | 领星月度导出的观察指标；结算毛利润费用口径未核实，不能作为真实净利润。 |
| 最大FBA可售库存 | 该月快照中的最大 FBA 可售库存，不是 Q1 首批备货量。 |
| 月度阶段判定 | 用中文说明该对象处于左截断、待观察、首月未出单、次月持续出单或次月未持续出单。 |

R1 和 R2 在本轮仅是月度阶段代理：R1 表示首个完整月有出单，R2 表示第二完整月持续出单；不等同于采购批次的正式 R1/R2。
