# 历史 SKU 上架基线字段说明

| 字段 | 含义 |
|---|---|
| 站点 / 国家 / 店铺 / SKU | 一个分析对象的业务主键；同一 SKU 在不同店铺或站点不合并。 |
| 首次FBA可售观察月 | 月度导出中首次出现 `FBA-可售 > 0` 的月份。 |
| 首次观察窗口开始日 / 结束日 | 该月度导出的完整日期范围。 |
| 首次观察月最大FBA可售库存 | 首次观察月内的 FBA 可售库存快照最大值，只用于库存观察，不是首批备货量。 |
| 观察期内FBA可售月份数 | 2025-04 至 2026-06 内，该对象有 FBA 可售库存的月份数。 |
| 首次FBA可售判定 | 说明首次观察月是否存在数据起点左截断。若显示“真实首次上架月未知”，不可把 2025-04 当真实上架月。 |
| 首次观察月份 | 该对象首次出现在月度导出中的月份，不要求 FBA 可售。 |
| 观察期内是否曾FBA可售 | 在整个窗口内是否至少一次 `FBA-可售 > 0`。 |
| 月度观察状态 | 对从未出现 FBA 可售的对象，说明其仅被观察到、尚未进入 FBA 上架 cohort。 |
| MSKU列表 / ASIN列表 / 父ASIN列表 | 观察窗口内关联到该店铺-SKU 的亚马逊标识集合。 |
| Listing标签 / 品名 / 商品标题 | 月度导出中的业务标签和商品描述，仅供识别与筛选。 |
