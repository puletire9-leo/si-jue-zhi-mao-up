## 口径

- 15 个团队目标店铺，8 位开发人员的有效 SKU 前缀。
- 以领星 `grossProfit` 作为结算毛利润；按币种独立汇总，不换汇、不相加。
- 每份汇总表包含团队和开发人维度；CSV 包含该月全部 SKU 的聚合结果和字段说明。
