## 计算说明

- 销量 = `SUM(total_sales_quantity)`。
- 销售额 = `SUM(total_sales_amount)`。
- 广告费 = `SUM(total_ads_cost)`。
- 总成本 = `SUM(total_cost)`；它是商品成本口径，原始字段可拆为采购成本 `cgPrice` + 头程 `cgTransportCosts` + 其他商品成本 `cgOtherCostsTotal`。
- 领星其他结算调整项 = `SUM(gross_profit) - SUM(total_sales_amount) - SUM(total_ads_cost) - SUM(total_cost)`。它使表内正好满足：销售额 + 广告费 + 总成本 + 其他调整 = 领星结算毛利润。
- 该调整项是原始 API 中未单独落列的结算项汇合，包含平台费、FBA 配送/仓储费、退款及费用退还、税费、促销、赔偿、库存调整和分摊费用等。它不是另一笔单独收费，不应与原始明细字段重复求和。
- 毛利润 = `SUM(gross_profit)`；直接采用领星 API 的已结算毛利润，不用销售额减总成本进行替代重算。
- 汇总毛利率 = `SUM(gross_profit) / SUM(total_sales_amount)`，不对每个 SKU 的毛利率直接平均。
- GBP 与 EUR 分开会计，未引入汇率，因此未转换或相加。
- 完整 SKU 汇总明细见 `2026年06月团队SKU财务利润明细.csv`。
