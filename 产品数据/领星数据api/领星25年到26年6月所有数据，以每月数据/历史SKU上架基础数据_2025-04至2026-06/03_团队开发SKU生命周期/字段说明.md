# 团队 SKU 生命周期字段说明

| 字段 | 含义 |
|---|---|
| 开发人 / SKU / 品名 / 创建时间 | 本地产品主数据中的开发归属和创建信息。 |
| 是否组合产品 | “是”表示组合主产品；组合子件关系尚未从详情接口取得，不能自动剔除。 |
| 首次FBA可售观察月 | 月度数据中首次观察到 FBA 可售的月份；空白表示窗口内未匹配到。 |
| FBA匹配店铺SKU数 / FBA匹配店铺 | 同一 SKU 在多少个店铺-SKU 对象中出现过 FBA 可售，以及对应店铺。 |
| 月度FBA匹配状态 | 是否在 2025-04 至 2026-06 的月度数据中出现过 FBA 可售；仅用于历史上架观察，不用于判定淘汰。 |
| 最近领星前端观察月 / 最近Listing标签 | 该 SKU 最近一次出现在领星月度前端清单时的月份和标签。 |
| 领星业务状态 | 以最近 Listing 标签判定：包含 `欧洲精铺2025淘汰` 为淘汰；待淘汰、侵权下架、季节性断货单独保留；其他前端 SKU 为上架在售。 |
| 标签状态说明 | 对领星业务状态的可读说明。未在前端观察到只表示月度前端清单未出现，不等于淘汰。 |
| 预计上架月份 | 以创建月后一个自然月作为最早应观察上架的月份。 |
| 首个完整销售月份 | 预计上架后的首个完整自然月，用于首月出单观察。 |
| 两个月成熟月份 | 创建后第二个月；到该月后才作为较稳定销售样本。 |
| 数据截止时销售成熟度 | 以 2026-06 为数据截止点判断销售观察窗口是否成熟；这是数据成熟度，不是业务状态。 |
