# 历史 SKU 上架基础数据

本目录按“先结论、后明细”组织。月度原始导出文件仍留在父目录，不与分析结果混放。

| 先后顺序 | 目录 | 什么时候看 |
|---|---|---|
| 0 | `00_整合工作簿` | 查看团队主总览、每个 SKU 的留存/回报/财务回正，以及每位开发人的月度经营时 |
| 1 | `01_快速总览` | 先看每月新增数量和核心口径 |
| 2 | `02_历史SKU上架基线` | 需要查首次 FBA 可售 SKU 或全量历史观察时 |
| 3 | `03_团队开发SKU生命周期` | 需要查看团队 SKU 最近领星标签状态、首次 FBA 可售月和销售观察成熟度时 |
| 4 | `04_月度模型测试` | 查看首个完整月出单、第二个月持续出单的 cohort 测试结果 |

## 统一口径

- 数据窗口：2025-04 至 2026-06，共 15 份领星月度导出，且已按业务所需 listing 标签筛选。
- 对象粒度：`marketplace + store_name + sku`；跨店铺、跨站点不合并。
- 首次 FBA 可售观察月：首次出现 `FBA-可售 > 0` 的月份，不等于精确上架日期。
- 团队 SKU 业务状态：以最近一次领星前端 `listing标签` 为准；包含 `欧洲精铺2025淘汰` 即为淘汰。FBA 可售只用于观察历史上架时间，未观察到 FBA 或未出现在前端清单都不直接推断为淘汰。
