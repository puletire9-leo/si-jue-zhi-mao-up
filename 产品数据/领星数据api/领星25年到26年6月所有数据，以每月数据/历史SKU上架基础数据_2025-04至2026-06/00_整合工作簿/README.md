## 边界

- 所有金额按 GBP、EUR 分开统计，未换汇、未相加。
- “财务回正”是累计领星结算毛利润首次转正的月份，不是严格的采购现金回本。
- 严格采购回本仍需要将首批采购 `quantity_real`、采购金额和汇率精确对应到店铺-SKU。

## 阅读顺序

1. **自然月总览**：按表现月份看当月发生的销售、利润和月间销售留存，适合观察团队经营变化。
2. **开品批次总览**：按 SKU 的创建月份归批，观察一批产品截至 `2026-06` 的留存、淘汰、累计销售、累计利润与财务回正，适合复盘开品质量。
3. **开发人 Sheet / SKU 明细**：定位到开发人、开品月份后再查看单个 SKU；SKU 数不因 GBP、EUR 两种币种而重复。
