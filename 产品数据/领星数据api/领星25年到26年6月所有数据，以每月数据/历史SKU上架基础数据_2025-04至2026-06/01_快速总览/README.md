# 快速总览

先看 `历史SKU_月度新增汇总_2025-04至2026-06.csv`，可快速看到每个月首次出现 FBA 可售的店铺-SKU 数量。

核心结论：

- 历史观察对象：6,639 个 `marketplace + store + SKU`。
- 曾出现 FBA 可售：5,195 个；英国 4,915 个，德国 280 个。
- 未曾观察到 FBA 可售：1,444 个。
- 2025-04 的 23 个首次观察对象存在左截断，不能认定为真实上架月。

需要逐个 SKU 查询时，再进入 `02_历史SKU上架基线`；需要看团队开发 SKU 的去留判断时，进入 `03_团队开发SKU生命周期`。
