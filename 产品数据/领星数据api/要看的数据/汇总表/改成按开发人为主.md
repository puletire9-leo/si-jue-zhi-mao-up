## 六、核心逻辑说明

### 横向列（39 列，5 大板块）

| 板块 | 包含指标 |
|------|----------|
| **基础库存** | 日期、SKU 总数、未上架、新货、试销、在售、淘汰、季节性、断货 >30 天、动销 >90 天 SKU、日销量在售 SKU 占比 |
| **销售数据** | 销量、日销额、销售额增长、销售额累计、销售占比 |
| **广告投放** | 曝光量、广告点击数、点击率 (CTR)、每日广告单量、每日广告点击量、广告销售额、广告总花费、广告占比、ACOS、平均 CPC、平均 ROI、COAS、ACOAS |
| **物流备货** | 广告排名、A10A 销量、FBA 销量、FBA 订单量、FBA 单量 |
| **利润核算** | 单品利润、整体利润、利润率、推广总利润、新品总利润、订单量占比 |

### 纵向行（时间汇总层级）

| 层级 | 说明 |
|------|------|
| **日明细** | 最细颗粒度，每日一行 |
| **周汇总** | 按周聚合，如第五十三周 (6.1-6.7) |
| **月汇总** | 按月聚合，如 4 月合计、5 月合计、6 月合计 |
| **总合计** | 全局汇总，所有数据总计 |

> 形成从每日明细 → 周度汇总 → 月度合计 → 全局总合计的漏斗式数据架构。

### 使用建议

此类宽表建议在 Excel 或 BI 软件中使用，**冻结首行和首列**，以保证在上下左右滚动时，日期和表头信息不丢失。
