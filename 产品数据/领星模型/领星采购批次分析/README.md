## 核心口径

| 维度 | 口径 |
|------|------|
| 批次单位 | PPG（`lingxing_purchase_plan.ppg_sn`），不是采购单PO |
| 批次边界 | PPG创建时间（`create_time`），同SKU同国同日多PPG合并为1批 |
| 状态过滤 | 只统计 `status=-2`（已完成） |
| 国家归属 | 余江燕创建=DE，其他创建人=UK |
| 利润归属 | 周表按marketplace归UK/DE，各国独立按PPG创建日分Q1/Q2/Q3 |
| 币种 | UK记GBP、DE记EUR，不换算不相加 |
| 数据同步 | 采购计划/采购单已同步到 2026-08-11 |

## 三个月备货率对比

| 月份 | SKU数 | UK有采购 | UK二次% | UK三次% | UK总毛利 | DE有采购 | DE二次% | DE三次% | DE总毛利 |
|------|----:|--------:|-------:|-------:|--------:|--------:|-------:|-------:|--------:|
| 4月 | 619 | 407 | 39.8% | 19.4% | +7 | 99 | 39.4% | 19.2% | -1962 |
| 5月 | 541 | 401 | 37.4% | 20.4% | +1677 | 91 | 31.9% | 7.7% | -631 |
| 6月 | 731 | 455 | 10.8% | 4.0% | +442 | 137 | 20.4% | 5.8% | -270 |

**趋势观察**：
- 6月补货率大幅下降（UK二次39.8%→10.8%），补货策略明显收紧
- UK首批亏损逐月收窄（Q1毛利 -1994→-811→-401）
- DE整体亏损持续收窄（-1962→-631→-270）

## 关键发现

### 补货决策失误（重点）
从4月/5月发现 **217个多批次补货失误案例**（≥2批 + 采购≥30 + 销售率<40%）：
- ≥3批仍销售率<40%：140个
- ≥7批极端案例：28个（如2551363补货10次）
- 总滞销库存：12222件

详见 [运营策略问题清单.md](./运营策略问题清单.md)

### 模型验证
- **首批筛选**：Q1毛利普遍为负（测款成本），符合精铺模式假设
- **三批转正**：Q3毛利多转正，验证"补货到三批才稳定盈利"
- **宋UK端唯一整体盈利**（+953 GBP），三批全盈

## 使用说明

### 生成新月份报表
1. 从 `产品数据/产品表/理实产品开发表/理实产品开发表X月份/` 提取SKU清单
2. 按开发人（龙梦临/周沁仪/宋凤莉/陈杨）分文件
3. 运行分析脚本（参考 [备货率分析流程.md](./流程文档/备货率分析流程.md)）
4. 输出到 `报表/` 目录

### 数据同步
如采购数据过期，先触发增量同步：
```bash
POST http://127.0.0.1:8025/api/v1/modules/lingxing/purchase/plans/sync
POST http://127.0.0.1:8025/api/v1/modules/lingxing/purchase/orders/sync
```
