## 一、页面架构（P0 已完成）

```
领星（一级菜单，menuGroup='领星'）
├─ 领星工作台            menuOrder 49   ← P0
├─ 导入领星              menuOrder 50   （旧）
├─ 领星本地产品           menuOrder 51   （旧）
├─ 领星店铺              menuOrder 52   （旧）
├─ 领星利润统计           menuOrder 54   （旧）
```

**设计原则**：不再拆分多页面，用页内 Tab 收敛。避免用户在功能间频繁切换。

`/lingxing/product-performance` 页面及其菜单已退役。对应数据库表、Java Service 和
`/product-performance` 后端端点均已删除，前端不得继续保留可访问入口或调用旧 API。

## 二、领星工作台

**路径**：`/lingxing/workspace`
**代码**：`frontend/src/modules/lingxing-workspace/`

### 用途

系统门户 + 数据看板 + 运维中心。一屏回答"当前领星系统状态如何？"。

### 结构

```
顶栏 —— 数据规模摘要 + 刷新按钮
   ↓
8 个统计卡片 —— baseline / monthly / weekly / profit / local_product / seller / purchase / sync_run
   ↓
Tab 1 概览
  ├─ 开发人分布柱状图（Top 8）
  ├─ 币种分布饼图（GBP / EUR）
  ├─ 起算月分布柱状图（近 24 个月）
  └─ 分析状态标签云
Tab 2 同步中心
  ├─ 限流规则提示条
  └─ 最近同步任务表格（run_id / type / marketplace / 时间窗 / 状态 / 写入数）
Tab 3 凭证 & API 规则
  ├─ appId/appSecret 更新表单（仅管理员可见、可操作）
  ├─ ping 链路验证按钮
  └─ 6 条领星 API 规则清单
```

### 依赖后端端点

- `GET /api/v1/modules/lingxing/overview` — 主数据
- `POST /api/v1/modules/lingxing/credentials` — 管理员更新凭证；凭证放 JSON body，禁止放 URL 查询参数
- `POST /api/v1/modules/lingxing/ping` — 链路验证

生产环境优先通过部署环境变量注入凭证。页面更新只用于管理员受控维护，`appSecret`
不得出现在 URL、代理访问日志、前端错误日志或前端持久化状态中。生产
`java-product:8002` 不对外网发布，宿主机 `8025` 只绑定 `127.0.0.1`；外部调用必须
经过 Gateway 的 JWT/RBAC。

## 三、ASIN 基准表

**路径**：`/lingxing/baseline`
**代码**：`frontend/src/modules/lingxing-baseline/`

### 用途

6945 团队 ASIN 主表的界面化。之前只能查数据库，现在支持筛选/查看/编辑。

### 结构

```
筛选栏 —— 关键词(ASIN/SKU/标签/开发人) + 开发人 + 币种 + 起算月 + 状态
   ↓
主表（11 列）
  ├─ ASIN（可点击进详情）
  ├─ 基础 SKU / 基础店铺
  ├─ 开发人（tag）
  ├─ 币种（tag，GBP=蓝 EUR=绿）
  ├─ 国家
  ├─ 领星标签（多 tag，按语义配色）
  ├─ 起算月 / 起算依据
  ├─ FBA 首月
  ├─ 分析状态（tag）
  └─ 操作：详情 / 编辑
   ↓
分页器（20 / 50 / 100 / 200）
   ↓
[详情抽屉] —— 4 块信息分组
  ├─ 基础信息（ASIN / SKU / 店铺 / 开发人 / 创建时间 / 标签）
  ├─ 起算判定（起算月 / 起算依据 / FBA 首月 / FBA 判定）
  ├─ 首次库存 / 首次可售
  └─ 版本与状态
   ↓
[编辑对话框] —— 5 个受控修正字段
  ├─ 开发人（团队固定选项）
  ├─ 领星标签（拆分、去空白后提交）
  ├─ 起算月（YYYY-MM 月份选择器）
  ├─ 起算依据（去空白、长度校验）
  └─ 分析状态（固定枚举）
```

### 依赖后端端点

- `GET /api/v1/modules/lingxing/baseline` — 分页列表
- `GET /api/v1/modules/lingxing/baseline/{asin}` — 单个查询
- `POST /api/v1/modules/lingxing/baseline/{asin}` — 更新

### 人工修正边界

基准表仍是所有模型共用的公共事实源。“公共基础事实只能由独立维护程序更新”中的
“独立维护程序”，是指维护入口必须独立于模型计算程序，并非禁止一切人工修正。
前端编辑属于基准维护入口：只提交允许字段，前后端都必须校验开发人、月份格式、
状态枚举与文本长度；模型一、模型二的生成脚本继续只读，不能借此回写基准表。

### 筛选口径

| 前端字段 | 后端参数 | 说明 |
|----------|----------|------|
| 关键词 | `keyword` | `LIKE` 匹配 ASIN/SKU/标签/开发人 |
| 开发人 | `developer` | 精确匹配 |
| 币种 | `currency` | GBP→英国/UK；EUR→德/法/意/西/荷 |
| 起算月 | `modelStartMonth` | 精确匹配 YYYY-MM |
| 分析状态 | `analysisStatus` | 固定状态精确匹配；“未标注”使用专用筛选值匹配 NULL/空串 |

起算月选项按当前月份动态生成，不能固定以 `2026-07` 为上限。

## 六、模块自动加载

前端模块化架构：**新增页面只需在 `src/modules/` 建目录**，不需要改路由和菜单。

```
src/modules/lingxing-xxx/
├── manifest.ts   ← 定义 id / name / icon / menuGroup / route
└── index.vue     ← 页面主体
```

`src/modules/index.ts` 用 `import.meta.glob('./*/manifest.ts')` 自动扫描。见 [frontend/CLAUDE.md](../../frontend/CLAUDE.md)。
