## 一、对接层（已读 `LingxingClient.java` 逐行核实）

单一客户端类承载全部对接，仿 `BazhuayuClient` 风格，用 JDK 原生 `java.net.http.HttpClient`。

**核心文件**：`java-backend/sjzm-product/src/main/java/com/sjzm/product/modules/lingxing/service/LingxingClient.java`

| 项目 | 说明 | 位置 |
|------|------|------|
| Base URL | `https://openapi.lingxing.com`，可用 `LINGXING_BASE_URL` 覆盖 | `application.yml:81-86` |
| Token 获取 | `POST /api/auth-server/oauth/access-token?appId=&appSecret=`，返回 access_token（含 expires_in）+ refresh_token | `LingxingClient.java:81-96` |
| Token 续约 | `POST /api/auth-server/oauth/refresh?appId=&refreshToken=`，过期前 **60 秒**自动刷新；refresh 失败降级重新换 token | `LingxingClient.java:61-116` |
| refresh_token 特性 | 2 小时有效、只能用一次，每次续约返回新的 refresh_token | `LingxingClient.java:98-116` |
| 签名算法 | 空值/null 剔除 → bool→`true/false` → 集合→紧凑 JSON → ASCII 排序拼 `k=v&` → MD5 转大写 → AES/ECB/PKCS5Padding（**密钥=appId 字节**）→ Base64 | `LingxingClient.java:214-237` |
| 公共参数 | `access_token / app_key / timestamp / sign`。POST：业务参数参与签名但只放 body，URL 只带 4 公共参数；GET：全部拼 URL | `LingxingClient.java:143-203` |
| 限流重试 | 识别 code `3001008` / `103` 为限流，最多 8 次、每次 `30s×(attempt+1)` 线性退避 | `LingxingClient.java:263-316` |
| 凭证来源 | `LingxingConfigService` 优先读 DB `api_config` 表（`lingxing_app_id` / `lingxing_app_secret`），回退环境变量，不硬编码 | `LingxingClient.java:35,82-86` |

**响应码约定**：业务接口 `code=0`、token 接口 `code="200"` 为成功；其余抛异常带 `request_id`（`LingxingClient.java:288-293`）。

> 注：本类使用 `javax.crypto.*`（第 11 行）**不违反**"禁止 javax.*"铁律——那条针对 Jakarta EE（javax.servlet 之类），javax.crypto 是 JDK 标准加密库、无 jakarta 等价物。

**配置绑定**：`modules/lingxing/config/LingxingConfig.java`（`@ConfigurationProperties(prefix="lingxing")`）
```yaml
# application.yml:81-86
lingxing:
  base-url: ${LINGXING_BASE_URL:https://openapi.lingxing.com}
  app-id: ${LINGXING_APP_ID:}
  app-secret: ${LINGXING_APP_SECRET:}
  connect-timeout: 10s
  read-timeout: 30s
```

## 二、落库数据域（约 10 张 lingxing_* 表）

建表脚本：`java-backend/sql/create_lingxing_*.sql`（共 6 个文件）

| 数据域 | 领星 API 路径 | 落库表 | 幂等键 |
|--------|--------------|--------|--------|
| 店铺列表 | `GET /erp/sc/data/seller/lists` | `lingxing_seller` | sid |
| 本地产品 | `POST .../local_inventory/productList` | `lingxing_local_product` | lingxing_id |
| 利润统计-ASIN | `POST /bd/profit/statistics/open/asin/list` | `lingxing_profit_asin` | asin\|sid\|dataDate\|currency |
| 产品表现 | `POST /bd/productPerformance/openApi/asinList` | `lingxing_product_performance` | summaryField:value\|sidScope\|start\|end\|currency |
| ASIN 基准表 | Python `weekly_asin_sync` 写入 | `lingxing_asin_baseline` | asin (PK) |
| 采购计划 | `POST .../getPurchasePlans` | `lingxing_purchase_plan` | SHA-256 业务键 |
| 采购订单 | `POST .../purchaseOrderList` | `lingxing_purchase_order` | SHA-256 业务键 |
| 采购订单子项 | 同上展开 item_list | `lingxing_purchase_order_item` | SHA-256 业务键 |
| ✨亚马逊 Listing | `POST /erp/sc/data/mws/listing` | `lingxing_listing` | `sid+seller_sku` |
| SKU 周表现 | 二次加工 | `lingxing_sku_weekly_performance` | snapshot+marketplace+sid+sku |
| SKU/ASIN 月表现 | 周表聚合 | `lingxing_sku_monthly_performance` / `lingxing_asin_monthly_performance` | 同上 |
| 同步运行记录 | 系统内部 | `lingxing_data_sync_run` | run_id |

**衍生表**：`lingxing_sku_store_snapshot`、`lingxing_target_sku_pool`（6 标签 SKU 池）、`sku_pool`（旧）。

**Mapper**：领星 Mapper 沿用老约定放 `com.sjzm.product.mapper`（已被 `ProductApplication.@MapperScan` 第一行覆盖，无需另注册）。2026-07-30 新增 `LingxingListingMapper`。

**同步 Service**（关键）：
- `LingxingSellerSyncService`（店铺同步）
- `LingxingLocalProductSyncService`（本地产品同步 + 写回）
- `LingxingProfitAsinSyncService`（利润同步）
- `LingxingPurchaseDataLayerService`（采购数据层）
- `LingxingOverviewService`（工作台总览）
- SkuDataLayer / PurchaseDataLayer 相关 Mapper（周/月/快照/目标池加工）

## 三、触发方式（关键结论）

**Java 后端无任何 `@Scheduled` 定时任务用于领星，全部手动触发。**

| 入口 | 说明 |
|------|------|
| Java Controller REST | `POST /api/v1/modules/lingxing/{resource}/sync` 手动触发同步 |
| `LingxingController` 调试端点 | `/ping`（链路验证）、`/call`（通用透传调试） |
| Python `scripts/lingxing_daily/weekly_asin_sync.py` | 手动执行（`python ... --api`），通过调 Java `/call` 透传领星 API，识别新 ASIN 更新 baseline |
| Python 脚本集（20+ 个） | 各种模型构建/回填/导出，均人工手动执行，无 cron/celery 定时 |

Python 基础访问模块：`scripts/lingxing_daily/lingxing_base_access.py`
