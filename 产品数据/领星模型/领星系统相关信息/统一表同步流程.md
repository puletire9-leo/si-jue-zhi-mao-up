# 领星产品统一表 —— 同步流程

> 生成时间：2026-07-30
> 事实来源：直接阅读实现代码 + 生产实测。
> 目标：把领星「产品表现」按周同步落库，加工成一张 **ASIN 维度产品统一表** `lingxing_product_unified`，只保留目标标签的 ASIN。

---

## 一句话

**店铺列表 → 产品表现(多店批量) → 周表 → 统一表（新ASIN INSERT上架时间 + 全量UPDATE经营指标）**，一条链路自动跑完。上架时间首次写入后锁定不变。

---

## 一、完整链路（6 步，一次调用跑完）

```
① 刷新店铺列表         /erp/sc/data/seller/lists（GET，一次性全量 1497 家）
        │  取 UK(mid=4)/DE(mid=5) 在售店铺 → 约 228 家
        ▼
② 产品表现多店批量拉    /bd/productPerformance/openApi/asinList（POST, summary_field=msku）
        │  分批 ≤200 sid/批，批间 10s；落 lingxing_product_performance（raw_json 含 price_list/tag_set）
        ▼
③ 加工进周表           从 raw_json 展开 price_list[*]/tag_set[*]，限 mid IN(4,5)
        │  落 lingxing_sku_weekly_performance（SKU×店铺×周 一行，SHA256 幂等）
        ▼
④ 重算统一表           只留 6 个目标标签 ASIN，新 ASIN INSERT（上架时间一次写入）+ 全量 UPDATE 经营指标
        │  落 lingxing_product_unified（每 ASIN 一行，truncate 后重建 → 新 ASIN INSERT（上架时间一次写入）+ 全量 UPDATE 经营指标）
        ▼
⑤ listing 覆盖同步     /erp/sc/data/mws/listing（POST, sid 逗号合并分页 ≤1000）
        │  truncate 整表 → 目标店铺 sid「逗号合并一次传」全局分页拉（不传时间参数=所有时间全量快照）
        │  → 只落白名单内 asin 的行 → Map 按 sid+seller_sku(小写归一) 去重 → 一次性落库
        │  （要最新数据 → 覆盖式；目标 ASIN 集中在少数店，合并 sid 分页比按店循环/按 asin 每批 10 个都快）
        ▼
⑥ 回填 listing_time 回填     UPDATE lingxing_product_unified.listing_time ← DATE_FORMAT(MIN(listing.open_date), '%Y-%m')
	           WHERE listing_time IS NULL（仅回填上架时间为空的新 ASIN，已有值的不动） ← MIN(listing.open_date) BY asin
           WHERE listing_time IS NULL（仅回填上架时间为空的新 ASIN，已有值的不动）
```

**统一触发入口**：`POST /api/v1/modules/lingxing/scheduled/run-now`
body：`{"startDate":"2026-07-06","endDate":"2026-07-12"}`（一个周窗口）

`LingxingScheduledSyncService.run()` 串起 ①~⑥ 全流程。

**⑤⑥ 关键 1：目标店铺 sid 实时算，非固定清单**——`LingxingListingMapper.selectTargetSids()` 在周表与统一表「刚重建之后」执行，
取 `周表 sid+asin ∩ 统一表目标 ASIN` 去重的 sid。本周新增店铺、其货打了目标标签 → 其 sid 自动纳入；
ASIN 退出目标标签 → 其独占店铺自动移除。实测某周 18 家，仅当次观测值。

**⑤⑥ 关键 2：sid 合并 + 大小写去重（踩坑记录）**——
- sid 支持逗号分隔多店一次查（文档 `"sid":"1,16"`），18 家合并成一个逗号串全局分页（~17 页），远少于按店循环几十次；`search_value`(asin) 上限仅 10，6994 ASIN 按 asin 查需 ~700 批，最差。
- **不传任何时间参数** → 拉「所有时间」的当前全量 listing 快照；每周 truncate 后重拉最新（覆盖式）。
- **唯一键大小写陷阱**：领星同店会返回仅大小写不同的 `seller_sku`（如 `12P` vs `12p`），MySQL 唯一键 `uk_sid_seller_sku` 用 `utf8mb4_general_ci`（大小写/尾空格不敏感）视为同一键，而 Java 精确区分。故 Map 去重 key 必须 `seller_sku.trim().toLowerCase(ROOT)` 归一化对齐 collation，否则一次性落库撞 `Duplicate entry`。

单独触发：`POST /api/v1/modules/lingxing/listings/sync-target`。

## 二、准入铁律：只允许 6 个目标标签 ASIN

以「该 ASIN 最新一周的 `tag_ids`」为准（周表 tag_ids 逗号分隔，`FIND_IN_SET` 精确匹配 tag_id）：

| 标签 | global_tag_id |
|------|---------------|
| 欧洲精铺2025 | 907563170455592213 |
| 欧洲精铺2025非标品 | 907654877317203632 |
| 欧洲精铺2025淘汰 | 907585631391968576 |
| 欧洲精铺2025待淘汰 | 907585847123066054 |
| 欧洲精铺2025季节性断货 | 907596133278666918 |
| 绿标 | 907657425150046095 |

**明确排除**：侵权下架(907677931879515735)、普通产品、新品、淘汰产品、需确认 等一律不进。

**动态性**（关键）：以最新周标签为准 →
- 旧 ASIN 改成非目标标签 → 自动退出统一表
- 新上架 ASIN 打了目标标签 → 自动进入
- 不是死名单（CSV 是 6 月快照 6617，7 月同步后为 6994，多出的是新上架目标标签 ASIN）

## 三、统一表字段（自包含，经营指标每周刷新、上架时间锁定不变）

数据全部从周表算。

| 组 | 字段 | 来源 |
|----|------|------|
| 身份 | asin, parent_asin, base_sku, base_msku, base_store, country, developer, title, listing_tags | 周表 |
| **上架时间** | **listing_time**（三级兜底：FBA可售首现→listing上架日→创建时间，**首次写入后锁定不变**）+ listing_time_source（依据标记） | **周表算，仅新ASIN计算** |
| FBA库存首现 | fba_inventory_first_month, inventory_first_store/country/sku/qty | 周表按时间序取首次>0 |
| FBA可售首现 | available_first_store/country/sku/qty | 周表按时间序取首次>0 |
| 观测状态 | fba_observation_status | 周表 |
| 经营累计 | total_volume/amount/order_items/gross_profit, avg_gross_margin, active_months, first_sale_month, last_sale_month | 周表聚合，每周刷新 |
| 最近周快照 | latest_month, latest_volume/amount/fba_available, latest_avg_star, latest_reviews_count | 周表最新 week_end，每周刷新 |
| 元数据 | data_cutoff_month, unified_version, synced_at | — |

## 四、限流规则（领星文档 §附加说明）

- 令牌桶容量 **1**，必须**串行**（上次返回后再下次）
- 单店查询间隔 **1s**；**多店查询间隔 10s**
- 按「账户 + path」维度限流，同账户多 appId 共享
- 客户端已内置 code 3001008/103 自动退避重试

> 注：领星只有**限流**，无"配额"概念（配额是卖家精灵侧）。

## 六、自动调度

- `@Scheduled(cron = "0 30 3 ? * MON")` 每周一 03:30
- 开关 `LINGXING_SCHEDULED_ENABLED`（默认 false，验证后设 true 才自动跑）
- 窗口取「上周一~上周日」完整一周
