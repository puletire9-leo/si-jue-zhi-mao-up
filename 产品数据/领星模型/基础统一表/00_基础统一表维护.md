# 领星基础统一表维护

## 固定规则

- 本目录是所有领星模型共用基础事实的唯一存放位置。
- 各模型只能读取这里的基础表，不得在模型目录复制、生成或修改公共基础表。
- 基础表按主题放入独立文件夹；当前上架批次基准位于 `上架批次和批次ASIN集合永远锁定基础批次表`。

## 维护入口

只更新“ASIN 模型分析起算月基准”时，在项目根目录执行：

```powershell
python scripts/lingxing_daily/maintain_asin_model_start_baseline.py
```

需要连同上游 FBA 库存首现基准一起完整重建时执行：

```powershell
python scripts/lingxing_daily/maintain_lingxing_base_tables.py
```

维护程序依次生成：

1. `ASIN_FBA库存首现月基准_2025-04至2026-06.csv`
2. `ASIN_FBA可售优先_商品信息创建时间兜底_模型分析起算月基准_2025-04至2026-06.csv`
3. `月表未观察到FBA库存_ASIN_2025-04至2026-06.txt`

模型生成程序不会自动调用该维护入口。更新基础事实与运行模型是两项独立操作。

模型读取统一基础事实时使用：

`scripts/lingxing_daily/lingxing_base_access.py`

该模块只读，不生成模型、不更新基础表，并集中维护数据库连接、统一 ASIN 基准
读取和采购计划事实读取，防止模型之间互相导入。
