# L3 · 留存率 vs 利润率:三个反转案例

## 核心命题

**留存率高 ≠ 开品方向好。淘汰率高 ≠ 团队差。**

在 L1 报告里,留存率是主要"业绩指标",但接入 L3 后发现留存率和真实利润严重脱钩。

## 案例 1 · 蒋舒:淘汰多 = 团队最赚

| 指标 | 数值 | 排名 |
|---|---:|---|
| L3 记录数 | 478 | 第 5 |
| 留存盈利率 | 23.6% | 第 2 |
| 已淘汰率 | 10.7% | 中等 |
| **累计利润率** | **7.74%** | 第 3 |
| **累计利润(GBP)** | **+2,073** | 第 3 |
| **单条平均利润** | +4.34 GBP | **第 1** |

**解读:** 蒋舒的招牌打法是"低价定制挂牌"(采购价 ¥4,售价 £6.99),每条 SKU 单价低但重复复购强。**她敢淘汰,淘汰得快,留下的都是真赚钱的。**

**给候选判断的启示:** 蒋舒开的品若走标品定制,盈利率高;若跟风套装(S06)则会失效。

## 案例 2 · 龙梦临:留存高 = 大规模亏损

| 指标 | 数值 | 判断 |
|---|---:|---|
| L3 记录数 | 552 | 高体量 |
| 留存盈利率 | 15.6% | 中偏低 |
| **留存但亏损** | **37.9%** | ❌ **接近 40% 保留但亏损** |
| 已淘汰率 | 10.0% | 淘汰过慢 |
| **累计利润率** | **-5.55%** | ❌ 负 |
| **累计利润(GBP)** | **-906** | ❌ 团队第 3 大亏损来源 |

**解读:** 龙梦临 L1 描述最细致("狐狸元素加上秋天质感"),但**留存 552 条里 209 条在亏损**。淘汰行动不够,把亏损当作"待观察"拖着。她的打法是 S07 精修 + T4 蝴蝶结 —— **T4 是团队最大亏损主题**。

**给候选判断的启示:** 龙梦临的品如果走 T4 蝴蝶结方向,**L3 会亏损**,除非能明确证明区别于历史 T4。

## 案例 3 · 周沁仪:证据链完整 ≠ 卖得好

| 指标 | 数值 | 判断 |
|---|---:|---|
| L3 记录数 | 524 | 高体量 |
| 留存盈利率 | 15.1% | 低 |
| **留存但亏损** | **36.1%** | ❌ **保留 189 条亏损品** |
| 已淘汰率 | 10.5% | 淘汰慢 |
| **累计利润率** | **-5.31%** | ❌ 负 |
| **累计利润(GBP)** | **-716** | ❌ |

**解读:** 周沁仪 L1 描述最专业("美国站销量稳定的老品,英国站翻新卖的自发货也有出单"),证据链完整。但 L3 结果反而最差。原因:**T4 蝴蝶结**是她的主打主题(130 条),而 T4 累计亏损 -1,247。

**给候选判断的启示:** L1 表述能力不代表 L3 表现。周沁仪的品如果走 T3 猫狗 (67 条,+734) 而非 T4 蝴蝶结,盈利率会显著提高。

## 案例 4 · 陈杨:高产 + 高利润

| 指标 | 数值 | 判断 |
|---|---:|---|
| L3 记录数 | 802 | 第 2 高 |
| 留存盈利率 | 21.9% | 第 2 |
| 已淘汰率 | 13.6% | 中等 |
| **累计利润率** | **12.15%** | ⭐ **第 1** |
| **累计利润(GBP)** | **+6,352** | ⭐ **团队第 1** |

**解读:** 陈杨是"高产 + 高盈利"的**双料冠军**,主打 T5 高地牛(78 条)+ T3 猫狗(73 条),两个都是盈利主题。她开的品从 L1 到 L3 全部走通。

**给候选判断的启示:** 陈杨的品**优先信任**,除非明显偏离她的历史主题+手法。

## 三条铁律

**铁律 1:** 留存率高但利润率负 = **淘汰太慢的信号**,不是"方向好"

**铁律 2:** 留存率低但利润率高 = **敢淘汰 + 留精品的招牌操作**,是团队真本事

**铁律 3:** L1 表述能力 ≠ L3 卖出结果 · **靠数据不靠文字**

## 应用到候选卡

L3 层输出必须回答两个问题:

1. 该开发人的**留存池利润率**(> 15% ✅ / < 0% ❌)
2. 该开发人在**类似主题+手法上的历史累计利润**(正 ✅ / 负 ❌)

若开发人历史留存池亏损,即使 L1 印象良好、L2 转化率正常,也要**给候选打红旗**,建议换其他开发人接手或换方向。
