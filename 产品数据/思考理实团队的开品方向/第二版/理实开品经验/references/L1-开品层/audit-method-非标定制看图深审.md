# 非标定制看图深审(4 步法)

> 本文件针对**定制/非标品**这一子类,补齐"仅凭标题+利润数字判不出该品为什么能赚"的盲区。
> 定制品的核心卖点是**图案**,标题文字只是图案的索引。跳过图看数据 → 复制不出同款成功。

## 何时启用

同时满足以下条件时,**必须**执行本方法,不能只跑普通 8+3+9 红线:

- `产品名称` 包含 `【定制】` 或 `定制` 前缀,或
- L2 层 `最新Listing标签` 含 **"非标品"** / **"NSP"** / **"定制"** 关键字,或
- `采购价¥` ≤ ¥5 且 `产品名称` 含 "挂牌/贴牌/彩印/异形/无货源/半定制" 词根

## 数据准备

跑本方法前必须拿到 3 份**原始事实**:

| 事实 | 来源 | 字段 |
|---|---|---|
| 开发上传的图片 | `lingxing_local_product.pic_url` → 领星本地表 | `lx_pic_url` |
| 开发标题 | 对接表 | `产品名称` |
| **亚马逊真实标题** | `lingxing_product_performance.item_name` | `亚马逊item_name` |

**不要**用开发标题当亚马逊标题。开发标题是内部编号,亚马逊标题是运营写给消费者的话术,两者卖点侧重可能完全不同——这个错踩过。

数据行必须来自 `data/sku_full_lifecycle.csv`(已完成 L1→L2→L3 贯通 + 补 Amazon 字段)。

## 4 步法

### 步骤 ① · 看图识别元素

用图像分析(人工或 vision 模型)列出图片中**所有可命名的视觉元素**,不要漏细节。

产出:元素清单 + 每个元素的占比印象。

**关键要求:**
- 元素粒度到"能被搜索的名词"为止——"热气球 × 6"比"多个热气球"更好
- 记录构图关系(左/中/右、前/后、大/小)
- 记录风格(彩绘玻璃/水彩/线稿/剪影 …)——风格本身就是关键词
- 记录**颜色主调**——彩虹/暖色/冷色/单色

### 步骤 ② · 三层命名对齐

把三段文本并排,做**元素级对齐**:

```
图片元素     ↔  开发标题字段     ↔  亚马逊标题 keyword
─────────────────────────────────────────────
热气球 × 6   ↔  "农场热气球款"    ↔  Hot Air Balloon
彩绘玻璃风   ↔  (未出现)          ↔  Rustic Stained Glass Style
郁金香花田   ↔  "农场"(泛化)     ↔  Flower Field / Farm
挂件形态     ↔  "挂牌"           ↔  Suncatcher / Hanging Ornament
```

产出:一张三列表,标注**哪些卖点开发已捕获、哪些是运营在亚马逊侧新加的**。

**判断信号:**
- 开发标题 ⊂ 亚马逊标题 → 运营做了 SEO 二次包装,常见于成熟品
- 开发标题 ⊄ 亚马逊标题 → 运营改了卖点方向,是否图案不足以支撑关键词?
- 亚马逊标题里有开发标题没提到的**核心品类词**(如 Suncatcher/Ornament) → 该品类才是真实搜索入口,开发标题是二级信息

### 步骤 ③ · 卖点组合判断

回答一个问题:**图 + 亚马逊标题共同定义了什么消费场景?**

模板:
```
购买者:______(谁买)
场景:  ______(挂在哪、什么时候用)
情绪:  ______(为什么愿意花 £6.99)
替代品:______(不买这个会买什么)
```

以 SKU 2255624 为例:
```
购买者:花园/阳台装饰爱好者、送礼消费者
场景:  窗户 / 花园 / 阳台悬挂,光线穿过时有彩虹效果
情绪:  乡村田园治愈 + 复古玻璃工艺感 + 中低价冲动购买
替代品:传统金属风铃(贵 3-5 倍)、水晶棱镜挂件(风格不匹配)
```

**若这四栏填不出、或替代品都是团队更强的品类** → 卖点组合不成立,该候选不进入 L2 判断。

### 步骤 ④ · 利润来源判断

结合 L3 数据回答:**该品是靠什么赚到 ¥1.49 结算利润 / 32% 空运利润率?**

必看字段:
- `售价` / `采购价¥` / `空运利润率` — 结构利润
- `最新月销量` / `累计销量` — 是否边缘留存
- `累计广告花费` / `最新周tacos` — 是否靠广告撬销量
- `首月销量` — 是否有 launch 期
- `最新月仍在卖` — 是否已被淘汰

**判断表:**

| 特征组合 | 利润机制 | 团队可复用性 |
|---|---|---|
| 采购价 ≤ ¥5 + 售价 £6.99 + tacos < 8% + 累计销量 < 20 | **低量长销稳赚**(自然搜索 + 极低成本) | 高:找同类"低成本 + 独特图 + 长尾关键词"品 |
| 采购价 ≤ ¥5 + tacos > 15% + 累计销量 > 100 | 广告推动型 | 中:需评估广告 ROI 是否可持续 |
| 采购价 > ¥10 + 售价 > £10 + 累计销量 > 50 | 溢价审美型(常见于 S07 异形) | 中:需确认审美壁垒 |
| 采购价 ≤ ¥5 + tacos > 25% + 累计销量 < 10 | 广告烧钱堆销量,利润被吃穿 | **拒绝**:典型 S06 套装陷阱 |

## 输出格式

深审完成后,把结论沉淀成**审计档案**,保存到 `data/审计档案/<SKU>.md`,字段至少包括:

- 基础信息(SKU / ASIN / 开发 / 供应商 / L1 月份)
- 图片本地路径 + 元素清单
- 三层命名对齐表
- 卖点组合四栏
- 利润机制归类
- **可复用规则**(以 `R-<主题>-<编号>` 形式命名,例如 `R-非标定制-01`)
- 下一步动作(是否加入 developer-profiles-L1 / 是否升级为红线)

## 与 8 手法体系的关系

**本方法不是第 9 个手法**,而是对 8 个手法**内部**"非标定制"子类的强化判断。定制品可能落进 S01 / S05 / S07 任意一个,深审的目的是解释**同一个手法下,为什么这一件赚了钱**。

深审产出的可复用规则应写回:

- 命名/图案层规律 → `themes-pool.md`
- 开发人偏好规律 → `developer-profiles-L1.md`
- 通用红线规律 → `judgement-rules-L1.md`(P10+)
- 供应商能力规律 → `supplier-profiles.md`
