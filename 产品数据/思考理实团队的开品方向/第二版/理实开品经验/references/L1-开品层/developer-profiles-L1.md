### R-蒋舒-05 · 低量长销模型(2026-07-16 新增)

**来源**: [SKU 2255624 深审档案](../../data/审计档案/2255624.md) · 农场热气球款 Sun Catcher

**观察到的规律:**
- **采购价 ¥4 挂牌类**是蒋舒的隐藏主力,不写在推荐场景里但真实占比约 30%
- 特征:采购价 ≤ ¥5 + 售价 £6.99 + 空运利润率 30%+ + 单单毛利 < 售价 × 20% + tacos < 8%
- **经营亚类归属**:低量长销(非"盈利明星"、非"边缘留存")
- 上架 3 个月内累计销量 8-15,月销 1-3 稳定

**判断要点(命中蒋舒挂牌类的候选):**
1. 采购价必须 ≤ ¥5(蒋舒供应链能拿到 ¥4 挂牌是核心竞争力,¥8+ 走的是别人的路)
2. 售价锁 £6.99,不试 £7.99+(蒋舒品在 £6.99 段有价格心智)
3. 图案元素必须 ≥ 5 个(单元素定制在蒋舒品里几乎不出货)
4. 亚马逊标题必须由运营重写,吃图的关键词(见 [audit-method-非标定制看图深审](audit-method-非标定制看图深审.md))
5. **不要**用累计销量作为二次进货决策依据——单单毛利 + tacos 更能反映真实经营质量

**招牌供应商**: 义乌鼎禾工艺品有限公司(172 条,其中 ¥4 挂牌类占比高)——找蒋舒挂牌类候选,先查这家的新款。

**能力边界**:
- ✅ 强项:低成本图案定制、田园/复古/彩绘玻璃风、Sun Catcher / Hanging Ornament 品类
- ⚠️ 慎选:高客单(£15+)、需精工工艺、需求专利/版权授权的 IP 类
- ❌ 不适合:大套装(她的 S06 集中在 2-4 件小套装,非 8+ 件密度装)

## 推荐算法

对候选按以下顺序推荐开发人:

1. **主匹配手法独占开发人** → 直接推荐
   - **S03 拓款 = 宋凤莉** (79% 独占率)
   - **T2 恐龙 = 张子轩** (团队独占)
2. **主匹配手法 + 主题匹配** → 从"强绑定手法" ∩ "主打主题"两个条件下选人
3. **供应商招牌手法一致** → 若候选走的手法与该供应商的招牌手法一致,推荐该供应商常合作开发人
4. **无命中** → 不推荐特定人,建议团队负责人分派
