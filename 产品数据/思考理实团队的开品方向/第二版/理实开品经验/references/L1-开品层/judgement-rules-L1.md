# 判断准则(5 条硬红线 + 1 条口径修正)

这是从对接表 12 个月数据反推出的团队实际边界,**触及任一红线的候选必须打红旗**,由人工二审。

> 2026-07-16 更新:新增 P10 图案密度红线 + P11 单单毛利警戒线 + R-销量口径-01。
> 前 3 条(P1/P2/P3)是**基础结构红线**,任何品都必检;P10/P11 是**非标定制专用红线**,需先判定候选属于定制子类再触发。

## P1 · 售价窄区间

**规则**: 售价必须落在 £/€ 5.99 ~ 12.99 区间内。

**数据依据 (2026-06 · n=151):**
- 中位数: **£7.99**
- 89% 落在 £5.99-£12.99
- 超过 £20 只有 6 条(高地牛熟食拼盘/直升机风车/发光花园装饰),都是特殊品类

**判断:**
- 售价 < £4.99 → 极低价段,团队无利润空间,拒绝
- £5.99 ≤ 售价 ≤ £12.99 → **P1 通过**
- £13 ~ £19.99 → P1 通过但需说明售价高于团队常态
- ≥ £20 → **P1 触发红线**,须回答:是否高地牛/花园装饰这类高客单已知品类?若否,拒绝

**德国站补正**: 德国售价视为含税价,须先 ÷1.2 换算成不含税再判断。

## P2 · 采购价上限

**规则**: 单件采购价必须 ≤ ¥25。

**数据依据 (2026-06 · n=157):**
- 中位数: **¥8.50**
- 96% 的 SKU 采购价 ≤ ¥25
- 唯一超 ¥25 的是发光花园装饰(¥38),对应售价 £34.99,是特殊高客单品

**判断:**
- 采购价 ≤ ¥5 → 强绑定 method-04(季节化)/method-06(套装),利润率通常最高
- ¥5 < 采购价 ≤ ¥15 → **P2 通过**,主流区间
- ¥15 < 采购价 ≤ ¥25 → P2 通过但需验证利润率仍在 20% 以上
- > ¥25 → **P2 触发红线**,须回答:售价能否覆盖到 £20+?若否,拒绝

**套装校正**: 套装类候选须换算单件采购价,不能用总采购价直接判断。

## P3 · 利润率警戒线

**规则**: 空运利润率必须 ≥ 20%。

**数据依据 (2026-06 · n=151):**
- 中位数: **23.13%**
- 均值: **24.31%**
- min = 17.41% (低于警戒线的 3 条,均为大套装)
- max = 39.25%

**判断:**
- 利润率 ≥ 28% → 优质候选,常见于 method-04 老品季节化
- 20% ≤ 利润率 < 28% → **P3 通过**,主流区间
- 17% ≤ 利润率 < 20% → P3 触发**警戒**,需说明:是否必须靠销量摊薄?
- < 17% → **P3 触发红线**,拒绝

**估算方法**: 若候选还没实测数据,用 `scripts/estimate_profit.py`(待建)按以下逻辑估算:

```
利润率 = (售价 - 采购价$ - 头程$ - 平台佣金$ - VAT$ - FBA配送费$ - 广告$ - 退款$) / 售价
```

详细公式见 `产品数据/产品表/算法.md`。

## 综合红线检查表

对候选按以下顺序打 3 个布尔:

| 检查项 | 判断依据 | 通过条件 |
|---|---|---|
| P1 售价区间 | 售价 | £5.99 ≤ 售价 ≤ £12.99 (或已知特殊品类) |
| P2 采购价上限 | 单件采购价 | 采购价 ≤ ¥25 |
| P3 利润率警戒 | 空运利润率(估算或实测) | 利润率 ≥ 20% |

三项全通过的候选 → 进入手法匹配阶段。
任一 fail → 打红旗,人工二审。

## 补充红线(非硬性,但需关注)

以下情况即使 P1/P2/P3 都通过也需人工介入:

| 情形 | 原因 |
|---|---|
| 采购价与售价比 > 1:2 | 供货链风险高,单点故障影响大 |
| 单 SKU 独立候选(无兄弟 SKU) | 团队标准打法是 3-6 SKU 组批,单 SKU 效率低 |
| 涉带电/液体/儿童玩具 | 需要 CE/UKCA/GPSR 合规审查 |
| 涉宗教/政治/敏感文化元素 | 需要人工审查是否触碰平台规则 |
| 尺寸最长边 > 45 cm | 超出团队常用 FBA 尺寸段,须重新算配送费 |
| 毛重 > 3 kg | 空运物流费快速上升,利润率可能崩 |

## P10 · 图案密度红线(非标定制专用)

**规则**: 定制/非标品必须同时通过**图案元素数量**和**图案-标题对齐**两条子检查。

**触发条件**: 候选 `产品名称` 含"定制/挂牌/贴牌"或 L2 层 `最新Listing标签` 含"非标品/NSP"。

**子检查:**

**P10.1 图案元素数 ≥ 3**
- 单元素图 → 拒绝(易被抄袭,团队无审美壁垒)
- 2 元素图 → 警戒(允许通过但需说明差异化)
- ≥ 3 元素图 → **P10.1 通过**

**P10.2 亚马逊标题必须包含图案主元素的英文关键词**
- 若 vision 识别出的 top 2 视觉元素**都没进** `亚马逊item_name` → 说明运营没吃到图的红利,拒绝
- 若 top 2 元素**都进标题** → **P10.2 通过**
- 若 top 2 只进 1 个 → 通过但需人工看是否可优化标题

**数据依据:**
- SKU 2255624(农场热气球款)7 个元素全进标题 → 32% 利润率、留存盈利
- 深审发现的**边缘留存**多数是"图案单一 + 标题没吃到图" → 卖点无法被搜到

**判断:**
- P10.1 fail 或 P10.2 fail → 打红旗,回到深审第 ② 步:是不是标题没写好?能否改标?
- 若无法改标(如已 GTIN 绑死) → 拒绝

## P11 · 单单毛利警戒线(边缘留存杀手锏)

**规则**: 单单**结算利润** ≥ 售价 × 20%。

**计算方式**:
```
单单结算利润 = 总结算利润 / 累计销量
```

**数据依据 (2026-04 · 蒋舒 SKU 2255624):**
- 累计销量 8 · 总结算利润 £1.49
- 单单结算利润 = 1.49 / 8 = **£0.186**
- 售价 6.99 · 20% 阈值 = **£1.398**
- **单单毛利 £0.186 < £1.398 → P11 触发警戒**

**这个警戒的意义:**
- L3 层的 `生命周期状态` = "留存且盈利" 会把 £0.186 单单毛利归入"盈利"
- 但**真实经营质量是边缘留存**——广告一停或退货一发就翻负
- 只看累计利润数字会掩盖**低毛利长销**的脆弱性

**判断:**
- 单单毛利 ≥ 售价 × 30% → 强健品,可复制
- 售价 × 20% ≤ 单单毛利 < 售价 × 30% → **P11 通过**
- 售价 × 10% ≤ 单单毛利 < 售价 × 20% → **警戒**,可留存但不宜追加投入
- 单单毛利 < 售价 × 10% → **P11 触发红线**,拒绝复制

**注意**:此规则不否定"低量长销"作为一种可接受的经营形态,但要求候选被明确**归类**为"低量长销"而不是错标成"盈利明星"。

## R-销量口径-01 · "边缘留存"必须与"盈利明星"分离

**问题**: 静态的 `生命周期状态` = "留存且盈利" 把两种质量完全不同的品混为一谈:

- **盈利明星**: 单单毛利 ≥ 售价 × 30% + 累计销量 ≥ 50 + tacos < 10%
- **低量长销**: 单单毛利 < 售价 × 20% + 累计销量 < 20 + tacos < 8%
- **边缘留存**: 单单毛利 < 售价 × 20% + 累计销量 < 20 + tacos > 15%

**规则**: 深审输出**不允许**直接引用 `生命周期状态` 作为最终判断。**必须**结合 P11 单单毛利 + `最新月销量` + `最新周tacos` 三个字段重新分类。

**数据落地**: 未来 enrich 脚本应加一列 `经营亚类`,取值 `盈利明星 / 低量长销 / 边缘留存 / 已淘汰 / 数据不足`,以替代粗粒度的 `生命周期状态` 用于候选决策。

## 综合红线检查表(更新版)

对候选按以下顺序打布尔:

| 顺序 | 检查项 | 判断依据 | 通过条件 | 适用范围 |
|---|---|---|---|---|
| 1 | P1 售价区间 | 售价 | £5.99 ≤ 售价 ≤ £12.99 | 全部 |
| 2 | P2 采购价上限 | 单件采购价 | 采购价 ≤ ¥25 | 全部 |
| 3 | P3 利润率警戒 | 空运利润率 | ≥ 20% | 全部 |
| 4 | P10 图案密度 | 图片 + 亚马逊标题对齐 | 元素 ≥ 3 且 top2 进标题 | **定制/非标** |
| 5 | P11 单单毛利 | 总结算利润 / 累计销量 | ≥ 售价 × 20% | 已上架的候选参照品 |

前 3 项全通过 → 进入手法匹配。
若为定制/非标候选,追加 P10;若有 L3 参照品,追加 P11 校验。
任一 fail → 打红旗。
