# L2 转化分析:开品到 FBA 有多远

## 团队整体漏斗 (2026-01 至 2026-06)

```
5,312 SKU 开品
   ↓  65.2%
3,466 SKU 进入 L2 基础表
   ↓  79% (相对进入基础表)
~2,730 SKU 有 FBA 可售证据
```

## 转化路径的三大信号

### 1. **进入基础表 ≠ FBA 上架**

参考 [judgement-rules-L2.md](judgement-rules-L2.md) 里的 P6 数据。特别关注:

- **S03 拓款 73.8% 进 L2 但只 21.5% 有 FBA 证据** —— 建 Listing 但不备货,自发货为主
- **S02 跨站复制 67.5% 进 L2 但只 18.4% 有 FBA 证据** —— 跨站类几乎全走 FBM
- 蒋舒 74.4% 进 L2 且 63.2% 有 FBA —— 团队"最扎实"的开发人

### 2. **未进 L2 的四类原因**

对候选做 L2 匹配失败时,须区分:

| 原因 | 特征 | 处理 |
|---|---|---|
| 运营主动放弃 | 品线冷,竞品多,运营没选 | 记录为"开发-运营分歧" |
| Listing 未建 | 供应商未提供合规资料 | 追供应商询 CE/UKCA |
| 上架执行失败 | 图片/文案/合规问题 | 找运营复盘 |
| 标签范围外 | 不在"欧洲精铺2025"标签 | 数据映射问题,不算失败 |

### 3. **成熟批次是唯一可比口径**

参考 [judgement-rules-L2.md](judgement-rules-L2.md) 里的 P5:创建时间 ≤ 2026-04 的成熟 SKU 才能横向比较。2026-05、2026-06 新品还在窗口内,不能过早判死。

## 开发人 L2 详细分析

### 蒋舒 · 团队最扎实的执行者
- 成熟批次未进 L2 只 30.2%
- 有 FBA 证据 63.2% (团队最高)
- 说明她开的品**运营愿意做且能做起来**
- **推荐场景**: L2 转化风险敏感的品,首选蒋舒

### 陈杨 · 高产但需筛
- 成熟未进 L2 34.3%,健康
- 但产量最大(1,117 SKU),绝对数量的未上架 SKU 达 220 条
- **判断**: 陈杨作为高产开发人,合理有开而未上,但需筛出真正好的方向

### 宋凤莉 · 拓款打法验证转化好
- 成熟未进 L2 33.7%,健康
- L2 转化 71.5%,团队第 2
- **判断**: 拓款打法(S03)本身 L2 转化率就高(73.8%),宋凤莉的招牌打法**在 L2 层是有效的**,问题在 L3

### 张子轩 · L2 转化红旗
- 成熟未进 L2 **53.0%**,超过一半
- 有 FBA 证据只 32.0%,主要靠自发货
- **判断**: 恐龙+套装打法**开发过多但运营承接跟不上**,需重新评估

### 刘淼 · 已离岗,数据留档
- 成熟未进 L2 **53.4%**,超过一半
- 已离岗 4 月后无数据
- **判断**: 历史数据仅供参考,不能用作现有候选判断依据

### 黄雨珊 · 样本太新
- 只有 5-6 月数据(236 SKU),多数未成熟
- 有 FBA 证据 21.6%,主要在 FBM 试水期
- **判断**: 8 月后再评估

## 判断建议

对候选做 L2 判断时:

1. **看开发人历史 L2 转化** —— 参考 P4 数据
2. **看该手法的 L2 转化 vs FBA 转化差** —— 大差距(如 S03)表明是自发货打法
3. **看是否成熟批次** —— 新月份数据不参与横向比较
4. **看未上架原因** —— 分类四种,不同处理

**输出候选卡时,L2 层必须回答:**
- 该开发人历史 L2 转化率 = X%
- 该手法历史 L2 转化率 = Y%
- 若 X<60% 或 Y<65% → **L2 红旗**
