- 数据源: `领星模型/基础统一表/ASIN_FBA可售优先*.csv`

## P6 · 手法 L2 转化警戒线

**规则**: 走某手法的候选,该手法的历史 L2 转化率必须 ≥ 65%。

**数据依据:**

| 手法 | L2 转化率 | FBA 证据率 |
|---|---:|---:|
| **03 自有链接拓款** | **73.8%** ⭐ | 21.5% |
| **07 异形审美精修** | 72.7% | 39.6% |
| **05 元素载体重组** | 72.2% | 43.8% |
| **04 老品季节化改款** | 69.0% | 32.6% |
| 08 FBM 验证 | 67.2% | 38.8% |
| 02 热销跨站复制 | 67.5% | **18.4%** ⚠️ 极低 |
| 01 供应商新款首发 | 67.2% | 39.3% |
| 06 套装数量密度 | 66.5% | 43.8% |

**关键洞察 · L2 转化和 FBA 证据不同步:**
- **S03 拓款 L2 高但 FBA 低(73.8%/21.5%)** → Listing 建了但不备货,可能是自发货占主
- **S02 跨站 FBA 极低(18.4%)** → 跨站类基本走 FBM,不上 FBA
- **S06 套装 FBA 高但 L3 亏损** → 上架效率高但经营效率低

## 综合红线检查表 (L2 补齐)

| 检查项 | 判断依据 | 通过条件 |
|---|---|---|
| P4 开发人转化 | 历史 L2 转化率 | ≥ 60% |
| P5 成熟批次未上架 | 成熟批次未进 L2 比例 | ≤ 45% |
| P6 手法转化 | 手法历史 L2 转化率 | ≥ 65% |

三项全通过 → 进入 L3 经营检查。任一 fail → 打红旗,人工二审。
