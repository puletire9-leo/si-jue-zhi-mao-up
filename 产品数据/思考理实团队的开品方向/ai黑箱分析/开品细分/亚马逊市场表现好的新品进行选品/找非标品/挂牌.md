## 一、定锚：我们自己的「挂牌」是什么（有依据）

### 1. 数据路径（必须走完）

```
lingxing_local_product.product_name LIKE '%挂牌%'
  → sku
lingxing_asin_baseline.base_sku = sku
  → asin
lingxing_asin_monthly_performance (sku+asin)
  → title（亚马逊真实标题）+ 月销量/利润
```

禁用：`lingxing_product_performance`（当前 0 行）。

### 2. 实查规模（2026-07-24）

| 项 | 值 |
|---|---|
| 品名含「挂牌」 | **1218** SKU |
| 能映射 ASIN | 572 SKU / 667 ASIN |
| monthly 有标题/经营 | 550 SKU / 636 ASIN |

### 3. 我们开的挂牌长什么样（从品名）

- 材质覆盖：**亚克力和玻璃（含彩绘玻璃 / stained glass）都能做**；其次木质；少量铁皮/拼图/吊坠
- 尺寸高频：**20×20cm**
- 几乎都带 **【定制】**
- 元素高频：花、猫、龙、知更鸟/罗宾、高地牛、猫头鹰、万圣节、十字架/圣母、蜂鸟、狐狸…

品名形态示例：
- `【定制】亚克力挂牌-20*20cm-蓝黄双猫`
- `【定制】挂牌-20*20cm-新知更鸟`
- `【定制】木质挂牌-20*20cm-木制知更鸟款`
- `【定制】圆形铁皮挂牌-【罗宾】`

### 4. 亚马逊标题里它叫什么（从 monthly.title）

对挂牌 SKU 的标题统计：

| 标题词 | 占比/量级 | 判断 |
|---|---|---|
| **Suncatcher / Sun Catcher** | ~**81%** | **主体形态** |
| Ornament / Stained Glass / Acrylic | 高 | 亚克力或玻璃彩绘窗挂 |
| Window Hanging | 中高 | 窗挂场景 |
| Wall Plaque / Hanging Sign | **很低** | 旁支，不是主体 |

德语标题对应：
- `Sonnenfänger`
- `Fensterdeko`
- `Acrylplatte` / `Fensterdeko Hängend`

**定锚一句话：**

> 我们说的「挂牌」= 以 **Suncatcher / Stained Glass Window Hanging（窗挂吸光片/彩绘挂饰）** 为主体的非标装饰，材质包括亚克力和玻璃；  
> 不是门牌号、不是厕所门牌、不是通用 metal sign 大海。
> **产能口径：玻璃产品可以按原材质照搬，我们能做；不能把玻璃款仅降级为亚克力换图参考。**

旁支（可单独记，勿混进主检索）：
- Wooden Wall Plaque / Hanging Sign
- Memorial / Key Holder 等

## 二、市场检索词（由定锚反推，分三国）

### UK / US（英文）— 主词

```text
suncatcher
sun catcher
window hanging
stained glass          -- 玻璃/彩绘玻璃本身就是目标材质，叠加 window/hanging 可减少非挂件噪声
acrylic ornament
glass suncatcher
stained glass window hanging
```

可选加元素词（来自我们已开元素）：
```text
cat / robin / dragon / highland cow / owl / hummingbird / flower / halloween
```

### DE（德语）— 主词

```text
Sonnenfänger
Fensterdeko
Acryl + Fenster / hängend
```

### 不要当主词（旧误区）

```text
plaque / hanging sign / wall sign / door sign / house number
schild / türschild / wandschild   -- 能捞到墙牌门牌，不是我们挂牌主体
```

这些只用于**旁支墙牌线**，或定锚后再做对照，不能作为「找挂牌」第一步。

## 四、推荐漏斗（优化路径 · 2026-07-24 验证）

```
L0  领星定锚 → 主词 suncatcher / Sonnenfänger，不是 plaque
L1  锁国家 + 本周批次（两源各自锁）
L2  双通道召回（必须并集，缺一不可）
      A. 标题主词
      B. 类目路径 Sun Catchers / Sonnenfänger
L3  两源并集：shop_products ∪ competitor_products_clean
      同 (marketplace, asin) 去重，优先 units 高；来源打 shop/clean/both
L4  形态/材质分桶（先分桶再看量，禁止混着排）
      平板亚克力 | 成品玻璃/彩绘玻璃 | 拼图suncatcher | 类目补漏 | 噪声珠串棱镜 | 其他
L5  有量门槛：listing_days < 120；UK/DE units≥5；US units≥10
L6  反查已开：lingxing_asin_baseline.asin → 标 is_owned
L7  元素分桶（词边界！避免 catcher 误伤 cat）→ E02
```

### 双通道 WHERE（核心，复制即用）

```sql
(
  -- A 标题
  title LIKE '%suncatcher%' OR title LIKE '%sun catcher%' OR title LIKE '%sun-catcher%'
  OR title LIKE '%sonnenfänger%' OR title LIKE '%sonnenfanger%'
  OR title LIKE '%fensterdeko%'
  -- B 类目
  OR node_label_path LIKE '%Sun Catchers%'
  OR node_label_path LIKE '%Sonnenfänger%'
  OR node_label_path LIKE '%Sonnenfanger%'
)
```

### 载体机器筛选的三层口径（2026-07-28 召回审计后）

机器筛选不能把 `DIY / kit / Bastelset / crystal pendant` 一刀切，因为拼图挂牌、钻石画成品挂件、带附属水晶吊坠的完整挂牌也会使用这些词。载体配置分三层：

1. **硬排除词**：珠子、贴纸、链条、玻璃片、颜料、空白框等明确原料/配件，无条件排除。
2. **条件排除词**：`DIY set / Bastelset / crystal pendant / prism` 等，通常排除。
3. **成品保护词**：`acrylic puzzle / stained glass window hanging / acrylic window hanging / diamond art hanging ornament` 等；命中时只覆盖条件排除，不能覆盖硬排除。

补充召回形态：`Sun Acrylic Catcher` 插词标题、`Suncatchers` 连写类目、`Glass Art & Suncatchers`、`Stained Glass Panels`，以及不含 suncatcher 但明确写成品 Window Hanging 的亚克力/玻璃标题。

### 形态分桶规则

| 桶 | 规则 |
|---|---|
| **噪声-珠串棱镜** | bead/Perlen/Bastelset/chandelier/icicle；纯 crystal/Kristall/prisma 且主体不是一整块成品画面 |
| **拼图suncatcher** | puzzle / jigsaw |
| **平板亚克力** | (suncatcher系 或 类目Sun Catchers) **且** acrylic/acryl；图片为一整块成品画面 |
| **成品玻璃/彩绘玻璃** | glass / stained glass / leaded glass；图片为一整块可直接悬挂的成品画面。**可按原玻璃材质开发** |
| **类目命中-待分** | 类目是 Sun Catchers 但标题材质词弱 |
| **其他窗挂** | 其余 |

### 看图判定标准（标题/类目判不准时的最终裁决）

标题词和类目会误召（珠子标题堆 suncatcher、原料套件被误归 Suncatcher 类目），**最终看图**。判据是「图片主体是不是一块成品挂牌」：

**是挂牌（要）——单体成品挂件作图片主体：**
- 一整块**亚克力、玻璃或彩绘玻璃**为主体，可以是真玻璃，也可以是仿 stained-glass 纹理，具有整幅图案（花、猫、热气球、日落等）
- 顶部带**挂链/挂绳**，即挂即用的成品
- 形状不限：
  - **圆形**（如 B0H2VN3YBY：圆盘 + 紫鸢尾白百合彩绘）
  - **异形**（如 B0H2HRTM71：热气球轮廓 + 底部吊篮）
- 判断关键：**买回来直接挂**，主体就是那一块画面。

**不是挂牌（排除）——原料 / 配件 / 半成品，即便挂在 suncatcher 类目下：**
- 珠子 / 水晶串 / 八角珠（beads / Perlen / octagon bead / 替换珠 Ersatzperlen）
- 链条 / 连接夹 / 吊灯棱镜配件（chandelier connector / prism parts / metal chain）
- 玻璃颜料、空白木框 DIY 套件（glass paint / unfinished frame kit / chicken wire kit）
- 一图里是**一堆散件/一包材料**，而不是一块成品画面 → 排除

> 拼图 suncatcher（puzzle / jigsaw，如 B0H2VN3YBY 标题的 Jigsaw）算**要**——它是成品挂牌的一种形态，别被 "kit/puzzle" 字样误当原料套件；以图片主体是否为一块成品挂件为准。
>
> 玻璃 suncatcher / stained glass window hanging 同样算**要**，且我们可以按原玻璃材质照搬开发；是否保留只看它是不是一整块可直接悬挂的成品，不因玻璃材质降级或排除。参考：`B0GVF5FWFH`（The Reader Skeleton Sun Catcher Stained Glass Window Hanging）。

### 元素分桶注意

- 不要用裸 `LIKE '%cat%'`，会命中 **catcher**。
- 用词边界或排除：`(title REGEXP '[[:<:]]cats?[[:>:]]')` 且排除 suncatcher 干扰；或先剥掉 catcher 再匹配。
- 德文：Katze / Rotkehlchen / Eule / Fuchs / Kolibri / Biene / Lebensbaum / Schmetterling。

## 七、方法注意

1. **先领星后市场**；没有 title 定锚不许开搜。
2. 三国分开；DE 用 Sonnenfänger，不是 plaque。
3. 主形态是 **Suncatcher 窗挂**，Wall Plaque 是旁支。
4. 候选必须反查是否已是我们 ASIN。
5. 元素从我们品名沉淀，市场只负责验证「还在涨/有空白」。
6. 批次按天锁本周，不写死「最新一天」。
