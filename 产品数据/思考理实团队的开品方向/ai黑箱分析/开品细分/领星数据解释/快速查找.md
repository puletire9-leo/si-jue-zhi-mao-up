# 领星数据 · 快速查找

> 场景：知道一个中文品类词（如「挂牌」），要快速得到：
> 1）我们开过哪些 SKU  
> 2）对应哪些 ASIN  
> 3）亚马逊上真实标题是什么  
> 4）再据此去市场库找同类非标品  
>
> 表结构详见同目录 `数据库中关于领星的表与相关数据.md`。

---

## 0. 先记住的铁律

1. **中文品名 ≠ 亚马逊标题**。判断市场叫法，只认 `title` / `item_name`。
2. **`lingxing_product_performance` 当前 0 行，禁用。**
3. SKU→ASIN 主路径：`lingxing_asin_baseline.base_sku`。
4. 标题主路径：`lingxing_asin_monthly_performance.title`。
5. 国家字段不统一：monthly 用「英国/德国」，weekly 用 `UK/DE`。

---

## 1. 三步标准查法（以「挂牌」为例）

### Step A · 本地品名圈 SKU

```sql
SELECT sku, product_name, product_developer, status_text, cg_price, pic_url
FROM lingxing_local_product
WHERE product_name LIKE '%挂牌%'
ORDER BY lx_update_time DESC;
```

挂牌实查：约 **1218** 条。

### Step B · SKU → ASIN

```sql
SELECT lp.sku, lp.product_name, b.asin, b.available_first_country, b.developer
FROM lingxing_local_product lp
JOIN lingxing_asin_baseline b ON b.base_sku = lp.sku
WHERE lp.product_name LIKE '%挂牌%';
```

挂牌实查：约 **572 SKU / 667 ASIN** 有映射（不是每个本地 SKU 都已上架映射）。

### Step C · ASIN/SKU → 亚马逊标题 + 表现

```sql
SELECT
  m.sku, m.asin, m.country, m.month,
  lp.product_name AS our_name,
  m.title AS amz_title,
  m.price, m.volume, m.gross_profit, m.gross_margin, m.tacos
FROM lingxing_local_product lp
JOIN lingxing_asin_monthly_performance m ON m.sku = lp.sku
WHERE lp.product_name LIKE '%挂牌%'
ORDER BY m.volume DESC;
```

备选（周级）：
```sql
SELECT w.sku, w.asin, w.marketplace, w.week_start,
       w.local_name, w.product_name AS amz_or_listing_title,
       w.volume, w.gross_profit, w.tacos
FROM lingxing_local_product lp
JOIN lingxing_sku_weekly_performance w ON w.sku = lp.sku
WHERE lp.product_name LIKE '%挂牌%'
ORDER BY w.week_start DESC, w.volume DESC;
```

备选（日财务标题）：
```sql
SELECT p.local_sku, p.asin, p.country_code, p.local_name, p.item_name,
       SUM(p.total_sales_quantity) qty, SUM(p.gross_profit) profit
FROM lingxing_local_product lp
JOIN lingxing_profit_asin p ON p.local_sku = lp.sku
WHERE lp.product_name LIKE '%挂牌%'
GROUP BY p.local_sku, p.asin, p.country_code, p.local_name, p.item_name
ORDER BY qty DESC;
```

## 2. 一条 SQL 直接出「我们的挂牌长什么样」

```sql
SELECT
  lp.sku,
  LEFT(lp.product_name, 60) AS our_name,
  b.asin,
  b.available_first_country AS first_country,
  m.country,
  m.month,
  LEFT(m.title, 140) AS amz_title,
  m.price,
  m.volume,
  m.gross_profit
FROM lingxing_local_product lp
JOIN lingxing_asin_baseline b
  ON b.base_sku = lp.sku
JOIN lingxing_asin_monthly_performance m
  ON m.asin = b.asin AND m.sku = lp.sku
WHERE lp.product_name LIKE '%挂牌%'
ORDER BY m.volume DESC, m.month DESC
LIMIT 50;
```

## 3. 从标题反推市场检索词（挂牌实查结论）

对 monthly 里挂牌 SKU 的 `title` 统计（约 9507 月行 / 636 ASIN）：

| 标题词 | 约命中 | 含义 |
|---|---:|---|
| Suncatcher / Sun Catcher | ~81% | **主形态：窗挂吸光片** |
| Ornament | 高 | 装饰挂件 |
| Stained Glass | 高 | 彩绘玻璃风格（多为亚克力仿） |
| Acrylic | 高 | 材质 |
| Window Hanging | 中高 | 窗挂 |
| Wall Plaque / Hanging Sign | 很低 | 传统墙牌/门牌 **不是我们挂牌主体** |

**德语站对应词**（从 DE 标题）：
- `Sonnenfänger`
- `Fensterdeko`
- `Acrylplatte`
- `Fensterdeko Hängend`

### 结论（有依据，不是猜）

我们品名里的「挂牌」，在亚马逊上**主要不是** plaque / door sign / house number，  
而是：

> **Acrylic Suncatcher / Window Hanging Ornament（亚克力窗挂吸光片）**  
> 尺寸常见 20×20cm；元素=猫/龙/知更鸟/高地牛/花/万圣节等图案。

少数支线才是：
- Wooden Wall Plaque / Hanging Sign（木质墙牌）
- Memorial / Key Holder / Toilet door sign 等边缘款

## 4. 用自有标题词去市场库找（下半程）

有了标题锚点后再查 `shop_products` / `competitor_products_clean`：

**UK/US 主检索词（优先）**
```text
suncatcher
sun catcher
window hanging
stained glass   （常与 suncatcher 同现）
acrylic ornament
```

**DE 主检索词**
```text
Sonnenfänger
Fensterdeko
Acryl + Fenster
```

**弱相关 / 勿当主体**
```text
plaque / hanging sign / house number / door sign
```
这些能捞到墙牌门牌，但是**我们挂牌主力形态的旁支**，不是定锚词。

批次/国家锁定仍遵守：
- 店铺：`marketplace` + `batch_date`
- 新品榜：`marketplace` + `DATE(created_at)`
- 本次标准周：`2026-07-20` ~ `2026-07-24`

## 5. 常见查找卡片

### 5.1 某开发人的挂牌
```sql
SELECT sku, product_name, cg_price, status_text
FROM lingxing_local_product
WHERE product_name LIKE '%挂牌%'
  AND product_developer = '陈杨';
```

### 5.2 某 SKU 全链路
```sql
-- 1 本地
SELECT * FROM lingxing_local_product WHERE sku = '2255960';
-- 2 ASIN
SELECT * FROM lingxing_asin_baseline WHERE base_sku = '2255960';
-- 3 月度标题与经营
SELECT month, country, asin, title, volume, gross_profit, tacos
FROM lingxing_asin_monthly_performance
WHERE sku = '2255960'
ORDER BY month DESC;
```

### 5.3 只看有销量的挂牌（月 volume>0）
```sql
SELECT m.sku, m.asin, m.country, m.month, m.title, m.volume, m.gross_profit
FROM lingxing_asin_monthly_performance m
JOIN lingxing_local_product lp ON lp.sku = m.sku
WHERE lp.product_name LIKE '%挂牌%'
  AND m.volume > 0
ORDER BY m.volume DESC;
```

### 5.4 数据是否最新
```sql
SELECT run_type, status, MAX(finished_at) last_finish, COUNT(*) c
FROM lingxing_data_sync_run
GROUP BY run_type, status
ORDER BY last_finish DESC;
```

## 7. 挂牌定锚后对方法卡的修正（摘要）

旧误区：在市场用 `plaque/sign/schild` 当挂牌主词。  
有依据后：

| 层级 | 正确主词 |
|---|---|
| 我们中文品名 | 挂牌 / 亚克力挂牌 / 木质挂牌 |
| 英德消费者标题 | Suncatcher, Sun Catcher, Window Hanging, Sonnenfänger |
| 材质信号 | Acrylic, Stained Glass style, 20x20 cm |
| 元素信号 | Cat/Robin/Dragon/Highland Cow/Flower/Halloween…（从 our_name 抽） |
| 旁支 | Wall Plaque / Hanging Sign / Memorial / Key Holder |

完整方法应改写 `找非标品/挂牌.md`：先领星定锚，再市场检索。
