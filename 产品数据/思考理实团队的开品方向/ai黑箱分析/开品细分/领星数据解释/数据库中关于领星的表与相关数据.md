## 二、各表关键字段

### 1. `lingxing_local_product`（我们开的品）
| 字段 | 含义 |
|---|---|
| `sku` | 本地 SKU（如 2255960） |
| `product_name` | **中文品名**（含「挂牌」「亚克力」「知更鸟」等） |
| `product_developer` | 开发人 |
| `cg_price` | 采购价 |
| `pic_url` | 产品图 |
| `status` / `status_text` | 状态（在售等） |
| `raw_json` | 领星原始 JSON（可含 global_tags 等） |

### 2. `lingxing_asin_baseline`（SKU → ASIN）
| 字段 | 含义 |
|---|---|
| `asin` | 亚马逊 ASIN |
| `base_sku` | 基准 SKU（主关联键） |
| `inventory_first_sku` / `available_first_sku` | 首入库存/可售 SKU（偶有不同） |
| `available_first_country` | 首可售国家（英国/德国…） |
| `developer` / `listing_tags` | 开发人、Listing 标签 |
| `fba_available_first_month` 等 | 生命周期时间点 |

**主关联**：`baseline.base_sku = local_product.sku`

### 3. `lingxing_asin_monthly_performance`（月度经营 + 亚马逊标题）
| 字段 | 含义 |
|---|---|
| `month` | 月份 `YYYY-MM` |
| `asin` / `sku` / `msku` | 标识 |
| `country` | 国家（库内多为「英国」「德国」中文） |
| `title` | **亚马逊 listing 标题** ← 判断「市场上叫什么」看这个 |
| `product_name` | 本地中文品名（与 local_product 同源） |
| `volume` / `amount` / `gross_profit` / `gross_margin` | 销量/销售额/毛利 |
| `price` | 售价（带币种符号字符串，如 `￡6.98`） |
| `tacos` / `acos` / 广告列 | 广告结构 |
| `fba_available` 等 | 库存 |

国家分布（实查）：英国 ~88,732 行 / 德国 ~9,870 行。

### 4. `lingxing_sku_weekly_performance`（周表现）
| 字段 | 含义 |
|---|---|
| `week_start` / `iso_year` / `iso_week` | 周 |
| `marketplace` | `UK` / `DE`（英文代码） |
| `sku` / `asin` / `seller_sku` | 标识 |
| `product_name` | 常见为**英文标题** |
| `local_name` | 本地中文名 |
| `volume` / `gross_profit` / `spend` / `tacos` | 经营 |

注意：UK 行远多于 DE（约 41 万 vs 4.6 万）。

### 5. `lingxing_profit_asin`（日财务）
| 字段 | 含义 |
|---|---|
| `data_date` | 日 |
| `asin` / `local_sku` / `sid` | 标识 |
| `item_name` | 亚马逊标题 |
| `local_name` | 本地名 |
| `total_sales_quantity` / `gross_profit` / `gross_rate` | 销量利润 |

### 6. 空表 / 慎用
- **`lingxing_product_performance`：0 行**。旧文档若写用它取 `item_name`，现状不可用。
- `lingxing_target_sku_pool` 仅有 `2026-W29` 一个快照，不能当历史标签源。

## 四、标准串联路径（找自有某类品长什么样）

```
① lingxing_local_product
     product_name LIKE '%挂牌%'  → 得到 sku 清单 + 中文品名结构
        │
        ▼
② lingxing_asin_baseline
     base_sku = sku              → 得到 asin + 首国
        │
        ▼
③ lingxing_asin_monthly_performance
     sku + asin                  → 得到 title（亚马逊标题）+ 月销量/利润
        │
        ├─ 备选：lingxing_sku_weekly_performance（周级，product_name 常是英文标题）
        └─ 备选：lingxing_profit_asin.item_name（日级标题兜底）
```

**禁止**：只凭中文品名脑补英文市场词；必须落到 `title` / `item_name`。

## 五、和「市场选品池」的边界

| 池 | 表 | 用途 |
|---|---|---|
| **自己的品** | 上述 lingxing_* | 定义「我们要的载体/元素长什么样」 |
| **市场候选** | `shop_products` / `competitor_products_clean` | 按自有标题词去市场捞相似品 |

流程应是：
1. 领星定锚（挂牌 = 我们开过的这些 SKU/标题形态）
2. 从标题提炼市场检索词
3. 再进市场池按国家+批次找

不是先在市场用 plaque/sign 瞎搜。
