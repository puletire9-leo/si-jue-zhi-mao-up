## L1 基础结构红线（任何品都必检）

### P1 · 售价区间（按站点分档）
**售价必须落在所属站点的区间内**，不同站点上限差别大（美国最高、英德较低）：

| 站点 | 售价区间 | 说明 |
|---|---|---|
| 英国 UK | **£4.99 ~ £19.99** | 团队主力段中位数 £7.99 |
| 德国 DE | **€5.99 ~ €19.99** | 见下方德国站补正 |
| 美国 US | **$6.99 ~ $27.99** | 上限最高，选品验证的主场 |

- 落在所属站点区间内 → **P1 通过**；接近上限（英德 £15+、美国 $20+）→ 通过但需说明高于团队常态，核对是否高地牛/花园装饰这类已知高客单品类。
- 低于下限 → 无利润空间，拒绝；超过上限 → 触线，须回答是否已知高客单品类，否则拒绝。
- **德国站补正**：德国售价视为含税价，须先 ÷1.2 换算成不含税再判区间。
- 依据(2026-06 n=151)：英国主力中位数 £7.99，89% 集中在 £5.99-12.99——这是**分布重心**，不是硬边界；边界按上表站点区间判。

### P2 · 采购价上限 ¥25
- 依据(2026-06 n=157)：中位数 ¥8.50，96% ≤¥25。
- ≤¥5 → 强绑定 04 季节化/06 套装，利润率通常最高；¥5-15 主流；¥15-25 需验证利润率仍>20%；>¥25 触线。
- **套装校正**：套装须换算单件采购价，不能用总采购价判。

### P3 · 利润率警戒 ≥20%
- 依据(2026-06 n=151)：中位数 23.13%，均值 24.31%，min 17.41%（低于线的均为大套装），max 39.25%。
- ≥28% 优质（常见 04 季节化）；20-28% 主流；17-20% 警戒（需说明是否靠销量摊薄）；<17% 拒绝。
- 公式：利润率 = (售价-采购价$-头程$-平台佣金$-VAT$-FBA配送费$-广告$-退款$)/售价。

### 补充关注项（P1-P3 通过也需人工介入）
采购/售价比>1:2（供货单点风险）｜单 SKU 无兄弟（标准打法 3-6 组批）｜带电/液体/儿童玩具（CE/UKCA/GPSR）｜宗教/政治/敏感文化元素｜最长边>45cm｜毛重>3kg（空运费崩利润）。

## 非标定制专用追加红线

### P10 · 图案密度（触发：产品名含"定制/挂牌/贴牌"或 Listing 标签含"非标品/NSP"）
- **P10.1 图案元素数 ≥3**：单元素拒绝（易抄无壁垒）／2元素警戒／≥3通过。
- **P10.2 亚马逊标题必须含图案 top2 视觉元素英文关键词**：top2 都没进→运营没吃到图的红利，拒绝；都进→通过；进1个→需人工看能否改标。
- 依据：SKU 2255624 农场热气球 7 元素全进标题 → 32% 利润率留存盈利；多数"边缘留存"是"图案单一+标题没吃到图"。

### P11 · 单单毛利 ≥ 售价×20%（边缘留存杀手锏）
- 计算：单单结算利润 = 总结算利润 / 累计销量。
- ≥售价×30% 强健可复制；20-30% 通过；10-20% 警戒（可留存不宜追投）；<10% 拒绝复制。
- 依据：SKU 2255624 单单毛利 £0.186 < 阈值 £1.398 → 触警戒。静态"留存且盈利"标签会把它错归"盈利"，实为边缘留存，广告一停就翻负。

### R-销量口径-01 · "边缘留存" 必须与 "盈利明星" 分离
深审输出**不允许**直接引用静态 `生命周期状态`。必须用 P11 单单毛利 + 最新月销量 + tacos 重新分类：
- **盈利明星**：单单毛利≥售价×30% + 累计销量≥50 + tacos<10%
- **低量长销**：单单毛利<售价×20% + 累计销量<20 + tacos<8%（可接受形态）
- **边缘留存**：单单毛利<售价×20% + 累计销量<20 + tacos>15%（脆弱，慎复制）
