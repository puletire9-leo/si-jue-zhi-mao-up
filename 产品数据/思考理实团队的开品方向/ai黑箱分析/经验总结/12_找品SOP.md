# 12 · 找品 SOP

> 把整个知识库串成可执行流程：**从市场系统里找出团队该开的品，每个给一个成立的理由。**
> 输入：市场候选品（M01 新品榜达标 + 竞品店铺数据）。输出：三层候选卡 + 一句优势理由 + 下一步动作。

## 阶段 A · 圈定市场候选（在哪找）

1. **数据源锁定**：只在 `competitor_products_clean`(m01_active=1，M01 新品榜达标品) + 竞品店铺数据表里找，有详细竞品数据。
2. **优先看美国站**（见 [01 总纲](01_开品模式总纲.md)）：美国市场大反应快，跨站投诉风险小。先在 US 找被验证好卖的品/元素。
3. 记录每个候选：标题、图、类目、竞品售价、竞品月销/上架天数、（若有）供应商。

## 阶段 B · 分流标品/非标品（走哪条线）

看图+标题判定：
- **功能主导 = 标品** → 走标品线（阶段 C-标）。开品方向只有：换新款式 / 性价比（价格·搭配·数量，注意特性和场景，不一味推数量）。
- **图案/元素主导 = 非标品** → 走非标线（阶段 C-非标）。必跑 [07 非标看图深审法](07_非标看图深审法.md)。

## 阶段 C-标 · 标品处理

1. US 表现好的标品 → 判断英德是否已有 → 没有则**直接照搬**上英德。
2. 换新款式：去 [10 供应商画像](10_供应商画像.md) 看供应商新款，或亚马逊上找同功能新款。
3. 性价比：对比竞品**每件单价**（数量优势必须每件更划算，否则名不副实，见 [11 陷阱一](11_经营真相与教训.md)）。

## 阶段 C-非标 · 非标品处理

1. 提取核心视觉元素（[07 步骤①](07_非标看图深审法.md)），竞品作为**元素验证器**（E01）。
2. 判断英德是否已有一模一样：
   - 英德**没有** → 同载体同图案照搬上英德。
   - 英德**已有** → **改图案** 或 **换载体**。
3. 选载体：在 [08 载体库](08_载体库.md) 找能承载该元素的团队可定制载体（三匹配校验：用户群体×载体×元素）。

## 阶段 D · 三层证据链 + 红线校验（该不该开）

对每个候选依次跑（详见 [02 证据链](02_三层证据链.md) / [04 红线](04_硬红线P1-P11.md)）：

**L1 粗筛** → P1 售价在所属站点区间(UK £4.99-19.99/DE €5.99-19.99/US $6.99-27.99) / P2 采购≤¥25 / P3 利润率≥20%（非标追加 P10 图案密度）。任一 fail 打红旗。
**L1 匹配** → [03 手法](03_八大开发手法.md) 匹配主/次手法 + [05 主题池](05_主题元素池.md) 识别主题 + [10 供应商](10_供应商画像.md) 核对。
**L2 转化** → P4 开发人转化≥60% / P5 未上架率≤45% / P6 手法转化≥65%。
**L3 经营**（最硬）→ P7 开发人盈利>0且≥15% / P8 手法盈利≥0且≥10% / P9 主题利润≥0（非标追加 P11 单单毛利）。
> **强否决**：命中 T4蝴蝶结/T6花朵（亏损主题）或 06套装（亏损手法）或 龙梦临/周沁仪（亏损开发人）→ 直接红旗，除非另有校验通过的优势顶上。

## 阶段 E · 逼出优势理由（E02，最后一关）

每个候选必须填出一句：**"这个品我们的优势是 ___"**，且经数据校验成立（见 [01 总纲第四节](01_开品模式总纲.md)）：
- 市场空白/低竞争/价格/配件/数量/定制图案/利润 任一成立 → 可开。
- 填不出，或填了被每件单价/同价/溢价数据打脸 → 拒绝或存疑。

## 阶段 F · 输出候选卡

```
候选: <标题>  [标品/非标品]
━━ 分流 ━━ US验证? 英德是否已有? → 照搬/改图/换载体
━━ L1 ━━ P1/P2/P3 = ✓/✗  主手法<method> 信心高/中/低  主题<T?>  载体<from 08>  供应商<from 10>
━━ L2 ━━ P4/P5/P6 = ✓/✗  类似历史SKU的FBA转化率<X%>
━━ L3 ━━ P7/P8/P9 = ✓/✗  开发人累计利润<X GBP>  手法/主题累计利润
━━ 优势理由 ━━ "我们比竞品强在___"（数据校验：每件单价/价差/图案/空白）
━━ 综合 ━━ 强开/开/谨慎开/拒绝
━━ 下一步 ━━ 人工看图/找供应商询价/换开发人/放弃
最相似历史SKU(3-5): <SKU 标题 售价 L3状态 图URL>
```

## 何时不用本流程

- 问销量预测/库存/上架状态 → 不属于本知识库。
- 问某已上架 SKU 的即时表现 → 走领星表现分析。
- 非理实 8 人团队的开品逻辑 → 数据不适用。

## 数据追溯

任何输出必须能溯源到 `第二版/理实开品经验/data/sku_full_lifecycle.csv`（三层贯通主表）或领星模型原始表。溯源失败须标"推测"。
