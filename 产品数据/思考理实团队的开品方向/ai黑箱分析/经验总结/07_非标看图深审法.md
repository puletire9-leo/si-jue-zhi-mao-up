# 07 · 非标看图深审法

> 针对**定制/非标品**这一子类，补齐"仅凭标题+利润数字判不出该品为什么能赚"的盲区。
> 定制品的核心卖点是**图案**，标题文字只是图案的索引。跳过图看数据 → 复制不出同款成功。
> **本方法不是第 9 个手法**，而是对 8 手法内部"非标定制"子类（常落进 01/05/07）的强化判断。

## 一、E01 · 「换载体」手法：竞品是元素验证器，不是同款对标

> 触发样本：SKU 2255958 蒋舒 铁皮画-白花蝴蝶。关联 [03 手法](03_八大开发手法.md) 的 05 元素×载体重组 / 04 老品季节化。

**一句话**：换载体开品里，竞品和我们**不是同品类，也不该是同款**。竞品的作用是**元素来源 + 热卖验证器**——它证明某组视觉元素在某价位有真实需求；团队把这组已验证元素 copy 微改，搬到自己擅长的微定制载体上。

**为什么会看错**：第一直觉拿竞品和开品比"是不是同一种东西"，发现品类不同就判"竞品对标错误"。**这是错的**——换载体的本质就是跨品类搬元素，品类本来就应该不同。

判断竞品用得对不对，不看"品类是否相同"，看**三者是否对齐**：

```
用户群体  ×  载体  ×  元素   三者对齐 → 换载体成立
```

**样本 SKU 2255958**：我们铁皮成品装饰画 £6.99 vs 竞品 B0GRYRD1NN 数字油画 DIY 套装 £6.99（月销95/上架78天）。品类完全不同（成品画 vs DIY 套装）但**不是问题**；元素相同（田园花卉雏菊向日葵蝴蝶）、价位相同、用户群体一致（买雏菊数字油画的人≈喜欢田园花卉家居装饰的人≈买铁皮花卉挂画的人）→ 三者对齐 → 换载体成立。

**换载体 SOP**：
1. **找元素来源**：从新品榜/竞品里找一组"已被销量验证好卖"的视觉元素（不限品类，DIY套装/贴纸/抱枕/马克杯都行）。
2. **copy 微改**：copy 出来做符合团队微定制能力的改动（避免直接侵权）。
3. **选载体**：搬到团队擅长、成本可控的微定制载体（铁皮画/亚克力挂牌/帆布袋/木牌/Suncatcher，见 [08 载体库](08_载体库.md)）。
4. **三匹配校验**（任一不匹配则否）：用户群体（买竞品元素的人会买这个载体吗）／载体（适合承载这组元素吗，尺寸/风格/材质）／元素（在新载体上表达完整吗，别丢核心卖点）。

**竞品参考价值口径（修正版）**：
- **同款对标型**（02跨站复制/竞品热销复制）：竞品越同款、上架天数越短 → 参考价值越高。
- **换载体型**（05元素×载体/04季节化）：竞品**不必同款**，只需"元素被验证好卖 + 用户群体与载体匹配"。看竞品的"元素销量证据"，不看"品类是否一致"。
## 二、4 步深审法

**何时启用**（满足任一必须跑，不能只跑普通红线）：
- 产品名含"【定制】/定制"前缀，或
- L2 层最新 Listing 标签含"非标品/NSP/定制"，或
- 采购价 ≤¥5 且产品名含"挂牌/贴牌/彩印/异形/无货源/半定制"词根。

**数据准备**（3 份原始事实，缺一不可）：

| 事实 | 来源 | 字段 |
|---|---|---|
| 开发上传图片 | `lingxing_local_product.pic_url` | lx_pic_url |
| 开发标题 | 对接表 | 产品名称 |
| **亚马逊真实标题** | `lingxing_product_performance.item_name` | 亚马逊item_name |

⚠️ **不要用开发标题当亚马逊标题**。开发标题是内部编号，亚马逊标题是运营写给消费者的话术，卖点侧重可能完全不同——这个错踩过。

### 步骤① 看图识别元素
列出图片中**所有可命名的视觉元素**。要求：粒度到"能被搜索的名词"（"热气球×6"优于"多个热气球"）；记录构图关系（左/中/右、前/后、大/小）；记录风格（彩绘玻璃/水彩/线稿/剪影——风格本身就是关键词）；记录颜色主调（彩虹/暖色/冷色/单色）。

### 步骤② 三层命名对齐
把"图片元素 ↔ 开发标题 ↔ 亚马逊标题 keyword"三段并排做元素级对齐，标注哪些卖点开发已捕获、哪些是运营在亚马逊侧新加的。
- 开发标题 ⊂ 亚马逊标题 → 运营做了 SEO 二次包装（成熟品常见）。
- 开发标题 ⊄ 亚马逊标题 → 运营改了卖点方向，图案是否不足以支撑关键词？
- 亚马逊标题有开发标题没提的**核心品类词**（Suncatcher/Ornament）→ 该品类才是真实搜索入口。

### 步骤③ 卖点组合判断
回答：图+亚马逊标题共同定义了什么消费场景？填四栏 —— **购买者**（谁买）／**场景**（挂哪、何时用）／**情绪**（为何愿花 £6.99）／**替代品**（不买这个会买什么）。
> 若四栏填不出、或替代品都是团队更强的品类 → 卖点组合不成立，不进 L2 判断。

### 步骤④ 利润来源判断（结合 L3）
必看：售价/采购价/空运利润率（结构利润）、最新月销量/累计销量（是否边缘留存）、累计广告花费/最新周tacos（是否靠广告）、首月销量（有无 launch）、最新月仍在卖（是否淘汰）。

| 特征组合 | 利润机制 | 可复用性 |
|---|---|---|
| 采购≤¥5 + 售价£6.99 + tacos<8% + 累计<20 | 低量长销稳赚（自然搜索+极低成本） | **高**：找同类"低成本+独特图+长尾词" |
| 采购≤¥5 + tacos>15% + 累计>100 | 广告推动型 | 中：评估广告 ROI 可持续性 |
| 采购>¥10 + 售价>£10 + 累计>50 | 溢价审美型（常见 07 异形） | 中：确认审美壁垒 |
| 采购≤¥5 + tacos>25% + 累计<10 | 广告烧钱堆销量，利润被吃穿 | **拒绝**：典型 06 套装陷阱 |

## 三、输出与规则回写

深审完成沉淀成审计档案 `data/审计档案/<SKU>.md`，字段：基础信息／图片本地路径+元素清单／三层命名对齐表／卖点四栏／利润机制归类／可复用规则（`R-<主题>-<编号>`）／下一步动作。

可复用规则回写去处：命名/图案规律→[05 主题池](05_主题元素池.md)；开发人偏好→[09 开发人画像](09_开发人画像.md)；通用红线→[04 红线 P10+](04_硬红线P1-P11.md)；供应商能力→[10 供应商画像](10_供应商画像.md)。
