# E02 · 开品第一性原理：开品理由 = 我们相对竞品的优势点

> 首次沉淀：2026-07-20 ｜ 触发：重估 SKU 2640484 马桶螺丝时纠正"月销低=需求薄=谨慎"的错判
> 这是所有手法之上的总纲，E01 换载体是它的一个特例。

## 一句话

不管什么开品手法，**最终的开品理由都收敛为一句话——我们相比已有竞品有优势**。
判断一个品该不该开，就是问：**这个品，我们相对市面竞品的优势点是什么？说得出且成立 = 可开。**

## 优势的形态（谱系，每一种都成立）

| 优势类型 | 一句话 | 对应手法 | 竞品数据怎么看 |
|---|---|---|---|
| 市场空白（换市场） | 新元素/图案在这个载体上是空白的，我们先占 | 换载体、元素×载体重组 | 竞品证明元素好卖，我们载体是空白 |
| 价格优势 | 跟竞品比——更便宜 | 供应链、成本控制 | 对比竞品单价/单件价 |
| 配件优势 | 跟竞品比——更丰富（多给配件） | 套装组合 | 竞品配件少 |
| 数量优势 | 跟竞品比——更多、有性价比 | 套装/数量密度 | 对比"每件单价"是否真更划算 |
| 定制/图案优势 | 定制品做出新的、更好看的图案 | 异形审美、非标定制 | 竞品图案旧/糙 |
| 低竞争入场 | 小类目竞争小，销量小但好进场吃份额 | 供应商新款、跨站复制 | **月销小不是缺点**，是干净池子 |
| 利润优势 | 结构上有利润空间（≥20%） | 通用 | 空运利润率 |

> 这些形态可叠加。一个品可以同时有"数量优势 + 图案优势"。

## 关键纠正：销量高低 ≠ 好坏

**错误思维**：竞品月销高 = 需求强 = 好；竞品月销低 = 需求薄 = 谨慎。

**正确思维**：销量只是"需求验证强度"的一个信号，要和"竞争程度""我们的优势"一起看：
- 竞品销量高 + 上架短 → 需求已验证且在爬升，但**竞争往往也大** → 要问"我们凭什么比它强"（价格？图案？）
- 竞品销量低 + 小类目 → **可能是低竞争入场机会** → 优势是"先占干净池子"，只要我们有价格/利润优势就能吃下

## 重估样本 · SKU 2640484 马桶盖固定螺丝（两次纠正）

- 我们：6件套 £8.99，利润率 19.84%；竞品 B0GYVYJ2MW：4件套 £5.32，月销13，上架38天。
- **错判一**：竞品月销仅13 → 需求薄 → 谨慎。（错：月销低是低竞争入场信号，不是坏事）
- **错判二**：用了"数量密度"手法 → 数量密度是陷阱 → 优势弱。
  （错：**数量优势本身是成立的优势形态**，不能因为"用了数量优势"就否定）
- **正确判断**：数量优势没问题，问题是**这个品的数量优势具体不成立**：
  - 数量优势要成立，得"每件更划算"：我们单件 £8.99/6=£1.5 vs 竞品 £5.32/4=£1.33
    → 件数多了但**单件反而更贵**，数量优势名不副实。
  - 换个优势形态也不行：无图案（定制优势×）、单件更贵（价格优势×）、利润 19.84% 破线（利润优势×）。
  - → 结论：**不是"数量密度是陷阱"，是"这个品所有优势形态都填不出/被数据打脸"**，故谨慎。

## 校验优势"真伪"的动作

自称某优势，必须用数据验一遍别自打脸：
- 称数量/价格优势 → 算**每件单价**，比竞品真的更低吗？（马桶螺丝就栽在这）
- 称配件优势 → 竞品配件数 vs 我们，真的多吗？
- 称图案优势 → 看图，比竞品真的更好看/更新吗？
- 称市场空白 → 竞品是不是同载体？同载体就不算空白了。

## 落到过品动作

每个 SKU 过品，最后必须逼出一句话：**"这个品我们的优势是 ___"**。
- 填得出且成立（空白/低竞争/价格/利润/差异化任一）→ 可开
- 填不出，或填了但数据打脸（如自称价格优势但单件更贵）→ 拒绝或存疑

> 配合 E01：先分清是"同款对标型"还是"换载体型"手法，再按本篇找优势点。
