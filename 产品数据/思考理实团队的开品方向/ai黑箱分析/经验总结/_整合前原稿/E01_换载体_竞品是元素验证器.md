# E01 · 「换载体」手法：竞品是元素验证器，不是同款对标

> 首次沉淀：2026-07-20 ｜ 触发样本：SKU 2255958 蒋舒 铁皮画-白花蝴蝶
> 关联方法卡：第二版 method-05 元素×载体重组 / method-04 老品季节化改款

## 一句话

「换载体」开品里，**竞品和我们不是同品类，也不该是同款**。竞品的作用是
**「元素来源 + 热卖验证器」**——它证明某组视觉元素在某价位有真实需求；
团队把这组已验证元素 copy 微改，搬到自己擅长的微定制载体上。

## 为什么会看错

第一直觉会拿竞品和开品比"是不是同一种东西"，发现品类不同就判"竞品对标错误"。
**这是错的**。换载体的本质就是跨品类搬元素，品类本来就应该不同。

判断竞品用得对不对，不看"品类是否相同"，看**三者是否匹配**：

```
用户群体  ×  载体  ×  元素   三者对齐 → 换载体成立
```

## 样本拆解 · SKU 2255958

| 维度 | 我们的开品 | 竞品 B0GRYRD1NN |
|---|---|---|
| 品类 | 铁皮成品装饰画（买回直接挂） | 数字油画 DIY 套装（买回自己画） |
| 售价 | £6.99 | £6.99 |
| 核心元素 | 雏菊+向日葵+蝴蝶+复古木纹+励志英文 | 雏菊等花卉 |
| 市场证据 | — | 月销 95 / 上架 78 天（元素被验证好卖） |

- 品类完全不同（成品画 vs DIY 套装），但这**不是问题**。
- 元素相同（田园花卉），价位相同（£6.99）。
- 用户群体一致：**买雏菊数字油画的人 ≈ 喜欢田园花卉的家居装饰人群 ≈ 买铁皮花卉挂画的人**。
- 三者对齐 → 换载体成立。开品理由"换新载体"正确。

## 可复用的开品动作（SOP）

1. **找元素来源**：从新品榜/竞品里，找一组"已被销量验证好卖"的视觉元素
   （不限品类，DIY 套装、贴纸、抱枕、马克杯……都行）。
2. **copy 微改**：把这组元素 copy 出来，做符合团队微定制能力的改动（避免直接侵权）。
3. **选载体**：搬到团队擅长、成本可控的微定制载体上
   （铁皮画 / 亚克力挂牌 / 帆布袋 / 木牌 / Suncatcher…）。
4. **三匹配校验**（关键约束，任一不匹配则否）：
   - 用户群体：买竞品元素的人，会不会买这个载体？
   - 载体：这个载体适合承载这组元素吗（尺寸/风格/材质）？
   - 元素：元素在新载体上表达完整吗（别丢了核心卖点）？

## 判断竞品参考价值的口径（修正版）

- **同款对标型手法**（跨站复制 / 竞品热销复制）：竞品越同款、上架天数越短 → 参考价值越高。
- **换载体型手法**（元素×载体重组 / 老品季节化）：竞品**不必同款**，只需
  **元素被验证好卖 + 用户群体与载体匹配**。看竞品的"元素销量证据"，不看"品类是否一致"。

> 教训：不要因为"竞品和开品不是同一种产品"就判竞品选错。先分清这是哪种手法。
