## C1. 新增 batches API 端点

   ```python
   async def list_batches(
       marketplace: str = Query(..., description="站点 UK/DE"),
       batch_type: str = Query("zheng_model", description="批次类型"),
   ):
   ```
2. 内部调用新增的 `list_batches_by_marketplace()` 函数（在 `save_results.py` 中）
3. 查询 `analysis_batches` 表: `WHERE marketplace = %s AND batch_type = %s ORDER BY id DESC`
4. 返回 `{"code": 200, "data": [{"batch_id": "...", "status": "...", "version": N, "month": "...", "created_at": "..."}]}`

**修改文件**: `selection-agent-v2/tools/selection/save_results.py`

新增函数:

## C2. 模型 API 参数适配

**问题**: 前端点击 L2 小类时只有 `nodeId`，不知道 `bsr_id`（bsr_id 在 L1 层级）。当前 API 要求 `bsr_id` 为必填。

**修改文件**: `selection-agent-v2/api_server.py`

**方案**: 将 `bsr_id` 改为可选参数。当未提供时，自动扫描 `{MODEL_BASE_DIR}/{marketplace}/` 下所有 bsr_id 子目录，查找包含 `{node_id}.json` 的目录。

修改 `get_product_line_model` 和 `get_product_line_model_md`:
```python
@app.get("/api/v1/product-line/model/{node_id}")
async def get_product_line_model(
    node_id: int,
    marketplace: str = Query(..., description="站点 UK/DE"),
    bsr_id: str = Query(None, description="品线 bsrId（可选，不传则自动查找）"),
):
```

当 `bsr_id` 为 None 时:
1. 扫描 `{MODEL_BASE_DIR}/{marketplace}/` 下所有子目录
2. 检查 `{subdir}/by_node_id/{node_id}.json` 是否存在
3. 找到则使用该 bsr_id，找不到返回 404
4. 找到多个匹配时取第一个（理论上 nodeId 在 bsr_id 下唯一）

## C3. Vite 代理添加 product-line 路由

**问题**: `/api/v1/product-line/model/` 请求落入 `^/api` 兜底规则 → Python 后端 (8090) → 404。

**修改文件**: `frontend/vite.config.js`

在 `/selection-api` 代理规则之前（Java 代理之后），添加:
```javascript
'/api/v1/product-line/model': {
  target: mode === 'development'
    ? `http://${env.VITE_SELECTION_AGENT_HOST || 'localhost'}:${env.VITE_SELECTION_AGENT_PORT || '8011'}`
    : (env.VITE_SELECTION_AGENT_URL || 'http://localhost:8011'),
  changeOrigin: true,
  secure: false,
  timeout: 30000,
  logLevel: 'warn'
},
'/api/v1/product-line/batches': {
  target: mode === 'development'
    ? `http://${env.VITE_SELECTION_AGENT_HOST || 'localhost'}:${env.VITE_SELECTION_AGENT_PORT || '8011'}`
    : (env.VITE_SELECTION_AGENT_URL || 'http://localhost:8011'),
  changeOrigin: true,
  secure: false,
  timeout: 30000,
  logLevel: 'warn'
},
```

注意: 必须放在 `'^/api'` 兜底规则之前，否则会被兜底拦截。
