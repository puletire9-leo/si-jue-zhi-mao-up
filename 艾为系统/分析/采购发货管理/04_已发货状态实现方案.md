# 艾为系统"已发货"状态实现方案 - 可直接借鉴

## 🎯 核心发现

艾为系统（张总系统）的数据模型：

```
采购计划 (purchase_plan)
    ↓ 关联
采购订单 (purchase_order)  ← 这个相当于我们的"批次"
    ↓ 关联
发货计划 (shipment_plan)   ← 从采购订单发往FBA的计划
    ↓ 关联
实际发货 (shipment_actual) ← 实际发出去的货物
```

## 🔄 判断"已发货"的逻辑

### 方案1：通过发货计划表关联（艾为系统的做法）

```sql
-- 查询某个采购单（批次）的发货情况
SELECT 
    po.order_sn AS batch_no,
    po.sku,
    po.quantity_entry AS good_num,
    po.quantity_receive AS good_transit_num,
    po.quantity_total AS total_num,
    -- 🔑 关联发货计划，汇总已发货数量
    COALESCE(SUM(sp.shipment_plan_quantity), 0) AS shipped_planned,
    -- 🔑 关联实际发货，汇总实际发货数量
    COALESCE(SUM(sa.actual_quantity), 0) AS shipped_actual
FROM app_amz_bsr_purchase_order_sync_lingxing po
LEFT JOIN app_amz_bsr_shipment_plan_lingxing sp 
    ON po.order_sn = sp.purchase_order_sn 
    AND sp.status >= 5  -- 只统计待处理/已处理的发货计划
LEFT JOIN app_amz_bsr_shipment_actual_lingxing sa 
    ON sp.isp_id = sa.isp_id
WHERE po.order_sn = #{batchNo}
GROUP BY po.order_sn;
```

**判断逻辑**：
```javascript
const getShipmentStatus = (row) => {
    if (row.shipped_actual > 0) return { status: 'shipped', text: `已发货 ${row.shipped_actual}`, type: 'primary' };
    if (row.shipped_planned > 0) return { status: 'planned', text: `待发货 ${row.shipped_planned}`, type: 'warning' };
    if (row.good_num > 0) return { status: 'arrived', text: '已到仓', type: 'success' };
    if (row.good_transit_num > 0) return { status: 'in_transit', text: '在途', type: 'warning' };
    return { status: 'pending', text: '待入库', type: 'info' };
};
```

### 方案2：领星API同步发货计划数据

艾为系统有完整的同步Service：

```typescript
// src/modules/app/service/bsr_shipment_plan_lingxing.ts
async syncShipmentPlansFromLingxing(params: {
    order_sns?: string[];  // 按采购单号同步
    start_date?: string;   // 按日期范围同步
    end_date?: string;
}) {
    // ① 调用领星API获取发货计划列表
    const response = await this.lingxingClient.post('/erp/sc/routing/inventory/listShipmentPlan', {
        order_sns: params.order_sns,
        start_date: params.start_date,
        end_date: params.end_date
    });
    
    const plans = response.data.list;
    
    // ② 批量upsert到本地
    for (const plan of plans) {
        await this.shipmentPlanRepo.upsert({
            isp_id: plan.isp_id,
            seq: plan.seq,
            order_sn: plan.order_sn,
            sku: plan.sku,
            shipment_plan_quantity: plan.shipment_plan_quantity,
            status: plan.status,
            purchase_order_sn: plan.purchase_order_sn,  // 🔑 关联采购单
            last_sync_time: new Date()
        }, ['isp_id']);
    }
    
    return { synced: plans.length };
}
```

```java
public class LingxingInventoryBatchDetail {
    // ... 现有字段
    
    private Integer shipmentPlanQty;
    private Integer shipmentActualQty;
    private String shipmentStatus;
    
    // 暂时用推算
    public Integer getShipmentActualQty() {
        if (shipmentActualQty != null && shipmentActualQty > 0) {
            return shipmentActualQty;
        }
        // 推算：总数 - 可发 - 在途 = 已发
        int calculated = totalNum - goodNum - goodTransitNum;
        return Math.max(0, calculated);
    }
    
    public String getShipmentStatus() {
        if (shipmentStatus != null) return shipmentStatus;
        if (getShipmentActualQty() > 0) return "shipped";
        return "none";
    }
}
```

**2. 同步Service**（参考艾为的逻辑）：
```java
@Service
public class LingxingShipmentPlanService {
    
    public Map<String, Object> syncShipmentPlans(String startDate, String endDate) {
        // ① 调用领星API
        JsonNode response = lingxingClient.post("/erp/sc/routing/inventory/listShipmentPlan", 
            Map.of("start_date", startDate, "end_date", endDate));
        
        JsonNode list = response.path("data").path("list");
        int synced = 0;
        
        // ② 批量upsert
        for (JsonNode plan : list) {
            LingxingShipmentPlan entity = new LingxingShipmentPlan();
            entity.setIspId(plan.path("isp_id").asInt());
            entity.setSeq(plan.path("seq").asText());
            entity.setOrderSn(plan.path("order_sn").asText());
            entity.setSku(plan.path("sku").asText());
            entity.setShipmentPlanQuantity(plan.path("shipment_plan_quantity").asInt());
            entity.setStatus(plan.path("status").asInt());
            entity.setPurchaseOrderSn(plan.path("purchase_order_sn").asText());  // 🔑 关键
            entity.setSyncedAt(LocalDateTime.now());
            
            shipmentPlanMapper.upsert(entity);
            synced++;
        }
        
        return Map.of("synced", synced);
    }
}
```

**3. 查询时关联**：
```java
// Mapper
@Select("""
    SELECT 
        b.*,
        COALESCE(sp.total_plan_qty, 0) AS shipment_plan_qty,
        COALESCE(sa.total_actual_qty, 0) AS shipment_actual_qty
    FROM lingxing_inventory_batch_detail b
    LEFT JOIN (
        SELECT purchase_order_sn, SUM(shipment_plan_quantity) AS total_plan_qty
        FROM lingxing_shipment_plan
        WHERE status >= 5
        GROUP BY purchase_order_sn
    ) sp ON b.batch_no = sp.purchase_order_sn
    LEFT JOIN (
        SELECT sp.purchase_order_sn, SUM(sa.actual_quantity) AS total_actual_qty
        FROM lingxing_shipment_plan sp
        JOIN lingxing_shipment_actual sa ON sp.isp_id = sa.isp_id
        GROUP BY sp.purchase_order_sn
    ) sa ON b.batch_no = sa.purchase_order_sn
    WHERE b.data_date = #{dataDate}
""")
List<InventoryBatchDetailDTO> selectWithShipmentInfo(@Param("dataDate") String dataDate);
```
