# 到货情况看板开发计划

## 📋 项目概述

**目标**：开发一个到货情况看板，展示领星同步的批次到货明细数据

**核心需求**：
1. 主列表显示SKU基本信息
2. 点击SKU查看详情，展示该SKU的所有批次
3. 批次按运营人分组展示
4. 支持按开发人、运营人筛选
5. 批次支持多种状态（已到仓、在途、已发货、待入库）
6. 批次可按状态优先级和时间排序

### 4. "已发货"状态支持（中优先级）

**任务**：计算并显示"已发货"状态

**计算逻辑**：
```typescript
const getShippedQty = (batch) => {
    // 如果有显式的shippedNum字段，直接用
    if (batch.shippedNum !== undefined) return batch.shippedNum;
    // 否则通过差值推算：总数 - 可发货 - 在途 = 已发货
    return Math.max(0, batch.totalNum - batch.goodNum - batch.goodTransitNum);
};
```

**状态判断**：
```typescript
const getStatusText = (batch) => {
    const shipped = getShippedQty(batch);
    if (shipped > 0) return `已发货 ${shipped}`;  // 🔵 蓝色
    if (batch.goodNum > 0) return '已到仓';       // 🟢 绿色
    if (batch.goodTransitNum > 0) return '在途';   // 🟠 橙色
    return '待入库';                               // ⚪ 灰色
};
```

**修改文件**：`frontend/src/modules/lingxing-inventory-arrival/index.vue`

**排序函数**：
```typescript
const sortBatches = (batches) => {
    return [...batches].sort((a, b) => {
        // ① 先按状态优先级排序
        const priorityDiff = getStatusPriority(a) - getStatusPriority(b);
        if (priorityDiff !== 0) return priorityDiff;

        // ② 同状态内按时间排序
        const timeA = new Date(a.purchaseInTime).getTime();
        const timeB = new Date(b.purchaseInTime).getTime();
        return timeOrder === 'desc' ? timeB - timeA : timeA - timeB;
    });
};
```
