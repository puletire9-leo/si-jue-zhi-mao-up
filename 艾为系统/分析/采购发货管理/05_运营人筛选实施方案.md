## 🎯 实施方案

### 方案A：从采购计划表关联（推荐，精确）

#### 1. 数据关联逻辑（✅ 已确认表结构）

```sql
-- 批次明细表通过 plan_sn 关联采购计划表
SELECT 
    b.*,
    p.creator_real_name AS operator  -- 🔑 采购计划创建人 = 运营人
FROM lingxing_inventory_batch_detail b
LEFT JOIN lingxing_purchase_plan p 
    ON JSON_UNQUOTE(JSON_EXTRACT(b.plan_sn, '$[0]')) = p.plan_sn
WHERE b.data_date = '2026-08-12'
  AND b.developer = '刘淼'  -- 可选：开发人筛选
  AND p.creator_real_name = '李杉';  -- 可选：运营人筛选
```

**关键点**（已从文档确认）：
- **表名**：`lingxing_inventory_batch_detail`（批次明细），`lingxing_purchase_plan`（采购计划）
- **plan_sn字段**：JSON数组格式，如 `["PP260423142", "PP260615006"]`
- **提取方式**：`JSON_UNQUOTE(JSON_EXTRACT(plan_sn, '$[0]'))` 取第一个plan_sn
- **运营人字段**：`creator_real_name`（采购计划创建人 = 运营人）

**或者用 MyBatis-Plus 的方式**：

```java
@Service
public class LingxingInventoryBatchService {
    
    @Autowired
    private LingxingInventoryBatchMapper batchMapper;
    
    @Autowired
    private LingxingPurchasePlanMapper planMapper;
    
    public IPage<LingxingInventoryBatchDetail> pageWithOperator(
        int current, int size, String developer, String operator, String dataDate) {
        
        // 1. 先查批次明细
        IPage<LingxingInventoryBatchDetail> page = batchMapper.selectPage(
            new Page<>(current, size),
            new LambdaQueryWrapper<LingxingInventoryBatchDetail>()
                .eq(LingxingInventoryBatchDetail::getDataDate, LocalDate.parse(dataDate))
                .eq(developer != null, LingxingInventoryBatchDetail::getDeveloper, developer)
        );
        
        List<LingxingInventoryBatchDetail> records = page.getRecords();
        
        // 2. 批量提取 plan_sn（第一个）
        Map<String, String> batchToPlanMap = new HashMap<>();
        for (LingxingInventoryBatchDetail detail : records) {
            String planSnJson = detail.getPlanSn();
            if (planSnJson != null && planSnJson.startsWith("[")) {
                try {
                    JSONArray arr = new JSONArray(planSnJson);
                    if (arr.length() > 0) {
                        batchToPlanMap.put(detail.getBatchNo(), arr.getString(0));
                    }
                } catch (Exception ignored) {}
            }
        }
        
        // 3. 批量查采购计划的创建人
        Collection<String> planSns = batchToPlanMap.values();
        if (!planSns.isEmpty()) {
            List<LingxingPurchasePlan> plans = planMapper.selectList(
                new LambdaQueryWrapper<LingxingPurchasePlan>()
                    .in(LingxingPurchasePlan::getPlanSn, planSns)
                    .select(LingxingPurchasePlan::getPlanSn, 
                           LingxingPurchasePlan::getCreatorRealName)
            );
            
            Map<String, String> planToOperatorMap = plans.stream()
                .collect(Collectors.toMap(
                    LingxingPurchasePlan::getPlanSn, 
                    LingxingPurchasePlan::getCreatorRealName
                ));
            
            // 4. 回填 operator
            for (LingxingInventoryBatchDetail detail : records) {
                String planSn = batchToPlanMap.get(detail.getBatchNo());
                if (planSn != null) {
                    String operatorName = planToOperatorMap.get(planSn);
                    detail.setOperator(operatorName);
                }
            }
        }
        
        // 5. 如果有 operator 筛选，前端过滤（或重新分页查询）
        if (operator != null && !operator.isEmpty()) {
            records = records.stream()
                .filter(d -> operator.equals(d.getOperator()))
                .collect(Collectors.toList());
            // 注意：这会导致分页不准，建议改为SQL JOIN
        }
        
        page.setRecords(records);
        return page;
    }
}
```

### 方案B：从SKU统一表关联（备选，简单）

如果采购计划表数据不完整，可以从产品Listing统一表获取：

```sql
SELECT 
    b.*,
    l.creator_real_name AS operator  -- 产品创建人 = 运营人
FROM lingxing_inventory_batch_detail b
LEFT JOIN lingxing_product_listing l 
    ON b.sku = l.sku
WHERE b.data_date = '2026-08-12';
```

**优点**：关联简单，不需要解析JSON  
**缺点**：可能不够精确（产品创建人 ≠ 该批次的运营人）
