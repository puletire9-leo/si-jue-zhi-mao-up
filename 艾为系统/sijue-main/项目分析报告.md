# 思觉（sijue）跨境电商 Listing 优化与运营管理系统 —— 项目分析报告

> 生成日期：2026-06-30
> 分析范围：cool-admin-midway（后端）、cool-admin-vue（前端）、keyword-research-ms-go（微服务）

---

## 一、项目概述

### 1.1 项目定位

思觉（sijue）是一套面向亚马逊跨境电商卖家的**全链路运营中台系统**，覆盖从选品、采购、物流、Listing 优化、定价策略到补货管理的完整业务闭环。系统深度集成领星 ERP，并内嵌 AI 能力（LLM 文案生成、图像生成、竞品分析），目标是提升卖家在多站点、多店铺环境下的运营效率与决策质量。

### 1.2 核心能力矩阵

| 能力域 | 说明 |
|--------|------|
| **BSR 选品** | 基于亚马逊 BSR 榜单的自动化爬虫、候选产品筛选、采购计划生成 |
| **Listing 运营** | Listing 管理、AI 自动生成标题/五点/描述、A+ 内容素材管理 |
| **关键词研究** | 多维度关键词评分（图片相似度 + 文本匹配度）、搜索量分析、竞品关键词反查 |
| **竞品分析** | 竞品信息抓取、价格追踪、库存监控、历史趋势分析 |
| **定价自动化** | 新品/竞品/清仓/日常四种策略的实时定价规则引擎 |
| **供应链协同** | 采购订单、物流追踪、补货计划、FBA 货件管理 |
| **多店铺管理** | 支持 21 个亚马逊市场站点的店铺统一管理 |

## 五、Go 微服务详细说明

### 5.1 服务定位

`keyword-research-ms-go` 是独立于主后端的**关键词研究微服务**，负责处理计算密集型、异步型的关键词评分任务。

### 5.2 技术栈

| 技术 | 用途 |
|------|------|
| Gin | HTTP API 服务 |
| Asynq | Redis 任务队列（异步执行） |
| SQLite | 本地数据持久化 |
| Oxylabs API | 亚马逊页面爬虫 |
| 阿里云 ImageSearch | 商品图片相似度计算 |

### 5.3 服务拆分

| 组件 | 命令 | 说明 |
|------|------|------|
| API 服务 | `./cmd/api` | HTTP 接口，接收任务、查询结果 |
| Worker | `./cmd/worker` | 任务消费者，执行关键词评分 |

### 5.4 任务流程

```
1. 创建任务 -> POST /v1/tasks/keyword-research
2. 任务入队 -> Redis Asynq Queue
3. Worker 消费 -> 异步执行
4. 执行流程：
   a. score2 计算（关键词匹配度）
   b. score1 计算（图片相似度，需调用 Oxylabs + 阿里云搜图）
   c. keyword_type 分类
5. 查询结果 -> GET /v1/tasks/:taskId/results
```

### 5.5 缓存策略

| 缓存 Key | 说明 |
|----------|------|
| `oxysrp:{market}:{keywordNorm}:{page}` | Oxylabs 搜索结果缓存 |
| `imgsim:{market}:{targetKey}:{imgFingerprint}:{targetVersion}` | 图片相似度结果缓存 |

### 5.6 部署配置

- 端口：`8099`
- 数据库：`/app/data/keyword_research_go.db`（SQLite）
- 外部依赖（生产模式）：
  - `OXYLABS_API_URL`、`OXYLABS_USERNAME`、`OXYLABS_PASSWORD`
  - `IMAGESEARCH_ACCESS_KEY_ID`、`IMAGESEARCH_ACCESS_KEY_SECRET`
  - `IMAGESEARCH_ENDPOINT`、`IMAGESEARCH_REGION_ID`、`IMAGESEARCH_INSTANCE_NAME`

## 九、项目复杂度评估

### 9.1 规模指标

| 指标 | 数值 |
|------|------|
| 后端实体 | 120+ |
| 后端服务 | 70+ |
| 前端页面 | 60+ |
| Docker 服务 | 5 |
| 微服务 | 1（Go） |
| 支持站点 | 21 个 |
| AI Provider | 3 个 |
| 外部 API 依赖 | 6+ |

### 9.2 复杂度特征

1. **状态机密集**：BSR 候选（7+ 状态）、关键词（5 状态）、竞品（5+ 状态）、爬虫任务（多阶段）
2. **多系统集成**：领星 ERP、Oxylabs、阿里云 ImageSearch、SIF、SellerSprite
3. **异步任务繁重**：BullMQ + Asynq 双队列，处理爬虫、AI 生成、数据分析
4. **多语言/多市场**：21 个亚马逊站点，货币、汇率、重量单位、语言均需转换
5. **AI 原生**：LLM 不是附加功能，而是 Listing 生成、文案改写、竞品分析的核心生产力
6. **反爬对抗**：Cookie 池、代理轮换、请求频率控制、User-Agent 伪装

## 十、总结

思觉（sijue）是一个**成熟度高、业务闭环完整**的亚马逊跨境电商运营中台。其技术架构采用 **Node.js + Vue + Go 微服务** 的三层架构，通过深度集成领星 ERP 和多外部数据服务，实现了从选品、采购、物流到 Listing 优化、定价、补货的全链路数字化运营。系统内置的 AI 能力（多 LLM Provider 支持）使其在 Listing 内容生成和竞品分析方面具有显著的效率优势。

项目的核心复杂度集中在 **BSR 选品系统** 和 **供应链协同** 两大域，涉及复杂的状态机、审批流、多系统数据同步和异步任务调度。对于新接入的开发者，建议从 Listing 管理和关键词研究模块入手，逐步理解 BSR 选品的业务逻辑和数据流。
